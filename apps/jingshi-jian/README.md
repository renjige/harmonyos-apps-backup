# 静时笺

基于时间轴的生活记录与内心陪伴鸿蒙应用 — **纸间光阴，静时成笺**。

## DevEco 工程路径

```
apps/jingshi-jian/app/
```

用 DevEco Studio 打开上述 `app/` 目录（非上级 slug 目录），Sync 后编译运行。

## 上架图标路径

```
apps/jingshi-jian/store/logo/preview-1024.png
```

工程内同步副本：`apps/jingshi-jian/app/AppScope/resources/base/media/app_icon.png`

## 核心功能

| 模块 | 说明 |
|------|------|
| 时间轴·笺页 | 日/周/月视图，卡片式时间轴，FAB 写笺 |
| 写一笺 | 文字记录 + 6 种心情标签，本地自动草稿 |
| 心情统计 | 月度热力图、心情分布、连续记录天数 |
| 智慧笺语 | 本地模板陪伴短句（无「AI」字样），可收藏 |
| 我的空间 | 累计统计、收藏夹、导出、深色模式、隐私合规 |

## 数据与隐私

- **全部数据仅本地存储**，无网络权限，无账号登录
- 首次启动隐私同意 Overlay，可撤回
- 运营者：魏文波

## 品牌色

- 檀棕 `#8B6B4D` · 米白 `#F7F3EB` · 晨曦金 `#D4A55A`

## 上架自检

```
□ 时间轴 → 写笺 → 详情 → 收藏/删除 闭环
□ 心情页热力图与分布可刷新
□ 智慧笺语可收藏，文案无「AI」
□ 深色模式对比度可读
□ 导出纯文本可用
□ 撤回隐私同意有 Toast 反馈
```
