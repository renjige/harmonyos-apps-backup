# Logo Concept — 亲子智谜

- 公司 / App / 行业：魏文波 · 亲子智谜 · 亲子益智谜题
- 品牌关键词：Explore / Together / Wonder / Calm / Clarity
- 核心元素（仅 2）：圆润星球 + 谜盒缺口（两点星轨为附属，不另算第三主体）
- brandAnchor：谜（语义融合进星球谜盒，不写汉字、不画人物肖像）
- 禁止项自检：无父母儿童写实肖像、无机器人老师、无彩虹渐变球、无 AI 大脑、无问号文字堆砌
- 色板：2 色 — 深星空蓝 `#1E3A6E` + 白色 `#FFFFFF`
- 对比策略：App Icon 深底白标；灰度后星球与盒盖轮廓仍清晰
- 行业模板 vs 本稿：
  1. 非童趣算坊的数字/算盘珠
  2. 非家庭备忘的勾选清单
  3. 非教育类书包/铅笔卡通
