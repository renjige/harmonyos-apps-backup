# Logo Concept — 约定提醒

- 公司 / App：魏文波 · 约定提醒
- 行业：task-efficiency / 时间约定管理
- brandAnchor：**约**（App 名首字语义：约定、守约）
- 品牌关键词：Time · Promise · Reliable · Minimal · Precision
- 核心元素（2 个）：**时间圆环** + **勾选符号**（负空间或叠加，非闹钟）
- 对比策略：深海军底 `#0A2540` + 白色圆环与勾选 + 点缀 `#1677FF` 弧段
- 禁止：闹钟卡通、红色警告、打卡风、渐变球、AI 模板图形
- 与行业模板差异：非 house/doc 图标；几何时间环表达「守约完成」
