# 约定提醒 — 差异化说明

1. **工作台而非模板墙**：首页是下一件倒计时 + 今日时间线 + 冲突/空档，模板只是入口之一。
2. **Tab 结构**：首页/约定/日历/我的（4 Tab），无 AI/看板/消息 Tab，文案不用「AI」。
3. **核心实体**：AppointmentItem（约定）含场景、时长、准备清单、置顶、跟进。
4. **主闭环**：创建 → 冲突检测 → 智慧提醒 → 会前准备 → 改期/完成跟进。
5. **智能整理**：8 题规则报告 + 一键创建对应约定，不是聊天生成。
6. **模板**：8 个生活场景独立摄影封面，禁止共图。
7. **HarmonyOS**：桌面卡片 + Agent 提醒。
8. **准入**：open_optional，游客可本机守约，登录后同步。
