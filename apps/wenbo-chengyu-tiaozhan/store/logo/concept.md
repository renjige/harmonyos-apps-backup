# Logo Concept — 成语挑战

- 公司 / App / 行业：魏文波 · 成语挑战 · 成语竞技
- 品牌关键词：Seal / Ink / Challenge / Clarity / Heritage
- 核心元素（仅 2）：方印外框 + 几何「成」字笔画（戈形斜笔 + 横）
- brandAnchor：成（成语挑战首字，几何化进方印，不写实毛笔）
- 禁止项自检：无写实毛笔「成语」二字、无战鼓/竹简插画、无渐变球、无 AI 大脑、无第三色
- 色板：2 色 — 墨黑底 `#1A1A1A` + 朱砂标 `#E84A4A`
- 对比策略：App Icon 深底朱红标；转灰度后印框与「成」的横、斜笔仍可辨
- 行业模板 vs 本稿：
  1. 非亲子智谜的星球谜盒
  2. 非口算闯关的数字/星星
  3. 非教育类书包/铅笔卡通
