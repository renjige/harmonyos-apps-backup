# 成语挑战 差异化

当前 App 名称：**成语挑战**

相对仓库内已有产品（亲子智谜、口算闯关、轻知阁等）的硬差异：

| 维度 | 成语挑战 | 避免撞车的对象 |
|------|----------|----------------|
| 主任务 | 一关精研一个成语五题；每日五题 15 秒连击 | 亲子谜题对答、口算键盘、知识卡片流 |
| 视觉 | 墨韵现代 + 朱砂印 + 宣纸摄影 | 儿童卡通、星空蓝、咨询顾问蓝 |
| Logo | 几何「成」字方印 | 渐变球 / 通用书本 |
| 题型 | 释义 / 填空 / 出典 / 用法 / 反义 | 算术、亲子默契百分比 |
| 推荐 | 本机错题主题规则排序，文案用「智慧」 | 不出现 AI 字样、不走 /ai/chat |

禁止换皮：不得复用亲子智谜的家庭对答、口算闯关的数字键盘、咨询类顾问预约。
