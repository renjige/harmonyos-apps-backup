# 差异化说明 · 露营课堂

相对仓库内 **露营玩家**（`wenbo-luying-wanjia`）及旅行类产品，本 App 是 **户外教育学习工作台**，不是装备称重或营地发现换皮。

| 维度 | 露营课堂 | 露营玩家 / 对照 |
|------|----------|-----------------|
| 主任务 | 系统学习露营知识 → 管理装备 → 规划行程 → 社区分享 | 称装备克重 → 发现营地 → 写日记 |
| 首页 | 学习进度 + 勋章 + 课程筛选 + 今日推荐横滑 | 天气 + 规划行程 + 装备模板 |
| Tab 架构 | **4 Tab**：首页 / 社区 / 行程 / 我的 | 5 Tab：首页 / 装备 / 发现 / 记录 / 我的 |
| 独特能力 | 标记已学、学习进度%、入门/进阶筛选、智慧匹配问卷 | 克重统计、营地设施档案 |
| 社区 | 独立 Tab，公开笔记流 | 攻略发布在「记录/我的」 |
| 品牌色 | 森林绿 #16A34A + 暖阳橙 #FB923C + 米白 #FAFAF5 | 深绿 #2D5A27 + 营火橙 |
| Logo | 帐篷 + 翻开书本（教育意象） | 单一帐篷门洞 |
| 文案 | 「在大自然里，把露营学扎实」 | 「称完装备再出发」 |
| 隐私 | 协议勾选在登录页；无独立隐私首屏 | 同工厂规范 |
| 无 AI 字样 | FeatureFlags.LLM_ENABLED=false；「智慧匹配」问卷 | 同 |

禁止换皮：不得把露营玩家的五 Tab 营地发现结构改几个字出货。
