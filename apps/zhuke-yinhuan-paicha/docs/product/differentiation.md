# 与「筑科质量巡查」的差异

| | 筑科隐患排查 | 筑科质量巡查 |
|---|---|---|
| 主任务 | 安全隐患发现、整改、复查闭环 | 施工质量巡查与问题跟踪 |
| 品牌色 | 海军蓝 #16324F + 工程橙 #F28C28 | 蓝色质量标 |
| Logo | 楼体结构 + 安全勾 | Z 字质量标 |
| Tab | 首页 / 隐患 / 检查 / 我的 | 首页 / 巡查 / 问题 / 我的 |
| 类别 | 临边、高处、用电、消防、机械、脚手架、文明施工 | 质量检查项 |
| 风险语义 | 低 / 中 / 高风险 | 质量问题等级 |

两款同属筑科建筑工程现场工具，但闭环对象不同：本 App 不提供质量验收表格，质量巡查 App 不提供安全隐患复查闭环。
