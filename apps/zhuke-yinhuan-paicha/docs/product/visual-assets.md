# 影像资产

应用内封面均来自 `app/entry/src/main/resources/base/media/`：

- `hero_site.png` 首页 Hero / 默认封面
- `banner_edge.png` 临边防护、脚手架
- `cover_electric.png` 用电安全
- `cover_fire.png` 消防安全
- `cover_height.png` 高处作业
- `cover_civil.png` 文明施工
- `empty_site.png` 空态插图（可选）

功能图标走 HarmonyOS Symbol（`AppIcon`）。启动图标见 `store/logo/`（盾牌感楼体 + 工程橙勾，非质量巡查 Z 标）。
