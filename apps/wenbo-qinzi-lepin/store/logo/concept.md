# Logo Concept — 亲子乐拼

- 公司 / App / 行业：魏文波 · 亲子乐拼 · 亲子拼图教育
- 品牌关键词：Together / Nest / Warmth / Play / Clarity
- 核心元素（仅 2）：两枚圆角拼图块相互嵌合（左凸榫 + 右凹口）
- brandAnchor：乐（嵌合完成时的快乐，不写汉字、不画人物）
- 禁止项自检：无儿童肖像、无机器人、无彩虹渐变球、无灯泡、无星球谜盒（亲子智谜）
- 色板：2 色 — 深木棕 `#5C2E12` + 暖白 `#FFFCF6`（横版字同深棕）
- 对比策略：App Icon 深底白标；灰度后两块轮廓与榫卯仍清晰
- 行业模板 vs 本稿：
  1. 非亲子智谜的星球 + 谜盒
  2. 非童趣算坊的数字 / 算盘珠
  3. 非教育类书包、铅笔、卡通笑脸堆砌
