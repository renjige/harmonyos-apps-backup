# 活力纪行

轻量级**每日活力记录与回顾**鸿蒙应用 — 3 秒记录运动、心情、精力，可视化看见成长轨迹。

## 核心功能

| Tab | 功能 |
|-----|------|
| 今日 | 三维打卡、修改记录、规则活力处方（可勾完成）、高光日 |
| 回顾 | 周/月图、两周对比、本周纪行、足迹详情（编辑/删除） |
| 成就 | 8 项徽章（含处方/高光/周纪行）+ 上月摘要 |
| 我的 | 昵称、提醒、导出、主题、隐私 |

针对华为 50104-3.5：不是纯展示、不是单页、不是系统健康套壳。闭环为「记录 → 做处方 → 回顾编辑删除 → 写周纪行」。

## 数据与合规

- 纯本地存储（Preferences），无网络权限
- 首次启动隐私同意弹窗（勾选协议后进入）
- 无 AI、无支付
- 运营者：魏文波

## 验收步骤（给审核员 3 分钟）

1. 勾选协议 → 今日页选三维 →「记录今日活力」
2. 在「今日活力处方」点完成至少 1 条；可点「修改今日记录」「收藏高光日」
3. 回顾 → 点趋势柱或足迹进入详情 → 编辑保存 / 删除有二次确认
4. 回顾 → 写下「本周纪行」并保存；查看本周 vs 上周对比
5. 成就 → 可见初出茅庐 / 行动派 / 高光等解锁
6. 我的 → 导出文本、提醒、撤回隐私
