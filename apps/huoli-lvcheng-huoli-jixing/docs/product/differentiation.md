# 活力纪行 · 差异化说明（50104-3.5）

## 不是什么

- 不是系统健康 App：不读穿戴、不采步数心率
- 不是单一打卡页：有处方执行、足迹详情编辑删除、周纪行
- 不是信息流 / 攻略 / Web 套壳：全部 ArkUI 原生，数据仅本机
- 不是计算器/手电筒类系统简易功能

## 实质功能闭环（审核员 3 分钟）

```text
今日：三维记录 → 生成 3 条活力处方 → 勾完成（即时点亮）
     → 本周打卡目标进度条
     → 60 秒盒式呼吸练习
     → 可修改记录 / 收藏高光日
回顾：本月打卡统计实时同步
     → 活力洞察（维度分析 + 建议）
     → 点趋势柱或足迹 → 详情（封面+正文+CTA）
     → 编辑保存 / 删除确认 / 勾处方
     → 写本周纪行一句并保存
     → 看见本周 vs 上周均分变化
成就：处方、高光、周纪行会解锁对应徽章
我的：导出文本、每日提醒（含发布提醒权限）、协议全文、撤回隐私
```

## 隐私合规

- 首次启动隐私弹窗由 **华为平台隐私托管服务** 统一展示，App 内不再重复弹出
- 《用户协议》《隐私政策》可在「我的 → 设置与隐私」随时查看

## 创意点

「纪行」= 主观三维快记 + 规则处方（立刻可做）+ 足迹高光（可回看编辑）。
处方按运动/心情/精力组合用本地规则生成，不调用大模型。
