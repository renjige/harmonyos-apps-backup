# 知行页差异化

对照 avoidSlugs：慧忆册、学知小筑、知识寻宝、读书札语、智行日记、灵感备忘

1. 主实体是「知识卡片 + 学习计划」双对象，不是单一记忆条或闯关地图  
2. 首页是摄影 Hero + 四入口 + 双列卡片流（catalog-tool），不是记录列表或路径大卡  
3. 第二 Tab 是行录环形进度 + 计划时间线 + 习惯打卡，不是相册/画板  
4. 第三 Tab 是检索/提醒/统计/规则推荐 + 学情自检，不是对话页  
5. 知识图谱按标签云关联，不是日历首页  
6. 品牌：深蓝 #2D3B66 + 暖金 #C9A84C + 书页路径 Logo，与慧忆册蓝琥珀、灵感备忘黄橙便签区分  
7. 文案全程不用生成式对话卖点  
8. 游客可本机写；新用户列表为空
