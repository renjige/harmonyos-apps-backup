# 知行页 · 华为审核说明（AGC 版本信息可粘贴）

## 产品定位（3.5 / 3.7）

知行页是 **知→行闭环学习工具**（非简单记事本/计算器类 App）：

- **知库**：知识卡片、笔记、摘要、收藏、专题检索、继续阅读
- **行录**：计划模板 + 子任务、习惯打卡、行动日志、成长时间轴
- **智慧**：本周三维目标、复习队列、专注计时、统计仪表盘、成就墙、到点提醒
- **闭环**：写卡片 → 转入计划 → 子任务打卡 → 复习队列巩固 → 专注计时写日志 → 成就/导出

## 建议审核演示路径（3.5 实质价值 · 约 3 分钟）

1. **知库** → 新建知识卡片（或打开已有卡片）→ **转入学习计划**
2. **行录** → 新建计划时选 **21 天阅读/技能攻坚模板** → 勾选子任务 → 习惯打卡
3. **智慧** → **本周学习目标**（知识/打卡/复习进度）→ **复习队列** 完成一条 → **专注学习** 25 分钟（结束自动写行动日志）
4. **智慧** → 成长仪表盘 / 成就墙 / 时间轴查看联动数据
5. **我的** → 导出 JSON（系统保存对话框 + 剪贴板备份）

以上模块均有完整二级页与可执行动作，非单一记录列表。

## 问题 1：智能提醒打开失败

**已修复。** 开关独立状态 + 失败不误报「已关闭」；日历型每日提醒优先。

## 问题 2：功能偏简单（3.5）

**已升级为完整学习闭环（非堆按钮）：**

| 模块 | 能力 |
|---|---|
| 首页工作台 | 今日进度、本周三维目标、待复习入口、专注快捷入口 |
| 复习队列 | 7 天未更新知识逐条复习，计入本周目标 |
| 专注学习 | 15/25/45 分钟本地倒计时，结束写入行动日志 |
| 本周目标 | 知识/打卡/复习目标可调整，自动累计进度 |
| 计划模板 | 21 天阅读 / 技能攻坚 / 习惯计划，含预设子任务 |
| 已有能力 | 收藏、搜索、时间轴、成就墙、成长仪表盘、周/月回顾 |

## 问题 3：计划重新打开 / 导出

- 重新打开：进度与子任务均重置
- 导出：系统保存对话框 + 剪贴板备份
