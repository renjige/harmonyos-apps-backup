# Logo Concept — 知行页

- 公司 / App / 行业：魏文波 · 知行页 · know-act（知识卡片 × 行动闭环）
- 品牌关键词：Knowledge / Path / Unity / Editorial / Practice
- brandAnchor：知（首字；以翻开书页表达「知」，以向上路径表达「行」，二者在书脊处会合）
- 核心元素（仅 2 个）：翻开的双页书 + 自书脊向上延伸的路径
- glyphStrategy：semantic-fusion
- 禁止项自检：无大脑、无机器人、无灯泡、无渐变球、无发光、无毛玻璃、无 3D、无 house 模板、无系统备忘录回形针
- 色板：深蓝底 `#1A2A6C` + 暖金路径 `#C9A84C`；书页米白 `#F4EBD0`（书页为同一「知」元素的左右两面，不算第三主体）
- 对比策略：App Icon 用「深邃蓝底 + 浅金路径/米白书页」，灰度后书页轮廓与向上路径仍清晰；禁止蓝叠蓝
- 行业模板对比：
  1. 非慧忆册「重叠书页弧线 + 琥珀圆点」
  2. 非学知小筑路径课时大卡风格标
  3. 非知识寻宝地图/徽章闯关标
  4. 非智行日记旅行轨迹标
