# 晨雾计划 · 差异化说明

对比参考 App：`wenbo-chengzhang-shouce`（成长手册）、`qiguang-zha`（栖光札）、`xiaobu-xiangqian`（小步向前）

| # | 差异点 |
|---|--------|
| 1 | **纯本地零权限**，无 INTERNET / 登录 / SaaS 平台依赖 |
| 2 | **阶段计划树**（Plan→Phase→Task），非扁平待办或日记流 |
| 3 | **阶段复盘**为独立三级表单（收获/问题/下一步），绑定 Phase 完成 |
| 4 | Tab 命名与 IA：**晨雾｜计划｜成长｜回顾｜我的**（非成长空间/札记/主题） |
| 5 | **晨雾蓝 #5B8FA8 + 晨光金** 美学，Logo 为太阳弧+雾线（非成长绿/栖光札册） |
| 6 | **智慧整理**为本地规则引擎，禁止 AI 对话与 LLM |
| 7 | 习惯记录强调**心得与变化**字段，非早起打卡墙 |
| 8 | 内置 **4 套计划模板**（阅读/学习/整理/兴趣）一键生成阶段结构 |

## 主闭环

设定目标 → 制定计划 → 执行记录 → 阶段复盘 → 成长档案

## 影像差异

晨雾湖面 Hero、雾中路径 Banner、分类目标封面摄影（非通用窗口光/札纸）
