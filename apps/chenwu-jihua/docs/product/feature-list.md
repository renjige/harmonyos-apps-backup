# 晨雾计划 · 功能清单

## 核心闭环

| 功能 | 状态 | 说明 |
|------|------|------|
| 晨雾空间首页 | ✅ | 今日完成率、档案数字、快捷入口、智慧回望 |
| 目标档案 | ✅ | 五分类目标 CRUD + 详情 Hero + CTA |
| 成长计划 | ✅ | 长期/阶段/短期计划 + 阶段任务 + 模板创建 |
| 阶段复盘 | ✅ | 收获/问题/下一步三级表单 |
| 习惯记录 | ✅ | 行为记录含心得与变化 |
| 成长日志 | ✅ | 今日完成/发现/明天调整 |
| 成长时间轴 | ✅ | 回顾 Tab 聚合事件流 |
| 智慧整理 | ✅ | 规则提醒（无 AI） |
| 年度成长报告 | ✅ | 本机统计报告 |
| 成就系统 | ✅ | 徽章墙规则解锁 |
| 全局搜索 | ✅ | 计划/目标/日志/日期 |
| 隐私合规 | ✅ | 首启同意、设置撤回、清除缓存、导出 JSON |

## Tab

晨雾 | 计划 | 成长 | 回顾 | 我的

## 权限

零系统权限 · 纯本地 Preferences

## 验收步骤

1. 首启勾选协议进入晨雾空间
2. 计划 Tab → 用模板创建 30 天阅读计划
3. 打开计划详情 → 勾选阶段任务 → 完成阶段 → 写复盘
4. 成长 Tab → 添加习惯并记录
5. 回顾 Tab → 查看时间轴与年度报告
6. 我的 → 成就墙 / 智慧整理 / 导出 / 撤回隐私
