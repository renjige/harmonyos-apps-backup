# Logo Concept — 脑力探秘

- 公司 / App / 行业：魏文波 / 脑力探秘 / 认知训练（非医疗）
- 品牌关键词：Explore / Insight / Path / Discovery / Signal
- brandAnchor：探
- 核心元素（2）：几何菱形罗盘（探路）+ 北端金色探点（发现）
- 禁止项自检：无解剖大脑、无放大镜叠脑、无渐变球、无发光、无火箭/灯泡/六边形科技套
- 行业模板对比：
  1. 不是医疗脑切片 icon
  2. 不是成语朱砂方印
  3. 不是儿童卡通星球
- 色板：深底 #0A1628 + 金标 #F5A623（仅 2 色）
- 对比策略：近黑底 + 高明度金标，灰度后轮廓仍是菱形+圆点
