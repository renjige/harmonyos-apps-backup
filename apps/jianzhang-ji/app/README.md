# 简章集 — DevEco 工程

当前 App 名称：**简章集**

北京简章集科技有限公司 · HarmonyOS NEXT 客户端

## 打开方式

DevEco Studio 打开本目录（`apps/jianzhang-ji/app/`），Sync → Build → Run。

## 核心功能

- 首页：搜索、层次/类型筛选、简章列表、招生资讯
- 收藏：本地 + 登录云端同步
- 对比：2–4 所院校并列对比
- 我的：统计、浏览历史、关注院校、消息、设置与隐私
