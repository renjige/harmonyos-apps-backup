# Logo Concept — 出行备忘

- 公司 / App / 行业：魏文波 / 出行备忘 / 智慧出行效率工具
- 品牌锚点：取“行”的行动与路线含义，不使用通用飞机图标
- 品牌关键词：Route / Clarity / Prepared / Mobile / Trust
- 核心元素：备忘卡片轮廓 + 延伸为定位点的连续路线
- 构图：卡片留出开放右上角，路线从卡片内部延伸至定位点，表达“记录计划后出发抵达”
- 色板：深海蓝 `#082A5A`、智慧蓝 `#1677FF`、白色作为反白稿
- 对比策略：App Icon 采用深海蓝底与白色主体，智慧蓝仅作小面积状态点；主体与背景保持高明度差
- 行业模板对比：不使用飞机、地球或地图库存图标；路线与卡片共用一条几何语言；24px 下仍可识别卡片与定位点
- 禁止项自检：无渐变球、无发光、无玻璃、无 3D、无投影、无机器人/灯泡/火箭/六边形套模板
