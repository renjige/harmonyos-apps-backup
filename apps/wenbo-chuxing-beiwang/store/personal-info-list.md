# 个人信息收集清单

应用名称：出行备忘  
开发者 / 运营者：魏文波

| 信息类型 | 具体字段 | 使用场景 | 是否必需 |
|---|---|---|---|
| 账号信息 | 账号、密码 | 注册、登录与身份校验 | 是（登录用户） |
| 注册资料 | 姓名、联系电话 | 账号资料与用户服务 | 是（注册时） |
| 可选注册信息 | 邀请码 | 注册来源识别 | 否 |
| 行程信息 | 标题、目的地、开始/结束日期、摘要 | 创建与展示旅行计划 | 否，用户主动创建 |
| 每日安排 | 日期、时间、地点、事项、备注 | 行程时间轴 | 否，用户主动创建 |
| 清单信息 | 分类、事项、完成状态 | 出行准备管理 | 否，用户主动创建 |
| 提醒信息 | 类型、提醒时间、关联行程 | 出发、入住和自定义提醒 | 否，用户主动创建 |
| 备忘信息 | 标题、正文、关联行程 | 保存旅行备忘 | 否，用户主动创建 |
| 本地状态 | 登录会话、协议同意状态 | 自动登录与隐私合规 | 是（使用对应功能时） |

应用不收集定位、相机、通讯录、麦克风、支付信息或社交关系。游客浏览公开模板时不收集上述注册和个人业务信息。
