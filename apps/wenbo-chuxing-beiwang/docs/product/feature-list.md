# 功能清单 · v1.1.0

- 首页工作台：出行进度卡、4 维数据摘要、准备打卡、最近动态、全局搜索入口、出行成长入口
- 行程：目的地与日期、每日安排、时间轴、准备进度、导入清单、创建提醒、编辑/删除
- 准备中心：清单/提醒/备忘三分栏、准备度实时刷新、CRUD
- 攻略：模板+贴士、分类筛选、关键词搜索、收藏
- 全局搜索：行程/清单/备忘/模板/贴士统一检索
- 出行成长：统计、8 项成就徽章、收藏夹、出行动态、已结束行程回顾
- 准备打卡：出发前每日打卡（平台 habit-logs）、连续天数统计
- 我的：个人数据摘要、搜索/成长入口、设置与隐私
- 账号：游客浏览、账号密码注册登录、会话持久化、注销
