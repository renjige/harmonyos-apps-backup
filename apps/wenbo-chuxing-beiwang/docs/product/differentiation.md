# 出行备忘差异化说明

## 产品主任务

- 核心对象：个人旅行计划
- 主闭环：创建行程 → 添加每日安排 → 准备清单 → 设置提醒 → 完成出行
- 打开前三秒主任务：查看最近行程与准备进度
- 工作台：`timeline-board`
- 布局变体：`A`

## 与通用效率应用的差异

1. 首页以大尺寸旅行摄影行程卡为视觉中心，不使用三列 KPI 或通用快捷宫格。
2. 核心实体是目的地、旅行日期和每日安排，非普通待办的标题与截止时间。
3. 详情页按旅行日分组展示时间轴，并提供“添加安排”主操作。
4. 清单固定证件、衣物、设备、用品四类，完成进度与所选行程关联。
5. 提醒区分出发、入住和自定义三种业务语义，不是通用消息列表。
6. 备忘记录围绕行程关联，支持从首页快速进入。
7. 影像采用城市蓝色时刻、整理出行物品和路线规划三种独立场景。
8. Logo 将备忘卡片的开放边缘延伸为定位点，不使用飞机、地球或普通待办勾选。
9. 不提供支付、票务交易或复杂社交能力，审核边界明确。
10. 游客可浏览模板与功能说明，写操作才进入账号密码登录与注册。

## 结构指纹自检

- 无 SearchPill
- 无三列等宽 KPI
- 无同构 ShortcutGrid 作为首屏主体
- 无实色智能横幅
- 首页真实内容影像不少于两处引用
- Tab、字段、CTA 和空态均使用出行领域文案
