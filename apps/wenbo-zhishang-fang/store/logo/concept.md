# Logo Concept — 纸上方

- 公司 / App / 行业：魏文波 · 纸上方 · paper-excerpt
- 品牌关键词：Paper / Lift / Wisdom / Ink / Settle
- brandAnchor：纸（首字；以上扬纸页负空间暗示「从纸页提取智慧」，不写汉字）
- 核心元素（仅 2 个）：30° 上扬的单页纸张 + 一枚智慧金点
- glyphStrategy：semantic-fusion
- 禁止项自检：无大脑、无机器人、无灯泡、无渐变球、无发光、无毛玻璃、无 3D、无 house 模板、无打开的书本库存 icon
- 色板：墨蓝底 `#2C3E6B` + 米白纸页 `#F5F0E8`；点缀金 `#D4A84B`（第三色仅作 1 枚圆点）
- 对比策略：App Icon 用「深墨蓝底 + 浅纸页标」，灰度后上扬纸角与金点仍清晰；禁止蓝叠蓝
- 行业模板对比：
  1. 非读书札语五 Tab 书架标
  2. 非慧忆册书页涟漪+琥珀
  3. 非轻知阁知识库几何标
