# 差异化 — 纸上方

对照 avoidSlugs：`wenbo-dushu-zhayu`、`huiyi-ce`、`wenbo-qingzhige`

1. **主实体是书摘 BookNote**，不是书架书籍、不是通用记忆、不是轻知条目：字段含书名、页码、原文、感悟、封面。
2. **三 Tab：书房 / 添加 / 智慧回顾**，添加是独立一级 Tab 而非 FAB；设置从书房齿轮进入。
3. **工作台 catalog-tool + 布局 A**：首屏 Hero 翻开纸书 + 书名搜索 + 圆角 12 书摘卡片。
4. **智慧分类**为本地规则（文学/哲学/商业/科技/历史/心理），界面禁止「AI」字样。
5. **今日智慧**从收藏稳定按日抽取；**抽卡回顾**先藏出处再回想，按掌握次数优先抽薄弱卡片。
6. **本月阅读报告**：新增摘录数、复习次数、阅读目标进度；**摘录时间线**按日期串联最近书摘。
7. **书籍档案**：按书筛选后展示摘录数、收藏数、主分类、阅读跨度，可一键复制该书书摘合集。
8. **标签云**按频次缩放，点击筛选；书房支持摘录/感悟全文检索；编辑智慧分类后详情/列表即时刷新。
9. **影像**：墨蓝纸页摄影（hero_library / banner_today / empty_desk / paper_texture），非慧忆册书桌笔记本、非读书札语荐书横滑。
10. **品牌**：上扬纸页 + 金点，主色 #2C3E6B，禁止换皮蓝 KPI 宫格。
11. **导出 CSV**（书籍/页码/摘录/感悟/标签），非 txt 记忆导出。
