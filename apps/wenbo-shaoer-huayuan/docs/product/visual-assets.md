# 少儿画苑 视觉资产

当前 App 名称：**少儿画苑**

暖纸、木廊、儿童画作静物摄影。禁止卡通吉祥物、禁止色块冒充封面。不同 `coverKey` 对应独立 PNG，文件体积互不相同。

| Key | 用途 | 文件 |
|-----|------|------|
| hero_gallery | 首页 Hero | `app/entry/src/main/resources/base/media/hero_gallery.png` |
| banner_timeline | 策展问卷 / 时间氛围 | `banner_timeline.png` |
| banner_share | 画册页横图 | `banner_share.png` |
| empty_easel | 空态画架 | `empty_easel.png` |
| theme_* | 六套策展主题封面 | 水彩 / 涂鸦 / 家人 / 人物 / 四季 / 动物 |
| hall_* | 四套展厅 | 暖木 / 白墙 / 窗边 / 夜间 |
| ms_* | 里程碑 | 握笔 / 圆形 / 人物 / 水彩 / 签名 / 故事 |
| guide_* | 珍藏指南 | 拍照 / 故事 / 画册 / 小展 / 多孩工位 |

上架图标：`store/logo/preview-1024.png`（深底米白画笔+幼苗）。
