# 童趣算坊 · 丰富度升级方案（1.0.5）

## 1. 产品重新定位

童趣算坊不是「四则运算生成器」，而是**亲子口算学习工作台**：孩子练、家长出题、错题沉淀、按周盯目标、能回头看自己的练习史。

保留：本机出题、温和反馈、无广告支付、不承诺提分、不新申请权限。

## 2. 当前问题

| 项 | 现状 |
|---|---|
| 定位 | 儿童口算 / 数学学习辅助 |
| 已有 | 挑战、热身、口诀表、闯关、错题、收藏、七日计划、勋章、周报 |
| 页面 | 首页 / 练习 / 成长 / 我的 + 答题 Overlay |
| 底栏 | 4 Tab，保留（不机械加第 5 个） |
| 数据 | session / wrong / favorite / settings，几乎全是引擎生成题 |
| 跳转 | 首页卡片 → 答题；练习列表 → 详情 → 答题；成长多为只读卡片 |
| 重复 | 成长页「周报」入口出现两次；首页快捷与任务有重叠 |
| 空旷 | 成长页信息以短文案卡片为主；练习页长列表同构 |
| 一层详情 | 题型详情后只有「开始练习」，没有用户自己的题单/备注 |
| 结构 | 偏「预置目录 + 生成题」，缺少用户创造内容 |
| Demo 感 | 审核仍可能看成简易运算练习 |
| 持续使用 | 主要靠每日挑战；家长无法留下「自己出的题」 |

## 3. 新增功能（均有真实数据闭环）

1. **家长出题**：录入 `7+8`、`12−5` 等，生成「我的题单」，孩子按该单练习  
2. **练习专题**：自建题单（勾选加法/减法/口诀等），一键开练  
3. **本周目标**：30/50/80/100 题，进度来自本周真实作答  
4. **学习打卡**：练完自动记一天；可补一句家长备注  
5. **练习时间轴**：按日串起挑战 / 打卡 / 出题 / 口诀  
6. **今日/本周/本月回顾**：文案来自真实 session，可复制  
7. **收藏标签**：口算 / 应用题 / 口诀 / 数感，可筛选  
8. **错题备注**：给错题写一句提醒  
9. **练习页筛选**：年龄 / 趣味 / 基础 / 数感 / 生活  
10. **首页工作台**：进度、四数据、出题/打卡/回顾、最近一组  
11. **成就**：出题、收藏 10 题、打卡 7 天、连续 30 天  

## 4. 页面结构

```
首页工作台 → 今日挑战 / 口诀 / 出题 / 打卡 / 回顾
练习中心 → 筛选 → 题型详情 → 答题
         → 我的题单 / 家长出题 → 编辑 → 按单练习
成长 → 本周目标 → 时间轴详情 → 回顾全文 → 勋章详情
我的 → 设置（含周目标）/ 协议
答题 Overlay（保留）→ 收藏 / 错题写入
```

底栏仍为：**首页｜练习｜成长｜我的**

## 5. 数据模型（本机 Preferences）

- `CustomSet` / `CustomExpr`：家长出题  
- `StudyPack`：专题（modes 逗号串）  
- `DayCheckIn`：日期 + 备注 + source  
- `MathSettings.weekGoal`  
- `WrongItem.tag` / `WrongItem.note`  
- `LocalBundle.recentModes`  
- 时间轴由 session + checkin + customSet 派生，不另存一份假数据  

## 6. 首页布局

欢迎 + 年龄 → 今日挑战大卡（进度条）→ 四数据 → 今日任务 → 出题/打卡/题单/时间轴 → 最近一组 → 口诀/收藏/闯关  

## 7. UI

沿用书桌摄影、蓝金、大数字键盘。新页用同一套卡片与空态，不新增五彩宫格、不申请新权限。

## 8. 用户闭环

浏览题型 → 练习 → 收藏/错题 → 家长出题或专题再练 → 打卡与周目标前进 → 时间轴/回顾看见自己的数据 → 勋章解锁  

## 9. 华为 3.5

不是资讯聚合或套壳。出题、目标、打卡、时间轴都服务「把口算练下去」，且必须真的改本机数据。

## 10. 明确不做

第 5 个 Tab、相机/定位、云端儿童练习单据、AI 对话、支付、提分承诺、空按钮。
