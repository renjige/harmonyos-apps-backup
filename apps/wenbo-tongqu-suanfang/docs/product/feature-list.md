- 首页：今日任务板、今日挑战进度、本周目标、学习工作台（出题 / 题单 / 打卡 / 时间轴）、四数据、最近练习、热身、应用题、口诀表、收藏、趣味数学、学习回顾、闯关、七日计划、薄弱点
