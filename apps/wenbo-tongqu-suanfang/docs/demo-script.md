# 演示脚本

1. 欢迎页点「开始体验」。
2. 首页先看「今日任务」三项；点「开始计算」完成一组今日挑战；返回后确认「今日星星 / 累计星星」立即变化。
3. 设置今日挑战为 10/15/20 题，做到单双数：题干是「N 是什么数？」，选项为「N 是单数 / N 是双数」，与题干一致。
4. 任意练习中点「收藏本题」，下一题立即变为「收藏本题」（除非那一题本来已收藏）。
5. 打开「九九口诀表」，点「7 的口诀」专练一行。
6. 练习页搜索「单双数」；打开知识卡片；按顺序打闯关（数字认知 → 加减 → 乘除 → 应用题）。
7. 成长页查看亲子辅导、学习档案、周报复制。
8. 系统切深色模式 → 我的 → 设置 → 切换每日题量，顶部「已更新」为蓝底白字。
