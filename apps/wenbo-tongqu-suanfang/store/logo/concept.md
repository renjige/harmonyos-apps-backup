# Logo Concept — 童趣算坊

- 公司 / App / 行业：魏文波 · 童趣算坊 · 儿童轻量计算练习
- 品牌关键词：Clear / Calm / Count / Grow
- 核心元素（2）：圆润数字「7」轮廓 + 一颗算盘珠（珠内小星为珠的切口，不单算第三元素）
- brandAnchor：算（语义融进数字 7 与算珠，不单独写字）
- 禁止项自检：无卡通书包、无机器人老师、无彩虹渐变球、无奖杯、无 AI 大脑
- 色板：2 色 — 深蓝 `#1E3A5F` + 白 `#FFFFFF`
- 对比策略：App Icon 深底白标；灰度后 7 与算珠轮廓仍清晰；24px 可辨
- 行业模板 vs 本稿：
  1. 非教育类打开书本 / 铅笔剪影套模板
  2. 非成长手册上升箭头
  3. 非游戏徽章与彩带
