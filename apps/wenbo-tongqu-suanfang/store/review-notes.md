# 华为审核说明（可粘贴至 AppGallery Connect · 版本信息 · 应用审核信息）

本应用是面向 3～12 岁儿童的**亲子口算学习工作台**，不是「输入算式 → 出结果」的简易四则运算工具。1.0.6 已补齐家长侧创作、目标管理、打卡与时间轴回顾，形成可持续使用的学习闭环。

---

## 一、为何不是「简易运算练习」（对应审核指南 3.5）

| 简易口算工具 | 童趣算坊（本应用） |
|---|---|
| 只有随机出题 + 判对错 | 今日任务板 + 年龄路径 + 闯关 + 知识卡片 |
| 无用户创造内容 | **家长出题**（手写算式题单）+ **我的题单**（组合题型） |
| 无持续使用动机 | **本周目标** + **学习打卡** + **七日计划** |
| 练完即忘 | **练习时间轴** + **今日/本周/本月回顾**（可复制） |
| 错题用完即丢 | 错题小本 + **备注** + 收藏 **标签筛选** + 再练 |
| 无成长感知 | 星星/正确率/连续天 + **勋章墙** |

**核心差异**：孩子练题 + 家长出题/盯目标 + 双方可回看练习史 —— 这是**学习管理产品**，不是单一运算器。

---

## 二、建议审核员体验路径（约 5 分钟）

请按以下顺序操作，可完整看到非「简易练习」的闭环：

1. **首屏引导**：打开 App → 首屏展示「亲子口算学习工作台」及四项能力说明 → 点「进入工作台」。
2. **首页工作台**：可见「今日任务」「本周目标」「学习工作台」（出题/题单/打卡/时间轴）、「今日表现」「最近练习」。
3. **家长出题**：首页 → 学习工作台 → **家长出题** → 输入 `7+8`、`12-5` → 保存 → **去练习**（按家长题单练，非随机题）。
4. **本周目标**：首页「本周目标」卡片 → 切换 30/50/80/100 题 → 完成一组练习后进度变化。
5. **学习打卡**：学习工作台 → **学习打卡** → 写一句备注保存；或练完一组后自动记一天。
6. **练习回顾**：首页 → **学习回顾** → 切换今日/本周/本月 → 文案来自真实练习记录 → 可复制。
7. **成长 Tab**：星星、柱状图、近四周打卡、勋章墙、时间轴入口。
8. **练习 Tab**：年龄筛选、九九口诀表、闯关、知识卡片、错题备注、收藏标签。

## 三、功能清单（均有真实数据逻辑）

- 今日任务板（热身 / 挑战 / 口诀或闯关）
- 按 3-5 / 6-8 / 9-12 岁路径 + 多种题型（选择、比大小、应用题、趣味游戏等）
- 九九口诀表（点一行专练）
- 数学闯关（关卡解锁）
- 知识卡片
- **家长出题** + **我的题单**
- **本周目标** + **学习打卡**
- **练习时间轴** + **学习回顾**
- 错题小本（备注）+ 收藏夹（标签）
- 七日计划 + 勋章
- 游客可用；无广告、无支付、无商城；不承诺提分

## 四、本版缺陷修复（对应审核指南 3.1）

**问题**：做题后或清除本地数据后，首页「今日表现」不更新，需冷启动。

**修复**：练完/清除/切回首页 Tab 后，今日星星、正确率、已练题数**立即刷新**，无需杀进程。
