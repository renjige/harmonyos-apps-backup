# 功能清单

- [x] 思览空间：今日思考、档案数字、快捷入口、最近沉淀、智慧回顾
- [x] 思考札记：创建、编辑、分类、体裁、标签、状态（草稿/整理中/已沉淀/珍藏）、收藏、删除确认
- [x] 阅读沉淀：篇名、来源、日期、核心观点、我的理解、收获
- [x] 知识卡片：蒸馏观点；可从札记/阅读「沉淀为卡片」
- [x] 灵感：想法/创意/问题/计划；可升级为札记
- [x] 主题空间：创建专题并关联内容
- [x] 时间轴回顾
- [x] 思考统计（分类、月度趋势）
- [x] 年度思览报告
- [x] 智慧整理（未分类/缺标签/长期草稿/归档建议，无生成式 AI）
- [x] 成就墙
- [x] 观点收藏与搜索
- [x] 详情 Hero + 正文 + CTA；列表→详情→编辑/删除
- [x] 设置与隐私：协议全文、撤回同意（Toast）、清除缓存、深色模式、导出摘要
- [x] 零系统权限、纯本机、无登录墙
