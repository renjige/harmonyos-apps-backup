# 清凉出行 · 差异化对照

本 App 必须与仓库内已有夏日/出行类产品明显不同，禁止换皮。

对照对象：`xiaoye-manxing`（杂志手记）、`wenbo-qingliang-yichu`（衣橱）、`wenbo-xingcheng-beiwang`（时间线备忘）、`wenbo-bishu-youji`（避暑目的地/游记）。

| # | 维度 | 清凉出行 | 对照产品为何不同 |
|---|------|----------|------------------|
| 1 | 主任务 | 3 秒内看见清凉指数，决定现在出不出门、走哪条更凉快 | 漫行是手记排版；衣橱是穿搭；备忘是行程节点；避暑游记是目的地+游记 |
| 2 | 首页构图 | 城市摄影 Hero + 环形清凉指数 + 预警条 + 适宜时段 chips | 不是杂志封面网格，不是衣橱九宫格，不是时间轴，不是目的地卡片瀑布 |
| 3 | 核心实体 | 城市天气快照、清凉路线、休息点、出行建议 | 不是 Dest/Guide/Journal，不是 Outfit，不是 Memo |
| 4 | 路线对比 | 同一起终点下步行 / 骑行 / 公共交通的树荫率、室内占比、清凉指数并排 | 导航类最短路或旅游攻略里程，不比树荫 |
| 5 | 天气用法 | 栏目快照 + 城市选择，不申请 GPS；24h 体感柱标注适宜出门 | 不是实时雷达图，也不是游记里的气温区间装饰 |
| 6 | 色彩与材质 | 极淡蓝白底 `#F0F7FF` + 清凉蓝 `#00B4D8` + 深海青 `#0B2A36` 摄影遮罩 | 禁止暖纸杂志、禁止衣橱浅杏、禁止游记翠绿山岳主色 |
| 7 | 图标与 Logo | 开口降温光环 + 「清」水部弧线；禁止雪花库存标、太阳+雪花模板 | 与避暑游记山形、衣橱衣架轮廓不相似 |
| 8 | 文案边界 | 智能/智慧，禁止「AI」；天气为出行参考，不替代气象台 | 游记强调写作，衣橱强调搭配 |

验收：截图并排四款 App 首页，普通人 3 秒内能说出「这是通勤清凉指数，不是避暑游记」。
