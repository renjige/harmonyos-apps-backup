# 清凉出行 个人信息收集清单

运营者：魏文波  
应用名称：清凉出行  
更新日期：2026-08-22

| 信息 | 场景 | 目的 |
|------|------|------|
| 账号、密码、姓名、手机号、邀请码（选填） | 主动注册 / 登录 | 创建与核验账号 |
| 访问凭证 | 登录成功后 | 本机保持登录态 |
| 收藏的路线 / 休息点标题与编号 | 登录后主动收藏 | 同步「我的收藏」 |
| 出行规划（起终点、方式、路线编号） | 登录后主动保存 | 同步「我的规划」 |
| 常用出行方式、热敏感 | 本机偏好设置 | 路线页默认筛选 |
| 隐私同意状态 | 登录/注册勾选或撤回 | 记录协议同意 |

游客浏览栏目时不采集上表账号类信息。不收集精确位置、通讯录、相册、短信或通话记录。
