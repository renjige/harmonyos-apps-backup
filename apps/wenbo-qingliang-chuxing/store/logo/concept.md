# Logo Concept — 清凉出行

- 公司 / App：魏文波 · 清凉出行
- brandAnchor：清
- glyphStrategy：semantic-fusion
- 品牌关键词：Cool / Commute / Shade / Index / Path
- 核心元素（2）：开口降温光环（呼应「清」的水部弧线）+ 内芯圆点（体感中心 / 出行落点）
- 禁止项自检：无雪花库存标、无温度计、无太阳+雪花模板、无渐变球、无定位针
- 色板：深海青底 `#0B2A36` + 近白光环 `#E8FBFF`；内芯薄荷绿 `#4ECDC4`（辅助，面积很小）
- 对比策略：深底浅标，灰度后光环轮廓仍清晰
- 行业模板对比：
  - 清凉衣橱：衣橱轮廓 + 衣物
  - 夏野漫行：山脊 + 太阳
  - 行程备忘：时间线节点 + 卡片
  - 避暑游记：山水目的地符号
  - 本稿：开口光环包住出行落点，表示把热气挡在环外
