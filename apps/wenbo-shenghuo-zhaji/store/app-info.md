## 应用介绍

生活札记是个人生活管理与成长记录应用，不只是日记备忘：

- **生活瞬间 / 写札记**：从系统相册选择个人照片，图文保存（保存后展示所选照片）
- **生活主题模板**：今日心情、美食、旅行、阅读、灵感、家庭时光
- **心情轨迹**：每日心情打点与历史回顾
- **生活日历**：按日期查看当天札记与时间轴
- **每日打卡**：习惯项目、连续天数
- **生活清单**：计划事项与完成勾选
- **生活洞察**：融合札记/心情/打卡/清单，自动生成月度成长摘要与情绪分布
- **分类 / 标签**：生活感悟、兴趣收藏、家庭、工作成长、学习、旅行足迹
- **年度回顾、相册、美好收藏、智慧整理**

首次进入首页为空；登录后仅展示用户自己创建的内容。

## 审核复测路径（v1.0.5 · HarmonyOS 6.0/6.1）

**差异化说明**：除日记/相册外，提供「生活洞察」月度成长摘要（融合心情轨迹、习惯打卡、生活清单与札记数据），以及主题模板、生活日历等组合能力，非单一相册/日记工具。

**选图设计**：使用系统 PhotoViewPicker，用户主动选图；照片复制到应用沙箱并以所选原图展示。

1. 登录 → 相册 → 进入相册详情 →「添加精选配图」→ 确认后配图立即出现在相册图片网格
2. 记录 → 打开札记详情 →「加入美好收藏」→ 再次点击提示「已在美好收藏中」
3. 我的 → 每日打卡 → 添加习惯 → 今日打卡 → 页面即时显示「今日已完成」
4. 我的 → 生活清单 → 点击待办项 → 状态即时变为已完成/待办
5. 首页 →「生活洞察 · 月度成长摘要」→ 查看本月成长指数与情绪分布
6. 浅色模式下首页模板标签、二级按钮文字对比度可读（深灰字 + 白底描边）
