# 差异化说明 · 生活札记

与通用日记/相册 App 及仓库内 `chenqi-zaoqi-daka`（morning-habit）对比：

1. **核心定位**：个人生活管理与成长记录，非单纯日记备忘或相册浏览
2. **生活洞察（独有）**：融合札记、心情轨迹、习惯打卡、生活清单，自动生成月度成长摘要、情绪分布与生活成长指数
3. **多维度工具链**：主题模板（6 类）+ 生活日历 + 心情轨迹 + 每日打卡 + 生活清单，形成记录→回顾→洞察闭环
4. **Tab 结构**：首页·记录·相册·回顾·我的，回顾页含年度统计 + 生活洞察入口
5. **视觉气质**：奶油白 + 莫兰迪橙手账风（soft-editorial），非工程蓝仪表盘
6. **主 CTA 动词**：「写今日札记」「查看生活洞察」「收藏这段回忆」
7. **智慧能力**：规则模板 + 月度洞察摘要，非 LLM 对话（FeatureFlags.LLM_ENABLED=false）
8. **行业 Pack**：life-journal 独立 `/biz/life-journal/*` 与 Admin lj* 模块
