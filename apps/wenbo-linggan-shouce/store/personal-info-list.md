# 个人信息收集清单 — 灵感手册

| 信息类型 | 收集场景 | 是否必需 | 用途 |
|---------|---------|---------|------|
| 账号 | 注册/登录 | 是 | 身份识别与登录 |
| 密码 | 注册/登录 | 是 | 账号安全验证 |
| 姓名 | 注册 | 是 | 账号资料展示 |
| 手机号 | 注册 | 是 | 账号资料与联系 |
| 灵感标题/正文/标签 | 创建灵感 | 否（用户主动） | 灵感记录与同步 |
| 画板名称/描述/卡片 | 创建画板 | 否（用户主动） | 创意画板管理 |
| 计划名称/目标/进度 | 创建计划 | 否（用户主动） | 创意计划跟踪 |
| 收藏内容 | 添加收藏 | 否（用户主动） | 灵感收藏 |
| 设备型号/系统版本 | 崩溃诊断 | 否 | 稳定性保障 |

游客浏览推荐内容时不收集账号与业务内容。
