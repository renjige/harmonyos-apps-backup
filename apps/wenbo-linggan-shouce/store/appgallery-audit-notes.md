# 灵感手册 v1.2.1 — AppGallery Connect 审核说明（粘贴到「版本信息 → 应用审核信息」）

## 产品定位（非简易笔记）

「灵感手册」是面向创作者的多模块创作工作台，核心闭环为：

**记录灵感 → 画板整理 → 计划推进 → 专题归档 → 周回顾复盘**

除文字记录外，还提供：情绪画板、创意计划（里程碑 + 进度）、创意专题合集、创作打卡、成长中心、创作时间轴、统一搜索、本周回顾、平台精选「记入手册」等能力。

## 建议审核演示路径（约 3 分钟）

1. **工作台**：查看今日创作概览、快捷打卡、计划/时间轴预览  
2. **记录 Tab**：新建灵感 → 详情 →「关联到计划/画板」→ 选择器显示名称 → 保存后在「关联创作」点击可跳转计划/画板详情  
3. **计划 Tab**：新建计划并设置初始进度（如 30%）→ 列表与详情显示 30% → 勾选里程碑即时更新 → 滑块调整进度不影响里程碑  
4. **我的 → 创意专题**：进入专题详情 → 加灵感/画板/计划 → 选择器显示名称 → 合集列表可点进详情  
5. **我的 → 本周回顾**：填写反思并保存 → 退出再进入 → 反思内容仍在
