# 差异化说明 — 观物 vs 参考 App

对比 avoidSlugs：`ximan-guan` · `nuanjian-xinjianrichang` · `jilei-riji`

1. **实体模型**：四象 `mood/scene/thought/environment`，非溪漫观单一情绪 50 字笔记
2. **影像气质**：东方静物摄影 + 智慧蓝/琥珀金，非溪水绿或暖杏手账
3. **首页工作台**：摄影 Hero 早安卡 + 三概览卡 + 智慧提醒，非 50 字限 3 条
4. **Tab 结构**：今日/万物集/洞察/我的（4 Tab），非漫观/图谱/洞察/我的
5. **洞察维度**：场景热力 + 四象里程碑，非仅情绪关键词
6. **配图**：每条最多 3 张 PhotoViewPicker 沙箱图，非纯文字
7. **Logo**：几何观眼 + 山形瞳孔，非溪流或纸笺
8. **品牌色**：#5B6ABF + #C9A96E + #1A1A2E，独立色板
