# 晨光笺 差异化

相对仓库内「灵感笺 / 心笺日常 / 松岚札 / 星语心笺」等记录类 App，晨光笺必须可被一眼区分：

| 维度 | 晨光笺 |
|------|--------|
| 行业 Pack | `dawn-slip`（新包，不是 heart-note / inspiration-slip） |
| 信息架构 | 仅 3 Tab：笺集 / 标签 / 我的 |
| 主视觉 | 米白纸张 `#F5F0E8` + 暖金 `#D4A574` + 折角信笺 Logo |
| 每日晨语 | 启动 Overlay（按日轮换，平台 ≥32 条） |
| 标签 | 标签云字号 = 使用频率 |
| 天气 | 时辰笺语，不申请定位 |
| 工作台 | `timeline-board` / layoutVariant `E` / `soft-editorial` |
| 数据 | 随笔正文默认本机；云端只放晨语/标签/笺语栏目 |

禁止换皮五态心情、工厂六件套 Tab、把私人随笔默认上传云端。
