# 展格创作集

**墨展工作室** 旗下个人创作者作品集 App — 纯本地、离线可用、无需登录。

## 功能模块

| Tab | 说明 |
|-----|------|
| 作品 | 2 列网格、分类筛选、搜索、下拉刷新、新建/编辑、点击进入详情（轮播 + 描述 + 标签） |
| 关于 | 头像、简介、技能标签云、联系方式、可编辑资料与头像 |
| 看板 | 作品总数、分类数、最近更新、本地访问与详情浏览统计、分类柱状图 |
| 设置 | 浅色/深色/跟随系统、JSON 导入导出、隐私协议 |
