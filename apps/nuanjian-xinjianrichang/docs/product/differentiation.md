# 差异化

对照：`wenbo-shenghuo-zhaji`、`wenbo-xinqing-shouce`、`xingyu-xinjian`、`xinjian-shouzuo-xinjian`、`shiyi-shouzhang`

1. **产品语言是「心笺」不是日记/手账/星座信**：写下今天、我的心笺、看见生活留下的痕迹。
2. **严格 4 Tab**：首页 / 心笺 / 回顾 / 我的，无第五个 AI Tab、无相册、无星座宫格。
3. **暖杏红 `#E98D83` + 米白 + 深灰**：不是心情手册奶油橙，也不是星语心笺深夜蓝或拾意雾霾紫。
4. **Logo 为折角纸笺负形 + 小心形 + 日轮**，禁止完整爱心+笔+日历模板。
5. **正文默认只在本机 Preferences**：平台只提供今日一句/标签/金句栏目，POST 心笺会被拒绝。
6. **回顾是规则统计 + 三则精选**，文案不出现「AI」，也不做心理测评。
7. **游客即可写心笺**；登录可选，仅账号与机构通知。
8. **无支付、社交、会员、商城、复杂云同步。**
