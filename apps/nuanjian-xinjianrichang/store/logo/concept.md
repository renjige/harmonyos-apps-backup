# Logo Concept — 心笺日常

- 公司：暖笺生活 / App：心笺日常 / 行业：heart-note
- 品牌关键词：Warm / Letter / Daily / Quiet / Tender
- 核心元素（2）：折角纸笺 + 心形负空间（日轮落在折角处）
- brandAnchor：笺
- 禁止项自检：无渐变球、无 3D、无发光、无人物、无俗气完整爱心描边、无信封套模板（与「手作心笺」信封封缄区分）
- 色板（2）：暖杏红 `#E98D83` 底 + 米白 `#FFF9F6` 纸笺
- 对比策略：深暖杏红底 / 近白纸笺；心形为负形露出底色，24px 仍可辨折角与心形
- glyphStrategy：semantic-fusion
