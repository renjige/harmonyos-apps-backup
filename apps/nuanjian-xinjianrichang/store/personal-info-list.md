# 个人信息收集清单

运营者：魏文波  
应用：心笺日常

| 信息 | 场景 | 目的 | 存储 |
|---|---|---|---|
| 用户名、密码、姓名、手机号 | 你主动注册/登录 | 账号标识与注销 | 平台账号库（按租户隔离） |
| 心笺标题、正文、心情、标签、日期 | 写下今天 / 编辑 | 本机展示与回顾 | 设备本地 Preferences |
| 你选择的本地图片（最多 3 张） | 点击「添加图片」 | 该篇心笺配图 | 应用私有目录 |
| 深色模式、字号、提醒开关 | 我的页偏好 | 记住外观与提醒 | 设备本地 |
| 隐私同意状态 | 登录勾选 / 撤回 | 合规记录 | 设备本地 |
| 租户标识（X-Tenant-Id） | 拉取今日一句等栏目 | 区分应用数据 | 请求头，不含日记正文 |

不收集通讯录、精确位置、麦克风录音、短信或通话记录。
