# 个人信息收集清单

应用：避暑游记  
运营者：魏文波

| 信息 | 场景 | 方式 | 存储 |
|---|---|---|---|
| 账号、密码、姓名、手机号 | 主动注册 / 登录 | 用户填写 | 业务平台（按租户隔离） |
| 邀请码 | 注册选填 | 用户填写 | 业务平台 |
| 游记标题、正文、日期、目的地标记、封面键 | 新建游记 | 用户主动输入或点选图库 | 业务平台（按 userId） |
| 收藏的目的地 / 攻略 | 详情页收藏 | 用户点击 | 业务平台（按 userId） |
| 访问凭证 | 登录成功 | 系统生成 | 本机 Preferences |
| 隐私同意状态 | 登录勾选 / 撤回 | 用户操作 | 本机 Preferences |

不收集：精确位置、通讯录、短信、通话记录、相册原图、人脸、设备指纹广告 ID。
