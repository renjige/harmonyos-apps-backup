# Logo Concept — 避暑游记

- **公司 / App**：魏文波 · 避暑游记
- **brandAnchor**：避
- **glyphStrategy**：semantic-fusion
- **关键词**：Cool · Peak · Cloud · Escape · Journal
- **核心元素（2）**：一座简化山峰 + 一朵遮住峰顶的云（「避」热就在云荫里）
- **对比策略**：深海蓝底 `#1B4F72` + 近白山形与云 `#F4FAFF`（明度差大，灰度轮廓清晰）
- **禁止项**：无飞机、地球、定位针、行李箱、温度计、帐篷插画、渐变球、发光、毛玻璃
- **行业模板对比**：
  1. 不同于夏野漫行的「山脊+暖橙太阳+路径」
  2. 不同于旅行札记的手册/相机折线
  3. 本标没有太阳，强调云荫避热，不是「出发去晒太阳」
