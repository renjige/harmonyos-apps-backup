# 差异化 — 避暑游记

相对仓库内相近产品，本 App 不以「慢行 / 手记 / 行程备忘」换皮，而以**气温区间 + 地貌分类**作为首页主任务。

## 对照（≥6）

| 已有产品 | 主任务 | 避暑游记如何不同 |
|---|---|---|
| 夏野漫行（xiaoye-manxing） | 轻路线节点 + 出行清单 + 手记 | 本 App 是避暑**目的地目录**（温度/海拔/美食），不是沿途节点路线；无清单 |
| 旅行札记（wenbo-lvxing-zhaji） | 泛旅行记录 | 只做盛夏避暑筛选，卡片强制展示气温区间与海拔 |
| 行程备忘（wenbo-xingcheng-beiwang） | 行程备忘清单 | 无待办清单；闭环是「看地 → 收藏/写游记」 |
| 清凉衣橱（wenbo-qingliang-yichu / cool-wardrobe） | 夏日穿搭 | 与穿衣无关，是地理避暑 |
| 球星风采等体育 App | 人物档案 | 地貌摄影与游记时间线，无赛事 |
| 咨询/家装类 | 预约顾问 | 无预约、无支付；出行自测只匹配目的地 |
