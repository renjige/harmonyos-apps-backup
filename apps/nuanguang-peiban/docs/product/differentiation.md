# 暖光陪伴 — 差异化说明

与仓库内相似 App 的差异（≥6 条）：

1. **3 Tab 结构**：今日心情 / 陪伴时光（分段）/ 我的空间 — 非清凉计划 4 Tab，非心笺日常手账流
2. **视觉**：暖阳金 `#F5A623` + 米白 `#FFF8F0` — 非冰泉青清凉计划、非莫兰迪心笺
3. **5 档心情 + 智慧反馈**：great/good/ok/low/bad + 平台预设反馈文案 — 非清凉指数环
4. **陪伴时光三合一**：呼吸引导 + 白噪音 5 轨 + 暖心语录 — 单 Tab 分段，非独立呼吸 Tab
5. **光点连续打卡 + 徽章墙**：7/14/30 天成就 — 非工地 KPI、非 AI 看板
6. **本机优先**：心情日记 Preferences 落盘，登录可选同步 — 非强制登录墙
7. **无 AI 字样 / 无 LLM**：FeatureFlags.LLM_ENABLED=false，界面用「智慧/贴心」
8. **无支付 / 无社交**：完全免费，无评论私信
