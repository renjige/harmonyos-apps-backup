# 隐私政策

**运营者**：魏文波  
**应用名称**：厨验Lab  
**更新日期**：2026-08-24

厨验Lab 是一款智慧厨房助手，提供菜谱浏览、食材库存与保质期管理、智慧匹配推荐、采购清单与烹饪实验笔记等功能。

## 一、我们收集的信息

1. **账号信息**：注册或登录时的账号、姓名、手机号及登录会话标识。
2. **业务数据**：你录入的食材库存、采购清单、实验笔记、收藏的菜谱标识。
3. **本地数据**：收藏列表等保存在本机 Preferences 中的偏好数据。
4. **游客**浏览菜谱时不采集上述账号与业务写入数据。
5. 本应用仅申请 **网络权限**（`ohos.permission.INTERNET`），不申请相机、定位、通讯录等权限。

## 二、使用目的

上述信息用于：展示平台菜谱与看板数据、同步你的食材/采购/笔记、登录鉴权、保质期提醒与智慧菜谱匹配。

我们不向用户提供生成式大模型自由对话；不提供商城下单或支付功能。

## 三、存储与共享

- 业务数据经 HTTPS 传输至 `saas16.qianqi.online` 平台 API 并按租户隔离存储。
- 当前版本**不接入**广告 SDK、支付 SDK 或第三方统计 SDK。

## 四、用户权利

你可以在 **我的 → 设置与隐私** 查看《用户协议》《隐私政策》，清除本地缓存，注销账号或**撤回隐私同意**。撤回后再次使用登录功能须重新勾选协议。
