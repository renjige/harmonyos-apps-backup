# 个人信息收集清单 — 厨验Lab

| 信息类型 | 字段/内容 | 是否必须 | 使用场景 |
|---------|----------|---------|---------|
| 账号 | 用户名 | 注册/登录时 | 身份识别 |
| 账号 | 密码 | 注册/登录时 | 鉴权（平台侧存储） |
| 账号 | 姓名 | 注册时 | 用户资料 |
| 账号 | 手机号 | 注册时 | 联系与账号安全 |
| 业务 | 食材名称、分类、数量、保质期 | 用户主动录入 | 库存与提醒 |
| 业务 | 采购项名称、数量、勾选状态 | 用户主动录入 | 采购清单 |
| 业务 | 实验笔记标题、正文、配方调整 | 用户主动录入 | 烹饪记录 |
| 本地 | 收藏菜谱 ID 列表 | 用户收藏时 | 本地 Preferences |
| 会话 | accessToken | 登录成功后 | 保持登录态 |

**游客浏览菜谱**：不收集上表业务与账号信息。

**撤回路径**：我的 → 设置与隐私 → 撤回隐私同意 / 注销账号
