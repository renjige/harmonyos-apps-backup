# 行旅笺

融合行程规划与旅行手记的智慧出行伴侣，帮助用户优雅地规划旅行、记录旅途灵感与回忆。

## 核心功能

- **行程笺**：创建行程、时间轴节点、智慧推荐模板、分享卡片入口
- **旅迹**：图文记录、标签分类、网格/列表视图、详情 Hero
- **灵感匣**：收藏目的地与攻略片段、离线查看
- **我的**：旅行统计、深色模式、数据导出、设置与隐私

## 数据说明

用户数据默认存储在本机 Preferences，无需联网即可使用核心功能。可选登录用于账号沉淀（open_optional）。
