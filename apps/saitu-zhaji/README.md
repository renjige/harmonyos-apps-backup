## 核心功能（对照华为 3.5）

| Tab | 实质能力（可演示） |
|-----|------|

## 审核员 4 分钟路径

1. 首页 → 打卡 → 看连续天与待办变化  
2. 档案 → 搜索/收藏 → 赛事中枢创建复盘  
3. 赛途 → 计划 + 节点 → 首页进度更新  
4. 成长 → 洞察月报滑动 + 成就徽章  
5. 时间轴 → 查看全部动态  
6. 不申请定位/网络/相册权限
