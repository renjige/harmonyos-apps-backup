# 赛途札记 Logo 概念

## brandAnchor
**赛** — 竞赛与旅途的双重语义

## glyphStrategy
abstract — 向上延伸的路径轨迹 + 记录节点

## 核心元素（≤2）
1. **上升路径线**：从左下向右上延伸的轨迹，象征「赛途」中的前进与成长
2. **记录节点**：轨迹末端的实心圆点，象征「札记」的记录落点

## 配色
- 背景：`#1C1C1E`（深空灰）
- 主体路径：`#007AFF`（华为品牌蓝）
- 节点：`#FFFFFF`

## 行业模板对比
- 非 house/book 行业默认 glyph
- 非成长绿/溪水绿（区别于 growth-handbook 与 ximan-guan）
- 路径+节点抽象，非笔记本/日历套图

## customLock
true — Agent SVG 终稿
