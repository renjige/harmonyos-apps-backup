# AppGallery Connect 审核说明（v1.3.3）

## 问题 1 · 3.5 内容丰富度

**赛途札记** 是个人赛途成长工作台（非简单赛事记事本 / 非资讯流），覆盖完整使用场景：

| 场景 | 入口 | 能力 |
|------|------|------|
| 观赛复盘 | 首页 → 适用场景 / 赛事中枢 | 比分、配图、四段结构化复盘、复制导出 |
| 自主训练 | 首页快捷 / 赛事中枢 | 时长、强度、项目、关联旅途 |
| 旅途推进 | 赛途 Tab | 计划任务、节点达成、打卡月历、旅途详情汇总 |
| 球队关注 | 赛事中枢 → 关注详情 | 自动关联赛事档案 |
| 习惯打卡 | 赛途 → 打卡月历 | 连续天 + 成就解锁 |
| 成长洞察 | 成长 Tab | 周/月报、关键词、看板进度 |
| 数据沉淀 | 我的 → 导出 | 全量 JSON 复制 |

**首页**：「适用场景」专页（6 类场景 + 直达操作）、「本周赛途摘要」动态统计。

## 问题 2 · 功能异常（已修复 v1.3.3）

| 测试项 | 修复 |
|--------|------|
| 赛途计划/节点修改状态不实时更新 | `saituTrackEpoch` 全局刷新 + ForEach `rowKey` 含状态字段 |
| 赛事中枢添加档案需先关闭才见编辑页 | 编辑器叠层置于赛事中枢之上 |
| 浅色/深色切换未实时更新 | `ThemeAppearance.apply` + `themeEpoch` 驱动全 App 重绘 |
| 撤回隐私同意文案与行为不符 | 文案对齐 AGC 托管策略；撤回后自动打开隐私政策全文 |

### 复测步骤

1. **赛途 Tab** → 打开计划详情 → 勾选任务 → 关闭后列表状态**立即**更新；节点「标记达成」同理  
2. **首页 → 赛事** → 添加赛事档案 → 选择类型后**直接**进入编辑页（无需先点关闭）  
3. **我的 → 外观** → 切换浅色/深色 → 页面与底栏**即时**变色  
4. **我的 → 撤回隐私同意** → 确认后弹出隐私政策全文 + Toast，文案不再承诺「返回隐私弹窗」

## 隐私说明

- 首次安装隐私确认由 **华为 AppGallery Connect 平台隐私托管**负责（50128），应用内无自建首启拦截弹窗  
- 「撤回隐私同意」清除本机记录并引导重新阅读协议；系统级隐私弹窗由平台控制，非应用可触发项  

## 权限

`requestPermissions: []` · 全部本机存储

4. 我的 → 切换深色模式 → 全界面即时生效  
5. 成长 → 管理旅途 → 改颜色 → 看板即时更新
