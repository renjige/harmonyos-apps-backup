## 产品要点

- **87 则官方图鉴**（自然 / 生活 / 科学 / 人文 / 趣味）
- **探索发现记录**（新建、编辑、删除、收藏，支持示例清除）
- **每日任务 + 7 日挑战 + 16 枚徽章 + 探索等级**
- **智慧探索 / 智慧回顾**、统计、时间轴、领域地图
- **纯本地**：无账号、无支付、无广告、无 INTERNET 权限
