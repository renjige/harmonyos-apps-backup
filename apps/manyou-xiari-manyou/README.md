# 夏日漫游

**公司**：漫游生活  
**App 名称**：夏日漫游  
**行业 Pack**：summer-wander  
**slug**：`manyou-xiari-manyou`

## 产品定位

用智慧的方式记录每一个夏日漫游时刻，发现城市美好角落，以轻量足迹留住治愈与灵感。

## 核心 Tab

| Tab | 功能 |
|-----|------|
| 地图 | 漫游点地图视图 + 横向卡片 + 智慧推荐 |
| 记录 | 漫游时间线（文字/图片/地点/心情） |
| 灵感 | 每日漫游灵感滑动浏览与收藏 |
| 我的 | 统计、设置与隐私 |
