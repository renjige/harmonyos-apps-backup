# 差异化说明 · 夏日漫游

相对仓库内 **夏野漫行**（xiaoye-manxing）与旅行札记类产品，本 App 为独立品牌与信息架构。

| 维度 | 夏日漫游 | 夏野漫行 |
|---|---|---|
| 品牌色 | 薄荷绿 #4ECDC4 + 天空蓝 + 阳光橙 | 森林墨绿 + 暖米白 |
| 首页形态 | **地图视图** + 横向漫游点卡片 | 杂志 Hero + 今日漫行 |
| Tab | 地图 / 记录 / 灵感 / 我的 | 漫行 / 路线 / 手记 / 我的 |
| 主任务 | 发现漫游点 → 记录 → 收藏灵感 | 选路线 → 清单 → 手记 |
| 智慧能力 | 智慧匹配问卷（六题规则） | 适合今天（同类引擎，不同品牌文案） |
| 公司/租户 | 漫游生活 / manyou-xiari-manyou | 夏野生活 / xiaoye-manxing |
| Logo | 渐变徽章 + 路径 | 山峦 + 暖橙太阳 |
| 布局变体 | layoutVariant B | layoutVariant A |

相对 **wenbo-lvxing-zhaji** 等札记类：本 App 以平台栏目漫游点为主，非纯日记相册。

禁止换皮：不得与 xiaoye-manxing 共用同一首页线框与品牌色出货。
