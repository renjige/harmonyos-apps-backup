# Logo Concept — 昆虫观察簿

- 公司 / App / 行业：林涧博物 · 昆虫观察簿 · 本地自然观察
- 品牌关键词：Observe / Leaf / Field / Quiet / Record
- 品牌锚点 `brandAnchor`：**昆**（观察之镜）
- 核心元素（仅 2 个）：放大镜镜头 + 叶片剪影（负空间落在镜片内）
- 对比策略：深森林绿底 `#1A4A3A` + 米白前景 `#F5F0E8`，灰度轮廓清晰
- 行业模板对比：不是房屋/书本/六边形复眼科技标；不是写实昆虫插画；不是山峰指南针（自然探索志）
- 禁止项自检：无渐变球、无发光、无 3D、无 AI 脑、无六边形科技套
