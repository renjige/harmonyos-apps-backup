# AppGallery Connect · 版本信息 · 应用审核信息（可直接粘贴）

应用名称：球队研判  
版本：**1.0.5**

---

## 问题（3.5）— 功能简单、使用场景有限

**现象**：容易被理解为「只是球队资料展示」。

**本次补齐（1.0.5）**：升级为球队数据研究与球迷分析工具，不只是介绍页。

| 能力 | 用户怎么用 |
|---|---|
| 球队资料库 | 球队 Tab：国内 / 国际 / 联赛 + 强攻/防守/年轻/豪门/黑马；详情含荣誉、主场、历史、阵容 |
| 状态分析 | 详情：近期战绩、得失球、主客场、进攻/防守说明、胜负趋势 |
| 数据图表 | 详情与对比：近场战绩分、进球柱状图（无数据不画假图） |
| 球队对比 | 发现 / 首页：两队积分、攻防指数、近期状态、交锋胜负 |
| 历史交锋 | 对比页统计 + 比赛详情「前瞻」列出过往对阵 |
| 关注球队 | 详情关注 → 首页关注区 / 关注页 / 桌面卡片 |
| 观察笔记 | 详情写个人研判，本机保存 |
| 比赛前瞻 | 打开任一场比赛，对照双方近况与交锋 |
| 球员档案 | 详情核心球员姓名与位置 |
| 资讯整理 | 发现 → 球队资讯，按项目筛选，可收藏 |
| 积分榜 | 联赛排名与积分；详情展示当前排名 |
| 研判收藏夹 | 我的：收藏球队/比赛/资讯 + 笔记研究库（新用户为空） |
| 每日观察 | 首页 / 发现：每日推荐一支球队与观察主题 |

**验证路径（建议写进审核备注）**：

1. 打开任意球队详情：应看到资料库、状态分析、图表、阵容，而不是只有简介。  
2. 发现 → 球队对比：选两支同联赛球队 → 应出现攻防对照、交锋统计、柱状图。  
3. 打开一场未开始或已结束比赛：下滑应有「比赛前瞻」与历史交锋。  
4. 我的 → 研判收藏夹：新账号为空；在详情加入收藏后应出现。  

不提供博彩、赔率或生成式 AI 对话。

## 附：公开资料 vs 用户数据

- **我的关注 / 提醒 / 笔记 / 收藏夹 / 动态**：用户操作后才有数据，新账号为空。  
- **公开球队档案 / 赛程 / 积分榜 / 联赛 / 资讯**：联赛公开目录，非用户个人历史。
