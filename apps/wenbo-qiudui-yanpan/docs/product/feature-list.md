# 功能清单 — 球队研判（v1.0.5）

## 闭环（均可演示）

- ✅ 公开球队档案：16 支 · 首页 / 球队 Tab 浏览 → 详情 Hero + 简介 + 近期比赛
- ✅ **球队资料库**：荣誉、阵容、主场、历史；分类 国内 / 国际 / 联赛 + 风格标签
- ✅ **球队状态分析**：近期战绩、得失球、主客场、进攻/防守说明、胜负趋势
- ✅ **数据图表**：战绩分变化、进球变化（已结束比赛；不足则提示，无假样本）
- ✅ **球队对比**：积分榜、胜率、进攻/防守指数、近期状态、历史交锋统计 + 图表 + 研判简报
- ✅ **历史交锋**：胜/负/平统计与交锋列表（对比页 + 比赛前瞻）
- ✅ **比赛前瞻**：双方近期状态、攻防参考、交锋记录（比赛详情内）
- ✅ **球员档案**：核心球员姓名与位置
- ✅ **关注球队**：登录后关注；首页 / 关注页；新用户为空
- ✅ **观察笔记**：本机保存研判观点
- ✅ **研判收藏夹**：收藏球队分析、重点比赛、资讯；与笔记汇总；新用户为空
- ✅ **球队资讯**：按项目浏览公开动态，可收藏
- ✅ **每日观察**：每日推荐一支公开球队 + 小知识 + 观察主题
- ✅ **积分榜**：联赛排名、积分、净胜；详情展示当前排名观察
- ✅ **发现 Tab**：KPI、进行中、公开联赛、分析工具入口
- ✅ 公开赛程 / 赛事日历 / 我的动态 / 桌面卡片
- ✅ 登录 / 注册 / 退出 / 设置与隐私（协议、撤回、注销）
- ✅ 竞技深色模式

## 公开资料 vs 用户数据

- 资料库、赛程、积分榜、资讯、每日推荐：联赛公开目录
- 关注 / 提醒 / 笔记 / 收藏夹：用户操作后才有数据
