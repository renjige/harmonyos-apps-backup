# 个人信息收集清单

**应用名称**：知语集  
**运营者**：魏文波  
**更新日期**：2026年8月24日

| 信息 | 场景 | 处理方式 |
|---|---|---|
| 用户名、密码、姓名、手机号 | 你主动注册或登录 | 用于账号标识与注销；不用于广告 |
| 收藏语录 ID 列表 | 你点击收藏 | **保存在本机 Preferences**；未登录不同步云端 |
| 今日已阅标记 | 你阅读每日智慧 | **保存在本机** |
| 深色模式偏好 | 你在「我的」中切换 | 仅保存在本机 |
| 隐私同意状态 | 登录/注册勾选协议 | 本机 Preferences + 登录后持久化 |
| 租户标识（X-Tenant-Id） | 拉取语录栏目 | 发往 saas16.qianqi.online |

不收集通讯录、精确位置、短信、通话记录、相册内容。游客浏览不采集账号信息。
