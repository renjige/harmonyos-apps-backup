# 差异化说明 — 知语集 vs 思见堂

| 维度 | 知语集 | 思见堂（同 Pack 参考） |
|------|--------|------------------------|
| Tab 数 | 3（首页 / 语录库 / 我的） | 4（今日堂 / 思录 / 思友圈 / 我的） |
| 核心闭环 | 读金句 → 收藏/分享 | 读慧语 → 写思录 → 思友圈点赞 |
| 数据侧重 | 510 条分类语录 API | 慧语 + 荐读 + 议题 + 社交精选 |
| 收藏 | 本机 Preferences 持久化 | 平台 favorites API |
| 主题色 | 墨蓝 #1A2A3A + 暖金 #C9A96E + 米白 #F7F5F0 | 深墨 #1A1A2E + 暖金 #C9A84C |
| 图标 | 书页「语」字 + 引号 | 「思」卷轴意象 |

知语集定位更轻：专注语录浏览与收藏，无 UGC 写作与社交模块。
