# 益智王国 · 差异化

相对仓库内已有儿童向应用，本产品必须可被一眼区分：

| 应用 | 主任务 | 本产品差异 |
|------|--------|------------|
| 童趣算坊 | 口算键盘、加减乘除、错题本 | 无数字键盘；以图形色块与路径节点闯关 |
| 亲子智谜 | 亲子对答、文字谜题 | 儿童独立点选图形/色彩/序列，不是家庭问答卡 |
| 成语挑战 | 成语填字 | 低幼观察与推理，无成语词库 |
| 少儿画苑 | 作品画廊 | 无涂鸦画板，是关卡路径王国 |
| 通用咨询脚手架 | KPI + 快捷入口网格 | 大厅为石阶 Hero + 四座圆形入口（layout D） |
| 智慧工地类 | 登录墙任务日报 | 游客可闯关，报告才需家长算术确认 |

独特体验：王国路径地图、拼图王冠 Logo、收藏馆点亮、每日益智按日期轮换。禁止游戏厅霓虹与「即将上线」。
