# Logo Concept — 益智王国

- 公司 / App / 行业：魏文波 · 益智王国 · 儿童分级益智闯关
- 品牌关键词：Wisdom / Kingdom / Explore / Clarity / Belonging
- brandAnchor：王
- 核心元素（仅 2）：几何「王」字（中横与竖笔）+ 顶横拉成城堡雉堞，左上拼图凸榫
- 禁止项自检：无灯泡、无 3D 积木、无渐变球、无发光、无卡通皇冠插画、无 AI 模板
- 色板：深底 `#1A1A2E` + 金标 `#F5C842`（2 色）
- 对比策略：近黑底 + 高明度金标，灰度下轮廓仍清晰；禁止蓝叠蓝
- 行业模板对比：
  1. 非童趣算坊的「7 + 算盘珠」
  2. 非亲子智谜的「星球谜盒」
  3. 非通用房屋 / 书本 / 灯泡教育模板
- 与旧版差异：scaffold 占位未采用；本稿以「王」为锚点做语义融合
