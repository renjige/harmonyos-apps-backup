# 个人信息收集清单

运营者：魏文波  
应用：生活备笺

| 信息 | 场景 | 目的 | 存储 |
|---|---|---|---|
| 用户名、密码、姓名、手机号 | 你主动注册/登录 | 账号标识、注销与可选同步 | 平台账号库（按租户隔离） |
| 备笺标题、说明、分类、日期、提醒、完成状态 | 新建 / 编辑 / 完成 | 本机展示、日历与回顾；登录后可选同步 | 设备本地 Preferences；登录后可写入租户 runtime |
| 深色模式、提醒开关 | 我的页偏好 | 记住外观与首页提醒提示 | 设备本地 |
| 隐私同意状态 | 登录勾选 / 撤回 | 合规记录 | 设备本地 |
| 租户标识（X-Tenant-Id） | 拉取分类、问候、场景与通知 | 区分应用数据 | 请求头 |

不收集通讯录、精确位置、相机影像、麦克风录音、短信或通话记录。
