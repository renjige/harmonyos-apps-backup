# Logo Concept — 生活备笺

- 公司：魏文波 / App：生活备笺 / 行业：life-memo
- 品牌关键词：Paper / Light / Quiet / Order / Care
- 核心元素（2）：圆角笺纸折角 + 一枚生活光点
- brandAnchor：笺
- 禁止项自检：无渐变球、无 3D、无发光、无汉字书法、无 house 模板、无心情心形、无购物车、无清单打勾板
- 色板（2）：青绿 `#3D8277` 底 + 暖米白 `#F7F5EF` 笺纸（光点同米色）
- 对比策略：深青绿底 / 浅米白标；24px 仍可辨折角与光点
- glyphStrategy：semantic-fusion
- 行业模板对比：
  1. 生活札记用笔记本+阳光刻度 → 本稿不用刻度与太阳
  2. 心笺日常用杏红心底负形 → 本稿不用心形
  3. 家庭备忘用清单勾选 → 本稿不用对勾
