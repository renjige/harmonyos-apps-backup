# 差异化

对照：`wenbo-shenghuo-zhaji`、`nuanjian-xinjianrichang`、`wenbo-jiating-beiwang`、`wenbo-gouwu-beiwang`、`wenbo-yueding-tixing`、`wenbo-qiuxing-fengcai`

1. **产品语言是「备笺」不是日记/心情/家庭清单/购物清单**：记录 → 分类 → 提醒 → 完成 → 回顾。
2. **严格 4 Tab**：今日 / 笺记 / 日历 / 我的，无第五个对话 Tab，无相册，无心情五态，无四宫格。
3. **暖米白 `#F7F5EF` + 青绿 `#3D8277` + 克制金 `#D6A86E`**：不是札记阳光橙，也不是心笺杏红或家庭备忘蓝。
4. **Logo 为圆角笺纸折角 + 生活光点**，禁止心形、对勾清单板、太阳刻度、购物车。
5. **正文默认只在本机 Preferences**：平台栏目是分类说明、今日问候与场景封面；云端 notes 表对新用户为空，仅登录后可选同步。
6. **「智慧整理」是本地关键词分类建议**，「生活回顾」是本周完成数/常用分类/连续天数，界面禁止出现「AI」。
7. **游客即可写备笺**；登录可选，仅账号、机构通知与同步。
8. **日历是按日查看备笺的月视图**，不是约会排期、不是出行行程、不是家庭任务看板。
