# Logo Concept — 常识集

- 公司 / App / 行业：魏文波 · 常识集 · common-sense
- 品牌关键词：Daily / Stack / Clarity / Trust / Ritual
- 核心元素（仅 2 个）：三层错叠知识卡片（「集」）+ 顶卡一枚暖金横杠（「今日」标记）
- brandAnchor：常（日常积累，而非一次性猎奇）
- glyphStrategy：semantic-fusion
- 行业模板对比：
  1. 不是轻知阁的「翻开书页 + 阁檐 + 圆形金点」
  2. 不是识趣阁的阁楼飞檐 / 书卷曲线
  3. 不是知识探宝的罗盘 / 积分图形
  4. 禁止用户草案中的「发光灯泡」（工厂 Logo 黑名单）
- 禁止项自检：无灯泡、无大脑、无火箭、无渐变球、无 3D、无滤镜、无圆角遮罩
- 色板：深蓝 `#0A2540` + 纯白卡片 `#FFFFFF`（暖金 `#F5A623` 仅作顶卡横杠，不计入大面积主色）
- 对比策略：App Icon 用深蓝底 + 白卡片叠层，缩小 24px 仍可辨三层堆叠与金杠；禁止蓝标叠蓝底
