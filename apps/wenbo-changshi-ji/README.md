## 四个 Tab

1. **今日常识** — 今日卡片、随机、日历、搜索/场景/问答/清单/工具/提醒入口
2. **分类浏览** — 分类筛选、搜索、列表/卡片视图
3. **我的收藏** — 收藏列表、分组整理、笔记、导出
4. **我的** — 学习记录、问答、场景库、清单、工具、提醒、打卡、设置与隐私
