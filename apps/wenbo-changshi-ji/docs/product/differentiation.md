# 常识集与同类应用的差异

常识集不是资讯聚合或纯百科列表。主任务是把「一条有用的生活知识」变成可管理的个人工具：按日历读今日一条并打卡，按场景（清洁、保存、出行、应急）取用，用搜索和分类快速定位，再用收藏分组、常识清单和问答测试把知识留在手里。

与「每日一文 / 趣味科普」类产品的区别：

1. 有可执行闭环：收藏分组、清单勾选、错题回顾、已掌握，而不是看完即走。
2. 有生活工具（日期、换算、节气、年龄）和每日提醒，服务真实家务与出行场景。
3. 栏目走平台 API，用户活动（收藏/清单/答题）默认空，避免审核看到假的「别人的学习记录」。
4. 不提供生成式对话，避免无资质的 AI 套壳。

视觉上用今日常识摄影 Hero + 分类封面，而不是色块堆入口。
