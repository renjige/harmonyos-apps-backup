# Logo Concept — 赛事纵览

- 公司 / App：魏文波 · 赛事纵览 · sports-events
- brandAnchor：赛（全场纵览）
- glyphStrategy：abstract
- 品牌关键词：Arena / Orbit / Motion / Focus / Precision
- 核心元素（仅 2）：正圆赛场环 + 紫色运动轨迹
- 禁止项自检：无足球、篮球、奖杯、渐变球、AI 扁椭圆、蓝点球体
- 色板：底 `#0F172A` + 白环 `#FFFFFF` + 轨迹 `#7C3AED`（≤2 强调色）
- 对比策略：深底白标，灰度轮廓仍清晰

## 行业模板 vs 本稿

- 非购物袋 / 房子 / 书本行业模板
- 圆环表达「纵览赛场」，不是俯视扁椭圆
- 轨迹表达即将开始的动势，不使用球体符号
