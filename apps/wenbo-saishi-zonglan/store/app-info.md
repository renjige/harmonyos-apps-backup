# 应用信息

- 应用名称：赛事纵览
- 公司：魏文波
- Bundle ID：sszl.wxy.huawei
- 版本：1.1.0
- 分类：体育 / 生活服务
- 一句话简介：个人观赛工作台 — 计划、打卡、笔记、统计与赛程提醒一站管理

## 应用介绍

赛事纵览面向体育爱好者，从「看赛程」升级为「个人观赛工作台」。首页聚合今日待看、观赛 KPI 与快捷创建计划；赛事页可按足球、篮球、网球、电竞筛选，比赛状态随开球时间自动更新。比赛详情支持关注、开赛前提醒、观赛打卡、写笔记与加入观赛计划；观赛 Tab 统一管理计划进度、笔记打卡、关注提醒与动态时间轴。观赛数据中心提供累计场次、连续打卡、成就徽章与周回顾；全局搜索可跨比赛/球队/联赛检索。积分榜、赛事日历、消息中心与竞技深色模式一应俱全。应用采用 HarmonyOS NEXT 原生体验，数据与后台同步，遵循隐私合规要求。

## 关键词

体育赛事, 观赛计划, 赛程, 积分榜, 观赛提醒, 鸿蒙

## 审核演示建议

1. 游客浏览首页 → 点比赛看赛况 → 登录 → 加入计划 + 设置提醒 + 观赛打卡
2. 首页「搜索」找球队 → 关注 → 观赛 Tab 查看今日待看与动态
3. 写观赛笔记 → 我的「观赛数据中心」查看统计与成就
