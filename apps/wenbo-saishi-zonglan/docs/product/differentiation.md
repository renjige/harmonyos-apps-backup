# 赛事纵览 · 差异化说明

## 定位差异

| 维度 | 常见体育资讯 App | 赛事纵览 |
|---|---|---|
| 核心价值 | 浏览赛程与比分 | **个人观赛工作台** — 计划、打卡、笔记、统计闭环 |
| 用户数据 | 收藏/提醒为主 | 观赛计划进度、打卡 streak、笔记沉淀、成长成就 |
| 首页 | 资讯流/赛程列表 | 今日待看 + KPI 卡片 + 快捷创建计划/搜索 |
| 观赛 Tab | 关注列表 | 五段式：今日待看 / 计划 / 笔记打卡 / 关注提醒 / 动态时间轴 |

## 独有功能

1. **观赛计划** — 自选多场比赛，跟踪完成进度，打卡自动推进
2. **观赛打卡** — 比赛详情一键打卡，关联计划与统计
3. **观赛笔记** — 赛后记录心得，支持评分与标签
4. **观赛数据中心** — 累计观赛场次、笔记数、连续打卡、成就徽章、周回顾
5. **全局搜索** — 跨比赛/球队/联赛快速检索
6. **动态时间轴** — 打卡、笔记、计划创建等行为聚合展示

## 视觉与品牌

- 竞技蓝主色 `#0B6BCB`，专属 Logo（球场纵览符号）
- 内容摄影：hero / banner / 联赛封面独立出图，非色块占位
- 竞技深色模式，摄影 Hero 渐变遮罩保证对比度

## 与同仓库 App 区隔

- 非咨询/家装/教育换皮；专注体育赛事 vertical
- 无 LLM 对话主路径（方案 B 合规）
- 用户活动数据（计划/笔记/打卡）新用户为空，须本人操作产生
