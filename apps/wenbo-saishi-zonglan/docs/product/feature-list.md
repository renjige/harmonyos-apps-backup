# 赛事纵览 · 功能清单（v1.1.0）

## 核心闭环

- ✅ 首页：观赛工作台（今日待看、KPI、快捷入口）、周末赛程、热门/赛果/联赛/球队栏目、观赛百科
- ✅ 赛事页：赛程 / 联赛 / 球队 Tab + 状态筛选
- ✅ 比赛详情：Hero、赛况时间线、历史交锋、关注、设置提醒、**观赛打卡 / 写笔记 / 加入计划**、复制分享
- ✅ 球队 / 联赛详情：介绍、相关赛程、关注、联赛积分榜入口
- ✅ 积分榜：多联赛排名、胜平负与积分
- ✅ 赛事日历：按月查看、点选日期看当日比赛
- ✅ **全局搜索**：跨比赛/球队/联赛检索
- ✅ **观赛 Tab**（五段）：今日待看 / 我的计划 / 笔记打卡 / 关注提醒 / 动态时间轴
- ✅ **观赛数据中心**：统计、成就、时间轴、周回顾
- ✅ 消息中心：机构通知
- ✅ 登录注册、关注/提醒/计划/笔记/打卡写操作、隐私协议与撤回

## 主闭环（审核演示建议）

1. 游客浏览首页 → 点比赛 → 详情看赛况/交锋 → 登录 → 加入计划 + 设提醒 + 打卡
2. 首页「搜索」→ 找球队 → 详情关注 → 观赛 Tab「今日待看」查看
3. 比赛详情「写笔记」→ 观赛 Tab「笔记打卡」→ 我的「观赛数据中心」看统计与成就
4. 关注 Tab「动态」查看观赛轨迹时间轴
