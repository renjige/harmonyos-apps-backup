# 差异化说明 — 竞技漫记

对比：`geren-guiji`（足迹）、`saichang-shilu`（赛场相册）、`yundong-tuce`（运动影像）、系统运动健康/日历

1. **不是系统健康复刻**：除次数/距离外，强制「本场收获 + 下次重点」复盘字段，详情对照个人最佳
2. **不是系统日历**：日历仅为回顾入口；主导航是「赛季挑战」，进度由真实训练自动计入
3. **不是图册/日记换皮**：没有相册墙，核心是量化训练 + 可编辑复盘 + 挑战闭环
4. **双实体详情**：训练记录 DetailPane 与挑战 DetailPane 结构不同（复盘 vs 赛季进度）
5. **训练模板**：晨跑/力量/骑行/球类一键开表，不是空表单
6. **规则问卷**：训练配比复盘产出下一步动作，不含生成式对话、不跳外链
7. **导出**：成长轨迹复制剪贴板，用户拿得到自己的数据
8. **独立数据 Tab**：6 个月趋势柱图、体感动态分布、项目配比进度条、个人最佳榜
9. **月度报告**：规则生成当月亮点摘要（次数/里程/主力项目/周对比）
10. **影像快捷入口**：首页摄影 Banner 卡片链问卷、日历、数据看板（非纯色块）
11. **视觉**：竞技蓝 #1A5CFF + 活力橙渐变卡片/进度条/类型封面，深色玻璃
