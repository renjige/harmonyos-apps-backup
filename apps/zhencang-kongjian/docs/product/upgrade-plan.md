# 《珍藏空间产品升级方案》

> 版本：v2.0 · 2026-09-01  
> 原则：渐进增强，保留 v1 核心（档案/主题册/轨迹/统计/导出），0 新增系统权限

---

## 1. 产品定位

**珍藏空间** = 个人珍藏档案 + 收藏主题管理 + 收藏故事 + 收藏计划 + 时光回顾 + 兴趣沉淀的数字藏间。

核心闭环：**发现 → 建档 → 分类 → 收藏 → 整理 → 计划 → 回顾 → 沉淀**

---

## 2. 当前问题（v1）

| 问题 | 说明 |
|------|------|
| Tab 仅 4 个 | 缺独立「藏间工作台」与「回顾」专区 |
| 首页偏列表 | 信息层次不足，缺最近入藏/主题/待整理/时光回顾 |
| 档案字段少 | 缺特点、评价、鉴赏评分、清单状态（刚入藏/已归档等） |
| 无收藏计划 | 缺目标进度 |
| 无收藏清单 | 缺待收藏/想寻找 |
| 无成就/回顾 | 缺里程碑与「往年今日」 |
| 无搜索/智慧整理 | 工具深度不足 |
| 分类默认值 | 偏卡牌纪念品，需改为书籍/纪念物/旅行等通用集 |
| 脚手架页残留 | Login/AI/Dashboard 等未清理 |

---

## 3. 差异化方向

区别于相册/记事本/收藏夹：

- **藏品档案**（多字段 + 鉴赏卡 + 状态机）
- **主题册/收藏领域**（视觉专题，非资讯）
- **收藏计划**（目标进度）
- **珍藏时间轴 + 收藏日历**（真实活动日志）
- **成就墙 + 收藏回顾**（数据驱动）
- **智慧整理**（规则引擎，非 AI 字样）
- **收藏领域地图**（分类可视化，非 GPS）

---

## 4. 功能架构

```
藏间工作台（首页）
├── 数据摘要 + 快捷入口
├── 最近入藏 / 我的主题 / 待整理 / 时光回顾
珍藏 Tab
├── 分类筛选 + 搜索 + 清单视图
├── 详情 → 鉴赏 / 轨迹 / 对比
主题 Tab
├── 主题册列表/详情/编辑
├── 收藏领域地图
回顾 Tab
├── 时间轴 / 日历 / 统计摘要 / 回顾语
我的 Tab
├── 成就墙 / 笔记 / 计划 / 标签 / 导出 / 设置
```

---

## 5. 页面结构 & 导航

**底部 5 Tab**：首页 | 珍藏 | 主题 | 回顾 | 我的

二级全屏 Overlay（`TreasureNav` + `tabBarHidden`）：

- 新建/编辑珍藏、详情、搜索、智慧整理、计划编辑、笔记编辑、对比、主题详情

---

## 6. 首页「藏间」结构

1. 品牌区 + 标语  
2. 核心卡：珍藏数 / 主题数 / 待整理  
3. 快捷：新建珍藏 · 创建主题 · 收藏计划 · 快速记录  
4. 最近入藏（3～5）  
5. 我的主题（横滑）  
6. 待整理列表  
7. 时光回顾（规则生成一句）  
8. 数据摘要条  

---

## 7. 数据关系

```
TreasureItem ─┬─ categoryId → CategoryItem
              ├─ tagIds → TagItem
              ├─ albumIds（多主题）
              ├─ planId（可选）
              └─ timeline[]

TreasureAlbum ─ itemIds[]

CollectionPlan ─ linkedItemIds[] / targetCount

WishItem（待收藏/想寻找）

CollectionNote（珍藏笔记）

ActivityLog（全局时间轴/日历）

achievementsUnlocked[]（设置内）
```

**联动**：任何写操作 → `TreasureStore.persist()` → `treasureRev++` → 各 Tab `@Watch` 刷新 + 写入 `ActivityLog` + 重算成就。

## 8. UI 视觉规范

- 气质：现代收藏馆 + 东方雅致 + 数字档案  
- 色：米白 `#F7F5F0` · 暖灰 `#85827B` · 墨青 `#2C3E42` · 深棕 `#4A3F35` · 暗金 `#B99A61`  
- 页面差异化：工作台 / 档案卡 / 主题封面 / 时间轴 / 日历矩阵 / 徽章墙  
- 禁止：大面积亮金、廉价 Card 堆、AI 字样

## 9. 用户闭环

| 动作 | 反馈链 |
|------|--------|
| 新建珍藏 | 首页+珍藏+统计+时间轴+日历+成就 |
| 改状态为已整理 | 待整理-1、统计+、活动日志 |
| 创建主题 | 主题 Tab+首页横滑+成就 |
| 完成计划进度 | 计划卡+回顾+成就 |
| 添加笔记 | 我的笔记列表 |

---

## 10. 华为 3.5 风险检查

| 风险 | 对策 |
|------|------|
| 简单收藏列表 | 多模块 + 计划 + 回顾 + 成就 |
| 假数据 | 零预置藏品；可选首次引导无示例灌数 |
| 单一页面 | 5 Tab + 10+ 二级页 |
| AI 字样 | 仅用「智慧整理」 |
| 权限 | 维持 `requestPermissions: []`，PhotoViewPicker 选图 |

---

## 11. 权限检查

**新增系统权限 = 0**（不申请相机/定位/通讯录等）

## 12. 开发优先级

| 优先级 | 任务 |
|--------|------|
| P0 | 模型+Store 扩展、5 Tab、藏间首页、档案字段、活动日志 |
