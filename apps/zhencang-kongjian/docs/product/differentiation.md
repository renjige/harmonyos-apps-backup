# 差异化说明 — 珍藏空间

对比 avoidSlugs：`shiyi-shouzhang`、`ximan-guan`

1. **核心实体不同**：TreasureItem 档案（来源/保管/轨迹）vs 手账 JournalEntry
2. **主 Tab 不同**：藏品/探索/统计/我的 vs 拾意/手账/回顾/我的
3. **档案完整度**：8 字段完成度闭环，非手账心情记录
4. **珍藏轨迹**：时间线事件维护，非日记时间线
5. **探索页**：按年/类/主题分析用户藏品，非月历回顾
6. **珍藏册**：主题合集，非「我的拾意」句子收藏
7. **视觉气质**：曜石黑+香槟金收藏馆 vs 雾霭莓紫手账纸
8. **无 AI Tab / 无诊断问卷**：纯档案管理工具
