# 功能清单 — 珍藏空间

## 核心闭环（建档 → 整理 → 主题 → 计划 → 回顾）

- ✅ 藏间首页工作台（数量、最近入藏、主题、待整理、计划、时光回顾）
- ✅ 珍藏档案 CRUD（状态、故事、鉴赏卡、标签、完整度）
- ✅ 列表 → 详情 → 编辑 / 对比 / 删除（回收站）
- ✅ 主题册创建 + 主题详情（添加/移出珍藏）
- ✅ 收藏领域可视化（无定位）→ 珍藏 Tab 筛选
- ✅ 收藏计划（目标、进度、列表）
- ✅ 收藏清单 + 可编辑模板（待收藏 / 想寻找）
- ✅ 珍藏笔记库
- ✅ 智慧整理（规则推荐，无「AI」字样）
- ✅ 全局搜索（珍藏 / 主题 / 计划）
- ✅ 回顾 Tab：回顾 / 时间轴 / 交互日历 / 统计
- ✅ 成就墙
- ✅ 首屏引导（ onboarding ）
- ✅ 导出档案（剪贴板）
