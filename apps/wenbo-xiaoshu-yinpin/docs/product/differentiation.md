# 消暑饮品 · 差异化说明

对照仓库内相近交付，本 App **不是换皮**。

## 对照 1：厨房妙想（`wenbo-chufang-miaoxiang`）

| # | 消暑饮品 | 厨房妙想 |
|---|----------|----------|
| 1 | 核心实体是「一杯消暑饮」：冰量、甜度、时段、体感温度区间 | 核心实体是「一道家常菜」：食材库存与妙想搭配 |
| 2 | 首页是体感滑杆 + 智慧推荐杯，不申请定位 | 首页是厨房清单 / 食材灵感，不是气温配饮 |
| 3 | 分类固定为冰饮 / 果茶 / 奶昔 / 冰沙 / 凉茶 | 分类是菜系或食材维度 |
| 4 | 三级动作是收藏这杯 + 记下试做 | 三级动作是备菜 / 妙想记录 |
| 5 | 配饮问卷按体感、忌口、手头工具匹配一杯 | 问卷或灵感围绕「今晚吃什么」 |
| 6 | 视觉是玻璃杯、冰块、薄荷、冰蓝主色 | 视觉是灶台、菜肴、暖厨房色 |

## 对照 2：避暑游记（`wenbo-bishu-youji`）

| # | 消暑饮品 | 避暑游记 |
|---|----------|----------|
| 1 | 场景在家里的杯子里，不涉及目的地 | 场景是出行目的地、路线与游记 |
| 2 | 栏目是 22 款自制饮配方 | 栏目是景点 / 攻略 / 游记 |
| 3 | 用户活动是试做记录（空起步） | 用户活动是游记或收藏行程 |
| 4 | 智慧来自体感温度 × 时段规则 | 智慧来自出行季节 / 目的地匹配 |
| 5 | 详情 CTA 是收藏与记下试做，无支付 | 详情 CTA 是收藏目的地或写游记 |
| 6 | Logo 是深海青底玻璃杯 + 薄荷叶 | Logo / 影像走旅途与风景，不是杯具 |

## 本 App 独特能力（必须保留）

1. 体感温度滑杆（24–40℃），**不申请定位**
2. 按时段（清晨 / 正午 / 午后 / 晚间）加权推荐
3. 每杯标注冰量、甜度、功效、食材与步骤
4. 配饮问卷规则匹配到具体 `drinkId`，可打开详情
5. 试做记录与收藏按登录用户隔离，新用户为空
6. 冰蓝 + 薄荷 + 珊瑚强调的温暖极简饮品视觉，与厨房 / 游记明显不同
