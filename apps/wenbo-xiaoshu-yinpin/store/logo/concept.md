# Logo Concept — 消暑饮品

- 公司 / App / 行业：魏文波 · 消暑饮品 · summer-drinks
- 品牌关键词：Cool / Refresh / Glass / Mint / Everyday
- 核心元素（仅 2）：玻璃杯轮廓 + 一片薄荷叶
- brandAnchor：消（消暑的「消」，图形表达为杯中暑气被水波「消去」）
- 禁止项自检：无渐变球、无发光、无 3D、无冰块写实堆砌、无柠檬插画过密、无 AI 大脑
- 色板：深海青底 #0B3A48 + 近白标 #F4FBFF（仅 2 色）
- 对比策略：背景 #0B3A48 / 前景 #F4FBFF。深底浅标，灰度后杯形仍清晰；禁止冰蓝标叠冰蓝底
- 行业模板对比：
  1. 不是厨房妙想的「勺+星」
  2. 不是避暑游记的「山峰+云」
  3. 不是清凉衣橱的衣架形
