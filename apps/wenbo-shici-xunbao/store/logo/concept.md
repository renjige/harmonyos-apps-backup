# Logo Concept — 诗词寻宝

- 公司 / App / 行业：魏文波 · 诗词寻宝 · 古典诗词闯关
- 品牌关键词：Ink / Seal / Verse / Discovery / Restraint
- 核心元素（仅 2）：方印轮廓 + 「诗」字；印角罗盘针为附属切角，不单算第三主体
- brandAnchor：诗（印章式汉字，不做毛笔写实插画）
- 禁止项自检：无渐变球、无放大镜套模板、无藏宝箱 3D、无 AI 大脑、无圆角裁进资源
- 色板：2 色 — 墨黑 `#1A1A2E` + 鎏金 `#C9A84C`
- 对比策略：App Icon 深底金标；转灰度后印框与「诗」字仍清晰
- 行业模板 vs 本稿：
  1. 非亲子智谜的星球谜盒
  2. 非读书札语的翻开书脊
  3. 非教育类铅笔/书包卡通
