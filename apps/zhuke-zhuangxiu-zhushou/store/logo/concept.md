# Logo Concept — 筑科装修助手

- 公司 / App / 行业：筑科 / 筑科装修助手 / 装修过程记录
- 品牌关键词：Structure / Record / Home / Order / Trust
- brandAnchor：筑（几何屋顶 + 结构支撑，不写「筑」字）
- 核心元素（2）：建筑折线屋顶 + 小型完成勾选
- 禁止项自检：无锤子扳手油漆刷、无写实房子、无工人剪影、无 3D、无渐变球、非 premium_logo house+cloud 模板
- 与家庭事项差异：家庭事项为墨绿底 + 暖米白屋檐勾；本稿为深蓝底 `#1D4ED8` + 白结构 + 青绿勾 `#10B981`
- 色板：深蓝底 + 白标 + 青绿勾（≤2 主色，勾为强调点）
- 对比策略：背景 #1D4ED8 / 前景 #FFFFFF，勾 #10B981 落在白结构空隙旁，灰度轮廓仍清晰
