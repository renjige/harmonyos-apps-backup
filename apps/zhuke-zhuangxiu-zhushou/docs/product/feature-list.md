# 筑科装修助手 · 功能清单（正式版 1.0.1）

游客首次进入为**空态**：无示例项目、无示例事项/材料/记录。用户自行创建后才有数据。

## 核心闭环

- [x] 首页：当前项目进度、今日待办、阶段、材料、现场记录
- [x] 项目：创建 / 详情 / 编辑 / 删除（二次确认）；多项目切换
- [x] 清单：事项 / 材料 / 记录 / 费用；筛选；保存与删除后列表即时刷新
- [x] 智能清单：按阶段给出建议事项，可加入当前项目
- [x] 轻量验收：对照勾选（通过 / 待验 / 不适用）
- [x] 面积 / 瓷砖 / 涂料估算（参考，非鉴定）
- [x] 费用备忘：记金额、类别、日期；对照预算；不提供支付
- [x] 施工时间线：事项、材料、记录、费用按日期汇总
- [x] 导出项目纪要到剪贴板
- [x] 现场记录可附相册照片（使用时授权）

## 账号与合规

- [x] 游客可本机记录；写操作无需强制登录
- [x] 注册 / 登录 / 退出；协议勾选在登录页
- [x] 我的 → 设置与隐私：协议全文、撤回同意、注销、清除缓存
- [x] 无「删除业务数据」按钮；无登录页演示账号
- [x] 新用户活动数据为空；栏目模板走平台 API

## 明确不做

- 装修公司案例展示 / 商城 / 在线支付
- 生成式 AI 对话（进度自检为问卷模板）
