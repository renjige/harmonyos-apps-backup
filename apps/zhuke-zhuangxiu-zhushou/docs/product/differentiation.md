# 筑科装修助手 · 差异化

相对仓库内相近产品，本 App 主任务不同：

1. 相对「筑科建筑 / zhuke-jianzhu」：不是企业官网、案例展示或招聘，而是业主侧过程记录。
2. 相对家装案例商城（如艺诚装饰）：不做报价商城、设计师橱窗、活动报名交易。
3. 相对家庭事项（wenbo-jiating-shixiang）：对象是装修六阶段与材料规格，不是日常家务日历。
4. 相对材料验收 / 质量巡查类企业工具：面向家庭业主轻量勾选，不做法务鉴定或工地巡检闭环。
5. 导航只有四 Tab（首页 / 项目 / 清单 / 我的），驾驶舱突出当前进度与今日事项。
6. 「智能装修清单」是按阶段规则推荐事项，禁止聊天窗与「AI」营销字样。
7. 游客可本机读写；登录仅用于同步。无支付、无广告、无社交。
