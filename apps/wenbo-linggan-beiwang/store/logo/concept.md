# Logo Concept — 灵感备忘

- 公司：魏文波 / App：灵感备忘 / 行业：inspiration-handbook
- 品牌关键词：Capture / Memo / Spark / Archive / Clarity
- 核心元素（2）：圆角备忘笺（折角） + 四芒灵感光点（负空间）
- brandAnchor：灵（光点即「灵」；笺面即「备忘」）
- glyphStrategy：semantic-fusion
- 禁止项自检：无灯泡、无笔尖写实、无渐变球、无 3D、无发光、无五角星模板、无人物
- 色板（2）：深紫底 `#2B1748` + 雾白笺 `#F5F6FA`
- 对比策略：近黑紫底 / 近白笺面；折角与光点用底色挖空，24px 仍可辨笺形与四芒
- 行业模板对比：
  1. 非 inspiraton-handbook 默认 spark-notebook 黄底手账
  2. 非「灵感笺」金笺五角星（本稿为白笺 + 四芒负空间）
  3. 非脚手架蓝方块 / premium_logo 房屋云朵
- App Icon：直角 1024 满铺深紫底，系统再裁 squircle；主体居中约 62%
