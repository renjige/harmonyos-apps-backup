# 个人信息收集清单 — 灵感备忘

| 信息 | 场景 | 目的 |
|---|---|---|
| 账号、密码、姓名、手机号 | 注册 / 登录 | 账号识别与登录 |
| 灵感标题、正文、标签、日期、封面标识 | 记录 / 编辑 | 云端同步与整理 |
