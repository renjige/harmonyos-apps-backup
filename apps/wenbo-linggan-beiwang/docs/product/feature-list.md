# 功能清单

应用名称：**转化工作台**

## 核心闭环（华为 3.5 实质功能）

| 场景 | 路径 | 状态 |
|---|---|---|
| 今日灵感提示 | 空间 → 今日灵感提示 → 预填记录 | ✅ |
| 工作台进度 | 空间 Hero：今日进度主卡片 + 四指标 + 进行中计划 | ✅ |
| 今日捕捉打卡 | 空间 / 打卡笺 → 本机记录 → 统计与成就刷新 | ✅ |
| 灵感专题 | 新建专题 → 加入/移出灵感 → 卡片显示「含 N 条灵感」→ 点进详情 | ✅ |
| 成就墙 | 按真实捕捉/钉板/计划/打卡点亮，无预置亮灯 | ✅ |
| 成长统计 | 环形完成率 + 本周每日条数，数据来自真实记录 | ✅ |
| 捕捉回顾 | 今日 / 本周 / 本月按实际条数生成模板回顾 | ✅ |
| 时间轴混排 | 捕捉、打卡、钉板、计划活动串在一起 | ✅ |
| 整理默认列表 | 进入整理即见全部；本周/标签/日期/关键词 + 最新/最早/标题排序 | ✅ |
| 收藏筛选 | 全部 / 文字 / 图片 | ✅ |
| 快记模板 | 空间 2×2：观察 / 配色 / 文案 / 构图 → 预填记录 | ✅ |
| 连续记录 | 登录后按记录日期计连续天数，点卡片继续记 | ✅ |
| 快速记录 / 编辑 / 续写 / 删除 | 记录 Tab；详情编辑；表单「追加续写」；删除二次确认 | ✅ |
| 钉到画板 | 保存时可钉；详情钉入文字卡片 | ✅ |
| 做成创意计划 | 详情内创建计划并打开；三条转化步骤可勾选 | ✅ |
| 灵感转化台 | 空间：捕捉 → 钉板 → 计划 计数与跳转 | ✅ |
| 对照写备忘 | 精选详情 → 三问生成结构化备忘 | ✅ |
| 计划转化步骤 | 详情做成计划后，三条步骤可勾选；列表显示步骤 x/3 | ✅ |
| 再写变体 / 按这篇写一条 | 我的灵感变体；精选仿写预填 | ✅ |
| 复制正文 | 详情复制到剪贴板 | ✅ |
| 本周复盘 | 已并入「今日/本周/本月回顾」 | ✅ |
| 收藏实时刷新 | 添加/取消后空间条带立刻更新 | ✅ |
| 整理 / 时间轴 | 标签搜索；按日期回顾 | ✅ |
| 画板 | 创建；详情展示已钉卡片 | ✅ |
| 删除灵感 | 详情删除 → 最近浏览 + 专题引用同步清理 | ✅ |
| 游客体验 | 未登录空间展示三步体验路径卡片 | ✅ |
| 机构通知 | 我的 → GET /messages | ✅ |


## 账号与合规

- 游客可浏览精选；写操作需登录
- 登录页协议勾选；设置与隐私：协议、撤回、注销
- 无生成式 AI、无支付、无商城、无会员
