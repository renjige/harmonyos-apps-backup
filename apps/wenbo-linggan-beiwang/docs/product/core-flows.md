# 核心闭环

1. **看见就记**：空间「今日灵感提示」→ 预填记录表 → 可选钉到画板。
2. **对照着用**：灵感/精选详情 → 钉到已有画板或「灵感工作台」→ 画板详情可见卡片正文。
3. **转化成计划**：灵感详情「做成创意计划」→ 三条转化步骤可勾选（钉板对照 / 写成下一步 / 本周推进）。
4. **对照精选**：精选详情「对照写备忘」用三问生成一条可复用备忘。
5. **每周回头看**：本周复盘按账号下本周记录、收藏、画板计数生成三步模板（捕捉 / 整理 / 收藏），再跳回记录或整理。
6. **收藏可逆**：详情收藏/取消，或空间收藏条右上角取消；首页收藏列表即时刷新。
