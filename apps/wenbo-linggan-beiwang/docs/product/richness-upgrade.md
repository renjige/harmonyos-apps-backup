# App 丰富度升级方案 — 灵感备忘

> 原则：渐进增强，不推倒重做；每个新模块有真实场景、真实数据和完整闭环；不新增系统权限；不机械套运动/读书模板。

---

## 1. 产品重新定位

**现定位：** 快速记录灵感、整理创意想法、管理个人素材。

**升级后：** 创意工作台。一条灵感要被**捕捉 → 钉到画板对照 → 拆成可推进的计划 → 用专题收纳 → 按周月回顾成长**。  
用户用得越久，自己的捕捉记录、专题、成就和统计越厚，而不是打开永远同一套精选列表。

禁止词维持：无生成式 AI、无支付、无商城、无会员。

## 3. 新增功能列表（均绑定本 App 主题）

已有且保留：捕捉、快记模板、钉板、创意计划+转化步骤、对照写备忘、收藏、搜索、本周复盘。

本次新增（约 10 项，每项有闭环）：

| 模块 | 场景 | 数据 | 闭环 |
|---|---|---|---|
| A 首页工作台 | 打开 App 知道今天有没有捕捉、本周挑战到哪 | 平台条数 + 本地打卡 | Hero 进度 → 去记录 / 去打卡 |
| G 今日捕捉打卡 | 来不及写长文也要留下「今天看见了」 | 本地 Preferences | 打卡成功 → 连续天数/周统计/成就刷新 |
| I 成长统计 | 看本周每天写了几条、计划完成率 | 真实 inspirations/plans | 环形+柱状，禁止假数 |
| J 成就墙 | 首次记录、连续 7 天、10 条、首块画板等 | 条件来自真实数据，解锁写入本地 | 解锁 Toast + 墙面亮灯 |
| K 灵感专题 | 把多条灵感收成「配色研究」「包装节奏」 | 本地专题 + 平台灵感 id | 新建专题 → 加入灵感 → 详情点进灵感 |
| E 整理增强 | 未搜索也能看全部；本周/标签/日期 | 现有 search API | 筛选后进详情 |
| C 收藏筛选 | 按文字/图片、最近收藏 | 现有 favorites | 筛选、取消收藏、数量回写 |
| H 活动时间轴 | 捕捉/钉板/计划/打卡串成一天 | 本地 activity + 灵感列表 | 点击回详情或记录 |
| L 回顾中心 | 今日 / 本周 / 本月 | 真实计数模板 | 从回顾跳去记录或整理 |
| B 最近浏览 | 看过的精选/灵感可回看 | 本地 recent | 空间与整理可点回详情 |
| F 计划可见性 | 首页展示进行中计划均进度 | 现有 plans | 点进计划 Overlay |

不新增：相机/定位等权限、新 Tab、LLM、假按钮、独立「训练中心」类套模板页。

## 4. 页面结构

```
空间（工作台）
  ├ Hero 今日进度 / 本周挑战
  ├ 四指标：记录 · 计划均进度 · 收藏 · 连续
  ├ 快捷操作（记录 / 打卡 / 专题 / 统计）
  ├ 灵感转化台（已有）
  ├ 今日提示 + 快记模板（已有）
  ├ 进行中计划（最多 2 条）
  ├ 最近动态（活动流水）
  ├ 精选 / 最近灵感 / 收藏条（已有）
  └ Overlay：打卡笺、统计、成就、专题、复盘、收藏、时间轴、计划

记录 Tab → 列表 → 灵感详情 → 编辑/钉板/计划/删除（已有）

画板 Tab → 列表 → 画板详情（已有）

整理 Tab
  ├ 本周摘要条
  ├ 搜索 / 标签 / 日期 / 本周
  ├ 默认列出我的灵感
  └ 入口：成长统计、成就墙、回顾中心

我的
  ├ 统计卡（已有，操作后刷新）
  ├ 灵感专题、成就墙、成长统计、回顾
  └ 收藏 / 计划 / 时间轴 / 设置（已有）
```

层级：一级 Tab → 二级列表/专题/成就墙 → 三级详情 → 操作层（打卡/编辑/加入专题）。

---

## 5. 底部导航方案

**维持 5 Tab：空间 | 记录 | 画板 | 整理 | 我的**

理由：已与「灵感手册」差异化；再改成「首页|探索|计划|成长|我的」会变成套模板，且计划已是 Overlay。  
整理从「空搜索页」升级为「检索 + 成长」；计划仍从空间/我的进入，避免第 6 个 Tab。

---

## 6. 数据模型

**平台（不变）：** Inspiration / Board / Plan / Favorite / Featured / TagPreset。

**本地 Preferences `inspiration_growth`，按 username 分桶（游客不写）：**

```
GrowthPayload
├ checkIns[]     { date, note }          每日捕捉打卡
├ topics[]       { id, title, summary, inspirationIds[], createdAt }
├ activity[]     { type, title, refKind, refId, at }   最多 80 条
├ recent[]       { kind, id, title, at }               最多 20 条
└ unlocked[]     已点亮成就 id
```

关联：专题只存灵感 id，展示时 `findInspiration`；成就条件每次用平台列表 + 打卡计算，新解锁才写入 `unlocked`。

## 7. 首页布局

1. **顶：** 问候 + 日期 + 今日是否已捕捉/已打卡  
2. **Hero：** 本周挑战「捕捉 5 条」进度条 + 主 CTA  
3. **四指标：** 记录数 / 计划均进度 / 收藏数 / 连续天数  
4. **快捷：** 记录 · 打卡 · 专题 · 统计  
5. **转化台、提示、模板**（保留）  
6. **进行中计划**（真实 progress）  
7. **最近动态**  
8. **精选 / 最近灵感 / 收藏**

---

## 8. UI 视觉方向

维持雾白 + 创意紫 `#7C3AED` + 活力黄点缀。Hero 用现有摄影 + scrim，不用廉价彩虹块。统计用已有 `AppBarChart` / `AppRingChart` 喂真实数。空态：短说明 + 一个主操作（写第一条 / 去打卡 / 建专题）。

---

## 9. 用户使用闭环

浏览精选 → 对照写备忘或快记模板 → 记录落库 → 可选打卡/钉板/做成计划 → 收入专题 → 整理检索 → 今日/周/月回顾 → 成就点亮 → 首页数字与挑战同步。

一次操作多处更新：打卡 → Hero、连续天数、周柱状、成就、时间轴、我的统计入口。

---

## 10. 华为 3.5 / 权限 / 不破坏

- 有实质闭环（捕捉转化 + 专题管理 + 打卡成长），不是纯展示或空笔记。  
- 创意点：对照三问、画板钉入、计划转化步骤、专题收纳，不是系统备忘录换皮。  
- **0 新增权限**（仍仅 INTERNET）。  
- 成长数据仅本机 Preferences，协议补充说明。  
- 保留现有详情 CTA 与审核已修的钉板/编辑/计划/删除。  
- 不把 `DashboardPage` 假数据接到任何 Tab。
