# 《App 丰富度升级方案》— 灵感备忘

> **执行原则**：渐进增强，不推倒重做；每个模块须有真实场景、真实数据、完整闭环；**0 新增系统权限**；禁止机械套「运动/读书/探索/任务」模板 Tab。  
> **审核背景**：华为 3.7 拒审「简易记录 / 与市面记事本类似」——须强化「创意转化工作台」差异，而非堆按钮。

## 一、现有项目分析（修改前必读）

### 1. 产品定位

| 项 | 内容 |
|---|---|
| App 名 | 灵感备忘 |
| Slug | `wenbo-linggan-beiwang` |
| 行业 Pack | `inspiration-handbook` |
| **现定位（升级后）** | **创意转化工作台**：捕捉 → 钉板对照 → 拆成计划 → 专题收纳 → 日周月回顾 → 成就成长 |
| **禁止定位** | 「智慧记录 / 空白备忘录 / 随手记」——易触发 3.7 |

### 2. 已有功能（✅ 已落地）

**内容层**：平台精选、用户灵感、画板、创意计划、收藏  
**操作层**：创建/编辑/续写/删除、钉板、收藏/取消、搜索、标签/日期/本周筛选  
**计划层**：创意计划、三条转化步骤勾选、±10% 进度、进行中计划展示  
**记录层**：时间轴（活动+灵感混排）、日/周/月回顾、最近浏览（已剔除已删项）  
**成长层**：今日打卡、连续天数、成长统计（环图+柱图）、成就墙（11 枚条件解锁）  
**个性化层**：灵感专题（本地）、快记四模板、对照三问写备忘、变体预填  

**特色闭环（非通用记事本）**：

- 灵感转化台（捕捉→钉板→计划可视化）
- 对照写备忘（三问结构化，非抄原文）
- 计划转化步骤（钉板对照 / 写成下一步 / 本周推进）
- 产品特色首启说明 + 空间「与简易备忘录的差异」四宫格

### 3. 页面结构

```
Index → MainTabPage（5 Tab）
├─ 0 空间 HomePage（工作台）
├─ 1 记录 RecordPage
├─ 2 画板 BoardPage
├─ 3 整理 OrganizePage
└─ 4 我的 MinePage

Overlay（非 Tab，均有返回闭环）：
收藏 / 时间轴 / 回顾 / 计划列表 / 消息 / 打卡 / 成长统计 / 成就 / 专题列表 / 专题详情
详情 Overlay：精选 / 灵感 / 画板 / 计划（Hero + 正文 + CTA）
```

**脚手架残留**：已删除 `DashboardPage` / `AIAssistantPage` / `CoreBizPage` / `PrivacyPage`（未接 Tab）

### 4. 底部导航

**维持**：空间 | 记录 | 画板 | 整理 | 我的  

**不改为**「首页|探索|计划|成长|我的」——避免套模板；计划从空间/我的 Overlay 进入，与「灵感手册」兄弟 App 已差异化。

### 5. 数据模型

| 层 | 存储 | 实体 |
|---|---|---|
| 平台 API | `platform/data/runtime/{tenantId}/` | inspirations, moodBoards, creativePlans, favorites, featured, tagPresets |
| 本地成长 | Preferences `inspiration_growth`（按 username） | checkIns, topics, activity, recent, unlockedAchievements |
| 认证 | 平台 | registered-users + SessionStore |

关联：专题存 `inspirationIds[]`，展示时 `findInspiration`；成就每次用真实列表+打卡计算，新解锁写入 `unlocked`。

### 6. 跳转关系（层级）

| 一级 | 二级 | 三级 | 操作 |
|---|---|---|---|
| 空间 | 精选/灵感卡片 | 详情 Overlay | 收藏/钉板/做计划/对照三问 |
| 记录 | 灵感列表 | 详情 | 编辑/删除/钉板/计划 |
| 画板 | 画板列表 | 画板详情 | 查看钉入卡片 |
| 整理 | 筛选列表 + 最近浏览 | 详情 | 搜索/标签/日期/本周 |
| 我的 | 专题/成就/统计/回顾 | 专题详情→灵感详情 | 打卡/设置 |

### 7. 功能重复

- 空间与「我的」均入口：收藏、计划、整理、回顾 → **保留**（工作台快捷 vs 账户中心），但文案区分职责。
- 时间轴 vs 活动流水：空间「最近动态」为摘要，完整时间轴在 Overlay → **可接受**。

### 8～12. 问题诊断

| 问题 | 状态 |
|---|---|
| 页面空旷 | 整理/记录空态已优化；新用户未登录时部分区块为空 → 需引导文案 |
| 一层详情 | 详情页已 Hero+CTA，B12 已过 |
| 简单记录感 | **3.7 主风险**；已通过转化台/专题/成就/首启说明缓解，Connect 文案与截图仍关键 |
| Demo 感 | 摄影 Hero 已有；禁止接入 DashboardPage 假图表 |
| 持续使用理由 | 打卡+周挑战+成就+专题 → **已具备**，需让用户首屏看见 |

## 三、产品重新定位

**一句话**：创意转化工作台 — 捕捉后钉板对照，再拆成计划与专题回顾。

**用户价值主张**：

> 不是「记完就结束」的备忘录，而是把碎片灵感推进成可对照、可执行、可回顾的创意项目。

**与饱和品类切割**：

| 市面常见 | 灵感备忘 |
|---|---|
| 空白输入 + 列表 | 快记模板 + 转化台 |
| 单条笔记 | 钉板对照 + 三问备忘 |
| 待办打勾 | 计划转化步骤 + 进度 |
| 无成长 | 打卡 / 成就 / 统计 / 回顾 |
| 全员相同 | 专题 + 个人数据沉淀 |

## 八、用户使用闭环

```text
游客浏览精选
  → 登录
    → 快记/提示捕捉
      → 详情：钉板 | 做计划 | 收藏
        → 专题收纳
          → 整理检索
            → 打卡 + 回顾
              → 成就解锁 + 首页 KPI 刷新
```

**一次操作多处更新**（须保持）：

- 捕捉 → 记录数、周挑战、连续、成就、活动、时间轴
- 打卡 → Hero、统计柱、成就、活动
- 收藏 → 空间条带、favoriteEpoch
- 删除灵感 → 列表刷新 + recent prune
