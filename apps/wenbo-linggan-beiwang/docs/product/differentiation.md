# 差异化说明 — 转化工作台 vs 灵感手册（同开发者 · 指南 3.6）

> **上架名称**：本 App 已更名为 **「转化工作台」**（原内部 slug `wenbo-linggan-beiwang`），与 **「灵感手册」** 在名称、Tab、首页、精选内容、主闭环上均做区分。

## 对照表（审核走查用）

| 维度 | 转化工作台（本 App） | 灵感手册（同账号另一 App） |
|---|---|---|
| **名称** | **转化工作台** | 灵感手册 |
| **定位** | 捕捉 → 钉板对照 → 计划步骤 → 专题 → 回顾 | 数字手账 + 创意杂志美学 |
| **Tab** | **转化台 · 捕捉 · 画板 · 归档 · 我的** | 工作台 · 记录 · 画板 · **计划** · 我的 |
| **主色** | 创意紫 #7C3AED + 活力黄 | 海军蓝 #1B2A41 + 薄荷绿 |
| **首页** | Hero + **转化流水线四列看板** + 就绪度评估 + 待转化队列 | 杂志 Hero + 推荐横滑 + 成长打卡 |
| **第四 Tab** | **归档**（搜索/筛选/日周月回顾） | **计划**（创意计划列表 Tab） |
| **计划入口** | 转化台 / 我的 Overlay，含 **三条转化步骤勾选** | 底栏计划 Tab，进度跟踪为主 |
| **独家能力** | **转化流水线看板**、捕捉阶段筛选、就绪度评估、对照三问、转化步骤勾选、专题/成就 | 成长中心、平台打卡、Topics 页 |
| **精选内容** | 转化方法论文章（租户独立 seed） | 通用创意灵感杂志式文章 |
| **Logo** | 紫底备忘笺 + 四芒光点 | 手账 spark-notebook |

## 本 App 不可替代闭环（请优先演示）

1. 转化台 → **转化流水线**（待钉板/待拆计划/推进中/已完成）+ 就绪度评估
2. 精选 → **对照写备忘**（三问结构化输出）
3. 捕捉 Tab → **阶段筛选队列** → 详情 → 钉板 → 计划 → **步骤 x/3 勾选**
4. 归档 Tab → 排序筛选 + **日/周/月模板回顾**
5. 我的 → **灵感专题** + **成就墙** + 成长统计
