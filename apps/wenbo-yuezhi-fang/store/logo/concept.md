# Logo Concept — 悦知坊

- 公司 / App / 行业：魏文波 / 悦知坊 / delight-atelier 轻量知识社区
- 品牌关键词：Delight / Atelier / Clarity / Warmth / Craft
- 核心元素（仅 2）：几何微开书卷折面（两片圆角矩形，开口朝右上）+ 右上角一枚暖橙实心圆点（光，非星芒）
- brandAnchor：「悦」——愉悦求知。书卷是工坊器皿，橙点是「悦」的温度，不是通用图书馆标。
- 禁止项自检：无 AI 模板、无渐变球、无发光、无五角星、无阁楼飞檐、无纸上方 30° 单页金点构图
- 色板：深邃蓝 `#1A2A6C` + 近白 `#F7F4EE` + 暖橙 `#F5A623`（橙仅作单点，算辅助强调）
- 对比策略：App Icon 深蓝底 + 近白折面 + 暖橙点。禁止蓝叠蓝。灰度下折面轮廓仍清晰。
- 行业模板对比：
  1. 识趣阁：阁楼飞檐抽象 — 本稿无建筑轮廓
  2. 纸上方：单页 30° 上扬 + 金点偏页面一角 — 本稿为对开折面，开口更宽
  3. 轻知阁：叶片/薄荷圆 — 本稿无植物形
