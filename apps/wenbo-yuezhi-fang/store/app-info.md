## 应用介绍

悦知坊是面向都市知识爱好者的个人知识工坊，不是资讯聚合或社区。你可以：

1. 按商业、人文、科技、生活、艺术五工坊阅读官方短篇
2. 在工坊台完成对应练习：三问检修、余味札、通知白名单、同一条路计时、临摹三记
3. 用专注计时按 5/10/15/25 分钟阅读，结束写入课业
4. 登录后将篇目收入书坊并自定义标签

全程免费，无内购。不提供生成式对话，不提供用户发帖、评论或公开社区。游客可浏览并完成本机课业。

## 应用审核信息（请粘贴到 AppGallery Connect）

本应用为官方知识阅读 + 个人工坊练习工具，不具备社区/舆论属性：

1. **核心闭环**：发现页「工坊台」提供五种可填写、可保存、可回看/编辑/删除的课业表单，以及专注计时，不是只读卡片列表。
2. **我的课业**：我的书坊 → 我的课业，可查看全部练习记录；删除需二次确认。
3. **私人书坊**：「收入书坊」是登录用户的私人收藏；课业仅保存在本机，不公开、不形成信息流。
4. **1.0.4+ 修复**：跟随系统深色模式，登录/注册与各工坊练习输入框文字对比度符合 UX 规范。
5. **1.0.5 优化**：我的页切换深/浅色后，当前页文字与按钮即时跟随刷新，对比度达标。
6. **1.0.9 修复**：发现页卡片详情「收入书坊 / 移出书坊 / 保存标签」及工坊保存、专注计时、我的页等提示，统一为顶层高对比 Toast（深色模式白字蓝底），不再被详情层遮挡。
7. **1.0.10 修复**：退出登录后「我的」书坊统计与「我的书坊」列表即时清空，无需重进界面。
8. **1.1.0 内容丰富**：官方知识卡扩至 20 篇；新增专题路线（5 条可执行阅读路径）、阅读进度与同工坊推荐；每日精选扩至 8 期。核心仍是「读完就练一页」工坊课业，非纯卡片浏览。
9. 旧版「灵感广场」已下线。请以 1.1.0 界面与介绍为准。

## 审核演示建议（约 3 分钟）

**建议设备开启深色模式**，验证输入框文字可见：

1. 发现 → **专题路线**任点一条 → 按序读 3 篇 → 做对应工坊练习
2. 发现 → 工坊台「三问检修」→ 保存 → 我的书坊看连续阅读/已读篇数
3. 登录后收入书坊 → 我的 → 退出登录 → 书坊数字即时变 0
