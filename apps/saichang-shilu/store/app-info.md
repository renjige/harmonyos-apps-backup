## 应用介绍

赛场拾录帮助球迷和业余球员把看过的比赛做成可复盘的个人档案：记录对阵与结果、用**比赛工作台**完成观赛清单/MVP/预测/多维评价/关联瞬间，**一键生成战报**；支持**预测实验室**、**MVP 排行榜**、**待看清单**、**场馆志**、**观赛周报**，以及球员追踪、球队中心、活跃热力图、双场对比与标签分析。首页提供全局搜索、记忆时间轴、赛季报告与数据洞察。数据仅存本机，不申请相册、相机或定位。

## 审核说明（AGC 版本信息-应用审核信息建议粘贴）

### 针对 3.5 实质价值 / 功能丰富度

本应用不是「仅填写对阵信息的简易日志」，而是围绕**观赛记录 → 复盘 → 分析 → 导出**的完整个人体育记忆工具链，主要能力包括：

1. **赛事档案**：新建/编辑/删除、置顶、状态（待看/已看）、标签、运动类型、时长、场馆、笔记与多维评分。
2. **比赛工作台**（单场深度操作）：观赛准备清单勾选、赛前预测、MVP 提名、关联精彩瞬间、打开复盘问答与时间轴。
3. **复盘体系**：分阶段复盘问答、时间轴回顾、与上一场同项对比提示。
4. **战报与导出**：一键生成文字战报并导出到本地文件；观赛周报汇总导出。
5. **分析工具**：数据洞察（条形图/统计）、双场对比、标签中心、记忆时间轴、赛季报告。
6. **专业扩展**：预测实验室、MVP 排行榜、待看清单、场馆志、球员追踪、球队中心、活跃热力图。
7. **收藏与搜索**：精彩瞬间卡片、全局搜索、归档浏览。
8. **我的**：成就统计、深色模式、本地导出、设置与隐私（协议/撤回/注销）。

建议审核路径：首页 → 赛事 Tab → 任一场次详情 → **比赛工作台** → 清单/MVP/预测；或首页「预测实验室 / MVP 榜 / 待看清单 / 场馆志 / 观赛周报 / 数据洞察」体验完整闭环。
