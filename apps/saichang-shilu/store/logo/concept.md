# Logo Concept — 赛场拾录

- 公司 / App / 行业：拾录体育 · 赛场拾录 · 运动赛事本地记录
- 品牌关键词：Record / Motion / Trust / Precision / Archive
- brandAnchor：**赛**（App 名首字，终点线意象）
- 核心元素（2）：抽象终点线斜切条 + 圆角记录笔触（快门弧）
- 禁止项：无渐变球、无 AI 脑、无机器人、无紫发光
- 色板：#007AFF（华为蓝）+ #FF6B35（活力橙），≤2 主色
- 对比策略：深底 #1A1A2E + 白/近白 Symbol + 橙色 accent 点
- 与行业模板差异：非 house/book 日记 glyph；融合跑道速度与记录符号
