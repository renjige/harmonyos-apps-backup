# 差异化说明 — 赛场拾录

对比 avoidSlugs：`jilei-riji` · `geren-guiji` · `wenbo-saishi-zonglan`

1. **定位**：个人赛事记录 + 观赛清单 + 比赛复盘 + 体育收藏，不是日记、不是只读赛程资讯
2. **清单**：待看 / 已看 / 重点关注，把「看过的比赛」做成可持续维护的档案
3. **复盘双通道**：6 题模板问卷 + 开场到结束时间轴，不是经营诊断换皮，也不是生成式对话
4. **瞬间**：手动文字卡片（标题/时间节点/描述/标签），不申请相册
5. **收藏库**：球队、球员、表现卡、专题夹，构成球迷侧的长期记忆
6. **持续使用**：本周挑战、观赛成就、赛季报告、每日拾录灵感
7. **视觉**：赛道摄影 + 蓝橙运动科技；头像用色板而非相册
8. **边界**：不替代运动健康步数/GPS；无自建隐私弹窗（华为托管）；数据默认本机
