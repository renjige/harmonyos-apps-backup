# 赛场拾录

个人赛事记录、比赛复盘与体育记忆管理工具。

## DevEco 工程

打开目录：`apps/saichang-shilu/app/`

## 上架图标

- 推荐上传：`apps/saichang-shilu/store/logo/preview-1024.png`
- 工程副本：`apps/saichang-shilu/app/AppScope/resources/base/media/app_icon.png`

## 核心功能

- **首页**：我的赛场数据、今日待看、快捷入口、赛季进度、拾录灵感、最近时间轴
- **赛事**：赛事档案 + 待看/已看/重点关注清单、标签与搜索
- **记录**：精彩瞬间卡片、赛场笔记、本周挑战、复盘问卷 / 复盘时间轴
- **收藏**：球队档案、球员档案、专题收藏夹、球员表现卡
- **我的**：色板头像、赛季报告、观赛成就、导出、协议、深色模式

全部为本地 Preferences，**不申请相册/相机/定位等权限**。首次打开使用华为标准化隐私声明托管，无自建隐私弹窗。

## 验收

1. 冷启动直接进首页（不弹自建隐私窗）
2. 记录赛事 → 详情 → 复盘时间轴 / 问卷 → 列表刷新
3. 记录 Tab 添加瞬间文字卡，能显示标题与描述
4. 我的：点色板改头像；开关深色模式后当页文字立刻变色
5. 导出文本有顶部 Toast
