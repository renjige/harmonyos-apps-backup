# 个人信息收集清单

运营者：魏文波  
应用名称：筑科质量巡查

| 信息 | 场景 | 目的 | 存储 |
|---|---|---|---|
| 账号、密码 | 注册 / 登录（可选） | 身份核验 | 服务端账号库；本机会话 |
| 姓名、手机号 | 注册（可选） | 账号资料 | 服务端账号库 |
| 邀请码 | 注册选填 | 渠道标识 | 服务端 |
| 项目 / 巡查 / 问题 / 整改内容 | 用户主动创建 | 质量闭环记录 | 默认本机；登录后可同步 |
| 现场图片 | 用户点击选择照片 | 问题与整改取证 | 本机文件；登录后可同步元数据 |
| 隐私同意状态、通知开关 | 设置 | 合规与提醒偏好 | 本机 |

游客使用时不采集注册资料。不收集定位、通讯录、短信、通话记录或麦克风音频。
