# Logo Concept — 词韵小院

- 公司 / App / 行业：词韵雅集 · 词韵小院 · poetry-courtyard（诗词赏析与格律工坊）
- 品牌关键词：Verse / Courtyard / Cadence / Ink / Restraint
- brandAnchor：词（App 名首字）
- 核心元素（仅 2）：庭院窗棂方框（院）+ 几何重构的「词」字主笔（左三横言旁暗示 + 右竖）
- 禁止项自检：无 AI 模板、无渐变球、无毛笔写实、无印章套「诗」印、无书本插画
- 行业模板对比：
  1. 非诗词寻宝的「诗」方印 + 罗盘针
  2. 非诗词挑战的对战/飞花令图形
  3. 非明阅坊翻开书页 + 光柱
- 色板：墨底 `#2C1810` + 宣纸框 `#F5F0E8` + 朱砂字 `#8B1A1A`（标为两色：框用宣纸、字用朱砂；底不算入标色）
- 对比策略：App Icon 深墨底 + 浅框/朱红字，灰度下窗框与笔画轮廓仍清晰；禁止红叠红
