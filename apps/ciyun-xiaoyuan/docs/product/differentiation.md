# 差异化 — 词韵小院 vs avoidSlugs

对照：wenbo-shici-xunbao（寻宝闯关+地图）、wenbo-shici-tiaozhan（每日挑战+飞花令）、shiyi-shouzhang（生活手账）

1. 主实体是「格律检测结果 + 诗库篇目」，不是关卡题目或飞花令对战。
2. 底栏：诗库 / 格律 / 赏析 / 我的，无地图、无挑战记录。
3. 首页工作台 catalog-tool：每日一诗摄影 Hero + 检索与朝代体裁主题芯片，无「开启今日寻宝」、无连续打卡。
4. 核心互动是规则平仄图谱与三韵书，不是答题得诗币。
5. 赏析 Tab 把笺注/背景/评点/译文做成详情闭环，不是图鉴闯关。
6. 品牌：朱砂+宣纸+窗棂「词」字标，非鎏金寻宝印、非手账雾紫。
7. 个人作品保存检测摘记，新用户空；无诗币徽章排行。
