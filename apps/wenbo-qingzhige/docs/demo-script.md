# 演示脚本 · 轻知阁

1. 首次启动 → 直接进入首页（游客可用；无独立隐私首屏）
2. 首页看到「今天，也学一点新的东西」与「今日轻知」主卡片
3. 点卡片进入详情 → 收藏 / 加入复习 / 记录相似内容
4. 知识库按分类浏览；点右下角加号「记录一条知识」并保存（提示：已经收进轻知阁）
5. 知识库进入灵感记录，写一条想法
6. 复习 Tab：逐条「记住了 / 稍后再看 / 下一条」；完成后看连续天数
7. 我的轻知空间：知识总数 / 收藏 / 记录 / 复习；内容管理、分类管理
8. 可选：登录 / 注册（协议勾选；未勾选不可提交）；登录页不展示演示账号
9. 我的 → 隐私设置 → 设置与隐私：协议全文、撤回同意、注销
