# Logo Concept — 轻知阁

- 公司 / App / 行业：魏文波 · 轻知阁 · light-knowledge
- 品牌关键词：Quiet / Page / Pavilion / Clarity / Warmth
- 核心元素（仅 2 个）：展开的书页 + 简化阁檐；一枚金杏色知识光点落在书脊负空间
- brandAnchor：轻（轻启一页，而非厚重书架）
- 行业模板对比：
  1. 不是生活备笺的「单页折角笺纸」
  2. 不是读书札语的厚书堆 / 书签带
  3. 不是 premium_logo 默认 house+cloud
- 禁止项自检：无灯泡、无大脑、无毕业帽、无渐变球、无 3D、无滤镜
- 色板：墨蓝 `#122A36` + 暖米白 `#F6F1EA`（金杏色 `#D4A574` 仅作光点，不计入大面积主色）
- 对比策略：App Icon 用深墨蓝底 + 近白米色书页符号，缩小 24px 仍可辨翻开页与檐线
