# 差异化说明 · 手作心笺

## 与同类 App 的差异

| 维度 | 手作心笺 | 常见换皮 |
|---|---|---|
| 定位 | 手作创作工作台（课堂+记录+成长） | 纯计时/纯日记/社区晒图 |
| Tab | 首页工作台 / 课堂 / 创作三分段 / 成长 | 首页列表 / 社区 / 我的 |
| 数据 | 官方课堂 API + 私人作品/灵感 | 客户端假数据或公开 UGC |
| 工坊 | 嵌入「创作→制作助手」，非独立计时 App | 独立倒计时首页 |
| 合规 | 无评论点赞/无社区，无需安全评估报告 | 公开互动需资质 |

## 审核说明要点

1. **非计时类独立应用**：计时仅为制作助手子功能，主路径是课堂跟做 → 记录作品 → 成长计划。
2. **非社区应用**：已移除评论、点赞、公开互动；用户内容为 private。
3. **功能完整**：列表→详情→CTA（跟做/收藏/记录）；成长页打卡/计划/成就可演示。

## 截图建议（≥5）

1. 首页工作台（进度条 + 四统计 + 快捷操作）
2. 课堂 Tab（搜索 + 分类 + 教程列表）
3. 创作 Tab（作品/灵感/制作助手分段）
4. 成长 Tab（打卡 + 计划 + 成就）
5. 教程详情（Hero + 步骤 + 跟做 CTA）
