# 手作心笺 — UI 设计方案

## 风格包

`soft-editorial` + 定制暖色令牌

## 色彩

| 角色 | 色值 | 用途 |
|------|------|------|
| 奶油白 | #FAF7F2 | 页面背景 |
| 莫兰迪粉 | #D4A5A5 | 品牌主色、Tab 选中 |
| 自然绿 | #8BA888 | 点缀、成就、标签 |
| 深棕灰 | #3D3A36 | 主文字 |

## 组件规范

- 卡片圆角：20–24vp
- 页面边距：20vp
- 图标：HarmonyOS Symbol（AppIcon）
- Hero：摄影图 + 底部 gradient scrim
- Tab：胶囊底 + 显式 icon color

## Logo

信笺轮廓 + 心形 + 纸纹线条 + 自然绿点缀（`store/logo/symbol.svg`）
