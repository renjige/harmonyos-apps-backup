# 演示脚本 — 家用册

1. 打开应用 → **直接进入首页**（无应用内隐私弹窗；系统托管弹窗如已接入以 AGC 为准）
2. 首页查看家庭名称、成员头像、时光轴
3. 点击「上传」→ 从系统相册选择 1～3 张照片 → 确认预览可见 → 填写地点/日期 → 保存
4. 保存后首页列表立即出现缩略图（无需切换 Tab）
5. 点击照片 → 详情可编辑、加入珍藏、删除
6. 相册 Tab → 点「人物/时间/地点」查看自动分册；点顶栏「多选」勾选删除
7. 家庭圈 → 添加成员与纪念日 → 查看上传动态
8. 我的 → 家庭年册 / 搜索 / 设置外观（深色应立即生效）

**说明**：无登录步骤；无需演示账号。
