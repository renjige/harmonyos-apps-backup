# 家用册

**一家人的记忆，一本就够了** — 面向家庭的私密智能相册与生活记录 App。

## DevEco 工程

打开目录：`apps/jiayong-ce/app/`

## 上架图标

- 推荐上传：`apps/jiayong-ce/store/logo/preview-1024.png`
- 工程副本：`apps/jiayong-ce/app/AppScope/resources/base/media/app_icon.png`

## 功能概览

| Tab | 功能 |
|-----|------|
| 首页 | 家庭名称、成员头像、时光轴、智慧回忆、年册入口 |
| 相册 | 人物/时间/地点/珍藏分册、主题册、搜索、多选删除 |
| 家庭圈 | 成员管理、纪念日、邀请码、家庭动态 |
| 我的 | 存储空间、年册/搜索/珍藏、设置与隐私、深色模式 |

## 技术说明

- **本地存储**：Preferences 保存照片元数据，照片文件复制至应用沙箱并以 `file://` 显示
- **无联网**：未声明 INTERNET 权限，数据不上传云端
- **隐私**：接入华为标准化隐私声明托管，应用内不弹首次隐私窗；协议全文见「我的 → 设置与隐私」
- **无「AI」字样**：界面使用「智慧/智能」表述

## 审核演示

1. 打开应用直接进入首页（无应用内隐私弹窗）
2. 点击「上传」从系统相册选择照片，预览可见后保存
3. 首页/相册立即看到缩略图；相册「人物/地点」可看到自动分册
4. 相册点「多选」勾选后批量删除
5. 家庭圈添加成员与纪念日
6. 我的 → 设置与隐私 → 点深色/浅色，当前页立即变色
