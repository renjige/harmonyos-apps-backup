# Logo Concept — 居家章

- 公司 / App / 行业：居家章 · 家庭事务提醒与整理 · home-services / 家庭工具
- 品牌关键词：Home / Seal / Ritual / Warm / Order
- 核心元素（2）：极简房屋轮廓 + 圆形印章环（居家仪式感）
- brandAnchor：居（印章内简化为方形印面，不写完整汉字贴图）
- 禁止项自检：无卡通家庭、无 3D、无渐变球、无紫 AI 光、无 premium_logo 模板
- 色板：前景暖橙 `#FF6B35` + 背景深海军 `#1A3A5C`
- 对比策略：App Icon 深底橙标，灰度后屋脊与印环仍可辨
- 差异化：相对「家庭事项」屋檐+勾选，本稿强调印章环 + 屋体线框，识别为「居家章」
