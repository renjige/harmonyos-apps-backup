# 个人信息收集清单 — 居家章

| 信息类型 | 使用目的 | 是否必需 |
|---------|---------|---------|
| 账号、密码 | 注册登录 | 使用云端同步时必需 |
| 姓名、手机号 | 账号资料 | 注册时填写 |
| 事项名称、日期、时间、分类、备注、负责人 | 计划与打卡 | 用户主动创建 |
| 物品名称、日期、位置、提醒提前量 | 到期系统通知 | 用户主动登记 |
| 备忘标题、标签、正文 | 共享备忘 | 用户主动创建 |
| 家人称呼与角色 | 轮值与负责人 | 用户主动添加 |
| 提醒与重复设置 | 系统通知调度 | 用户主动设置 |
| 本地游客数据 | 未登录时使用 | 可选，仅存本机 |
| 显示模式、默认提醒 | 偏好设置 | 可选 |
| 会话 token | 保持登录 | 登录后自动 |
