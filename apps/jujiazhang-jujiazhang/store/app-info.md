# 应用信息

- 应用名称：居家章
- 版本：**1.7.0**
- 一句话简介：**家庭生活工作台** — 打开即见场景与指南，非简单记事项

## 与「简易记事项」的本质区别

| 维度 | 简易待办 App | 居家章 v1.7 |
|------|-------------|------------|
| 冷启动首屏 | 待办列表 | **「发现」Tab**（8 场景 + 指南 + 手册） |
| 底栏 | 计划为主 | **发现 · 总览 · 物品 · 生活 · 我的** |
| 场景 | 无 | 详情页预览 + 一键生成清单/备忘/计划 |
| 内容 | 空 | 8 篇指南可读全文 + 维护模板 + 家庭手册 |
| 计划 | 首页勾选 | 仅在「生活 → 计划」分段 |

## 审核建议路径（3.5）

1. **冷启动** → 默认在 **「发现」Tab**（左起第一个）
2. 点「周末大扫除」→ **场景详情** →「一键应用到家庭」
3. 切 **物品 Tab** → 冰箱/护照档案；**生活 Tab** → 备忘/清单/计划/日记
4. **总览 Tab** → 有序指数、周报告、到期提醒、家人轮值（无待办勾选列表）

## 截图顺序（必换）

1. **发现 Tab 首屏**（8 场景 + 三指标）
2. **场景详情页**（Hero + 清单/备忘/计划预览 + 一键应用）
3. **居家指南全文**详情
4. **生活 Tab** 五段切换
5. **物品 Tab** 或 **总览 Tab**

## 审核备注模板

> 本应用为家庭生活工作台，非简易待办。请从底栏第一个 Tab「发现」进入，体验 8 大生活场景包（含详情页与一键生成）；「生活」含备忘/清单/计划月历/日记；「物品」含到期提醒。计划功能不在首屏。
