# Logo Concept — 茶香档案

- 公司 / App / 行业：茶香印记 · 茶香档案 · tea-archive（个人茶品档案与品饮记录）
- 品牌关键词：Archive · Leaf · Memory · Quiet · Oriental
- 核心元素（2）：**圆形档案印记** + **茶叶轮廓**（印记内细环为年轮）
- brandAnchor：茶（叶形，非茶壶、非山水、非书法）
- 对比策略：深茶墨绿底 `#1C2E26` + 米白叶形 `#F6F1E8` + 淡金印圈 `#C4A574`
- 行业模板对比：非 house 模板；非茶壶；非茶馆牌匾；非珍藏空间折角档案页
