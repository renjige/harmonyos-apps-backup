# 差异化说明 · 茶香档案

## 与茶知识百科的区别

| 维度 | 百科 / 图鉴 | 茶香档案 |
|------|------------|---------|
| 内容来源 | 预置茶类知识 | **用户自己建档**，新用户茶库为空 |
| 主闭环 | 浏览文章 | **建档 → 品饮 → 评分 → 回顾** |
| 品饮 | 无或附属笔记 | **独立「记录」Tab，一等公民** |
| 价值 | 信息展示（易触审核 3.5） | 个人茶生活沉淀工具 |

## 与仓库内其他 App 的差异

- 不复制「珍藏空间」目录结构：实体是茶品 + 品饮，不是藏品时间线
- 不复制「时光档案」：不是人生阶段，而是茶库柜格 + 品饮体验卡
- 茶墨绿 `#2F4A3C` + 淡金 `#C4A574` + 米白 `#F6F1E8`
- 五 Tab：首页 / 茶库 / 记录 / 回顾 / 我的
- Logo 为圆形茶叶档案印记（叶轮廓 + 年轮），非脚手架默认图

## 主任务（primaryJob）

3 秒内新增一款茶档案，或记下今日品饮。
