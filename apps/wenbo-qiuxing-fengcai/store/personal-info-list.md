# 球星风采 个人信息收集清单

运营者：魏文波  
更新日期：2026-08-20

| 信息类型 | 收集场景 | 是否必需 | 用途 |
|---------|---------|---------|------|
| 用户名 | 注册/登录 | 是 | 账号识别与登录 |
| 密码 | 注册/登录 | 是 | 账号安全验证 |
| 姓名 | 注册 | 是 | 账号资料展示 |
| 手机号 | 注册 | 是 | 账号联系与找回 |
| 关注球星记录 | 点击「关注球星」 | 否（需登录） | 同步关注列表 |
| 赛事提醒设置 | 详情页设置提醒 | 否（需登录） | 本机到期提示与云端同步 |
| 提醒偏好 | 设置提醒时 | 否 | 控制是否在打开应用时展示到期提醒 |

游客浏览球星资料时不收集上述账号与业务写入信息。
