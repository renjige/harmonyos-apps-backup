# Logo Concept — 球星风采

- 公司 / App / 行业：魏文波 · **球星风采** · sports-profiles
- brandAnchor：**星**
- glyphStrategy：semantic-fusion（四芒星 + 风采弧光）
- 品牌关键词：Presence / Archive / Orbit / Highlight / Character
- 核心元素（仅 2）：几何四芒星（「星」）+ 右侧开口弧光（「风采」光晕）
- 禁止项自检：无足球/篮球/奖杯/奔跑剪影、无渐变球、无发光、无跑道圆环套模板、无盾牌雷达
- 色板：底 `#16110D`（暖黑）+ 标 `#F4E6C3`（象牙）——仅 2 色
- 对比策略：暖黑底 + 象牙标，ΔL 极大；转灰度后四芒星轮廓仍清晰。不用青蓝，避免与「球队研判 / 赛事纵览」海军+青/紫撞车。
- App Icon：深底浅标；直角出图，资源内不裁圆角。

## 行业模板 vs 本稿

- 非房屋 / 书本 / 购物袋行业默认 glyph
- 非「赛事纵览」正圆赛场环 + 紫轨迹
- 非「球队研判」盾形 + 雷达十字
- 非健身类奔跑剪影 + 发光轨道（旧稿已弃）
