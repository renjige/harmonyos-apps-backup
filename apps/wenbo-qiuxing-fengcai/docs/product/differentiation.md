# 球星风采 · 差异化说明

## 与同类「球星资讯」App 的差异

| 维度 | 常见模板 App | 球星风采 |
|---|---|---|
| 信息架构 | 单一资讯列表 + 关注 | **5 Tab**：首页工具台 + 球星 + **赛事日历** + 关注 + 我的 |
| 工具能力 | 仅浏览 | **双星数据对比**、**项目专区**、**搜索**、**浏览足迹** |
| 关注体验 | 扁平列表 | **按项目智能分组** + **关联赛程**一键进详情 |
| 提醒 | 无或系统推送 | **应用内智慧提醒**（10/30/60 分钟），打开 App 即提示 |
| 数据 | 客户端假数据 | 平台 API 种子 + Admin 可改，前后端同步 |
| 形态 | 资讯聚合 | **百科工具**：资料 + 赛程 + 对比 + 提醒闭环 |

## 核心创作理念

面向体育爱好者提供「发现 → 深读 → 对比 → 关注 → 不错过比赛」的完整工具链，而非简单新闻罗列。

## 上架说明要点（供审核对照）

1. 游客可浏览球星资料、赛程、项目专区、对比工具（选星后可见结果）。
2. 登录后可关注球星、设置赛事提醒、同步关注列表。
3. 首页提供快捷入口：球星对比、赛事日历、浏览足迹。
4. 每条球星/赛事均可进入独立详情页，含封面 Hero 与可执行操作（关注/提醒/分享/查看关联）。
