# 球星风采 · 功能清单

> 更新：2026-08-27（针对华为审核 3.5 功能丰富度升级）

## 核心闭环

| 闭环 | 路径 | 状态 |
|---|---|---|
| 发现球星 | 首页/球星 Tab → 搜索或分类 → 球星详情（Hero+成就+数据） | ✅ |
| 赛事日历 | 赛事 Tab / 首页近期赛程 → 赛事详情 → 设置提醒 | ✅ |
| 双星对比 | 首页「球星对比」→ 选 A/B → 横向数据对照 → 进详情 | ✅ |
| 项目专区 | 首页项目入口 → 足球/篮球等专区 → 球星+赛程 | ✅ |
| 关注整理 | 登录 → 详情关注 → 关注 Tab 按项目分组 + 关联赛程 | ✅ |
| 观赛计划 | 赛事详情/首页 → 加入计划 → 倒计时 → 标记已看/移出 | ✅ |
| 球探笔记 | 详情或工具入口 → 打分 + 备注 → 保存/编辑/删除 | ✅ |
| 知识挑战 | 首页入口 → 作答 → 计分 → 再来一轮 | ✅ |
| 分享卡片 | 详情 → 复制球星/赛事卡片文本 | ✅ |
| 消息通知 | 消息中心 → 机构广播 | ✅ |

## Tab 与页面

| 模块 | 功能 | 状态 |
|---|---|---|
| 首页 | Hero、快捷工具、数据概览、项目专区、近期赛程、热门球星、浏览足迹 | ✅ |
| 球星 | 搜索、分类筛选、列表、详情 | ✅ |
| 赛事 | 分类+状态筛选、赛程列表、赛事详情、提醒 | ✅ |
| 关注 | 按项目智能分组、关联赛程 | ✅ |
| 我的 | 登录/注册、设置与隐私、撤回/注销、清除缓存 | ✅ |

## 合规

| 项 | 状态 |
|---|---|
| 协议勾选在登录页 | ✅ |
| 无独立隐私首屏 | ✅ |
| 撤回隐私 async + Toast + logout | ✅ |
| 无「删除业务数据」按钮 | ✅ |
| 栏目数据走平台 API | ✅ |
| 新用户关注/提醒为空 | ✅ |
| FeatureFlags.LLM_ENABLED=false | ✅ |

## 非功能（明确不做）

- ❌ 直播 / 社区 / 商城 / 聊天
- ❌ AI 对话 / AI 字样主功能
- ❌ 投注 / 博彩
