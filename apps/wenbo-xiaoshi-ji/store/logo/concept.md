# Logo Concept — 小事记

- 公司 / App / 行业：魏文波 / 小事记 / micro-moment（30 秒生活小事记录）
- 品牌关键词：Warm / Capture / Trace / Simple / Intimate
- brandAnchor：小
- 核心元素（仅 2 个）：实心圆点（一件小事）+ 开口短弧（连成生活轨迹）
- 禁止项自检：无渐变球、无发光、无无限符、无笔记本剪贴画、无火箭/灯泡/齿轮
- 色板：深暖橙 `#C44A22` + 白 `#FFFFFF`（2 色）
- 对比策略：App Icon 用深橙底 + 白标，明度差足够大；禁止橙标叠橙底
- 行业模板对比：
  1. 非松岚札「松针/云」
  2. 非溪漫观「溪流弧+日轮」
  3. 非生活札「折角笺纸」
- glyphStrategy：semantic-fusion（「小」的一点与轨迹弧）
