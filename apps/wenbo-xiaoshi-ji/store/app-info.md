# 应用信息

- 应用名称：小事记
- 公司：魏文波
- Bundle ID：xsj.llg.huawei
- 版本：1.1.0
- 分类：生活
- 一句话简介：今日工作台 + 生活记录 + 待办 + 成长复盘，把小事收成个人生活轨迹

## 应用介绍

小事记不是备忘录换皮，而是个人生活记录与回忆管理工具。1.1.0 起采用五 Tab 工作台：

1. **今日**：进度 Hero、四项统计、快捷记/待办/收束、场景模板、最近动态、进行中计划
2. **记录**：生活事件列表、搜索筛选、今日一句引导、随机回忆
3. **待办**：今日/本周/以后三桶；完成后可沉淀回时间线
4. **成长**：本周对照、里程碑、标签分布、动态条带；时光轴 / 见解 / 复盘 / 心情 / 打卡 / 专题 / 纪念日
5. **我的**：昵称统计、全局搜索、导出、设置与隐私

数据只保存在本机，无社交、无支付、无生成式对话。首次隐私声明由华为应用市场托管。

## 审核演示建议

1. 今日 Tab → 点「写一条小事」→ 选生活分类 → 保存后统计卡片与动态刷新
2. 待办 Tab 输入文字 → 添加 → 勾选完成 → 沉淀一句话到时间线
3. 成长 Tab → 时光轴 / 本周复盘 / 心情轨迹 / 重要纪念日
4. 今日 → 新建生活计划 → 勾选子任务 → 进度回写今日 Hero
5. 我的 → 全局搜索 → 输入关键词命中小事或待办
