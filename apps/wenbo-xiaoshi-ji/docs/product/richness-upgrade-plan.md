# 《App 丰富度升级方案》— 小事记

> 版本基准：**v1.1.0**（五 Tab 工作台已落地）  
> 目标版本：**v1.2.0**（渐进增强，非推倒重做）  
> 原则：每个模块须有真实数据逻辑与完整交互闭环；**0 新增系统权限**

---

## 1. 产品重新定位

**一句话**：个人生活记录与回忆管理 —— 30 秒记下一件小事，待办可沉淀、计划可推进、成长可回看。

**与同类 App 的差异**（已有，须保持）：
- 六类生活事件（非无差别便签）
- 待办 ↔ 小事双向转化（完成沉淀 / 拆成子待办）
- 打卡 + 心情 + 纪念日提醒 + 时光轴 + 专题合集
- 纯本机、无社交、无 LLM

**v1.2.0 定位升级**：从「功能已齐的工作台」→「数据可视化 + 回顾深度 + 成就激励更可见」的生活轨迹产品。

## 3. 新增 / 强化功能列表（v1.2.0 · 仅增量）

> 禁止：空页面、假按钮、重复 Tab、无数据逻辑的入口。

### P0 · 审核与体验硬项

| ID | 功能 | 场景 | 数据来源 |
|----|------|------|----------|
| R1 | **统一刷新链路** | 记小事/完成待办/星标后，今日四卡、成长统计、我的数字同步 | `MomentStore.notifyChanged()` + Tab 切换 bump + `onVisibleAreaChange` |
| R2 | **成长页数据可视化** | 标签分布柱状图、近 7 日记录折线/柱图 | `tagStats()` / `last7DayActivity()` → 已有 `AppBarChart` |
| R3 | **收藏中心** | 我的 → 星标小事 / 专题精选 一页浏览 | `starredNotes()` + `TopicCollection` |

### P1 · 丰富度与 3.5 合规

| ID | 功能 | 场景 | 闭环 |
|----|------|------|------|
| R4 | **本月回顾页** | 成长 → 回顾中心 → 本月：小事数、完成待办、心情摘要、可复制卡片 | `monthNoteCount` + mood trend + wrap 聚合 |
| R5 | **年度回顾（轻量）** | 年末或手动入口：12 个月柱状 + 总记录数 + 最长连续天 | 按 `createdAt` 聚合，无伪造 |
| R6 | **成就墙 Overlay** | 成长页「记录成就」→ 独立徽章墙；解锁 Toast | 扩展 `milestones()` 规则（7/30 天、50 条记录、收藏 10 条） |
| R7 | **本周挑战** | 今日 Hero 下：「本周再记 N 条」进度条（默认 5，可完成即成就） | `weekCompare()` + WritingGoal 等价轻量字段 |

### P2 · 视觉与 IA  polish

| ID | 项 | 做法 |
|----|-----|------|
| R8 | 成长 Tab 分区 | 「数据洞察 / 回顾 / 专题与纪念」三组卡片 + 顶部摄影条，减少纯 ListRow 堆叠 |
| R9 | 空状态统一 | 记录/待办/计划/专题空态均：真图 + 一句引导 + 主 CTA（已有 empty 图，补全待办/计划） |
| R10 | 首页「最近动态」 | 点击更多 → 时光轴（已有链，补显式入口文案） |

**明确不做**（避免换皮 / 权限 / 假丰富）：
- 不加第 6 个 Tab
- 不加相机/定位/麦克风
- 不加 LLM 对话
- 不加平台 API / 登录墙（保持本机 App）

## 6. 数据模型

已有模型足够，**v1.2 仅扩展聚合字段，不新建无法落库的实体**。

```text
MomentNote / MomentTodo / LifePlan / TopicCollection / LifeMemorial  （保持）

新增/扩展（Preferences JSON 内）：
├── WeekChallenge          # 可选：weekKey + target + done
├── AchievementUnlock[]    # 已有 MilestoneBadge，扩展 key 列表即可
└── MonthReviewSnapshot    # 计算型，可不持久化；年度回顾同理按年聚合

MomentStore 新增方法（示例）：
├── monthReview(year, month) → { notes, todosDone, topTag, moodSummary }
├── yearReview(year) → { monthlyCounts[12], totalNotes, maxStreak }
├── chartTagBars() → BarChartItem[]
├── chartLast7Days() → BarChartItem[]
└── bumpVisibleTabs() → notifyChanged + 可选 tabRefresh token
```

关联不变：一次 `saveNote` → 打卡 + 动态 + 首页统计 + 成就判定 + 图表数据源。

- **关键词**：暖纸感、珊瑚橙 + 薄荷点缀、摄影 Hero、留白、HarmonyOS Symbol 细线图标
- **禁止**：紫 AI 光、五色功能块、后台表格风、无图渐变 Banner
- **v1.2 重点**：
  - 成长 Tab 顶部 `calendar_window` / `hero_warm_desk` 窄条 + 数据卡片
  - 图表用 `Theme.chart1～5`，与品牌色一致
  - 成就解锁：轻量顶部 Toast + 徽章色变化（已有 warning/star 色）
  - 浅色/深色正文对比 ≥ 4.5:1（延续 v1.1 校正）

## 9. 用户使用闭环

```text
浏览（今日工作台 / 记录列表）
  ↓
使用（记小事 · 加待办 · 选场景模板）
  ↓
记录（Preferences 落盘 + flush）
  ↓
管理（编辑 / 星标 / 专题 / 计划子任务）
  ↓
回顾（收束 · 周报 · 月报 · 时光轴 · 随机回忆）
  ↓
成长（图表 · 成就 · 连续打卡 · 本周挑战完成）
  ↓
回到今日 Tab（统计 / Hero / 动态同步刷新）  ← v1.2 加固 R1
```

**联动验收用例（v1.2 必测）**：
1. 记 1 条小事 → 今日「记录」+1、成长图表 +1、打卡圆点亮、动态出现
2. 完成待办并沉淀 → 时间线多 1 条、今日「今日完成」+1
3. 星标 → 我的「星标」+1、收藏中心可见
4. 勾选计划子任务 → 今日 Hero 计划进度变化
5. 连续 7 天有记录 → 成就墙解锁「一周坚持」+ Toast

## 12. 验收标准（v1.2.0）

### 产品
- [ ] 提示词 12 类功能中 **≥10 类为「已完成」**，其余 2 类为「已强化」
- [ ] 无空页面、假按钮、假统计
- [ ] 老用户数据越多，首页/成长/我的越「满」

### UI
- [ ] 成长 Tab 含 ≥1 个真实数据图表
- [ ] 首页五层信息仍在，新增挑战条不拥挤

### 交互
- [ ] 任一写操作后 3 秒内相关数字可见更新（切 Tab 或回页即刷新）
- [ ] 成就解锁有 Toast

### 审核
- [ ] 仍属生活记录工具，非备忘录换皮
- [ ] 0 新增权限

---

**结论**：小事记 **v1.1.0 已完成主体「商业级丰富度升级」**；v1.2.0 应聚焦 **数据可视化、回顾深度、成就可见性、刷新可靠性**，而非再加空 Tab 或堆按钮。方案确认后按 §11 顺序实施。
