# 小事记 · 差异化说明

同类「记录 / 待办」应用常见形态是：写两行字、打勾、按日期列表回看。小事记把主任务做成「个人生活记录与回忆管理」，而不是再做一个备忘录。

- **六类生活事件**：日常生活、家庭时光、学习成长、工作记录、兴趣爱好、特别纪念，记下的不是无差别便签。
- **每日打卡 + 心情轨迹**：当天记下即打卡，连续天数可见；六种心情形成近 14 日变化。
- **重要纪念日**：生日、节日等到点系统提醒，把「记得住」做成可执行能力。
- **时光轴生活轨迹**：按日回看、本周对照、本周生活海报可复制。
- **待办 ↔ 小事**：完成待办可沉淀成时间线；一条小事可拆成 1～3 条今日待办。
- 纯本机、无社交无支付无大模型对话，场景完整且可演示。
