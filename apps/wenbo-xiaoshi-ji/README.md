# 小事记

个人生活记录与回忆管理工具：六类生活事件、每日打卡与连续天数、心情轨迹、纪念日系统提醒、时光轴按日回看生活轨迹。待办完成后可沉淀回时间线。数据仅保存在本机。

## 核心能力（1.1.0）

- **五 Tab 工作台**：今日 / 记录 / 待办 / 成长 / 我的
- **今日**：进度 Hero、统计四卡、快捷记/待办/收束、场景模板、最近动态、生活计划
- **记录**：生活事件列表、搜索筛选、今日一句、随机回忆
- **待办**：三桶 + 即时添加 + 完成后沉淀成小事
- **成长**：时光轴、生活见解、复盘中心、心情/打卡/专题/纪念日
- 生活事件六类、每日打卡、心情轨迹、重要纪念日系统提醒
- 全局搜索、活动动态、文本导出
