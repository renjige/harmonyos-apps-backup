# 书页漫游

在书页间漫游，发现属于你的阅读风景。

## 工程路径

- DevEco 打开：`apps/wenbo-shuye-manyou/app/`
- 上架图标：`apps/wenbo-shuye-manyou/store/logo/preview-1024.png`

## 核心功能

1. **每日一书** — 精选书籍节选，收藏 / 稍后读 / 标记读完
2. **阅读轨迹** — 时间线、关键词云、阅读统计
3. **主题书单** — 城市漫游、冬日书单、哲思入门、历史洞见
4. **阅读笔记** — 本机私人笔记（限200字）
