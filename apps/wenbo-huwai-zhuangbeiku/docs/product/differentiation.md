# 差异化说明 · 户外装备库

相对仓库内已有户外/露营/出行产品，本 App 是 **个人克重账本 + 路线就绪度对照 + 山野图鉴**，不是营地杂志、百科馆或清凉指数工具换皮。

| 维度 | 户外装备库 | 对照产品 |
|------|------------|----------|
| 主任务 | 录入装备克重 → 对照精选路线看缺类 → 出门前补件 | 露营玩家：按天数打包营地行程 |
| 核心实体 | 个人装备、图鉴规格、精选路线、就绪度 | 露营玩家：营地/天气规则/打包清单/日记 |
| 首页 | 炭灰 Hero「克重账本」+ 大数字总重 + 2 列装备网格 | 露营玩家：林下营火橙 + 天气卡 |
| 独特能力 | 路线详情按推荐类别对照已录入装备，给出就绪度百分比 | 山野探索：百科/足迹/今日灵感（非账本） |
| 问卷 | 出装检视 6 题：类型/过夜/海拔/负重/涉水/季节 → 类别缺口 | 清凉出行：清凉指数与树荫通勤 |
| 视觉 | 炭灰 #2C2C2C + 落日金 #D4A017；山峰对勾 Logo | 露营玩家丛林绿+橙；禁止复用 |
| 社区 | 官方山野手记 + 本人动态（新用户为空） | 无好友私信、无实时定位 |
| 行业 Pack | outdoor-gear（新建） | camp-player / cool-outing / mountain-explore |

禁止换皮：不得把露营玩家的营地/天气/打包清单改几个字出货，也不得做成山野百科馆。
