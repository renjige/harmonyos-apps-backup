# 个人信息收集清单 · 户外装备库

运营者：魏文波

| 信息 | 场景 | 目的 |
|------|------|------|
| 账号、密码 | 注册 / 登录 | 识别账号、同步装备账本 |
| 姓名、手机号 | 注册 | 账号资料 |
| 邀请码 | 注册（选填） | 渠道记录 |
| 装备名称/品牌/型号/类别/克重/购入日/成色/备注 | 登录后录入 | 克重账本与就绪度对照 |
| 自建路线字段 | 登录后创建 | 保存个人路线 |
| 收藏的路线编号 | 登录后收藏 | 收藏列表 |
| 动态标题与正文、评论 | 登录后发布 | 轻量社区 |
| 访问凭证 | 登录成功 | 本机自动登录 |

游客浏览图鉴、精选路线与官方手记时不采集上表业务字段。
