# Logo Concept — 户外装备库

- 公司 / App / 行业：魏文波 · 户外装备库 · outdoor-gear
- 品牌关键词：Ready / Ledger / Ridge / Weight / Contrast
- brandAnchor：户
- 核心元素（2）：山峰轮廓 + 对勾负形（装备齐全、准备就绪）
- 禁止项自检：无帐篷三角（露营玩家）、无树荫圆环（清凉出行）、无指南针/地球、无渐变球、无 AI 脑
- 色板：炭灰底 #1A1A1A + 落日金标 #D4A017（2 色）
- 对比策略：深炭灰底 / 落日金前景，灰度后山峰与对勾轮廓仍清晰
- 行业模板 vs 本稿：不是营地帐篷、不是百科山脊插画、不是清凉仪表；账本就绪符号
