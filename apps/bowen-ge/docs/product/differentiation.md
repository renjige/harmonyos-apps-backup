# 博闻阁差异化

对照 avoidSlugs：silan-xu、xuejian、wenbo-dushu-zhayu、gewu-ji、siwei-xia

1. **主实体**：博闻阁以 **知识卡片 + 学习记录** 为一等公民；思览叙以思考札记为主。
2. **Tab 结构**：博闻 / **知识** / **专题** / 回顾 / 我的；无独立「灵感」Tab。
3. **收藏体系**：四级收藏夹（待学习/精华/重要/长期保存），非 boolean 收藏。
4. **StudyLog**：独立学习记录实体（日期/主题/收获/总结），思览叙无此类型。
5. **首页主任务**：3 秒新建知识卡片 + 连续学习天数；非「写下今日思考」。
6. **Logo**：书阁轮廓 + 展开书 + 光束，brandAnchor「博」；思览叙为展开书页细光。
7. **品牌色**：#1A3347 + #B8956A；workbenchId `knowledge-vault` layoutVariant C。
8. **分类**：科技/历史/阅读/学习/工作/兴趣六类，卡片中心档案柜 UI。
