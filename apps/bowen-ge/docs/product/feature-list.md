# 功能清单 · 博闻阁

- [x] 博闻空间：今日新增、连续学习、档案数字、快捷入口、最近沉淀、智慧回顾
- [x] 知识卡片：创建、编辑、六类分类、标签、四级收藏、状态沉淀、关联专题、删除确认
- [x] 学习记录：日期、主题、内容、收获、总结
- [x] 阅读沉淀：书名、来源、观点、理解、收获、收藏
- [x] 知识专题：创建专题并关联卡片/记录/阅读
- [x] 时间轴回顾
- [x] 知识统计（分类比例、月度趋势）
- [x] 年度知识报告
- [x] 智慧整理（未分类/缺标签/长期草稿/专题建议，无生成式 AI）
- [x] 成长成就墙
- [x] 全局搜索
- [x] 详情 Hero + 正文 + CTA；列表→详情→编辑/删除
- [x] 设置与隐私：协议全文、撤回同意（Toast）、清除缓存、深色模式、导出摘要
- [x] 零系统权限、纯本机、无登录墙
