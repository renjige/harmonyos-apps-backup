# Logo Concept — 思览叙

- 公司 / App / 行业：思览文化 · 思览叙 · 个人思考档案
- 品牌关键词：Clarity / Archive / Reading / Quiet / Growth
- 核心元素（仅 2）：抽象展开书页 + 中间细光
- brandAnchor：思
- 禁止项自检：无大脑、无灯泡、无写实书本、无渐变球、无发光
- 色板：墨底 #12262F + 米白页 #F6F1E8 + 暖金光 #C4A574（2 主色 + 纸色）
- 对比策略：深墨底 + 浅色书页，灰度下轮廓仍清晰
- 行业模板对比：不是时光档案的「时间环+折角」、不是思维匣的「微启匣」、不是格物集的「井字格」
