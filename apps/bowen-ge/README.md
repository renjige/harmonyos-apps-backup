# 博闻阁

个人知识档案与学习整理空间 — 广泛收集，深度沉淀。

## DevEco 工程

打开目录：`apps/bowen-ge/app/`

## 上架图标

`apps/bowen-ge/store/logo/preview-1024.png`

## 核心功能

- **博闻空间**：今日学习、档案数字、连续学习、快捷入口、智慧回顾
- **知识卡片**：创建 / 编辑 / 分类 / 标签 / 四级收藏 / 关联专题
- **学习记录**：日期 / 主题 / 内容 / 收获 / 总结
- **阅读沉淀**：书名 / 观点 / 理解 / 评分（非电子书阅读器）
- **知识专题**：用户自建专题并关联内容
- **回顾**：时间轴、统计、年度报告、智慧整理（规则，非 AI）
- **成就墙** + 全局搜索 + JSON 导出

## 数据与权限

- 纯本地 Preferences，零系统权限，无联网
- 新用户无预置业务数据

## 验收

```bash
npm run gate:behavior -- apps/bowen-ge
```
