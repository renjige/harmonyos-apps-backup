# Logo Concept — 知识寻宝

- 公司 / App / 行业：知寻探索 · 知识寻宝 · knowledge-quest
- brandAnchor：**寻**（App 名视觉锚点）
- 品牌关键词：Quest / Atlas / Compass / Discovery / Wisdom
- 核心元素（2）：① 展开的藏宝图式双页（探索） ② 居中极简罗盘针（指引）
- 禁止项自检：无地球、无灯泡、无机器人、无渐变球、无打开书本库存模板直接套用
- 色板：深紫底 #2D1B69 + 金标 #FDCB6E（仅 2 色；白页 #F4EFE4 作为金的浅阶，打印时仍清晰）
- 对比策略：背景 #2D1B69 / 前景 #FDCB6E 与象牙页 #F4EFE4，眯眼可见展开地图轮廓
- 与行业模板差异：不是「一本打开的书」icon；双页是梯形地图折页，中央是菱形罗盘针而非书脊
