# 知识寻宝 · 差异化对照

对照仓内相近产品，本 App **不是换皮**。

| 对照 | 对方主闭环 | 本 App |
|---|---|---|
| 知识探宝（wenbo-zhishi-tanbao） | 每日知识卡片 + 连线匹配 | **主题知识地图通关**，6 题一图，解锁独立宝藏 |
| 诗词寻宝（wenbo-shici-xunbao） | 诗词填空 / 名句寻宝 | 覆盖历史/科学/文化/自然/生活，**非诗词品类** |
| 技能闯关册类 | 技能清单打卡 | 有封面摄影地图、难度星级、解析与 3 次重试 |
| 百科罗列 | 条目列表 | 必须答题才能点亮宝藏，禁止纯信息墙 |
| 答题工具模板 | 题库 + 分数 | 签到智慧值、徽章里程碑、我的宝藏网格 |
| 咨询脚手架 | 经营诊断预约顾问 | 问卷只匹配知识主题，文案禁止「AI」 |

硬差异 ≥6：地图主题、闯关重试、宝藏卡片、徽章、签到、智慧匹配问卷。
