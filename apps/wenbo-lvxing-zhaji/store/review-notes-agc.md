# 华为应用市场审核说明 · 旅行札记

## 针对 50104 §3.5「功能较为简单 / 相册仅内置图」

本版为 **旅行全流程工作台**（非简易日记），且 **相册与札记均支持从手机系统相册导入真实照片**（HarmonyOS PhotoViewPicker，无需 READ_IMAGEVIDEO 权限）。

### 功能矩阵（请按表验收）

| 场景 | 入口 | 能力 |
|------|------|------|
| 出行规划 | 底栏 **计划** | 创建目的地计划、任务清单勾选、进度百分比、每日打卡连续天 |
| 旅行成稿 | 底栏 **札记 → 旅行日记** | 写正文/标签/日期；**从手机相册选封面** |
| 相册策展 | 底栏 **札记 → 旅行相册** | **从手机相册多选** 创建/追加；设封面；全屏预览；移除 |
| 灵感探索 | 底栏 **探索** | 关键词 + 日期 + 标签筛选 |
| 成长回顾 | 底栏 **成长** | 年度/月度统计、成就徽章、时间轴、足迹城市 |
| 收藏沉淀 | 详情页 | 加入旅行收藏；我的可查看 |

### 相册「非仅内置图」复测步骤（约 5 分钟）

1. 使用演示账号登录（见 `store/demo-account.md`，**不在客户端 UI 展示**）
2. **札记 → 旅行相册 → 右下角 + → 创建相册**
3. 点击 **「从手机相册选择」**（首屏第一按钮）→ 系统相册选 2～3 张 **本机真实照片**
4. 填写名称 → 创建 → 进入详情：网格应显示全部照片；张数即时更新
5. 点 **「从手机相册添加」** 再追加 1 张 → 旧照片仍在、数量 +1
6. 点选照片 → **设为封面** → Hero 封面即时更换

### 札记封面复测

1. **札记 → 旅行日记 → +** 新建旅程
2. 点击 **「从手机相册选择封面」** → 选 1 张本机照片 → 保存
3. 详情 Hero 应显示所选真实照片（非内置素材）

### 计划闭环复测

1. **计划** Tab → 创建计划 → 添加 3 项任务 → 勾选 1 项 → 进度条更新
2. **今日打卡** → 连续天数 +1

### 游客路径

未登录可浏览 **探索** 与 **成长** 部分只读能力；写操作需登录（符合 open_optional 设计）。

## 权限说明

- `INTERNET`：同步云端数据
- **无**相机/定位/后台相册权限；选图走系统 PhotoViewPicker，用户主动选择

## 版本说明

若仍见「仅内置图」，请确认安装包为本仓库最新 Release HAP（含 PhotoPickService 与 CoverPhotoField）。
