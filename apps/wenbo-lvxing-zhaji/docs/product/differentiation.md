# 旅行札记 · 差异化说明（50104 §3.5）

## 产品定位

**全流程旅行工作台**，不是「简易日记 + 内置图库」：

| 维度 | 本 App | 简易日记模板 |
|------|--------|--------------|
| 信息架构 | 5 Tab：首页 / 探索 / 计划 / 札记 / 成长 | 单列表 + 我的 |
| 照片来源 | **系统 PhotoViewPicker** 导入本机真实照片 + 可选旅行素材 | 仅内置图或纯色 |
| 规划能力 | 出行计划清单 + 勾选进度 + 每日打卡连续天 | 无 |
| 回顾能力 | 月度统计、成就徽章、时间轴、足迹聚合 | 无或仅计数 |
| 数据闭环 | 平台 API 同步；Admin 可改栏目 | 客户端假数据 |

## 三大主闭环

1. **计划 → 打卡 → 成稿**：计划 Tab 建清单 → 勾选进度 → 每日打卡 → 札记 Tab 写旅程
2. **相册策展**：本机相册多选 → 创建/追加 → 设封面 → 全屏预览 → 移除
3. **探索 → 收藏 → 成长回顾**：探索筛选 → 详情收藏 → 成长 Tab 看统计/成就/时间轴

## 审核可见入口（勿只测示例相册）

- 札记 → **旅行相册** → 创建 → **从手机相册选择**（第一按钮）
- 札记 → **旅行日记** → 新建 → **从手机相册选择封面**
- **计划** Tab → 创建计划 → 勾选任务 → 每日打卡
- **成长** Tab → 数据 / 足迹 / 成就墙

## 与仓库其他 App 差异

- 品牌色 `#E8A87C` 旅行杂志美学；非咨询/工地/教育换皮
- `life-journal` 行业 Pack；实体含 journey / plan / checkin / album
- 无 LLM 对话（合规方案 B）
