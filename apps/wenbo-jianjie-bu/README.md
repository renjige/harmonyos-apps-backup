## 特性（v1.0.3）

- 三个 Tab：**记录 · 整理 · 成长**（记录 Tab 含思考工作台；成长 Tab 含应验率/徽章/思考工坊）
- 工作台：周计划、打卡、收藏中心、回顾中心、高级筛选、活动流、成就墙
- 思考工坊：今日一问 / 本周三问 / 判断台账 / 随机回看 / 金句墙
- 数据仅 Preferences + 沙箱图片，**不申请网络/位置权限**
- 游客即可使用全部功能（无华为账号联网登录）
- 首次启动隐私由华为应用市场托管；应用内不重复弹窗。设置内可查看协议与撤回


## 管理后台

本产品为单机工具，不依赖 SaaS。审核无需 Admin 登录。
