# Logo Concept — 见解簿

- 公司 / App / 行业：魏文波 · 见解簿 · 智慧记录与深度思考工具（insight-book）
- 品牌关键词：Insight / Ledger / Depth / Clarity / Stillness
- 品牌锚点 `brandAnchor`：**见**（看见洞见，而非普通「本」）
- `glyphStrategy`：semantic-fusion
- 核心元素（仅 2 个）：
  1. 翻开的簿页（左右两道弧线，构成「簿」）
  2. 书脊处一枚实心暖金圆点，隐喻「见」——记录中凝结的洞见
- 对比策略：App Icon 用深靛底 `#3B2D8E` + 暖金标 `#F0C27A`，明度差大，灰度轮廓仍清晰；禁止蓝叠蓝
- 行业模板对比：
  1. 非备忘录勾选列表 / 黄便签
  2. 非记事本横线 + 笔尖库存 icon
  3. 非 AI 大脑 / 发光星 / 机器人
- 禁止项自检：无渐变球、无滤镜发光、无 3D、无文字「AI」
