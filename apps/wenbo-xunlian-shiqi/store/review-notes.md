# 华为审核备注（50104-3.5 / 3.1 · 可直接粘贴）

本应用为**运动生活玩法工具**，主功能是跟练计时、随机玩法、呼吸放松、周运动剧本、生活场景一键玩法、动作图鉴与挑战馆，**不是训练计划或打卡记录类 App**。

## 建议审核路径（约 3 分钟）

1. 冷启动 → **默认进入「玩法」Tab**
2. **玩法 Tab** →「今天玩什么」/「呼吸放松」/「动作跟练」/「周运动剧本」/「生活场景」
3. **发现 Tab** → 动作图鉴五专区 + 运动挑战馆 + 任务清单（添加后立即刷新）
4. **成长 Tab** → 月度报告、热力日历、徽章墙
5. **我的 → 设置与隐私** → 用户协议/隐私政策全文即时显示，「我知道了」可见；外观与主题皮肤切换即时生效

## 本版修复（50104-3.1）

- 协议全文 Overlay 层级高于设置页，底部按钮不被遮挡
- 运动任务清单添加后即时刷新
- 周运动剧本「重新生成」即时刷新；开始玩法与「标记完成」分离，不再误翻转完成态
- 主题皮肤切换即时变色
