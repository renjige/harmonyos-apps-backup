# 个人信息收集清单

| 信息项 | 是否采集 | 存储位置 | 用途 |
|--------|----------|----------|------|
| 昵称 | 可选，用户填写 | 本机 | 首页问候展示 |
| 训练日志 | 用户主动创建 | 本机 | 统计、日历、时间轴、成就、挑战进度 |
| 训练挑战 | 用户主动创建 | 本机 | 挑战馆进度与领取完成 |
| 训练计划 / 清单 / 目标 | 用户主动创建或从模板复制后勾选 | 本机 | 习惯培养与进度管理 |
| 动作图鉴 / 训练笔记 | 用户主动加入或创建 | 本机 | 个人动作库、收藏与心得回顾 |
| 复盘选项 | 用户作答 | 本机 | 生成规则模板建议 |
| 活力积分与主题皮肤 | 本机计算 / 用户选择 | 本机 | 趣味激励与界面主题 |
| 主题偏好 | 用户选择 | 本机 | 浅色/深色模式 |
| 协议查阅记录 | 用户在设置中操作 | 本机 | 合规管理，不用于首次弹窗 |

本应用不上传上述信息至云端，不申请运动健康或定位权限。
