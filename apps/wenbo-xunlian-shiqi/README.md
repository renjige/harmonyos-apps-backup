# 训练拾趣

运动玩法工具：跟练计时、今天玩什么、呼吸放松、周运动剧本、生活场景一键玩法、动作图鉴、挑战馆与成长报告。数据默认仅保存在本机。

打开目录：`apps/wenbo-xunlian-shiqi/app/`

## 核心功能

- **玩法 Tab（冷启动默认）**：今天玩什么、呼吸放松、动作跟练、周运动剧本、六大生活场景（晨起/工间/晚间/周末/习惯/随想）
- **首页**：运动玩法入口、活力指数、快捷矩阵、挑战推荐
- **发现**：五专区动作图鉴（可收藏）+ 运动挑战馆（7/21/30 天）+ 清单/笔记/目标
- **成长**：月度报告、分类统计、活力日历、成长时间轴、徽章墙
- **我的**：积分主题、运动档案、导出、设置与隐私

## 数据与隐私

- 跟练、挑战、图鉴、笔记等仅存本机 Preferences
- 无联网、无账号登录、无支付、不申请运动健康或定位权限
- 已接入华为应用市场隐私声明托管，应用内不再弹出首次隐私声明；可在「我的 → 设置与隐私」查阅协议或撤回本机记录
