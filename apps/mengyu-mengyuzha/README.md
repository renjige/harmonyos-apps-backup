# 梦隅札

**梦隅文化** · 智慧型梦境记录与心灵札记应用

## DevEco 工程

打开目录：`apps/mengyu-mengyuzha/app/`

## 核心功能

| Tab | 功能 |
|-----|------|
| 记录 | 文字记录梦境、标签、多选情绪、睡眠时长、语音入口 |
| 札记 | 时间线 / 月历视图、搜索筛选、详情编辑 |
| 洞察 | 情绪趋势、标签云、主题归纳、每周札报 |
| 我的 | 头像昵称、导出 JSON/TXT、设置与隐私 |

## 数据

梦境正文 **仅存本机** Preferences；洞察为规则统计，无大模型。
