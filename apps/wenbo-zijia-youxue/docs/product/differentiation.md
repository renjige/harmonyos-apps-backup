# 差异化说明 · 自驾游学

相对仓库内旅行手账 / 轻漫行产品，本 App 的主任务是 **亲子自驾研学课堂**，不是日记相册，也不是夏日灵感目录。

| 维度 | 自驾游学 | 夏野漫行 | 行程备忘 / 旅行札记 |
|---|---|---|---|
| 主任务 | 选适龄研学路线 → 读分龄百科 → 规划每日学与玩 → 写下手账 | 发现夏日轻路线 → 清单 → 手记 | 备忘条目 / 札记流 |
| 核心实体 | 研学路线 + 景点百科 + 问答 + 家庭行程 | 漫行路线 + 灵感 + 语录 | 备忘 / 日记 |
| 首页 | 「车轮上的课堂」Hero + 四大研学主题筛选 | 「去吹一阵夏风」+ 今日漫行 | 记录流 |
| 详情动作 | 收藏、开始规划、打开百科、趣味问答、打卡 | 收藏、清单、手记 | 编辑条目 |
| 问卷 | 年龄 / 天数 / 主题 → 规则匹配路线 | 「适合今天」六题 | 无或不同 |
| 权限 | 仅 INTERNET；地点手填 | 仅 INTERNET | 可能含相册 |
| 视觉 | 森林绿 #2D8F5C + 暖阳橙；公路与自然人文摄影 | 暖米白 + 山脊太阳气质 | 不同品牌色 |
| 行业 Pack | study-roadtrip | summer-wander | trip-memo / 札记 Pack |

禁止换皮：不得把夏野漫行首页「今日漫行 + 语录」改色出货，也不得把札记时间轴改成路线列表冒充研学。
