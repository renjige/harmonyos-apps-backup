# Logo Concept — 自驾游学

- 公司 / App / 行业：魏文波 / 自驾游学 / 亲子自驾研学
- 品牌关键词：Explore / Grow / Nature / Classroom / Road
- brandAnchor：自
- 核心元素（仅 2）：方向盘圆环 + 翻开书页负空间；暖阳小圆为点缀而非第三主体
- 禁止项自检：无飞机地球定位针、无渐变球、无山脊太阳（与夏野漫行区分）、无火箭灯泡
- 色板：森林绿底 #143D28 + 书页/轮圈米白 #F4F7F2 + 暖阳 #F5A623（≤2 主色，橙为点缀）
- 对比策略：深底 + 浅标，灰度轮廓仍清晰
- 行业模板 vs 本稿：不是房子、不是山、不是单纯书本；是「开车去上课」
