# 个人信息收集清单

运营者：魏文波  
应用名称：自驾游学

| 信息 | 场景 | 是否必须 |
|---|---|---|
| 账号、密码 | 注册 / 登录 | 仅当你选择注册或登录 |
| 姓名、手机号 | 注册 | 注册时填写 |
| 邀请码 | 注册 | 选填 |
| 行程名称、日期、清单、备注 | 规划页保存行程 | 登录后自愿填写 |
| 手账标题、地点标记、正文 | 写研学手账 | 登录后自愿填写 |
| 景点打卡记录 | 景点详情打卡 | 登录后自愿操作 |
| 收藏的路线 / 景点编号 | 收藏 | 登录后自愿操作 |
| 访问凭证 | 登录成功后本机会话 | 登录后 |

游客浏览路线与百科时不收集上表账号与业务写入信息。不收集精确位置、通讯录、相册原图或人脸信息。
