# 差异化说明 · 夏野漫行

相对仓库内「旅行札记」类产品（如 wenbo-lvxing-zhaji），本 App 不是日记相册，而是 **夏日轻路线生活方式目录**。

| 维度 | 夏野漫行 | 旅行札记对照 |
|---|---|---|
| 主任务 | 发现 → 选择路线 → 准备清单 → 写下沿途 | 日记 / 相册 / 回顾 |
| 核心实体 | 漫行路线 + 灵感 + 语录 + 本地清单 | 札记条目 |
| 首页 | 大图 Hero「去吹一阵夏风」+ 今日漫行 | 记录流 |
| 详情动作 | 收藏路线、打开清单、加入手记 | 编辑日记 |
| 问卷 | 「适合今天」六题规则匹配路线 | 无或不同 |
| 权限 | 仅 INTERNET；不申请定位/相机 | 可能含相册 |
| 视觉 | 暖米白 + 森林墨绿 + 夏日暖橙 | 不同品牌色 |
| 行业 Pack | summer-wander | 其他生活记录 Pack |

禁止换皮：不得把札记 App 全文替换成路线目录后出货。
