# 个人信息收集清单

应用：夏野漫行  
运营者：魏文波

| 信息 | 场景 | 方式 | 存储 |
|---|---|---|---|
| 账号、密码、姓名、手机号 | 主动注册 / 登录 | 用户填写 | 业务平台（按租户隔离） |
| 邀请码 | 注册选填 | 用户填写 | 业务平台 |
| 手记标题、地点、正文、心情、日期、配图键 | 新建 / 编辑手记 | 用户主动输入或点选图库 | 本机 Preferences |
| 出行清单条目与勾选 | 出行清单 | 用户勾选 / 新增 | 本机 Preferences |
| 收藏路线编号 | 路线详情收藏 | 用户点击 | 本机 Preferences |
| 访问凭证 | 登录成功 | 系统生成 | 本机 Preferences |
| 意见反馈正文与选填联系方式 | 意见反馈 | 用户填写 | 本机展示（不强制上传） |

不收集：精确位置、通讯录、短信、通话记录、相册原图、人脸、设备指纹广告 ID。
