# Logo Concept — 夏野漫行

- **公司 / App**：夏野生活 · 夏野漫行
- **brandAnchor**：夏
- **glyphStrategy**：semantic-fusion
- **关键词**：Mountain · Sun · Path · Summer · Slow walk
- **核心元素（2）**：山脊剪影 + 夏日太阳；山下一条轻路径作为识别点
- **对比策略**：深林绿底 `#24352B` + 暖米白山形 `#F6F1E8` + 夏日暖橙太阳 `#E07A3D`
- **禁止项**：无飞机、地球、定位针、行李箱、渐变球、AI 模板
- **行业模板对比**：不同于「旅行札记」的手册+折线相机；本标是山野与太阳的生活符号
