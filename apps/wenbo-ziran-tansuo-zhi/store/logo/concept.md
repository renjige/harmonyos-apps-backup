# Logo Concept — 自然探索志

- 公司 / App / 行业：魏文波 / 自然探索志 / 自然户外探索
- brandAnchor：**自**（自然探索志首字）
- 品牌关键词：Nature / Compass / Trail / Forest / Quest
- 核心元素（2）：**山峰轮廓** + **指南针指针**（负空间融合「探索方向」）
- 对比策略：深墨绿底 `#1A1D1F` + 浅标 `#F5F0E8` 与琥珀点缀 `#C49A6C`，ΔL 足够
- 与山野探索差异：本稿强调「叶脉路径」式指南针，品牌色 `#2D5A27` 更深沉森林绿
- 禁止项：无 AI 模板、无渐变球、无 3D
