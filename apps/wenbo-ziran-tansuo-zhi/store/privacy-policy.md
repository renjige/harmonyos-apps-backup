# 隐私政策 — 自然探索志

运营者：**魏文波**  
应用名称：自然探索志  
更新日期：2026年8月

## 一、服务说明

「自然探索志」为户外与自然爱好者提供探索点发现、自然百科浏览与本机探索记录功能。

## 二、我们收集的信息

1. **账号信息（可选）**：注册/登录时的账号、密码、姓名、手机号  
2. **探索记录（本机）**：标题、地点、日期、天气、正文等，默认仅保存在您的设备  
3. **收藏（登录后）**：经 HTTPS 同步至平台租户存储  
4. **设备与日志**：崩溃日志、网络错误码，不含精确行踪轨迹  

## 三、信息使用

- 展示平台栏目（探索点、百科、户外技巧）  
- 保存与展示本机探索记录  
- 登录后同步收藏  
- 账号注册、登录、注销  

## 四、存储与共享

- 探索记录默认不上传云端  
- 栏目内容来自 `https://saas1.qianqi.online` 平台 API  
- 无付费功能，不出售个人信息  
- **不提供生成式文本服务**  

## 五、权限

- **INTERNET**：拉取探索点与百科、账号与收藏同步  

## 六、您的权利

在「我的 → 设置与隐私」可查看协议、清除缓存、注销账号或**撤回隐私同意**。
