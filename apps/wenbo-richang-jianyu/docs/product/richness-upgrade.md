# 《App 丰富度升级方案》日常笺语

> 对标华为审核指南 3.5：实质价值、完整闭环、可持续使用，而不是「多几个入口」。

## 1. 产品重新定位

**日常笺语**不是「写几句日记的工具页」，而是以「写一页」为创作核的 **生活笺台**：

今日进度 → 记录与收藏 → 计划与打卡 → 专题整理 → 回顾与成就

品牌气质保持东方留白 + 数字手帐（暖棕 / 浅金），不做成运动打卡或通用待办套壳。

## 2. 当前问题分析

| 问题 | 现状 |
|---|---|
| 审核观感 | 首页仍是问候 + Hero + 九宫格 + 最近列表，像「简单记录」 |
| 工具孤立 | 心情 / 待办 / 打卡藏在 Overlay，不驱动首页数字 |
| 缺少计划层 | 有目标进度，没有「周期计划 + 任务完成度」 |
| 缺少成长层 | 回顾 Tab 主要是年度统计 + 搜索，没有周/月叙事与成就墙 |
| 收藏偏薄 | 语句收藏只有扁平列表，没有匣子 / 专题 |
| 搜索偏窄 | 只能搜笺语标题，不能跨待办 / 习惯 / 计划 |
| 持续理由弱 | 用户数据没有串成动态时间轴，第二天打开首页变化不明显 |

已保留且不破坏：写一页 / 时光轴 / 相册 / 收藏 / 登录隐私 / 九项生活工具 / 提醒权限。

## 3. 新增功能列表（均有真实数据与闭环）

1. **今日笺台**：心情、笺语、打卡、待办、计划合成进度条与四项 KPI  
2. **首页可执行今日清单**：勾选待办 / 打卡，数字即时回写  
3. **生活计划**：本周 / 本月周期 + 子任务 + 完成度  
4. **成就墙**：14 枚徽章，按真实累计条件点亮  
5. **生活动态**：笺语 / 心情 / 待办 / 打卡 / 计划合成时间轴  
6. **生活专题**：用户自建主题，按标签聚合笺语  
7. **语句匣**：收藏夹分类，收入 / 移出  
8. **全文检索**：关键词 + 类型 + 标签，覆盖笺语 / 待办 / 习惯 / 计划 / 收藏  
9. **本周 / 本月回顾**：由本人数据生成摘要，不是固定文案  
10. **成长 Tab**：把回顾升级为成长笺台（年度笺历仍保留）

## 4. 页面结构

```
笺语（今日笺台）
  ├─ 写一页 → 时光轴详情 → 编辑 / 收藏
  ├─ 今日待办 / 打卡（当场完成）
  └─ 快捷：心情 / 计划 / 搜索 / 成就 / 更多工具

时光轴
  └─ 场景筛选 + 关键词 → 详情

相册
  └─ 列表 → 详情 → 选图创建

成长
  ├─ 本周 / 本月回顾
  ├─ 成就预览 → 成就墙
  ├─ 最近动态 → 生活动态
  ├─ 计划 / 专题 / 搜索
  └─ 年度笺历（原回顾页）

我的
  └─ 收藏（含语句匣）· 工具箱 · 设置与隐私
```

## 5. 底部导航方案

保持 5 Tab，不增空 Tab：

**笺语 | 时光轴 | 相册 | 成长 | 我的**

「回顾」更名为「成长」，避免第三层只有统计数字。

## 6. 数据模型

| 实体 | 关键字段 | 存储 |
|---|---|---|
| Diary / Favorite / Album | 已有 | 平台 + 本地缓存 |
| Mood / Todo / Habit / Goal / Tag / Reminder | 已有 | Preferences |
| Plan + PlanTask | cycle / start / end / done | Preferences |
| ThemeTopic | title / tagName | Preferences |
| QuoteFolder | title / itemIds | Preferences |
| Activity / Achievement | 由上述数据即时计算 | 不另造假库 |

一次勾选待办：列表状态、首页进度、成长统计、成就条件、动态时间轴同时变化。

## 7. 首页布局（今日笺台）

1. 问候 + 日期  
2. 摄影 Hero（今日笺语）  
3. 今日进度条（已完成 x / y）  
4. 四 KPI：笺语 / 完成 / 收藏 / 连续  
5. 快捷：写一页 · 心情 · 打卡 · 计划 · 搜索 · 成就  
6. 今日待办与打卡（可点）  
7. 最近笺语 / 往年今日 / 温暖片段  
8. 「更多生活工具」进入原工具箱（不在首页堆九宫格）

## 8. UI 视觉方向

暖棕纸感、少描边、摄影 Hero + 底部遮罩、卡片留白。禁止彩虹色块九宫格充当丰富度。功能图标继续走 HarmonyOS Symbol。

## 9. 用户使用闭环

浏览精选 → 写一页 / 记心情 → 勾待办与打卡 → 纳入计划与专题 → 收藏进匣 → 周月回顾与成就点亮 → 第二天首页进度与动态已不同。

## 10. 华为 3.5 合规检查

- 不是纯信息展示或单页日记  
- 新增能力都有创建 / 完成 / 回看，不是空按钮  
- 不新增任何系统权限（沿用 INTERNET + 提醒）  
- 不提供生成式 AI  
- 游客可逛；写操作登录  
- 数据随使用沉淀，形成持续使用理由
