# 日常笺语 · 差异化说明

对比参考 App `wenbo-shenghuo-zhaji`（生活札记）：

1. **品牌气质**：东方留白 + 数字手帐，非日系莫兰迪
2. **主色**：暖棕 `#A67B5B` + 浅金 `#D4AF37`，替代莫兰迪橙
3. **首页模块**：「今日笺语」含心情展示 + 今日记录状态
4. **动词体系**：「写一页」替代「写札记」
5. **Tab 命名**：笺语 / 时光轴 / 相册 / 成长
6. **今日笺台**：进度、KPI、计划与成就，而不是九宫格堆入口
7. **收藏模块**：「语句收藏」强调文字片段
8. **Logo**：信笺 + 钢笔 + 光晕 + 时间圆环
9. **问候文案**：晨间/午后/暮色笺语系列
