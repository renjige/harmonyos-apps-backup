# Logo Concept — 日常笺语

- 公司 / App / 行业：魏文波 · 日常笺语 · 生活手帐
- brandAnchor：笺
- 品牌关键词：Letter / Record / Warmth / Stillness / Everyday
- 核心元素（2）：展开的信笺 + 钢笔笔尖
- 行业模板对比：不是通用笔记本/太阳；信笺折线即「笺」；笔尖即书写记录
- 禁止项自检：无渐变球、无外圈光环、无 3D、无时钟第三元素
- 色板：米白底 `#FAF7F2` + 暖棕 `#A67B5B`（雾霾蓝仅作信笺描边）
- 对比策略：浅底 + 深棕主体；灰度后折线与笔尖仍清晰
- 画布：直角 1024×1024；主体约占 68%；四周安全区约 16%；无圆角蒙版（系统自行裁切）
