# 个人信息收集清单 · 日常笺语

| 信息类型 | 字段 | 用途 | 是否必需 |
|---------|------|------|---------|
| 账号 | 用户名、密码 | 登录注册 | 写操作必需 |
| 个人资料 | 姓名、手机号 | 账号识别与找回 | 注册必需 |
| 业务内容 | 笺语标题/正文/心情/场景/日期/标签 | 生活记录、笺历与同步 | 用户主动填写 |
| 本机缓存 | 笺语缓存、心情、提醒、待办、打卡、目标、计划、专题、语句匣、标签 | 保存后立即可见、离线可用 | 写操作产生 |
| 业务内容 | 相册名称/描述/照片标识 | 美好相册与时光册 | 用户主动填写 |
| 业务内容 | 收藏文字/片段 | 语句收藏 | 用户主动填写 |
| 设备 | 型号、系统版本 | 稳定性排查 | 自动采集 |

游客浏览时不采集账号与业务内容。
