## 应用介绍（提交市场时请用此版，勿写「简单日记/回忆」）

日常笺语是 **六大模块** 组成的数字生活笺台：

1. **笺台**：今日进度、六大模块导航、心情、计划摘要、待办打卡。
2. **灵感**：12+ 生活场景模板、本周挑战、精选片段、创作提示。
3. **计划**：周期计划+任务、今日待办、习惯打卡、生活目标（独立底栏 Tab）。
4. **记录**：时光轴、场景预填写作、编辑收藏。
5. **成长**：周/月回顾、近七日趋势、成就墙、生活动态。
6. **我的**：机构通知、语句匣、相册、更多工具。

## 审核补充说明（AppGallery · 1.0.3 · 50104-3.5）

**务必提交 versionName 1.0.3 安装包。** 底栏为：

`笺台 | 灵感 | 计划 | 记录 | 成长 | 我的`（共 6 项）

### 审核员 3 分钟路径

1. 登录演示账号 `auditor@wenbo.local` / `ReviewPass#2026`（见 store/demo-account.md；**客户端不展示**）。
2. 首次启动可见 **功能导览**（4 屏），说明非单一日记产品。
3. 登录后 **计划 Tab** 已有示例计划/待办/打卡/目标（仅审核账号本地数据）。
4. **灵感 Tab**：12 个场景卡片 + 本周挑战 → 点选自动打开写作页（预填框架）。
5. **笺台 Tab**：六大模块横滑条、进度 KPI、心情点选。
6. **成长 Tab**：周月回顾 + 七日趋势图。
7. **我的 → 机构通知**：可见 2 条机构广播（平台 API `/messages`）。

### 与「简单回忆记录」的差异

| 维度 | 本 App |
|------|--------|
| 导航 | **6 个底栏 Tab**，非 1～2 屏日记 |
| 创作 | 灵感页 12+ 场景 + 每周挑战 |
| 执行 | 计划 Tab：计划/待办/打卡/目标 |
| 回顾 | 成长 Tab：趋势/成就/动态 |
| 通知 | 机构通知走平台 API |
