# 私人日记

智能陪伴的私人日记本，记录生活每一刻的温暖与思考。

## DevEco 工程

打开目录：`apps/sikong-siren-riji/app/`

## 核心功能

- **日记撰写**：富文本标记（加粗/斜体/引用）、图片、心情、天气、自动草稿
- **日记管理**：时间线、日历标记、搜索、心情筛选、收藏
- **智慧回顾**：周摘要、月度统计、关键词云、那年今日
- **设置**：应用锁、主题/字号、TXT 导出、隐私协议

## 数据存储

全部日记数据保存在设备本地（Preferences），无云端同步。
