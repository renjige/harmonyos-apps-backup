## 第一步：现有项目分析（1.1.0 真实状态）

### 1. 产品定位

**五感观察练习本**（Observation Practice Journal）——不是备忘录、不是记账、不是日历工具、不是纯日记列表。  
品牌锚点「微」：用五感结构写此刻 → 对照看见变化 → 专题约束练习 → 专辑归档 → 图表与徽章记录成长。  
数据默认本机；可选登录；无 LLM 主路径；配图走系统相册选择器（无 CAMERA 权限）。

### 2. 已有功能（已实现 ✅）

| 层级 | 能力 |
|------|------|
| 写 | 五感填空卡 / 自由观察；标题、标签、相册图、草稿、自动保存 |
| 读 | 志 Tab 列表 → 详情 Hero + 类型徽章 + 正文 + CTA |
| 方法 | 对照观察（并排两篇 + 「这次不同」）；今日微题；七日微观察（按真实写作点亮） |
| 计划 | 观察专题（感官 + 目标篇数 + 进度条 + 起止日） |
| 收藏 | 星标珍藏 + **观察专辑**（自建册子、详情加入专辑） |
| 找回 | 关键词 / 五感 / 标签云 / 日期 / 珍藏 / 排序 |
| 历 | 月历打点、按日列表、补记、**本月回顾**、**观察足迹** |
| 成长 | 五感分布图、近 7 日柱图、六项统计、**徽章墙** |
| 回顾 | 本周回顾、本月回顾、时光胶囊 |
| 账号 | 可选登录注册；协议勾选在登录页 |
| 3.7 呈现 | 首次三屏引导；今日「观察方法」卡片区；详情「五感卡/对照观察」徽章 |

### 3. 页面结构（真实在用）

```
Index → MainTabPage（游客直进）
  ├─ 今日 TodayPage（工作台）
  ├─ 志 TimelinePage（内容中心）
  ├─ 历 CalendarPage（月历 + 足迹 + 本月入口）
  └─ 我的 MinePage（成长 + 专辑/专题/徽章入口 + 设置）

Overlay 链（全局 Stack）：
  详情 EssayDetailPane → 编辑 EssayEditorSheet
  对照 ContrastPane / 周回顾 WeekRecapPane / 月回顾 MonthRecapPane
  专题 ThemeListPane + ThemeEditorSheet
  专辑 AlbumListPane + PickAlbumSheet
  徽章 BadgeWallPane / 登录 LoginPage
```

**未进底栏（须保持禁用）**：HomePage、DashboardPage、AIAssistantPage、MessagesPage、CoreBizPage、PrivacyPage、TagsPage。

### 4. 底部导航（当前）

**今日 | 志 | 历 | 我的**（方案 B，已落地）

| Tab | 职责 | 为何不是「记事本三件套」 |
|-----|------|-------------------------|
| 今日 | 练观察工作台 | 进度 + 方法 + 图表，不是空白首页 |
| 志 | 观察档案库 | 完整筛选，不是单列表 |
| 历 | 按日回看 + 足迹 | 时间维度成长 |
| 我的 | 专辑/专题/徽章/统计 | 个性化沉淀 |

**不采用**「探索 / 计划 / 记录 / 成长」五 Tab 机械模板——「计划」已融入今日专题进度，「成长」在今日图表 + 我的，避免空 Tab。

### 5. 数据模型（当前）

```
MicroEssay（核心）
├── id, title, body, tagsCsv, imagePath
├── dateKey, createdAt, updatedAt, wordCount
├── favorite, senseKey
├── albumId, themeId, kind(card|free|contrast)
└── lastOpenedAt

ObserveTheme（观察专题 / 计划层）
├── title, senseKey, targetCount, startKey, endKey, status

ObserveAlbum（观察专辑 / 收藏层）
├── title, essayIdsCsv

ObserveBadge（徽章 / 成长层）
├── id, unlockedAt

PracticeStore（七日微观察课题状态）
GrowthStore + BadgeService + EssayStatsService
```

存储：Preferences 本机 JSON；`essayDataEpoch` 驱动多页刷新。

### 7. 功能重复（可接受 vs 待优化）

| 重复 | 处理 |
|------|------|
| 本周回顾：今日 + 我的 | 保留；我的行展示动态篇数，今日为快捷入口 |
| 对照/胶囊：今日 + 我的 | 保留；语义为「工作台快捷」vs「工具箱」 |
| 五感图：今日 + 我的 | ✅ 1.1.0 已双端展示，强化成长感知 |

### 8. 当前仍存在的问题（3.7 / 丰富度缺口）

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| P1 | **审核首屏仍可能判为「记录类」** | 高 | 若截图只有列表/详情，缺方法页与对照页 |
| P2 | **对照观察缺「来源链」** | 中 | 对照篇未展示并排来源两篇，深度感不足 |
| P3 | **最近浏览未产品化** | 中 | `lastOpenedAt` 有字段，无「继续阅读」区块 |
| P4 | **年度回顾缺失** | 低 | 模板 L 仅到本月 |
| P5 | **专题/专辑为单 Pane 内切换** | 低 | 功能完整但缺独立 Detail 头图，商业感可加强 |
| P6 | **脚手架页仍留工程内** | 低 | 未进路由，但增加审核误解风险，应删或移出 main_pages |
| P7 | **部分文案仍带「随笔/记录」** | 中 | LegalDocs 等需与「观察练习本」统一（五文件同步） |
| P8 | **空态日历仍偏素** | 低 | 无数据月历可再加强引导写第一张五感卡 |

### 9. 是否仍属「简单记录结构」？

**对外感知：否（若按完整路径体验）** — 有五感卡、对照、专题、专辑、徽章、分布图。  
**对外感知：是（若只扫一眼志 Tab）** — 仍是卡片列表，故 **3.7 拒审风险在「呈现与上架材料」，不在功能绝对数量**。

### 10. Demo 感 / 持续使用理由

| 项 | 1.1.0 状态 |
|----|-----------|
| Demo 感 | 已显著降低（摄影 Hero、方法卡片、图表）；志 Tab 筛选区仍可再紧凑 |
| 持续使用 | 专题进度 + 连续天 + 徽章 + 七日感官课题 + 对照差异 |

## 第二步：问题 / 定位 / 缺失汇总

### 产品重新定位（一句话）

> **微观志 = 带着方法的五感观察练习本**：写（五感卡）→ 比（对照）→ 练（专题）→ 收（专辑）→ 看（图表/徽章/回顾）。

### 与华为 3.7 禁用类目的关系

| 禁用/高风险类目 | 微观志关系 |
|----------------|-----------|
| 记事本 / 日记 | **必须主动差异化**：方法卡 + 对照 + 专题，上架文案禁主标「日记/备忘录」 |
| 打卡 / 计时 / 日历工具 | 不做独立打卡 Tab；「今日已观察」= 真实写作，非空按钮 |
| 计算器 / 木鱼 / 天气等 | 不涉及 |

### 模板 A–L 覆盖度（1.1.0）

| 代号 | 要求 | 微观志落地 | 状态 |
|------|------|-----------|------|
| A | 首页工作台 | 今日 Tab | ✅ 1.1.0 含图表 |
| B | 内容中心 | 志 Tab | ✅ |
| C | 收藏体系 | 珍藏 + 专辑 | ✅ |
| D | 用户创建 | 观察/专题/专辑/对照 | ✅ |
| E | 搜索筛选 | 志 Tab 全量 | ✅ |
| F | 计划系统 | 观察专题 | ✅ |
| G | 打卡 | 今日已写 + 连续天 + 七日感官 | ✅ 观察化，非打卡 App |
| H | 时间轴 | 历·足迹 | ✅ |
| I | 统计 | 五感条 + 7 日柱 + 六项 | ✅ |
| J | 成就 | 徽章墙 | ✅ |
| K | 专题 | 观察专题 + 专辑 | ✅ |
| L | 回顾 | 日/周/月/胶囊 | ⚠️ 缺「年度」 |

**已覆盖 11.5 / 12**；缺口为体验深度与上架呈现，非空白模块。
