# 《App 丰富度升级方案》— 微观志 1.0.5

版本：方案稿 · 2026-08-31  
对象：`apps/wenbo-weiguan-zhi`（当前客户端 **1.0.4**）  
原则：**渐进增强，不推倒重做**；每一个新模块必须有本机数据、完整闭环、与「五感观察」相关。  
禁止：通用待办、通用习惯打卡、空入口、假数据、新增系统权限。

## 0. 现有项目分析（修改前）

### 0.1 产品定位

本地观察随笔。不是备忘录、不是一日一篇日记、不是资讯聚合。  
品牌锚点「微」：用五感把此刻写成可重读、可对照的观察。  
数据默认仅本机；可选登录；`FeatureFlags.LLM_ENABLED=false`；无相机权限（配图走相册选择器）。

### 0.2 已有功能

| 能力 | 现状 |
|------|------|
| 写 | 五感填空卡 / 自由随笔；标题、标签、相册图、草稿、自动保存 |
| 读 | 时间线卡片 → 详情 Hero + 正文 + 珍藏/编辑/删除 |
| 方法 | 今日微题、七日微观察（光声味触色人空）、对照观察、时光胶囊、本周回顾 |
| 找回 | 关键词、五感筛选、标签云、今日/近7日/日期选择器、只看珍藏 |
| 历 | 月历打点、按日列表、补记 |
| 我的 | 六项统计、字号、深色、导出 TXT/MD、设置与隐私 |
| 账号 | 可选登录注册，协议勾选在登录页 |

### 0.3 页面结构（真实在用）

启动：`Index` → `MainTabPage`（游客直进）  
Tab：时间线 / 日历 / 标签 / 我的  
Overlay：详情、编辑、周回顾、对照、设置、协议、导出预览、登录  

工程里仍有脚手架页（`HomePage` / `DashboardPage` / `AIAssistantPage` / `MessagesPage` / `CoreBizPage` / `PrivacyPage`），**未进底栏**，本次不启用、不做成新 Tab。

### 0.4 底部导航

四 Tab。标签页只有标签云 + 点标签跳回时间线，信息过薄。时间线把工作台、筛选、列表堆在同一 Scroll。

### 0.5 数据模型

几乎只有 `MicroEssay`（title/body/tags/image/dateKey/favorite/senseKey/wordCount）。  
另有 `PracticeStore`（七日课题勾选 csv），与随笔弱关联。  
无：专辑、专题、足迹、浏览历史、成就解锁时间。

### 0.6 跳转关系

```
时间线 ──卡片──► 详情 ──编辑──► 编辑页 ──保存──► 时间线刷新
       ├──今日微题/观察卡/自由随笔──► 编辑
       ├──本周回顾──► 周列表 ──► 详情
       ├──时光胶囊──► 随机详情
       ├──对照──► 对照页 ──保存──► 新随笔
       └──标签筛选 / 日期 / 五感 / 搜索（同页）

日历 ──日──► 当日列表 ──► 详情 / 补记编辑

标签 ──点标签──► 切到时间线 + tagFilter

我的 ──统计只读
     ├──本周回顾 / 胶囊 / 对照（与时间线重复入口）
     ├──导出 / 字号 / 深色
     └──设置与隐私
```

### 0.7 功能重复

对照、胶囊、周回顾、七日课题在时间线与我的各出现一次。不是错误，但是「入口堆叠」而非「层次」。

### 0.8–0.12 产品问题（对应华为 3.5 / 3.7）

| # | 判断 |
|---|------|
| 页面空旷 | 标签页空旷；日历无数据时几乎只有格子；我的是统计+设置列表 |
| 点进去只有一页 | 标签：点完就走；成就/专题/收藏夹不存在，无法下钻 |
| 简单记录结构 | **是。** 审核员会看成「写一条 → 列表 → 详情」。五感卡/对照是差异化，但被埋在首屏按钮堆里 |
| Demo 感 | 时间线过长（Hero+微题+Hub+筛选+双日期+列表）；`TimelinePage` 已超 500 行；按钮条偏「功能清单」 |
| 持续使用理由不足 | 连续天数只是数字；七日课题与是否真的写了该感官弱绑定；没有「进行中的观察专题」、没有徽章墙、珍藏只是星标无专辑 |
| 时间线既是工作台又是内容库 | 新用户看不到「今天该做什么」，老用户找不到「我的全部观察」 |

## 1. 产品重新定位

**一句话：** 微观志是「带着方法的观察练习本」，不是空白日记本。

**主任务：** 3 秒打开五感卡写下此刻 → 用专题约束本周写什么 → 用对照看见变化 → 用历与回顾把观察变成自己的档案。

**升级后用户价值（不是功能清单）：**

1. 今天有没有完成一次观察（工作台进度，来自真实随笔）
2. 本周我在练哪一种感官（观察专题，有目标篇数）
3. 旧观察和新观察差在哪（对照，已有，要可换一对、可进详情）
4. 珍藏不是一颗星，而是我自己的专辑（窗边 / 雨天 / 食堂）
5. 用得越久，五感分布、足迹、徽章越像「我的观察史」

**明确不做（避免变成习惯 App / 待办 App，3.7 更差）：**

- 通用待办、番茄钟、习惯打卡日历
- 资讯、课程商城、AI 对话
- 第五个「探索」空 Tab
- 伪造图表数据
- 任何新系统权限

## 2. 当前问题分析（浓缩）

1. **信息架构扁平**：工作台、内容库、方法工具挤在时间线一页。  
2. **标签 Tab 过薄**：像凑数页面。  
3. **计划层缺失**：七日课题是勾选，不是「目标 7 篇 / 已写 3 篇」。  
4. **收藏层过浅**：只有 boolean 珍藏。  
5. **成长层只有数字**：无趋势、无五感分布、无徽章。  
6. **回顾只有近 7 日**：无本月、无足迹时间轴。  
7. **入口重复**：我的页复制时间线能力，没有下钻。  
8. **对照偏一次性**：随机抽一对，不能指定同感官、不能从详情再对照。

## 3. 新增功能列表（映射模板 A–L，全部观察化）

模板里的「计划 / 打卡 / 成就」**不得原样搬来**。下表是微观志自己的 12 项，全部有场景和闭环。

| # | 模板类型 | 微观志落地 | 闭环 |
|---|----------|------------|------|
| A | 首页工作台 | **今日 Tab**：欢迎、今日是否已写、进行中专题进度、四数据卡、快捷写、最近 3 篇、课题/胶囊入口 | 点进度继续写；写完数字与徽章刷新 |
| B | 内容中心 | **志 Tab**：全部观察；关键词 / 五感 / 标签 / 时间 / 珍藏 / 排序；标签云收进本页顶 | 点卡片进详情；筛选结果真实计数 |
| C | 收藏体系 | **观察专辑**：新建专辑、把珍藏篇放入专辑、取消、最近珍藏 | 详情「加入专辑」；我的 → 专辑 → 列表 → 详情 |
| D | 用户创建 | 已有写观察；新增 **新建专题**、**新建专辑**；对照生成新篇 | 创建后出现在工作台/我的 |
| E | 搜索筛选 | 志 Tab 完整筛选条 + 结果空态 | 无匹配时说明如何清除 |
| F | 计划 | **观察专题**：名称、主感官、目标篇数、起止日、完成度 | 写一篇且 sense 匹配则进度 +1；完成可归档 |
| G | 打卡 | **不另做打卡产品**。工作台「今日已观察」= 当天是否有随笔；连续天数沿用现统计；七日课题改为「写过对应感官才算完成」 | 勾选不再单独算完成 |
| H | 时间轴 | **观察足迹**：按日聚合「写了 / 珍藏了 / 对照了 / 专题进度」 | 点事件进详情或专题 |
| I | 统计 | **五感条形图 + 近 7 日篇数柱**（`AppBarChart`，数据来自 EssayStore） | 无伪造；零数据空态 |
| J | 成就 | **观察徽章墙**：首次五感卡、首次对照、连续 7 天、珍藏 10、专题完成、满七感各一篇 | 达成 Toast；我的可点徽章看条件 |
| K | 专题 | 即 F 的观察专题（用户自建「这个月只写声音」） | 专题详情：进度 + 该专题下的篇列表 |
| L | 回顾 | 今日（工作台）/ 本周（已有加深）/ **本月回顾** / 时光胶囊（可限定本月） | 列表 → 详情；计数与我的统计一致 |

以上 12 项均不新增权限。配图仍用现有相册选择器。

## 6. 数据模型（在现有 Essay 上扩展，不换存储引擎）

仍用 Preferences + JSON。`MicroEssay` 旧字段全部保留，旧数据可加载。

```
MicroEssay（已有 + 扩展）
├── id, title, body, tagsCsv, imagePath
├── dateKey, createdAt, updatedAt, wordCount
├── favorite, senseKey
├── albumId        // 所属专辑，可空
├── themeId        // 写入时归属的专题，可空
├── kind           // '' | card | free | contrast
└── lastOpenedAt   // 最近打开详情，用于「最近浏览」

ObserveAlbum 观察专辑
├── id, title, createdAt
└── essayIds[]

ObserveTheme 观察专题
├── id, title, senseKey, targetCount
├── startKey, endKey
├── status           // active | done | archived
└── createdAt

ObserveEvent 足迹（写入时追加，可从 Essay 推导补齐）
├── id, dateKey, at
├── type             // write | favorite | contrast | theme_progress
└── essayId / themeId

ObserveBadge 徽章状态
├── id               // first_card / first_contrast / streak_7 / fav_10 / theme_done / all_senses
└── unlockedAt       // 0 = 未达成
```

关联规则（必须可实现、可测试）：

- 保存随笔 → 足迹 `write`；若有进行中专题且感官匹配 → `themeId` + 专题进度重算  
- 珍藏 → 足迹 `favorite`；可再选专辑  
- 对照保存 → `kind=contrast` + 足迹 `contrast` + 徽章 `first_contrast`  
- 五感卡保存 → `kind=card` + 徽章 `first_card`  
- 删除随笔 → 专辑 id 列表去掉该篇，专题进度重算，足迹可保留或级联删（实现时：**级联从专辑移除，足迹保留「已删除」不展示详情**）

统计全部从上述真实数据聚合。禁止写死 128/36/42。

## 9. 用户使用闭环

```
浏览（今日微题 / 最近 / 志里筛选）
  → 使用（五感卡写下，或对照「这次不同」）
  → 记录（时间线/志、日历打点、足迹）
  → 管理（专辑、标签、专题归档）
  → 回顾（本周/本月/胶囊）
  → 成长（连续天数、五感分布、徽章、专题完成度）
```

一次写入的联动（验收必测）：

保存一篇「声音」观察卡  
→ 今日进度变为已写  
→ 志列表出现该篇  
→ 历当天打点 +1  
→ 若专题主感官是声音则 3/10 → 4/10  
→ 近 7 日柱 +1  
→ 若满足条件解锁徽章并 Toast  

删除该篇：进度、打点、专辑、统计全部回退。

3. 我的 → 新建专题「只写气味」目标 5 篇 → 再写一篇气味 → 进度变化  
4. 详情珍藏 → 加入专辑「窗边」
