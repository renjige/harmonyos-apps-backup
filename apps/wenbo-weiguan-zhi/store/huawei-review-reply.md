## 问题2 功能异常（审核指南 3.1 · 已修复）

### 审核意见原文

> 历-补记这一天：补记的日期不是今天的，显示到今天。

### 根因与修复（1.2.1 / 1.2.2）

- **根因**：日历页「补记这一天」未把用户选中的日期传给编辑器，新建观察默认写入「今天」；列表卡片此前展示「保存时间」而非「观察日」，造成误解。
- **修复**：
  1. 补记时传入 `presetDateKey = 选中日期`，保存写入正确 `dateKey`；
  2. 编辑页顶部显示「补记观察日：xxxx年x月x日」；
  3. 列表/详情优先展示 **观察日**（dateKey），月历打点按观察日统计。

### 请审核员复测步骤

1. 打开 **历** Tab → 在月历点选 **非今天** 的日期（如 3 天前）  
2. 点 **补记这一天** → 编辑页应显示「补记观察日：…（所选日期）」  
3. 填写五感观察卡并保存  
4. 该观察应出现在 **所选日期** 下方列表，月历该日出现打点；**不应**出现在今天  
5. 列表卡片与详情 Hero 显示所选观察日，而非今天

## 问题1 同质化 / 简易记录（审核指南 3.7 · 重点）

### 审核意见原文

> 应用为简易的记录功能，与市场上已有应用类似。

### 我方立场（请审核同事按下列路径体验）

**微观志不是「标题 + 正文 + 列表」的备忘录/日记换皮。**

产品品类：**五感观察练习本**（Observation Practice Journal）。  
核心差异：**方法驱动**——用户不是打开空白页写字，而是按「五感卡 → 对照 → 专题目标 → 专辑归档 → 成长图表 → 按日补记」完成观察练习。

### 与市面「日记 / 备忘录 / 随笔 App」对照

| 市面常见能力 | 微观志对应能力 | 是否独有 |
|-------------|----------------|----------|
| 空白页写日记 | **五感填空卡**（看见/听见/气味/触感/一句判断） | ✅ 结构化，非流水账 |
| 单条保存 | **对照观察**：并排两篇 + 写「这次不同在哪」；详情 **对照来源** 可跳转 | ✅ |
| 无练习目标 | **观察专题**：感官目标篇数 + 进度条 | ✅ |
| 星标收藏 | **观察专辑**：自建册子 | ✅ |
| 仅列表 | **今日工作台** + 继续阅读 + 五感图 + 徽章 + 足迹 + 年/月回顾 | ✅ |
| 三 Tab 记事 | **今日 / 练习 / 历 / 我的**（练习 Tab 首屏为方法入口 + 分类预览，全量列表在二级页） | ✅ |

**1.2.5 强化（专对 3.7）**：
- 今日首屏置顶 **差异化说明条** + **今日练习路径** + **观察方法**（列表下沉，最多 2 条预览）
- 练习 Tab 首屏同样展示差异化说明；全量列表仅在二级「全部观察」
- 历 Tab 标注「按观察日回看 · 五感练习足迹」
- **练习 Tab 首屏** = 观察方法卡片 + 五感卡/对照 **分类区块**（各最多 2 条预览），**不是**打开即全量文本列表
- 全量搜索/筛选列表移至二级 **「全部观察」** 页（从练习 Tab 底部或「查看全部」进入）
- 今日页 **「今日练习路径」**：五感卡 → 对照 → 专题，三步真实进度
- 列表卡片展示 **观察类型** 标签（五感卡/对照/自由）
- **我的 → 观察方法说明** 可重看三屏差异化引导

**请勿仅打开二级「全部观察」列表即判定为日记 App**；须从 **今日练习路径** 或 **练习 Tab 首屏** 进入五感卡/对照/专题完整路径。

### 审核员建议体验路径（约 3 分钟 · 务必从「今日」开始）

1. **今日** → 看 **「今日练习路径」** 与 **「观察方法 ≠ 普通日记」**  
2. 点路径第 1 步 → **五感观察卡** 写一篇 → 路径第 1 步打勾  
3. 点路径第 2 步 → **对照观察** → 保存 → **练习** Tab 五感卡/对照区块可见，或点「查看全部」筛选 **「对照」**  
4. **我的** → **观察专题** → 回今日看专题进度  
5. **历** → 非今日 **补记**（验证 3.1）  
6. 可选：**我的 → 观察方法说明** 重看差异化引导  

### 上架截图建议（≥5 张 · 禁止 5 张都是列表）

1. **今日练习路径 + 观察方法**（首屏，非列表）  
2. 五感观察卡编辑（看见/听见填空）  
3. 对照观察（并排两篇）  
4. **练习** Tab 首屏（方法卡片 + 分类预览，非列表）  
5. 观察专题进度 或 历·补记观察日横幅  

### 一句话说明

微观志是**五感观察练习本**：结构化观察、对照差异、专题练习、专辑归档与成长图表——**不是普通日记或备忘录**。
