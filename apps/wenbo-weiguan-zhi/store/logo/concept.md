# Logo Concept — 微观志

- 公司 / App / 行业：魏文波 / 微观志 / 微观随笔（观察记录）
- 品牌关键词：Micro / Observe / Record / Quiet / Amber
- 品牌锚点 brandAnchor：微（透镜中的观察点）
- 核心元素（仅 2 个）：圆形放大镜 + 镜内两道日志横线（观察与记录融合）
- 禁止项自检：无 AI 模板、无渐变球、无发光、无机器人/灯泡/六边形、无打开书本剪贴画
- 色板：≤2 色 — 墨蓝底 `#1A2A3A` + 象牙白标 `#F5F0EB`（琥珀金仅用于横版点缀，不进 App Icon）
- 对比策略：背景 #1A2A3A / 前景 #F5F0EB — 深底浅标，灰度轮廓清晰，禁止蓝叠蓝
- glyphStrategy：semantic-fusion
- 行业模板对比：
  1. 非知微集「双弧之眼 + 华为蓝微点」
  2. 非灵感备忘「折角备忘笺 + 四芒星」
  3. 非积累日记「笔记本+太阳」；本稿是放大镜+日志横线
