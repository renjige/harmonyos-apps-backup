# Logo Concept — 慧忆册

- 公司 / App / 行业：慧忆智能 · 慧忆册 · wisdom-memory
- 品牌关键词：Memory / Archive / Clarity / Warmth / Order
- brandAnchor：慧（首字；以翻开书页的交叠负空间暗示「开启智慧」，而非写汉字）
- 核心元素（仅 2 个）：重叠翻开的书页弧线（记忆涟漪）+ 一枚琥珀记忆点
- glyphStrategy：semantic-fusion
- 禁止项自检：无大脑、无机器人、无灯泡、无渐变球、无发光、无毛玻璃、无 3D、无 house 模板
- 色板：深蓝底 `#0B2A5C` + 近白书页 `#F7F9FC`；点缀琥珀 `#F5A623`（第三色仅作 1 枚圆点）
- 对比策略：App Icon 用「深海蓝底 + 浅白标」，灰度后书页弧线与琥珀点仍清晰；禁止蓝叠蓝
- 行业模板对比：
  1. 非生活备笺的青绿折角笺纸
  2. 非静时笺米底檀棕时间曲线
  3. 非松岚札翠绿山形松针
