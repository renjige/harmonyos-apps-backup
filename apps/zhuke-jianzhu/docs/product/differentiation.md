# 差异化说明 — 筑科建筑

## 与工厂默认 / 同行业 App 的差异（≥6）

1. **产品定位**：建筑工程企业**展示平台**（宣传/案例/资质/招聘），非巡检 SaaS、非 OA、非 AI 助手
2. **Tab 结构**：首页 · 案例 · 业务 · 资讯 · 我的 — 无 AI Tab、无看板 Tab
3. **首页工作台**：Banner + 企业简介 + 快捷入口 + 精品工程，非 KPI 仪表盘
4. **核心实体**：Project / News / Job / Certificate / GuestMessage，非 Inspection / WorkOrder
5. **视觉气质**：蓝白现代商务 + 建筑摄影影像（industrial-field），非工业巡检深色 HUD
6. **后台能力**：CMS 内容管理（Banner/案例/资讯/资质/招聘/留言/统计），非隐患整改闭环
7. **合规边界**：明确不含支付、AI、UGC、即时聊天，符合华为应用市场展示类审核
8. **品牌色**：Primary `#0B6BCB` + Deep `#0A2540`，Trust & Authority 企业网关风格

## 首页构图

- 顶部品牌 Hero（深蓝底 + 白字）
- 16:9 Banner 轮播（建筑摄影 + 底部渐变遮罩）
- 卡片式区块：简介 / 快捷入口 3×2 / 业务 2×2 / 工程 2×2 / 资讯列表 / 联系 CTA

## 影像差异

- 房建/市政/装饰/园林四类工程封面分图，非单一色块
- Banner 三张独立场景（地标/市政/绿色施工）
