# Logo Concept — 行程备忘

- 公司：魏文波 / App：行程备忘 / 行业：trip-memo
- 品牌关键词：Path / Time / Order / Quiet / Memo
- 核心元素（2）：竖直时间路径上的节点 + 圆角备忘卡片
- brandAnchor：行
- 禁止项自检：无飞机、无行李箱、无地球、无地图针堆、无渐变球、无 3D、无发光、无景点剪影
- 色板（2）：深墨蓝 `#1B2744` 底 + 暖白 `#F6F5F2` 路径/卡片
- 对比策略：深底浅标；24px 仍可辨竖线、圆点与卡片
- glyphStrategy：semantic-fusion（路径节点 + 卡片，呼应「行」的竖笔与停顿）
- 行业模板对比：
  1. 出行备忘用路线+定位点旅行感 → 本稿不用定位针与旅行摄影
  2. 夏野漫行用风景路线 → 本稿不做风景
  3. 约定提醒用铃铛 → 本稿不用铃铛
