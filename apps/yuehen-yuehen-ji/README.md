# 月痕集

情绪记录与月度回顾智慧应用。以「月」为周期，帮助用户记录每日情绪波动，月末生成专属的「情绪月痕报告」。

## DevEco 工程路径

```
apps/yuehen-yuehen-ji/app/
```

在 DevEco Studio 中打开上述 `app/` 目录（非上级 slug 目录），Sync 后编译运行。

- **推荐上传**：`apps/yuehen-yuehen-ji/store/logo/preview-1024.png`
- **工程副本**：`apps/yuehen-yuehen-ji/app/AppScope/resources/base/media/app_icon.png`

## 包名

`com.moonmark.app`

## 核心功能

| Tab | 功能 |
|-----|------|
| 首页 | 每日情绪（8 种可选 1～3）、一句话日记、配图、能量条 1～10 |
| 月报 | 情绪词云、能量曲线、高光 Top3、智慧月度寄语 |
| 画廊 | 日历色点、按情绪筛选、点击看详情 |
| 我的 | 头像昵称、累计统计、情绪分布、导出、设置与隐私 |

## 数据说明

- 全部数据仅存本机 Preferences，无云端、无登录
- 首次启动须同意隐私政策（勾选后可进入）
- 导出为结构化文本文件（应用沙箱 `exports/` 目录）

## 验收步骤

1. 冷启动 → 勾选协议 → 进入首页  
2. 选择情绪 + 写日记 + 调能量 → 保存  
3. 月报页切换月份，查看词云/曲线/寄语  
4. 画廊点击有色日期 → 详情 → 可删除  
5. 我的 → 导出报告 → 设置与隐私 → 撤回隐私同意  
6. 深色模式切换对比度可读
