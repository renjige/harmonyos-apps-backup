# Logo Concept — 悠隅纪

- 公司 / App / 行业：悠隅生活 · 悠隅纪 · quiet-corner（静谧一隅生活记录）
- 品牌关键词：Quiet / Corner / Window / Warmth / Record
- brandAnchor：隅（窗框 / 一角空间）
- 核心元素（仅 2）：圆角方窗棂 + 右上角光线楔形
- 禁止项自检：无心形、无折角纸笺星、无渐变球、无发光、无玻璃、无 3D、无日记本库存剪影
- 色板：胡桃深褐 `#3D2B1F` + 暖杏 `#D4A574`（第三色仅用于横版辅文，不进 App Icon）
- 对比策略：App Icon 用深底浅标——背景 `#3D2B1F`，窗框 `#F4E6D4` / `#D4A574`。灰度后窗棂轮廓仍清晰。
- glyphStrategy：semantic-fusion（窗 = 进入一隅的入口，切角光 = 记录的温度）
- 行业模板对比：
  1. 心笺日常：莓粉心底 + 折纸 → 本稿无心形
  2. 手账拾意：雾紫纸笺折角 + 星 → 本稿无星、无折角纸
  3. 积累日记：日记本块面 → 本稿是窗，不是本
- 几何说明：1024 画板；安全区 ≥25%；窗框落在中心约 60%；十字窗棂；右上内角一块浅色三角光。
- 横版：左 Symbol 右「悠隅纪」
