# 用户协议

运营者：魏文波  
应用名称：悠隅纪  
更新日期：2026-08-26

（全文与客户端 `LegalDocs.agreementBody()` 一致。）

一、服务说明  
悠隅纪是一款轻量个人生活记录应用。你可以在「一隅」按时间写下心情、标签与文字，在「胶囊」随机回顾过去的记录，在「纪事」查看总数、连续天数、本月条数与标签计数。游客即可使用主闭环。可选登录/注册不改变「正文默认保存在本机」的原则。本应用不提供社交、支付、会员、商城或心理诊断，也不提供生成式对话。

二、使用规范  
请合法使用本应用。你对自己写下的内容负责。

三、时光胶囊与纪事  
时光胶囊从你已经写下的本机记录中随机抽取一条。「连续天数」等数字仅统计本地记录，不构成心理评估或医疗判断。

四、数据  
卸载、清空本机记录或撤回隐私同意后，记录可能无法恢复。你可在「我的」导出文字副本到剪贴板。

五、账号  
若选择注册，应妥善保管密码。可在「我的 → 设置与隐私」注销账号。

六、协议更新  
更新后如继续使用，即视为了解变更。如不同意，请停止使用并清空本机数据。

七、联系方式  
请通过华为应用市场开发者预留渠道联系运营者魏文波。
