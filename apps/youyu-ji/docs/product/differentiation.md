2. **Tab 文案**：一隅 / 胶囊 / 纪事 / 我的 — 无「拾意」「心笺」「回顾月历」「相册」。

4. **时光胶囊**：独立 Tab 全屏随机抽取，不是月历圆点、精选横滑或年度报告。
5. **心情五态固定**：愉悦 / 平静 / 思考 / 怀念 / 期待（Symbol 圆钮），与心笺日常心情集不同构。

7. **数据**：默认本机 Preferences；登录仅账号，不上传正文。
8. **无生成式对话 Tab**，无「AI」字样；智能价值=胶囊随机 + 连续天数规则统计。
