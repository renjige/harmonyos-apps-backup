# Logo Concept — 购物备忘

- 公司 / App / 行业：魏文波 · 购物备忘 · 个人购物清单工具
- 品牌关键词：Remember / Check / Carry / Calm / Clarity
- 核心元素（仅 2）：购物袋轮廓 + 勾选（完成采购）
- brandAnchor：购（语义融合进购物袋，而非单独写字）
- 禁止项自检：无购物车、无人民币、无促销星、无渐变球、无 AI 模板脑/火箭
- 色板：2 色 — 深海军 `#082A5A` + 白色 `#FFFFFF`
- 对比策略：App Icon 深底白标，灰度后购物袋与勾选轮廓仍清晰
- 行业模板 vs 本稿：
  1. 非事项效率的勾选清单方块
  2. 非出行备忘的路线+定位点
  3. 非电商购物车/价格标签
