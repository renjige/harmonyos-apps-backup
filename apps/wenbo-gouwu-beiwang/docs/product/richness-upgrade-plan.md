# 购物备忘 丰富度升级方案（1.1.0）

## 定位

个人与家庭**采购工作台**：规划 → 执行 → 记录 → 管理 → 回顾 → 成长

## 底栏

| Tab | 内容 |
|-----|------|
| 首页 | 工作台 + 情景 + 今日清单 + 看板 |
| 清单 | 清单 / 备忘 / 模板（ListsHub） |
| 成长 | 数据 / 计划 / 打卡 / 成就 / 动态 / 回顾 |
| 我的 | 设置与工具入口 |

## 新增能力（1.1.0 已落地）

1. **GrowthLocalStore + GrowthService** — 计划、打卡、成就、收藏、时间轴、全局搜索
2. **首页采购工作台** — KPI、本周计划进度、最近动态、全局搜索入口
3. **成长 Tab** — 六段式成长中心
4. **ListsHub** — 清单与备忘合并，保留模板区
5. **SearchOverlay + ItemDetailOverlay** — 全局搜索与物品三级详情
6. **写操作联动** — 创建清单 / 勾选 / 出门核对 → 时间轴 + 成就

## 保留（不删）

情景工作台、常购库、历史、花费、路线、核对、提醒、Widget、消息、详情 Pane 等 1.0.x 全部能力。
