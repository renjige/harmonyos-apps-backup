# 差异化 — 购物备忘 vs 同类清单 App

avoidSlugs：wenbo-chuxing-beiwang、wenbo-shixiang-jian、wenbo-linggan-beiwang

1. **采购情景工作台**（首页横向情景卡）：超市动线 / 菜市场 / 家庭补货 / 出行打包 / 周末囤购 — 一键生成带模板的动线清单，非空白新建。
2. **卖场路线 + 出门全屏核对**：按超市动线排列未购项，出门前全屏逐项核对（非常规 memo 勾选）。
3. **补货周期「该补货了」**：超过 7 天未购自动提示，一点加入今日清单。
4. **采购习惯诊断**：问卷 + 可执行建议报告（非空壳 AI 对话）。
5. **花费统计**：预估 / 实付 / 分类 / 常购次数，首页展示「待购预估」随勾选即时变化。
6. **常购物品库 + 历史再买一次 + 清单收藏**，形成采购闭环而非单次备忘。
7. 明确非商城：无商品浏览、下单、支付。
8. 影像为厨房静物与购物袋；Logo 为购物袋 + 勾选。
