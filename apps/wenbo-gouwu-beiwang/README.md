# 购物备忘

## 1.3.0 商业级丰富度（面向华为 3.7）

- **首屏进度 Hero**：今日采购进度条（计划或今日清单双数据源）
- **采购 Tab**：清单 / 备忘 / 模板 / 情景 四段执行中心
- **采购日历 + 月度报告**：长期复盘与环比
- **高级搜索**：关键词 + 待购/已购 + 标签 + 分类
- **家庭分工看板**：按负责人汇总待购
- **gate:behavior**：pass · **CompileArkTS**：0 error

## 1.2.0 深度工作台

- **采购主题**：多清单归组（宝宝辅食 / 周末大采购等），首页 + 成长 Tab 可管理
- **计划编辑器**：自定义目标件数、预算、周期、关联清单
- **收藏中心**：星标清单 + 物品收藏统一入口
- **分类洞察**：完成率 + 分类购买频次分析
- **物品详情可编辑**：预估/实付/标签/负责人；清单与首页点文字进详情、点圈勾选
- **动态可跳转**：时间轴记录可点开对应清单/物品/主题

## 1.1.0 丰富度升级

- **底栏重构**：首页 / 清单（含备忘+模板）/ 成长 / 我的
- **成长中心**：采购计划、打卡、成就、时间轴、本周回顾
- **首页工作台**：KPI、计划进度、最近动态、全局搜索
- **三级详情**：搜索命中物品 → ItemDetailOverlay（勾选/收藏/进清单）
