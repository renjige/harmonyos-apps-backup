# 个人信息收集清单 — 职业课堂

| 信息类型 | 收集场景 | 是否必须 | 存储位置 |
|---------|---------|---------|---------|
| 用户名 | 注册/登录 | 是 | 平台 registered-users |
| 密码 | 注册/登录 | 是 | 平台 registered-users |
| 姓名 | 注册 | 是 | 平台 registered-users |
| 手机号 | 注册/报名 | 是 | 平台 registered-users / 报名记录 |
| 学习诉求备注 | 课程报名 | 否 | 平台 enrollments |
| 收藏课程 id | 收藏功能 | 否 | 本机 Preferences |
| 学习进度 | 课程学习 | 否 | 本机 Preferences |

游客浏览栏目内容时不收集上述信息。
