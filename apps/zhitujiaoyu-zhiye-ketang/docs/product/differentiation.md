# 差异化说明 — 职业课堂

与仓库内 art-education 示例「筝昕雅缘」及通用六件套 App 的差异：

1. **目标用户**：职场人士/求职者/转型者，非少儿美育家长
2. **Tab 结构**：4 Tab（首页·学习·收藏·我的），非 5–6 Tab 课程/AI/活动/商城
3. **课程品类**：沟通表达、管理能力、职业规划、Excel 等职场技能，非古筝书画
4. **主闭环**：浏览课程 → 详情学习 → 进度本地追踪 → 可选报名登记
5. **智慧能力**：职业倾向问卷 + 模板报告（方案 B），UI 称「智慧学习」非 AI 助手
6. **视觉**：深海蓝 #1A2A6C + 活力橙 #F39C12 轻奢商务风，Logo 书本+阶梯
7. **无支付**：全部课程免费，无商城 Tab、无在线支付
8. **工作台**：学习页聚合「我的进度 + 目录筛选」，非 KPI 三列仪表盘
