# 明阅坊 · 差异化说明

## 与仓库内同类 App 的差异

| 维度 | 明阅坊 | 读书札语 / 其他阅读类 |
|------|--------|----------------------|
| 品牌色 | 墨蓝 + 琥珀金 + 象牙白 | 墨绿书卷 / 其他色调 |
| 信息架构 | **3 Tab**：书架 · 笔记 · 我的 | 多 Tab 或计划/商城混排 |
| 首页焦点 | **今日明悟** 横滑卡片 + 两列书架网格 | 单一列表或 KPI 看板 |
| 笔记视觉 | Symbol 渐变封面（非通用摄影缩略图） | 纯文字列表或共用 Hero 图 |
| 收藏命名 | **明悟收藏**（非「札语」） | 札语 / 摘录 |
| AI | 关闭（`LLM_ENABLED=false`） | 部分含 AI Tab |
| 图标 | 书卷光芒 Logo + HarmonyOS Symbol | 不同 Logo / 线稿 |

## 核心闭环（审核可演示）

1. 游客浏览今日明悟与示例书目 → 详情 → 收藏/加书架（登录门禁）
2. 登录后添加书籍、写笔记、收藏明悟 → 我的统计更新
3. 阅读报告、消息中心、设置与隐私（协议/撤回/注销）完整可用

## 视觉策略

- **书籍 / 今日明悟**：真实氛围摄影 PNG（每 key 独立渐变与纹理）
- **笔记 / 标签**：SymbolCover + CategoryEmojiUtil 点缀
- **底栏**：浮动圆角 Tab + 胶囊选中态
