# 知识探宝

**App 名称**：知识探宝  
**公司**：魏文波  
**Slug**：`wenbo-zhishi-tanbao`  
**行业 Pack**：`knowledge-treasure`  
**BundleId**：`com.wenbo.zhishitanbao`

## 产品定位

通过每日智慧卡片与趣味知识闯关，在碎片化时间探索历史、科学、文学、艺术、哲学，收藏灵感、积累智慧积分。

## 核心功能

| 模块 | 说明 |
|------|------|
| 每日智慧 | 滑动浏览知识卡片、本周学习进度、收藏 |
| 智慧探索 | 主题闯关、知识连线、探索地图 |
| 我的宝库 | 智慧积分、收藏夹、学习统计、每日提醒 |
