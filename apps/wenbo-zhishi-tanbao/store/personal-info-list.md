# 知识探宝 个人信息收集清单

运营者：魏文波  
应用名称：知识探宝  
更新日期：2026-08-24

| 信息类型 | 是否必须 | 收集场景 | 用途 | 存储位置 |
|---------|---------|---------|------|---------|
| 用户名 | 可选 | 注册/登录 | 账号标识 | 平台 registered-users |
| 密码 | 可选 | 注册/登录 | 账号验证 | 平台 registered-users |
| 姓名 | 可选 | 注册 | 账号资料 | 平台 registered-users |
| 手机号 | 可选 | 注册 | 联系与找回 | 平台 registered-users |
| 收藏卡片 ID | 否 | 点击收藏 | 宝库展示 | 本机 Preferences |
| 智慧积分/连续天数/闯关记录 | 否 | 完成闯关 | 宝库统计 | 本机 Preferences |
| 隐私同意状态 | 是（登录时） | 勾选协议 | 合规记录 | 本机 Preferences |
| 租户标识 | 是 | 网络请求 | 栏目隔离 | 请求头 X-Tenant-Id |

游客浏览卡片与闯关时不采集账号信息。宝库数据默认仅存本机。
