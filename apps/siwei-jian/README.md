# 思维笺

## 功能概览

- **思维**：今日思考、档案四格、快捷入口、智慧回望
- **记录**：思考 / 灵感 / 观点卡
- **主题**：主题思维库
- **回顾**：时间轴、统计、年度档案、智慧整理
- **我的**：成就墙、搜索、设置与隐私

## 数据与权限

- 纯本地 Preferences，新用户数据为空
- **新增系统权限：0**（无 INTERNET / 相机 / 麦克风等）
