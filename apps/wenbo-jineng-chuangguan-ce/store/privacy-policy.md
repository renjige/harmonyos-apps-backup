# 技能闯关册 隐私政策

运营者：魏文波  
应用名称：技能闯关册  
更新日期：2026-08-25

## 一、我们收集的信息

- **注册账号**：用户名、密码、姓名、手机号
- **闯关提交**：自评星级（1–5）、心得备注（保存在本机 Preferences）
- **登录态**：访问令牌，用于账号识别与注销

游客模式不适用（本应用需登录）。

## 二、使用目的

- 提供技能关卡目录浏览、闯关进度统计
- 成长值、连续打卡、能力雷达、勋章展示
- 排行榜只读浏览（平台种子数据）
- 账号登录、退出、注销

**不提供生成式 AI 对话功能。**

## 三、存储方式

- 栏目数据（关卡/分类/勋章/排行）来自平台 API：`https://saas16.qianqi.online/api/v1`
- 闯关进度、成长值、雷达数据保存在本机；卸载后清除

## 四、第三方共享

不向第三方共享个人闯关心得；平台 API 由运营者自有服务器提供。

## 五、您的权利

查询、更正、删除：我的 → 设置与隐私 → 注销账号 / 撤回隐私同意 / 重置本机闯关进度 / 清除缓存

## 六、权限

`INTERNET`：拉取关卡目录与账号认证（使用时申请）

## 七、联系方式

华为开发者联盟预留渠道或应用内反馈。
