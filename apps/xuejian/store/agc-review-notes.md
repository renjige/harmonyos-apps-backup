# 学见 · 审核说明（AGC「版本信息-应用审核信息」）

版本：**1.0.5**

## 问题（3.5 功能场景偏窄）

学见不是单一番茄钟，而是 **「专注 → 笔记 → 卡片 → 复习 → 洞察」** 完整学习闭环，并叠加平台栏目与计划能力：

1. **首页 · 学习闭环**：五步进度可点（计时/笔记/卡片/复习/周报），含本周学习计划入口  
2. **学科分类**：学习 Tab 展示平台分类（数学/英语/编程等），进分类详情可新建卡片、复习、专注  
3. **学习日记**：首页/洞察热力日历 **点日期** → 查看当天专注记录、笔记、卡片与「今日一句」  
4. **本周计划**：勾选式周目标（默认 3 项，可自定义至 5 项）  
5. **智慧推荐 / 锦囊**：平台方法正文 + 按内容分流 CTA（专注 / 写卡片 / 复习）  
6. **节律自测**：7 题问卷 → 规则报告 → **按建议跳转**对应功能（非一律开计时）  
7. **消息中心**：通知列表 + 详情页  

## 问题1（我的-今日/笔记/卡片无法记录）

**不是功能设计，是程序问题。** 须用户点保存后才写入：

1. 打开 **我的** → 点 **今日 / 笔记 / 卡片** 切换表单  
2. **今日**：点 15/25/45 分或输入分钟 → **补记**  
3. **笔记 / 卡片**：填写后点 **保存**  

## 对比度（1.0.4 已修）

浅色/深色副标题、Tab、橙色 chip「点击填写」、翻转复习「换一张」等已加深，正文对比度 ≥4.5:1。

## 审核员建议路径（3～5 分钟）

1. 首页 → **学习闭环** → 点「① 专注计时」完成一段计时  
2. 首页 → 点热力 **某日** → 看学习日记  
3. 学习 → **学科分类** → 数学 → 新建卡片 → 随机复习  
4. 首页 → **本周计划** → 勾选一项  
5. 洞察 → 节律自测 → 报告底部「去 xxx」跳转对应 Tab/功能
