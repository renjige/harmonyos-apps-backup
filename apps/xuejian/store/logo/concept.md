# Logo Concept — 学见

- 公司 / App / 行业：学见 / 学见 / study-sight（专注计时与学习轨迹）
- 品牌关键词：Sight / Focus / Warmth / Growth / Clarity
- 核心元素（仅 2）：翻开的书页 + 书页上方一枚暖金光点
- brandAnchor：学
- glyphStrategy：semantic-fusion（书 = 知识；光点 = 「见」与被看见的成长）
- 禁止项自检：无渐变球、无 3D/发光/毛玻璃、无火箭/灯泡/机器人/大脑、无小屋屋顶（避免与学知小筑撞形）
- 色板：深空蓝 `#1A2A4A` + 暖阳金 `#F5A623` + 近白纸色 `#F7F4EE`（第三色仅作纸页，App Icon 深底浅标）
- 对比策略：背景 `#1A2A4A` / 前景书页 `#F7F4EE`（高 ΔL）/ 光点 `#F5A623` 与深蓝对比足够；灰度下轮廓仍是「开书 + 圆点」
- 行业模板对比：学知小筑是「书+小屋」；学见是「书+光点」，无屋檐
