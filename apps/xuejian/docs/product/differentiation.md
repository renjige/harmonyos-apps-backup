# 学见 差异化说明

对比参考 App（避免换皮）：`xuezhi-xiaozhu`、`wenbo-qingzhige`、`huiyi-ce`

| # | 差异点 | 学见 |
|---|--------|------|
| 1 | 品牌叙事 | 「让学习被看见」— 进度环 + 热力图，而非课程商城 |
| 2 | 主色与 Logo | 深空蓝 #1A2A4A + 暖阳金 #F5A623；翻开的书 + 光点 |
| 3 | Tab 结构 | 首页 / 学习 / 洞察 / 我的（无独立 AI Tab） |
| 4 | 工作台 | layoutVariant B 单环进度，非三 KPI 宫格 |
| 5 | 核心闭环 | 专注计时 → 笔记/卡片 → 周月报 + 规则「智慧分析」 |
| 6 | 数据存储 | 本机 Preferences 学习记录；栏目走 study-sight API |
| 7 | 自测模块 | 学习节律问卷（7 题），非经营 SWOT 诊断 |
| 8 | 影像风格 | 书桌晨光 editorial，8 张独立 PNG，无共图 |

行业 Pack：`study-sight`（专注方法 / 锦囊 / 分类 / 封面）
