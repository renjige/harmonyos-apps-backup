# 家庭事项 — 差异化说明

相对仓库内「家庭备忘」「事项笺」等轻量记录类产品，本 App 差异点：

1. **工作台**：timeline-board + layout B — 今日状态卡用大数字待处理 + 圆环完成率，而非清单模板入口。
2. **Tab**：首页｜事项｜日历｜统计｜我的（5 Tab），无「提醒」独立 Tab、无看板、无对话页。
3. **核心实体**：FamilyTaskItem（事项 + 分类 + 重复 + 时段上午/下午），不是备忘录、购物清单或企业任务。
4. **主闭环**：记录 → 智慧提醒 → 勾选完成 → 本周生活回顾。
5. **分类**：仅家务 / 采购 / 家庭 / 孩子 / 其他五类，带独立摄影封面。
6. **统计**：本周节奏 + 分类比例 + 规则模板回顾文案，不做 BI 图表。
7. **视觉**：深墨绿 #24443A + 暖米白 #F6F1E8，屋檐+勾选 Logo，生活方式气质而非办公蓝。
8. **准入**：open_optional，游客本机可写；登录仅用于 sync_records。

禁止换皮：不得复用家庭备忘的「提醒」Tab 或事项笺的效率看板文案。
