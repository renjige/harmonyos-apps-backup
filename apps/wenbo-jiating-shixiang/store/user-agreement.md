# 家庭事项 用户协议

运营者：魏文波  
应用名称：家庭事项  
生效日期：2026-08-21

## 1. 服务说明

「家庭事项」是轻量家庭事务管理工具。底部为首页、事项、日历、统计、我的。用于记录家庭生活中的小事、分类、智慧提醒、重复事项、日历查看与本周回顾。不是社交、聊天、支付、医疗或项目管理平台。

## 2. 账号

支持账号密码注册与登录。游客可在本机使用核心功能；跨设备同步需登录。

## 3. 用户行为

不得利用本应用从事违法或侵权行为。事项内容由您自行记录，请勿填写他人隐私。

## 4. 提醒

智慧提醒仅服务于您主动建立的事项。本版本以应用内高亮与设置说明为主；不会推送营销、新闻或广告。

## 5. 免责

本应用为生活辅助工具，不构成医疗、财务或法律建议。因设备、系统权限或未开启提醒而未看到事项时，运营者不承担间接损失。

## 6. 隐私

详见《隐私政策》。路径：**我的 → 设置与隐私**。
