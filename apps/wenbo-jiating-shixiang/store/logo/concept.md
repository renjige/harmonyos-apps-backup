# Logo Concept — 家庭事项

- 公司 / App / 行业：魏文波 · 家庭事项 · 轻量家庭事务提醒与整理
- 品牌关键词：Home / Order / Care / Calm / Complete
- 核心元素（仅 2）：极简屋檐折线 + 勾选（家里的事被妥善安排）
- brandAnchor：家（语义落在屋檐几何，不写汉字）
- 禁止项自检：无卡通三口之家、无写实房子、无爱心、无宠物、无 3D、无渐变球、无 premium_logo roof+body+cloud 模板
- 色板：2 色 — 深墨绿 `#24443A` + 暖米白 `#F6F1E8`
- 对比策略：App Icon 深底浅标，灰度后屋檐折角与勾选仍清晰
- 行业模板 vs 本稿：
  1. 非「家庭备忘」购物袋/备忘卡片构图
  2. 非事项效率的方块清单勾选
  3. 无房屋墙体与烟囱，仅屋檐折线 + √，避免通用 house 模板
