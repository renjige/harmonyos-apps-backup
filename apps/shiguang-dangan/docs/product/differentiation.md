# 差异化说明 · 时光档案

## 与日记/记事本的区别

| 维度 | 普通日记 | 时光档案 |
|------|---------|---------|
| 组织方式 | 按天堆文字 | **档案 + 阶段** + 时间节点 |
| 回顾视角 | 日历翻页 | **时间轴 + 统计 + 阶段回顾** |
| 分类 | 无或简单标签 | **分类 + 标签 + 完成度** |
| 数据 | 常云端同步 | **纯本地**，无账号 |

## 与仓库内其他 App 的差异

- 非咨询/教育/SaaS 换皮
- 墨蓝 `#182333` + 琥珀 `#C99855` + 云雾白 `#F7F6F2` 档案气质
- 四 Tab：总览 / 档案库 / 时间轴 / 我的
- 节点四字段结构（发生了什么 / 为何重要 / 感受 / 改变）

## 主任务（primaryJob）

3 秒内创建或打开一份人生档案，并在时间轴上看到阶段脉络。
