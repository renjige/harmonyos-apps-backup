# 《时光档案》产品升级方案

> 审计日期：2026-09-01 · 工程：`apps/shiguang-dangan` · 策略：**渐进式重构**（保留 v2 核心，补 Phase 3）

---

## 1. 当前产品定位

**已实现**：纯本地个人时光资料体系 — 档案、节点、计划、目标、习惯、重要时刻、灵感、回顾、成就；五 Tab 工作台；0 系统权限。

**目标定位（增强提示词）**：

> 个人时光档案 + 生活记录 + 目标计划 + 习惯沉淀 + 重要时刻 + 时间回顾 + 成长管理

闭环：**记录 → 整理 → 收藏 → 计划 → 执行 → 回顾 → 沉淀 → 成长**

## 3. 产品差异化

| 普通 App | 时光档案 |
|----------|----------|
| 单一日记列表 | 档案 + 节点 + 主题册 + 时间轴 |
| 独立 Todo | 计划 + 目标 + 习惯联动首页进度 |
| 系统日历 | 日历矩阵叠加记录/计划/习惯 |
| 收藏按钮 | 独立收藏中心 + 自定义收藏夹 |
| 假 AI 总结 | **智慧回顾**（规则化本地统计，无 AI 字样） |
| 云端账号 | 纯本地沉淀，隐私友好，0 权限 |

## 8. 页面层级

每个核心实体：**一级入口 → 列表 → 详情 → 创建/编辑**

- 档案：Library → DetailPane → CreateArchiveSheet  
- 计划：PlanPage → PlanDetailPane → 任务勾选  
- 主题册：Mine → ThemeAlbumListSheet → ThemeAlbumDetailPane  
- 清单/经验/收藏：Mine → 对应 Sheet

## 12. 用户使用闭环

```text
首次引导（3～4 步）→ 创建第一份档案
→ 日常记录/计划/习惯 → 日历与时间轴沉淀

```
