# 旅行拼图

**App 名称**：旅行拼图  
**公司**：拼图记忆  
**Slug**：`lvxing-pintu`  
**Bundle ID**：`com.pintu.lvxingpintu`

## 产品定位

将碎片化的旅行记忆拼合成完整的旅行故事。轻量本机保存，无登录、无云端、无支付。

## 核心功能

| Tab | 功能 |
|-----|------|
| 足迹 | 时间线 / 地图足迹、旅行统计 |
| 拼图 | 创建 3～9 张图拼图、智能布局模板 |
| 收藏 | 收藏拼图、标签回顾 |
| 我的 | 昵称、统计、深色模式、隐私设置 |

## 技术说明

- 单机离线：Preferences + 应用沙箱存图
- 选图：系统 PhotoViewPicker（无需相册 ACL）
- 无网络请求、无 AI 对话、无社交分享
- 首次启动须同意隐私政策（无独立登录页）
