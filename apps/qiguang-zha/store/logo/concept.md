# Logo Concept — 栖光札

- 公司 / App / 行业：栖光生活 / 栖光札 / light-archive（生活微片段档案）
- 品牌关键词：Perch / Light / Folio / Quiet / Archive
- brandAnchor：栖
- 核心元素（2）：打开的薄札册 + 一道垂直光缝（光点栖于缝上）
- glyphStrategy：semantic-fusion
- 禁止项自检：无钢笔、无山水、无儿童插画、无渐变球、无日记本剪影模板、无 AI 发光
- 色板：深雾青底 `#2F4A47` + 米白札页 `#F6F1E8` + 柔金光缝 `#C4A574`（≤2 主色 + 一页浅杏）
- 对比策略：深底 `#2F4A47` / 浅标米白+柔金，灰度后册形与光缝仍清晰
- 行业模板对比：
  1. 非时光档案「时间环+折角」
  2. 非松岚札绿标笔记
  3. 非手账拾意信笺剪影
