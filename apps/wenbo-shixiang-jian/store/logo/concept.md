# Logo Concept — 事项笺

- 公司 / App / 行业：魏文波 · 事项笺 · task-efficiency
- brandAnchor：「事」字意象 + 便签轮廓
- 品牌关键词：Clarity · Order · Focus · Rhythm · Trust
- 核心元素（2）：圆角便签矩形 + 右下角勾选笔迹
- 对比策略：深海军底 #0F172A + 白色 Symbol + 科技蓝点缀 #2563EB（ΔL 足够）
- 禁止：渐变球、AI 脑、灯泡、蓝叠蓝

## 与行业模板差异

1. 非 house/lattice 通用 glyph
2. 融合便签 + 勾选 + 时间小圆点（12 点方向）
3. 手写 SVG path，非 premium_logo 模板
