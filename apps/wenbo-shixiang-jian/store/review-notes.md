# 华为审核说明 — 事项笺（3.7 / 3.5）

提交时在 AppGallery Connect「版本信息 → 应用审核信息」粘贴。

## 本应用不是备忘待办日程换皮

审核员打开首页应看到 **「今日承诺工位」**，而不是无限待办列表。

核心规则（请按此路径实测）：

1. 登录演示账号（见 store/demo-account.md）。
2. 首页只有 **上午 / 午后 / 晚间** 三个席位，每天最多 3 件承诺。
3. 点「锁定今日承诺」→ 必须选时段；第 4 件自动进 **候补池**。
4. 点承诺卡片「开始专注」→ 选择 1 分钟（审核可快速走通）→ 计时结束。
5. 计时前无法「收工完成」；计时后详情页出现「收工完成」。
6. 若有未兑现承诺，点「今日关帐」必须选择原因。
7. 我的 → **本周承诺复盘** 查看兑现率与专注分钟。

## 与系统功能的区别

| 系统备忘录 / 日历 / 待办 | 事项笺 |
|--------------------------|--------|
| 无限添加 | 每日承诺上限 3 |
| 随时勾选完成 | 必须完成专注计时才能收工 |
| 不区分时段执行 | 事项必须进入上午/午后/晚间工位 |
| 无未完成问责 | 关帐必须填写未兑现原因 |
| 无执行统计 | 首页专注分钟 + 本周兑现率 |
