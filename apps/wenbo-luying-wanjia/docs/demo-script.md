# 演示脚本 · 露营玩家

1. 首次启动直接进首页（无独立隐私首屏），游客可浏览营地与攻略
2. 首页查看天气规则卡、装备模板、热门攻略；点卡片进详情
3. 写操作（规划行程 / 新增装备 / 写日记 / 收藏）唤起登录；登录页勾选协议后注册或登录
4. 发现营地 → 详情（Hero + 设施 + 收藏 + 规划行程 + 笔记）
5. 装备库套用模板 → 行程详情生成打包清单并勾选、看总重量
6. 智慧清单问卷匹配模板（规则，非生成式对话）
7. 记录页统计为空（新用户）；新建日记后时间线与相册有数据
8. 消息中心拉取机构广播；我的 → 设置与隐私 → 撤回同意有顶部 Toast 并退出登录
