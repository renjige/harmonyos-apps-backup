# 差异化说明 · 露营玩家

相对仓库内旅行/手记类产品（夏野漫行、旅行札记、行程备忘），本 App 是 **露营装备工作台 + 营地档案**，不是杂志风漫步或日记相册换皮。

| 维度 | 露营玩家 | 对照产品 |
|------|----------|----------|
| 主任务 | 规划行程 → 按克重打包 → 选营地 → 写过夜记录 | 漫行灵感 / 旅行手记 / 行程备忘 |
| 核心实体 | 营地、装备模板、打包清单、天气规则、日记 | 路线、语录、灵感 |
| 首页 | 林下 Hero「称完装备再出发」+ 天气规则卡 + 模板横滑 | 杂志大图 + 今日漫行 |
| 独特能力 | 克重统计、分类装备 CRUD、智慧清单规则匹配模板 | 无克重打包 |
| 问卷 | 天数/季节/人数/营地类型 → cpt01/02/03 | 「适合今天」匹配路线 |
| 权限 | 仅 INTERNET；天气按目的地城市规则，不申请定位 | 可能不同 |
| 视觉 | 森林深绿 #2D5A27 + 营火橙 + 亚麻白；帐篷 Logo | 其他品牌色与符号 |
| 行业 Pack | camp-player（新建） | summer-wander / life-journal 等 |

禁止换皮：不得把夏野漫行的杂志首页改几个字出货。
