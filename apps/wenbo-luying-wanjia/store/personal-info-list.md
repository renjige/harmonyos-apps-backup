# 个人信息收集清单 · 露营玩家

运营者：魏文波  
更新日期：2026-08-22

| 信息 | 场景 | 处理方式 |
|------|------|----------|
| 账号、密码 | 注册 / 登录 | 业务平台按租户隔离存储；密码仅用于认证 |
| 姓名、手机号 | 注册（必填） | 账号资料，用于联系与审核演示 |
| 邀请码 | 注册（选填） | 若填写则保存 |
| 行程字段 | 规划行程 | 目的地、日期、人数；登录后同步云端 |
| 装备字段 | 装备库 / 打包清单 | 名称、分类、克重、勾选状态 |
| 日记与封面键 | 露营记录 | 标题、正文、应用内图库封面键 |
| 收藏营地编号 | 营地详情收藏 | 仅本人列表 |
| 营地笔记 | 营地详情写笔记 | 仅本人可见 |
| 攻略标题与正文 | 发布攻略 | 展示在玩家攻略 |
| 访问凭证 | 登录成功 | 本机 Preferences + flush |
| 反馈正文与选填联系方式 | 意见反馈 | 默认仅本机 |

游客浏览营地、攻略、天气规则时不采集上表账号与业务记录。

不收集：精确位置、通讯录、短信、相册原图、支付信息、生物识别。
