# Logo Concept — 露营玩家

- **公司 / App**：魏文波 · 露营玩家
- **brandAnchor**：露
- **glyphStrategy**：semantic-fusion
- **关键词**：Tent · Ridge · Forest · Pack · Night
- **核心元素（2）**：A 字帐篷轮廓 + 门洞负空间（帐篷即山峰）
- **对比策略**：深绿底 `#163318` + 亚麻标 `#F5F0E8`（高明度差，灰度仍可辨）
- **禁止项**：无渐变球、无指南针库存、无火焰拟物、无地球、无太阳+山脊（与夏野漫行区分）
- **行业模板对比**：
  1. 夏野漫行：山脉剪影 + 暖橙太阳
  2. 旅行札记：手册/相机意象
  3. 本稿：单一帐篷几何，门洞负空间是识别点，无太阳
