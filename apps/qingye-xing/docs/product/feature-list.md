# 清野行 — 功能清单

## 核心闭环

| 功能 | 状态 |
|------|------|
| 清野空间首页（统计/快捷/最近/智慧回望） | ✅ |
| 探索记录 CRUD（创建/编辑/删除/收藏） | ✅ |
| 探索详情 Hero + 正文 + CTA | ✅ |
| 自然观察册（植物/天气/景色/发现） | ✅ |
| 主题空间（创建/关联/详情） | ✅ |
| 足迹时间轴 + 年度探索报告 | ✅ |
| 全局搜索 | ✅ |
| 探索成就徽章 | ✅ |
| 智慧整理（待整理提示） | ✅ |
| 设置与隐私（协议/撤回/导出/清缓存） | ✅ |
| 零系统权限 / 纯本地存储 | ✅ |

## 验收步骤

1. 冷启动 → 勾选协议 → 进入清野首页（统计为 0）
2. 新建探索 → 列表可见 → 详情完整 → 编辑保存
3. 添加观察 → 观察详情可查看
4. 创建主题 → 探索归入主题
5. 搜索关键词命中记录
6. 撤回隐私 → Toast → 再次启动须重新同意
