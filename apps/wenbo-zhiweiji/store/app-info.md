## 应用介绍

知微集是**个人微知识收集与学习管理**工具，不是简易备忘录。除记录外，提供完整学习与整理闭环：

**可读内容（首次安装即可用）**
- 内置 **知识文库 30 篇**短文，按生活百科 / 科普 / 历史 / 学习 / 兴趣 / 工作六类浏览、搜索、阅读
- **每日一知**推送当日知识，阅读打卡后可完成「三问」生成结构化笔记

**学习巩固**
- **间隔复习抽卡**：待学习条目翻面回忆，按「记得 / 模糊 / 忘了」自动安排 1～7 天后复习
- **消化处理台**：待消化 → 跟进中（可写下一步动作）→ 已消化，完整跟进流程

**整理与沉淀**
- **结构化模板**：技巧卡、摘录卡、百科卡、复盘卡，避免空白笔记
- 六大分类 + 学习标签；收藏夹、知识库专题；详情页展示**相关微知识**关联
- 成长页：周度洞察、本周回顾、成就墙、学习计划

数据默认保存在本机，核心功能无需登录。无支付、无会员、无生成式 AI 对话。

## 关键词

微知识, 间隔复习, 知识文库, 学习打卡, 知识管理, 鸿蒙

## 审核演示建议（50104-3.5）

1. 探索 → 知识文库 → 打开任意一篇（无需先记笔记）
2. 每日一知 → 打卡 → 完成三问 → 生成笔记
3. 工作台 → 间隔复习 → 抽卡翻面 → 选择记忆程度
4. 记微知识 → 选「技巧卡」模板 → 保存 → 消化处理台推进状态
