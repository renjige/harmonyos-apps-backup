> 应用仅有简易知识记录功能，内容丰富度与实用性欠佳，可覆盖的使用场景暂时还比较有限。

审核员若只体验「记一条标题+正文 → 看列表」，会判定为**简易备忘录**，不会认为具备「学习管理」价值。

**必须让审核在 2 分钟内看到：内置可读内容 + 学习闭环 + 多场景入口。**

## 审核演示脚本（建议录屏 90 秒一并提交）

1. 冷启动 → 工作台 → 点击 **「进入学习路径」**
2. 选择 **「7天微知识入门」** → 依次点 2～3 个「去完成」（会跳转文库/每日一知/复习）
3. 探索 → **查看全部文库** → 打开任意一篇阅读
4. 工作台 → **复习** → 抽卡翻面 → 选「记得/模糊/忘了」
5. 工作台 → **待消化** → 处理台查看三列状态

**全程无需登录。**

## 应用介绍（复制到华为后台）

知微集是一款**个人微知识收集与学习管理**应用，而非简易备忘录。

**内置内容**：知识文库 30 篇短文，按生活百科、科普、历史、学习、兴趣、工作六类浏览，首次安装即可阅读。

**学习管理**：
- 学习路径：入门 / 职场 / 生活三条引导，分步体验阅读、打卡、模板记录、复习与回顾；
- 间隔复习：抽卡回忆，按记忆程度自动安排复习；
- 每日一知：阅读打卡 + 三问巩固，生成结构化笔记；
- 消化处理台：待消化 → 跟进中 → 已消化完整流程；
- 结构化模板：技巧卡、摘录卡、百科卡、复盘卡。

数据默认保存在本机，核心功能无需登录。无支付、无会员、无 AI 对话。
