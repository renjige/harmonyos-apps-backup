# Logo Concept — 知微集

- 公司 / App / 行业：魏文波 · 知微集 · micro-insight（碎片收录与智能洞察）
- 品牌关键词：Insight / Micro / Gather / Clarity / Focus
- brandAnchor：微（瞳孔微点）
- 核心元素（仅 2）：双弧「知微之眼」+ 交汇微点；外围细环为「集」的汇聚，与眼同属一套几何
- 禁止项自检：无机器人、无大脑、无六边形科技、无渐变球、无发光、无玻璃、无 3D、无灯泡
- 色板：墨蓝 `#1A1A2E` + 近白 `#F5F7FA`（UI 品牌蓝 `#007AFF` 不进 App Icon，避免蓝叠蓝）
- 对比策略：App Icon 深底浅标——背景 `#1A1A2E`，弧线/环/微点 `#F5F7FA`。灰度后眼轮廓仍清晰。
- glyphStrategy：semantic-fusion（眼 = 洞察；微点 = 知微；环 = 汇聚成集）
- 行业模板对比：
  1. 悠隅纪：暖杏窗棂 → 本稿是眼，不是窗
  2. 灵感备忘：黄薄荷手账 → 本稿无本、无画板
  3. 积累日记：日记本块面 → 本稿几何眼
- 几何说明：1024 画板；安全区 ≥25%；眼落在中心约 60%；双弧对称；中心实心微点。
- 横版：左 Symbol 右「知微集」
