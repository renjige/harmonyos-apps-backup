# 个人信息收集清单

| 信息 | 场景 | 存储 |
|------|------|------|
| 用户名、密码、姓名、手机号 | 仅主动注册/登录 | 平台账号服务 |
| 微知识标题、正文、分类、学习标签、优先级、跟进状态、自定义标签 | 记微知识 | 本机 Preferences |
| 配图（系统相册选择器选中的副本） | 可选配图 | 本机沙箱，不上传 |
| 知识库专题、收藏标记 | 个人知识库 / 收藏夹 | 本机 |
| 每日一知已读、学习天数 | 每日一知打卡 | 本机 |
| 洞察摘要与关键词 | 由本机笔记统计生成 | 本机 |
| 金句收藏编号 | 主动收藏 | 本机 |
| 深色模式、隐私同意 | 设置 | 本机 |

游客可使用核心功能，不强制采集账号信息。本应用不采集音频，不申请相册读取权限。
