# 知微集 · 审核演示路径（约 3 分钟）

游客可直接进入，无需登录。

1. **记微知识**：首页点「记微知识」→ 写标题与正文 → 选一个分类（如生活百科）→ 可选学习标签 → 保存。列表应立刻出现该条。
2. **周度分类不为 0**：切到「洞察」→ 查看周度洞察。刚写过的笔记会出现在对应分类，数字大于 0。若近七日没有新笔记但历史有笔记，标题会改为「累计分类分布」，同样不为全 0。点某一分类进入列表。
3. **每日一知**：首页点「每日一知」卡片 → 阅读 →「标记已读 · 今日打卡」→ 可「收进我的知识库」。
4. **知识库与收藏**：打开「知识库」→ 可见默认专题（读书笔记 / 生活技巧 / 学习资料）→ 可新建专题。打开一条笔记详情 →「加入收藏夹」→「加入知识库专题」。首页「收藏夹」能筛出收藏。
5. **深色模式**：我的 → 打开深色模式开关，当前页立刻变深。
6. **设置与隐私**：我的 → 设置与隐私 → 可打开协议全文；撤回隐私同意有顶部 Toast。

不要在登录页寻找演示账号。演示账号仅在 `store/demo-account.md`。
