# 知微集 · 差异化说明

对照 avoidSlugs：`youyu-ji`、`songlan-zha`、`jilei-riji`、`wenbo-linggan-beiwang`、`huiyi-ce`

1. 核心实体是 **CaptureItem（碎片收录）**，不是心情时间线、日记相册、灵感画板或记忆册。
2. 首页工作台是 **catalog-tool**：双 CTA「记微知识 / 口述收录」+ 每日一知 + 知识库/收藏夹 + 六分类芯片 + 搜索，不是六件套 KPI 宫格。
3. 第二 Tab 是 **智能洞察**：当日关键词摘要 + 近七日热力下钻 + 周度分类分布条（可点进本周条目），规则统计，不是时光胶囊、也不是生成式对话。
4. 收录带 **待消化 / 跟进中 / 已消化** 进度，金句可 **收进知微集** 变成可跟进条目。
4. 第三 Tab 是 **灵感集市金句**，带独立封面图、收藏与复制分享，不是画板/计划。
5. 品牌是 **墨蓝深底 + 白「知微之眼」+ 华为蓝 CTA**，与悠隅纪暖杏窗、灵感备忘黄薄荷明显不同。
6. 布局变体 **E**（工具优先），底栏文案为 收录 | 洞察 | 集市 | 我的。
7. 产品文案禁止「AI」，使用智慧 / 智能；`FeatureFlags.LLM_ENABLED=false`。
8. 内容影像 8 张独立 PNG（hero/banner/四分类封面/空态），无共图。
