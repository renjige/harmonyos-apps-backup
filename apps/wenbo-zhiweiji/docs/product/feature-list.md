# 知微集 · 功能清单（v1.2.0）

- ✅ 知识文库：30 篇内置短文，分类浏览、搜索、按篇打开
- ✅ 间隔复习：抽卡翻面，记得/模糊/忘了自动排期
- ✅ 消化处理台：待消化 → 跟进中（可写下一步）→ 已消化
- ✅ 结构化模板：技巧卡 / 摘录卡 / 百科卡 / 复盘卡
- ✅ 每日一知三问：打卡后生成结构化笔记进复习队列
- ✅ 详情相关微知识：同分类关联推荐

- ✅ 底栏四 Tab：工作台 / 成长 / 探索 / 我的
- ✅ 工作台：今日进度、四格统计、快捷入口、学习计划、最近动态、待跟进
- ✅ 全部微知识：独立二级页，关键词 + 分类 + 标签 + 时间筛选
- ✅ 成长中心：周度洞察、本周/本月回顾、成就墙、学习计划、分类柱状图
- ✅ 成长时间轴：记录 / 消化 / 打卡 / 收藏事件流
- ✅ 探索：每日一知入口 + 知识目录预览 + 灵感金句
- ✅ 微知识记录：标题+正文、可选配图（系统相册选择器，不申请相册权限）
- ✅ 六大分类：生活百科 / 科普知识 / 历史文化 / 学习成长 / 兴趣探索 / 工作技巧
- ✅ 学习标签：待学习 / 已掌握 / 常用技巧 / 灵感，列表可筛选
- ✅ 知识收藏夹：详情加入/移出，首页与「我的」可进入
- ✅ 每日一知：当日实用知识、标记已读打卡、收进知识库
- ✅ 个人知识库：默认专题 + 新建专题，笔记可加入合集
- ✅ 知识卡片：详情复制重点文案到剪贴板
- ✅ 学习打卡：写下笔记或阅读每日一知计入学习天数
- ✅ 知识搜索：关键词 + 分类 + 标签 + 进度筛选
- ✅ 知识成长：我的页统计笔记数、收藏数、专题数、学习天数
- ✅ 跟进闭环：待消化 / 跟进中 / 已消化
- ✅ 口述收录入口（系统输入法，不申请麦克风）
- ✅ 列表 → 详情 Hero+正文 → 编辑 / 收藏 / 专题 / 删除确认
- ✅ 智能洞察：当日摘要、近七日热力；周度六分类分布（无近七日则累计，避免全 0）
- ✅ 灵感集市：每日金句、详情、收藏、复制、收进知微集
- ✅ 我的：统计、深色模式即时切换、导出剪贴板、关于、设置与隐私
- ✅ 游客可用核心功能；登录/注册可选；协议勾选在登录页
- ✅ 撤回隐私同意 async + Toast + 退出登录
- ✅ 无「删除业务数据」按钮；可清除缓存 / 清空本机收录（二次确认）
- ✅ FeatureFlags.LLM_ENABLED=false，无生成式对话
- ✅ Logo 分层 + 内容影像真引用
