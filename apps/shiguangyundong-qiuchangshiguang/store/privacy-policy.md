# 隐私政策

**运营者**：承德品冠体育发展有限公司  
**应用名称**：球场拾光  
**更新日期**：2026年8月29日

## 一、我们如何收集和使用您的个人信息

1. **账号信息**：注册时收集账号、密码、姓名、手机号，用于登录、预约身份识别与到场联系。
2. **预约信息**：您提交场地预约时收集运动类型、场馆、预约日期与时段、备注，用于生成预约凭证与场馆对接。
3. **运动时光记录**：登录后根据预约记录生成运动统计。
4. **球迷拾光**：观赛记录、球迷日志、球队收藏、复盘笔记、精彩瞬间、比赛清单、球员档案、球场知识、赛事日历、体育收藏册、挑战任务与成长统计由您主动填写，**仅保存在本机**，不上传服务器；不申请相册、定位或运动健康权限。
5. **设备与日志**：为保障服务稳定，可能收集设备型号、系统版本、崩溃日志。发现页距离为场馆参考值，**不申请定位权限**。

## 二、我们如何使用信息

- 展示场馆目录、完成预约申请、同步我的预约与运动统计  
- 发送预约提醒与机构通知（可在设置中关闭）  
- 球迷拾光仅用于您在本机整理赛事记忆  
- 改进产品与故障排查  

**本应用不含在线支付**，不涉及银行卡信息收集。

## 三、第三方共享

- 云服务：用于 API 数据同步（HTTPS 传输）  
- **不提供生成式 AI 对话**，不向大模型传输您的聊天内容  

## 四、您的权利

您可通过 **我的 → 设置与隐私** 查看《用户协议》与《隐私政策》、撤回隐私同意、注销账号。撤回或注销后我们将停止收集并按规则删除关联数据。
