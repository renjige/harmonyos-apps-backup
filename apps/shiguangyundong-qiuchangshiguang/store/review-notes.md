# 华为审核说明（可粘贴 AGC「版本信息-应用审核信息」）

## 问题 1（指南 3.5）功能深度 / 使用场景

**本版定位：个人球迷记录与赛事记忆管理平台（非简单单条笔记），默认进入拾光 Tab。**

### 新增（针对「内容丰富度欠佳」）

| 能力 | 说明 |
|------|------|
| **场景创作** | 4 条场景化入口：赛后复盘 / 成长报告 / 赛季合集 / 下一场观赛 |
| **赛后全套复盘向导** | 3 步向导一次生成观赛记录 + 精彩瞬间 + 复盘笔记（关联同场比赛） |
| **球迷成长报告** | 类型分布柱状图、挑战完成率、6 项里程碑、本月活跃日历、全量复制导出 |
| **成长概览** | 拾光首屏：分布图 + 里程碑 + 本月小结 |
| **默认 Tab 拾光** | 冷启动即见 12 项能力与场景入口，非空白首页 |

### 原有 12 项能力（保留）

观赛记录、球迷日志、球队收藏、复盘笔记、精彩瞬间、比赛清单、球员档案、球场知识、赛事日历、体育收藏册、球迷挑战、记忆时光轴；清单→观赛闭环、关联记忆、复制全文等。

不拉实时赛程、不申请定位/相册/运动健康；内容均由用户主动创建（审核演示请用向导现场生成）。

**复测路径（建议录屏 3 分钟）**  
① 冷启动 → 拾光 →「赛后全套复盘向导」→ 填 3 步 → 时光轴见 3 条  
② 拾光 →「球迷成长报告」→ 分布图/里程碑/复制全部  
③ 场景创作「赛季专题合集」→ 创建 → 记观赛收入合集  
④ 比赛清单 → 看完了写观赛记录

## 问题 2（深色模式）输入框不可见

**已修复**：登录/注册、发现搜索、球迷编辑、预约表单等输入框统一使用 `AppTextField`，显式设置 `fontColor` / `placeholderColor` / `caretColor`；`EntryAbility.onConfigurationUpdate` 监听系统深色模式切换并刷新 `themeEpoch`。

**复测路径**  
设置 → 深色模式 → 打开 App → 登录页输入账号密码（文字可见）→ 发现页搜索框输入（文字可见）。

## 问题 3（浅色模式）底部控件对比度 1.07

**已修复**（Mate X5 / HarmonyOS 6.1 无障碍检测）：

1. **底栏 Tab**：标签字号 10→12；未选中 `textPrimary`，选中 `brandDeep`；胶囊底改为 `surfaceSubtle`（不再橙字叠浅橙底）  
2. **次要按钮 / 胶囊 Chip**：新增 `textOnBrandContainer`（深海军蓝 `#1A2A3A`），替代 `brandPrimary` 叠 `brandPrimaryContainer`  
3. **反色文字**：浅色模式下 `textOnInverse` 改为纯白 `#FFFFFF`，避免 `#F8FAFC` 误叠白底  
4. **副标题**：`AppHeader` 去掉 `opacity(0.85)` 降对比度  

**复测路径**  
系统设置 → 浅色模式 → 打开 App 默认首页 → 无障碍/对比度检测扫描底部 Tab 区域（坐标约 y=2226–2359）→ 对比度应 ≥4.5:1。
