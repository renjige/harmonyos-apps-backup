# 华为 50104-3.5 对照 — 球场拾光

官方要求：实用价值 + 创意；不得纯信息展示、单一页面、套模板、内容聚合、罗列链接、Web 套壳、系统简易功能。

| 审核员担心 | 本 App 交付 |
|-----------|-------------|
| 纯信息展示 | 球迷笔记 CRUD + 预约 / 打卡 / 取消 / 收藏 |
| 单一页面 | 4 Tab + 场馆/优惠/实记详情 + 拾光工作台与记录详情 |
| 套模板 | 拾光工作台（成长 KPI + 影像入口）+ 时段网格预约，非资讯列表 |
| 内容聚合/外链 | 原生 ArkUI，栏目走平台 API，无浏览器跳转 |
| Web 套壳 | 无 WebView 主路径 |
| 虚假地图 | 「发现」为列表/距离排序，不冒充 MapKit |
| 系统简易功能 | 赛事记忆管理 + 场地预约，非计算器/手电筒 |

创意点：**用户主动写下的观赛记忆库**（观赛/日志/收藏/复盘/瞬间）+ **选时段 → 预约凭证 → 到场打卡**，区别于体育资讯 App 与场馆黄页。
