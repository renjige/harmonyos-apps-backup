## Tab

- **拾光（默认首屏）**：场景创作 · 复盘向导 · 成长概览 · 12 项工具 · 时光轴
- 首页：Hero、球迷记忆条、复盘向导/成长报告、场馆与实记
- 发现：列表 / 距离排序，搜索，点进详情
- 我的：预约、收藏、消息、设置

## 审核员 3 分钟路径（3.5 重点）

1. 冷启动默认 **拾光 Tab** → 点 **「赛后全套复盘向导」** → 3 步完成 → 自动进 **记忆时光轴** 见 3 条关联记忆
2. 拾光 → **球迷成长报告** → 看类型分布 / 里程碑 / 本月活跃 → **复制全部记忆**
3. 拾光 → **场景创作**「赛季专题合集」→ 创建收藏册 → 记观赛并收入合集
4. 比赛清单 → **看完了，写观赛记录** 闭环
5. （可选）发现 → 场馆预约 → 到场打卡

## 合规

- 无在线支付、无生成式 AI、无 Web 套壳、无外链聚合
- 球迷功能不申请定位/相册/运动健康；不拉实时赛程
- 无独立隐私首屏；协议在登录/注册页勾选
- 新用户球迷记忆为空（无假数据预填）；场景向导由审核员现场创作演示
