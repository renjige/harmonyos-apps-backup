# 个人信息收集清单

运营者：魏文波 · 应用：成长手册

| 信息 | 场景 | 目的 |
|------|------|------|
| 账号、密码、姓名、手机号 | 注册/登录 | 账号认证 |
| 成长记录正文、标签、日期、封面标识 | 写记录 | 同步与展示 |
| 目标名称、进度、拆解步骤 | 目标管理、卡住工坊 | 进度追踪 |
| 对照卡正文 | 前后对照 | 写入时间轴 |
| 月度主题与月报 | 主题月 | 本月经营与回顾 |
| 习惯名称、打卡日期 | 习惯打卡 | 连续天数统计 |
| 复盘四问内容 | 每周复盘 | 存档回顾 |
| 诊断选项 | 成长诊断 | 生成规则模板报告（不上传大模型） |
| 设备型号、系统版本、崩溃日志 | 运行异常 | 稳定性 |

游客不收集上表账号与业务内容。
