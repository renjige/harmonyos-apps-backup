# 华为复审操作清单 — 成长手册 v1.0.5

针对 **3.5（场景有限）** 与 **3.1（进行中目标返回后数据不刷新）**。

## 一、问题 3.1 — 完成度返回后不更新

**复现路径**：成长空间 → 进行中目标 → 详情 +10% → 返回 → 进度条/数字仍旧，需切 Tab 才变。

**修复（v1.0.5）**：

| 项 | 做法 |
|----|------|
| 详情关闭 | `MainTabPage` 监听 `detailRoute` 变空 → 强制 `bumpContentRefresh` |
| Tab 切换关详情 | 关详情同时刷新首页数据 |
| 列表重绘 | 进行中目标 `ForEach` key 含 `progress + listEpoch` |
| 首页快捷操作 | 进行中卡片可直接 **+10% 进度**，更新后进度条与「已完成」数字立即变化 |

### 复审自测

1. 成长空间 → 进行中目标 → **+10% 进度**（卡片按钮或进详情点 +10%）
2. 返回成长空间：**进度条与百分比立即变化**，无需切 Tab
3. 加到 100% 并完成仪式后，「进行中」列表立即少一条，「已完成」+1

## 二、问题 3.5 — 功能场景

成长空间首页可见完整闭环（无需进九宫格）：

| 模块 | 能力 |
|------|------|
| 今日成长仪式 | 三问写入当天记录 |
| 本周成长挑战 | 生成带三步清单的目标 |

| 习惯打卡 / 周复盘 / 成长诊断 / 年度报告 | 保留 |
