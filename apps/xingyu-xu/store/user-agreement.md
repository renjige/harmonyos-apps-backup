# 星隅叙 用户协议

运营者：魏文波  
应用名称：星隅叙  
更新日期：2026-09-02

## 一、服务说明

星隅叙为您提供本机生活档案空间，包含五个主要页面：

- 星隅：首页提问、档案数字、最近片段、今日回望
- 叙事：档案卡片、状态筛选、搜索、模板新建
- 主题：兴趣星域、创建主题、内容管理
- 回望：时间星轨、智慧回望、年度星册、数据中心
- 我的：星徽墙、收藏库、标签、设置与隐私

主闭环为：新建叙事 → 归入主题 → 打标签与状态 → 收藏星光 → 在时间星轨回顾 → 由日期规则触发智慧回望 → 点亮年册与成就。

本应用允许游客在本机直接读写。登录与注册仅建立本机账号，不提供云端备份或跨设备同步。

「智慧回望」根据您写下的日期做规则匹配（例如同月同日），不调用生成式模型，不编造您未写下的内容。

## 二、账号规则

注册需账号不少于 3 位、密码不少于 6 位、姓名与 11 位手机号。邀请码为选填。同一账号不可重复注册。未注册不可登录。登录/注册前必须勾选同意本协议与《隐私政策》。

您可随时退出登录或注销本机账号。注销后该账号不可再登录。路径：**我的 → 设置与隐私**。

## 三、使用规范

请勿利用本应用记录或传播违法违规内容。档案为个人生活整理工具，不构成医疗、法律、学历或心理辅导意见。

星徽与连续天数仅为本地统计趣味，不代表任何评测或奖励承诺。

## 四、免责声明

数据仅存本机。设备丢失、卸载、系统清理或存储故障可能导致内容不可恢复，请自行摘录重要段落。

本应用不提供付费功能、广告与应用内购买。

## 五、协议变更与联系

协议更新后将在应用内展示新版本。继续使用视为知悉。联系路径：我的 → 设置与隐私。运营者：魏文波。
