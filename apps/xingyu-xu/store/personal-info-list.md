# 星隅叙 个人信息收集清单

运营者：魏文波  
应用名称：星隅叙  
更新日期：2026-09-02

| 信息 | 场景 | 处理方式 | 是否必填 |
|------|------|----------|----------|
| 账号、密码 | 本机注册/登录 | 仅存本机 Preferences | 仅当您选择注册时 |
| 姓名、手机号 | 本机注册 | 仅存本机，用于账号资料 | 仅当您选择注册时 |
| 邀请码 | 本机注册 | 选填，仅存本机 | 否 |
| 叙事标题/正文/日期/状态/标签 | 新建或编辑叙事 | 仅存本机 | 否（游客可空） |
| 灵感标题/正文/计划 | 新建或编辑灵感 | 仅存本机 | 否 |
| 主题名称/封面 | 创建主题 | 仅存本机 | 否 |
| 收藏摘录 | 收藏叙事或灵感 | 仅存本机 | 否 |
| 隐私同意状态 | 登录/注册勾选 | 本机 Preferences | 登录/注册时须勾选 |
| 外观偏好 | 我的 → 深浅外观 | 本机 Preferences | 否 |

本应用不收集精确位置、通讯录、相册、设备标识用于画像，也不上传档案正文。
