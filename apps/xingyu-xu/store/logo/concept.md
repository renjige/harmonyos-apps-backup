# Logo Concept — 星隅叙

- 公司 / App / 行业：星隅叙 / 星隅叙 / 个人生活档案空间（star-nook）
- 品牌关键词：Nook / Starlight / Archive / Restraint / Warmth
- brandAnchor：隅
- glyphStrategy：semantic-fusion
- 核心元素（仅 2）：半圆角落（空间）+ 极简星点；一条细轨迹为辅，不构成第三主体
- 禁止项自检：无复杂星空、无十二星座、无塔罗、无日记本、无渐变球、无发光、无 AI 模板
- 色板：深夜蓝 `#12182B` + 月白 `#F6F3EC` + 柔金 `#C4A574`（标主体 2 色）
- 对比策略：App Icon 深底 `#12182B` / 前景月白弧 + 柔金星点（ΔL 足够，灰度轮廓清晰）
- 行业模板对比：
  - 不是时光档案的时间环+折页
  - 不是手账拾意的纸笺翻页
  - 不是 house/cloud 脚手架默认 glyph
