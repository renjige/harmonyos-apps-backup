# 星隅叙 · 差异化说明

对照仓库内同类「记录/回顾」产品（尤其 `shiguang-dangan` 时光档案、`shiyi-shouzhang`、`songlan-zha`、`shenghuo-zha`、`jilei-riji`、`ximan-guan`、`huiyi-ce`、`yunshui-jian`、`zhencang-kongjian`），星隅叙不是日记换皮。

1. **产品隐喻**：星隅 = 生活角落里的星光档案，不是「一天一篇日记」，也不是时光档案的「档案夹 + 时间节点树」。
2. **核心实体**：叙事（Narrative）+ 灵感星库（Spark）+ 主题空间（ThemeSpace），三维并列；时光档案是档案/节点，札记类是笔记/待办。
3. **主题星域**：阅读/旅行/成长/兴趣/生活各自独立封面，内容归入主题而非按日期堆叠。
4. **智慧回望**：仅日期规则匹配（同月同日等），明确关闭生成式对话；不是 AI 写日记，也不是心情打卡。
5. **时间星轨 + 年度星册 + 星徽墙**：回顾层是星轨/年册/成就，不是日历格子打卡，也不是相册时间线。
6. **视觉指纹**：深夜蓝 `#12182B` + 雾紫 + 月白 + 柔金，半圆角落 Logo（星隅印记）；与时光档案暖橙木色、松岚翠绿、积累日记纸感均不同。
7. **信息架构**：底栏五 Tab「星隅 / 叙事 / 主题 / 回望 / 我的」，无待办、无相机、无社交。
8. **本地零权限**：无 INTERNET、无相机/定位；游客可写；登录只建本机身份。不接 SaaS 栏目 API。
9. **工作台**：`catalog-tool` + layoutVariant `B`，首页是提问式 Hero 而非 KPI 仪表盘。

结构指纹自检：未使用「三 KPI + 宫格 + AI 横幅」工厂六件套，也未复用时光档案节点树。
