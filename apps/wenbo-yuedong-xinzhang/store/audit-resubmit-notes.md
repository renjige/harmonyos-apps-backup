## 问题 1 — 统计数据不更新（已修复 · v1.0.5）

**设计说明（非 Bug）：**
- 「今日完成率」= 今日已完成任务数 ÷ 今日总任务数
- 「跃动指数」= 综合今日完成率、连续天数、目标进度、进行中/已收官篇章的加权分（0–100）
- 「已收官章」= 在篇章详情写 ≥20 字复盘并点击「写完并收官」后计数 +1

**v1.0.5 修复：**
- 首页勾选任务后，今日进度卡片即时刷新（独立组件 + 本地状态同步）
- 成长/我的页指标改用 `@Prop` 驱动组件，全局 `ydDataRefresh` 触发重算
- 篇章收官后 Toast 提示累计篇数，并刷新「我的-已收官章」

**建议审核复测步骤：**
1. 今日 → 添加 1 条任务 → 勾选 Checkbox → 首页显示「已完成 1/1」
2. 成长 → 日视图「今日完成率」同步为 100%
3. 篇章 → 详情 → 写 ≥20 字复盘 →「写完并收官」→ 我的「已收官章」+1

## 问题 2 — 功能较简单（产品定位说明）

跃动新章是 **人生篇章管理工具**，不是简单备忘录，核心闭环：

| 模块 | 能力 |
|------|------|
| 篇章 | 7/14/30 天周期、主题、章末复盘收官 |
| 今日 | 任务分类、时间轴、勾选完成、投入分钟 |
| 目标 | 里程碑拆解、进度追踪、归档 |
| 成长 | 日/周/月/年统计、热力图、时间轴、12 徽章 |
| 数据 | 本周/月/年/篇章多格式导出、收藏、标签、搜索 |

「我的 → 使用指南」有完整操作说明；「成长 → 产品能力概览」列出八大能力。
