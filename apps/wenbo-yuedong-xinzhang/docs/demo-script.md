# 跃动新章 — 审核演示脚本（本地版 · 无登录）

**版本：** 1.0.5  
**DevEco：** `apps/wenbo-yuedong-xinzhang/app/`

## 1. 首次启动
- 直接进入「今日」Tab（无独立隐私首屏）
- 可选：我的 → 设置与隐私 → 查看《隐私政策》《用户协议》（全文 Overlay 可滚动）

## 2. 今日执行（问题 1 复测）
1. 点击右下角 **+** 添加任务（如「晨间阅读 30 分钟」）
2. 在任务行右侧 **勾选 Checkbox**（勿只点卡片）
3. 确认首页「今日进度」：**已完成 1/1**、圆环 **100%**
4. 切到 **成长** Tab → 日视图：**今日完成率 100%**、跃动指数上升
5. 切到 **我的** Tab → **完成率** 同步更新

## 3. 篇章收官（问题 1 复测 · 已收官章）
1. **篇章** Tab → 开启新章（或首页开启）
2. 进入篇章详情 → 章末复盘写 **≥20 字**
3. 点击 **「写完并收官」** → Toast 显示累计篇数
4. **我的 → 已收官章** 数字 +1

## 4. 目标删除（问题 3 复测）
1. **目标** Tab → 创建目标 → 进入详情
2. 点击 **删除目标** → 确认弹窗 **删除 / 取消** 两按钮完整可见、可点

## 5. 对比度（问题 4）
- 浅色 / 深色模式下，设置页次要按钮（如「查看《隐私政策》」）文字清晰可读

## 6. 功能丰富度（问题 2）
- **成长**：产品能力概览、时间轴、热力图、徽章、导出
- **我的 → 使用指南**：完整功能说明
- **搜索 / 收藏 / 标签 / 打卡 / 导出** 均可演示

## 7. 数据说明
- 全部数据存于本机 Preferences，无需账号与联网
- 卸载 App 会清除数据
