# 跃动新章 — 差异化说明

对比系统日历 / 备忘录，以及 avoidSlugs：`songlan-zha`, `jilei-riji`, `qingning-richang`

1. **核心实体是「人生篇章」**：一段有主题、有期限、必须写章末复盘才能收官的成长单元，不是日历事件。
2. **收官是写作动作**：复盘正文 ≥20 字才允许关闭篇章，并支持复制到剪贴板；系统提醒没有这项。
3. **领域时间账**：任务带工作/学习/生活标签 + 投入分钟，复盘页按占比可视化。
4. **跃动指数**：由完成率、连续天数、目标进度、进行中篇章、已收官章合成，非简单待办计数。
5. **今日章双视图**：清单 + 07:00–21:00 小时轴，任务点进详情可编辑备注。
6. **目标拆解里程碑**：独立于篇章与任务，完成自动归档。
7. **Tab 语义**：今日章 / 目标 / 复盘 / 我的，非系统「日历+待办」换皮。
8. **原生 ArkUI 全闭环**：无 WebView、无外链聚合、无广告。

## 审核员 3 分钟路径

```
开启新章（职场跃升 / 7天）
 → 写入今日任务（学习 25 分钟）
 → 点进详情补记投入、写备注、完成
 → 复盘页看时间账与跃动指数
 → 篇章详情写满 20 字收官 → 复制复盘
```
