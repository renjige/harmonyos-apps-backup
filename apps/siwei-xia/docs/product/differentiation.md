# 差异化 — 思维匣 vs 普通灵感备忘

对照：`wenbo-linggan-beiwang`（灵感备忘）· `inspiration-slip` 类灵感笺 · `songlan-zha`（札记）

## 核心差异（审核 3.7 重点）

**思维匣不是「只记一句灵感」的简易备忘**，而是 **灵感 → 加工 → 可视化** 的完整思维链路：

| 阶段 | 能力 | 普通备忘通常没有 |
|---|---|---|
| **收** | 速记 + 标签 + 附图 + 收藏分类 | 仅有文本列表 |
| **加工** | 思考工坊 6 工具：问题拆解 / 思维笔记 / 观点卡片 / 每日思考 / 目标推演 / 复盘 | 无结构化加工 |
| **链路** | **匣格链路**：灵感详情一键生成拆解/笔记/观点，SparkBridge 持久化关联 | 记录之间无关联 |
| **看** | 标签层级导图 + 主题分支 + 思考时间线 | 无导图/无时间线 |
| **洞察** | 本周思考洞察（新灵感/加工数/链路数/高频标签） | 无统计洞察 |

## 交互与信息架构

1. 底栏 **灵感 | 思考 | 导图 | 标签 | 我的** — 五 Tab 分工明确，非单页速记。
2. 首页 **匣格思维链路** 面板：展示灵感/已加工/拆解/笔记/观点数量，可直达思考工坊与标签导图。
3. 灵感详情 **思维加工** 区：拆解 / 笔记 / 观点 一键推进，并跳转对应工坊子工具。
4. 已加工灵感在列表显示 **「已加工」** 标记，与普通未加工卡片可区分。
5. 我的页 **本周思考洞察** + **思考时间线**：按时间串联灵感与加工记录。

## 视觉与品牌

- 品牌色深空蓝 `#1A2332` + 琥珀金，Logo 微启匣 + 光点。
- 影像为木匣/纸面/标签静物，非紫调灵感备忘或松岚绿札。
- 文案使用「智慧归类 / 智慧语音」，禁止「AI」字样。

## 数据与闭环

- 卡片正文 **仅本机**；平台只提供标签预设/词库/导读栏目。
- 回收站 30 天自动清理 + TXT/Markdown 导出（含思考工坊内容）。
- 游客可浏览速记；登录仅用于账号体系，不上传正文。

## 与仓库其它 App 区分

- 不是画板/创意计划，也不是随机灵感签或纯日记。
- 主实体是 **思维卡片 + 匣格链路 + 标签导图**，不是同质化「灵感列表」。
