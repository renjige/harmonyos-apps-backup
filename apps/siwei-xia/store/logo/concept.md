# Logo Concept — 思维匣

- 公司 / App / 行业：思维匣 / 思维匣 / thought-box（灵感卡片与思维导图）
- 品牌关键词：Casket / Structure / Amber / Quiet / Order
- 核心元素（仅 2）：微启方形匣 + 匣缝中 4 个有序圆点（思维碎片）
- 禁止项自检：无 AI 模板、无渐变球、无灯泡/大脑/机器人、无发光、无六边形
- 色板：深空蓝 `#1A2332` + 琥珀金 `#D4A56A`（仅 2 色）
- 对比策略：App Icon 用深蓝底 + 琥珀金标，明度差足够；灰度打印仍能看出打开的盒子轮廓
- brandAnchor：匣
- glyphStrategy：semantic-fusion
- 行业模板对比：不是灵感笺的「笺纸+星芒」，也不是备忘类折角便签
