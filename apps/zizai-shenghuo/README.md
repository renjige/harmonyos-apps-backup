# 自在生活

智慧生活助理 — 每日生活智慧语录、情绪记录与习惯节奏，帮助找回生活的掌控感与从容。

## DevEco 工程

打开目录：`apps/zizai-shenghuo/app/`

## 上架图标

`apps/zizai-shenghuo/store/logo/preview-1024.png`

## 核心功能

| Tab | 功能 |
|-----|------|
| 首页 | 每日生活智慧、天气节气（模拟）、收藏 |
| 记录 | 心情 + 感恩记录、月历标记、历史列表 |
| 节奏 | 待办勾选、习惯打卡、环形进度 |
| 我的 | 昵称、设置与隐私、主题切换 |

## 数据与合规

- **纯本地存储**，无网络权限，无需登录
- 首次启动隐私同意弹窗（勾选协议后进入）
- 运营者：魏文波

## 验收步骤

1. 冷启动 → 隐私弹窗 → 同意 → 进入四 Tab
2. 首页收藏一条智慧 → 我的收藏可见
3. 记录页保存心情与感恩 → 月历出现圆点
4. 节奏页勾选待办与习惯 → 进度环更新
5. 我的 → 设置与隐私 → 撤回隐私同意 → 再次弹出协议
