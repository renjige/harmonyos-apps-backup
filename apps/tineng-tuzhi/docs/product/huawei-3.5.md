# 华为 50104-3.5 对照 · 体能图志

官方要求：实质功能 + 创意；不得纯信息展示、单一页面、Web 套壳、模板聚合、系统简易功能换皮。

| 审核员可能质疑 | 本 App 如何回应 |
|---------------|----------------|
| 像系统运动健康 | 不读手环/GPS/计步；全部为用户手动记录 |
| 只有简单记录 | **日志库 + 模板再练 + 周对照 + 个人最佳 + 训练复盘 + 三套多周方案 + 图鉴/挑战/成就/档案** |
| 只能看图 | 日志增删改、清单勾选、挑战开始/完成、周训编排、收藏动作、**方案加入周期计划** |
| 单一页面 | 5 Tab：首页 / 计划 / 图鉴 / 成长 / 我的 + 多层 Overlay |
| 套模板 | 图鉴五类独立摄影、7 天活力计划、主题空间、智慧助手规则建议 |
| 半成品 | 详情 Hero + 字段 + 编辑/删除；保存后数字刷新 |
| 双隐私弹窗 | 仅华为隐私声明托管，应用内无第二份同意窗 |

审核演示路径见 `store/demo-account.md`。
