# 体能图志 — 差异化说明

对比 avoidSlugs：`yundong-tuce` · `huoli-lvcheng-huoli-jixing` · `chenqi-zaoqi-daka`  
对照系统能力：华为运动健康（GPS/计步）不是本 App 主路径。

1. **核心实体**：运动记录 + 周训图志 + 周图志报告 + 体能档案（计划/打卡/动作库）
2. **主差异化**：先排一周训练底图，再对照完成量与配比，并沉淀个人训练规划，不是被动同步手环数据
3. **工作台**：今日分钟 + 周训对照 + 记录 CTA，非打卡动效或影像相册
4. **热力图是入口**：点格子打开当日列表，可补记、进详情编辑删除
5. **品牌色**：活力橙 `#FF6B35` + 深空蓝 `#1A2332`
6. **Logo**：上升数据曲线 + 跑者轮廓，brandAnchor「体」
7. **智慧建议**：规则模板周报，不提供生成式对话
8. **本地闭环**：无登录墙、无 Web 套壳、无外链聚合
