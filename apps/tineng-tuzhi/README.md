# 体能图志（FitGraph）

**公司**：体能图志科技  
**定位**：个人体能成长空间 — 训练日志、计划、动作图鉴、挑战与成长图志，而不是系统计步换皮

## 信息架构

| Tab | 功能 |
|-----|------|
| 首页 | Hero、今日计划、智慧助手、快捷入口、今日日志 |
| 计划 | 周训编排、7 天活力计划、周期计划、挑战馆、今日清单 |
| 图鉴 | 热身/拉伸/力量/平衡/放松 · 详情收藏 |
| 成长 | 月度报告、配比/趋势/热力、时间轴、成就 |
| 我的 | 体能档案、状态笔记、主题空间、灵感库、隐私设置 |

## 数据存储

训练日志、计划、图鉴收藏与笔记默认仅存本机（Preferences），无需登录。不申请网络/定位/健康权限。

## 验收步骤

1. 首次启动：仅华为隐私托管弹窗，进入首页（无第二份应用内弹窗）
2. 首页 → 记录训练（名称 + 完成状态 + 星级）→ 累计次数非 0
3. 图鉴 → 打开动作详情 → 收藏 / 记入日志
4. 计划 → 套用 7 天活力计划；开始一项挑战；勾选清单看完成百分比
5. 成长 → 时间轴与成就；点热力格子看当日日志
6. 我的 → 状态笔记、主题空间、灵感库；设置与隐私 → 撤回（确认 + Toast）
