# 审核演示说明 · 体能图志

本应用**无需登录**。请按下面路径演示实质功能（对应华为 3.5，不是纯展示）：

1. 首次启动由华为应用市场隐私声明托管确认后进入首页（应用内**不再**弹出第二份隐私窗）
2. 首页点「编排周训」→「填入交叉训练模板」→ 改一天的类型/分钟 → 保存周训图志
3. 首页点「记录今日运动」→ 选类型、填时长、选体感/标签、写心得 → 保存
4. 打开「图志」：本周分钟 / 累计次数等应与刚保存的记录一致
5. 点「周图志报告」、今日记录、热力图某一天：进入详情或列表，不闪退
6. 「档案」打卡、新建 30 天计划、勾选准备清单、点挑战标记完成、收藏一条心得
7. 「我的 → 设置与隐私」可查看协议、导出数据、撤回隐私同意（二次确认 + Toast）

数据均存本机，卸载后清除。不申请健康、定位、传感器权限。
