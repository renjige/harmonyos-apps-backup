# 华为审核复测说明 · 体能图志

提交新版本时，可在 AppGallery Connect「版本信息 → 应用审核信息」粘贴下列要点。

## 问题 2（3.5 内容丰富度 · 本版重点增强）

审核意见：应用仅有简单记录功能，内容丰富度欠佳。

**本版已扩展为「训练日志 + 计划编排 + 动作图鉴 + 成长分析 + 个人档案」五位一体体能工作台**，非单一计数器：

| 模块 | 能力说明 |
|------|---------|
| **首页工作台** | 本周活跃日历、本周/上周对照、今日计划进度、智慧建议、快捷再练（重复上次 + 模板库）、全量日志库入口 |
| **训练日志库** | 全部历史记录、按运动类型筛选、进详情编辑/删除 |
| **计划中心** | 周训编排、7 天活力计划、**3 套结构化多周方案**（入门 4 周 / 跑步进阶 / 居家力量）、周期计划、挑战馆、今日清单 |
| **动作图鉴** | 五类内置动作收藏、详情、一键记入日志 |
| **成长页** | 周对照、个人最佳（时长/距离/消耗/单日）、**规则化本周训练复盘**、配比/趋势/热力图、时间轴、成就 |
| **我的档案** | 状态笔记、主题空间、灵感库、导出、设置与隐私 |

数据均来自用户手动记录，**不申请网络/定位/健康/传感器权限**。

## 问题 1（功能异常 · 已修复）

| 审核步骤 | 修复说明 | 复测路径 |
|---------|---------|---------|
| 记录后累计训练/坚持天数仍为 0 | 保存后通过全局 `fitDataEpoch` 立即刷新首页/我的统计 | 首页 → 记录训练 → 保存 → 累计训练应即时 +1 |
| 保存周训仍显示未排期 | 修复 weekKey 落库与当天开关 | 编排周训 → 保存 → 首页「今日计划」更新 |

## 建议审核演示路径（约 5 分钟）

1. 首次启动进入首页（无独立隐私首屏）
2. **记录一笔训练** → 看累计/本周活跃圆点变化
3. 首页 **「重复上次」或快捷模板** → 预填记录表单 → 保存
4. 首页 **「浏览全部训练日志」** → 类型筛选 → 点进详情
5. **计划** → **浏览训练方案库** → 加入周期计划 → 看「我的周期计划」
6. 勾选 **今日训练清单** 一项（即时变 `[完成]`）
7. **图鉴** → 动作详情 → 收藏
8. **成长** → 周对照 / 个人最佳 / 本周训练复盘 / 热力图点某天
9. **我的** → 状态笔记、主题空间
