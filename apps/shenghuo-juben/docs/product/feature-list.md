# 功能清单 — 生活剧本

## 核心 Tab

| 模块 | 功能 | 状态 |
|------|------|------|
| 我的剧本 | 卡片列表、搜索、心情筛选、Hero、创建 | ✅ |
| 创建/编辑 | 可选日期、标题、场景≤500、心情、1–3配图可删、智慧开场白 | ✅ |
| 详情 | Hero+开场白+场景+图集、编辑、删除二次确认 | ✅ |
| 时光相册 | 月历、当月空态、同日多剧本、进详情可编辑 | ✅ |
| 我的 | 头像、昵称保存、剧本数、版本、深色持久化 | ✅ |

## 合规与存储

| 项 | 状态 |
|----|------|
| 首次启动隐私弹窗 + 协议全文 | ✅ |
| 撤回隐私同意二次确认 + 即时生效 | ✅ |
