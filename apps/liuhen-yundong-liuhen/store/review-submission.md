# AppGallery Connect · 审核补充说明（v1.0.6）

提交新版本时，可在「版本信息 → 应用审核信息」粘贴以下内容。

## 针对问题 1（3.1 功能异常）— 已修复说明

本版本 **1.0.6** 已修复数据保存/清除后界面不刷新的问题，**无需杀进程**：

1. **首页「本周数据」**：保存或补记运动后，`DataBus.refreshAll()` 重算统计并递增 `dataEpoch`；首页通过 `@State` 同步 AppStorage 中的本周次数、总时长、平均与最长单次，保存后即时可见。
2. **清除全部运动数据**：「我的 → 设置与隐私 → 清除全部运动数据」同步清空运动记录、成就、周报印记及打卡/计划/挑战/心得；各 Tab 监听 `dataEpoch` 后自动 `reload()`。
3. **留痕 / 历史**：类型分布、个人纪录、周报印记、月历与近 4 周频率在数据变更后自动重载。
4. **计划 · 准备清单**：勾选采用乐观更新（先改 UI 再持久化），勾选框与删除线即时可见。

**建议复测路径（无需杀进程）**：

- 首页 → 开始运动（≥30 秒）→ 保存 → 查看「本周数据」是否增加
- 计划 → 准备清单 → 勾选任一项 → 应立即显示已勾选
- 我的 → 设置与隐私 → 清除全部运动数据 → 切换留痕/历史/首页应为空态

**关于「本周数据」口径**：统计 **自然周（周一至周日）** 内、按记录日期归属的运动。若「最近一次」不在当前自然周，首页会提示「该记录日期不在本周，不计入上方统计」——此为产品设计，非程序错误。

## 针对问题 2（3.5 内容丰富度）— 功能说明

「运动留痕」是个人运动计划与习惯管理工具，提供 **5 Tab 完整闭环**（非单一记录）：

| 模块 | 能力 |
|------|------|
| **首页** | 开始/补记运动、本周/本月统计、连续打卡、智能周报摘要 |
| **计划** | 每日打卡、周/月目标、7/21 天挑战、准备清单、**今日身体状态**、训练心得 |
| **留痕** | 运动时间线、类型分布、个人纪录、周报印记与复盘 |
| **历史** | 月历回顾、近 4 周频率趋势 |
| **我的** | 主题、目标、数据导出、清除数据、设置与隐私 |

数据仅存本机，不依赖定位/GPS/健康 Kit。
