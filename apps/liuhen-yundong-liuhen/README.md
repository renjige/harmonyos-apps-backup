# 运动留痕

轻量级运动记录与可视化鸿蒙应用 — **每一次运动，都留下痕迹**。

为满足华为应用市场 50104-3.5「实质价值」：五 Tab（首页 / 计划 / 留痕 / 历史 / 我的），运动记录、计划打卡、挑战、周报复盘均可演示，非纯展示、非系统健康套壳。

## 核心功能

- **首页**：本月目标、本周四维数据、打卡、开始运动
- **计划**：每日打卡、周期计划、挑战、准备清单、心得收藏
- **留痕**：时间线、类型分布、个人纪录、周报印记（写复盘/置顶）、补记
- **历史**：月历标记、周趋势、当日清单与详情
- **我的**：累计数据、成就、目标、导出、隐私
