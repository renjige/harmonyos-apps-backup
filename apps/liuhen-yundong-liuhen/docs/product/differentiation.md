# 差异化说明 — 运动留痕

对照华为 50104-3.5：本应用不是纯信息展示、不是单一页面、不是系统健康的换皮计时器。

对比 avoidSlugs：`huoli-lvcheng-huoli-jixing` · `yundong-tuce` · `chenqi-zaoqi-daka`

1. **主任务**：运动计时 + 事后补记 + 时间线记忆（非早起打卡 / 非影像日记）
2. **双实体**：WorkoutRecord（场次）与 WeeklySnapshot（周报复盘可写可置顶）
3. **五 Tab**：首页 / 计划 / 留痕 / 历史 / 我的，覆盖记录、计划、打卡、挑战与回顾
4. **写操作闭环**：创建（计时或补记）→ 详情 → 编辑 → 删除确认 → 统计即时刷新
5. **创意点**：把运动串成「痕迹」时间线，而不是 GPS 地图或系统运动健康数据镜像
6. **无套壳**：ArkUI 原生，无 WebView、无外链聚合、无广告
7. **联网**：纯本地零权限，与 SaaS 打卡类 App 不同
8. **Logo / 影像**：轨迹线+印记点；跑道 Hero 与健身房空态，非手账风
