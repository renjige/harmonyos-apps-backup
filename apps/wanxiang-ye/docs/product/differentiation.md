# 万象页差异化说明

## 与「简单资讯聚合」的区别

| 维度 | 普通资讯 App | 万象页 |
|------|-------------|--------|
| 定位 | 只读内容流 | 个人轻知识工作台 |
| 用户数据 | 仅收藏/历史 | 自建知识 + 灵感 + 计划 + 打卡 + 成就 |
| 导航 | 首页/搜索/我的 | 首页工作台/知识库/复习/我的 |
| 闭环 | 浏览→详情 | 浏览→记笔记→转知识→复习→统计成长 |

## 核心创意

1. **读记一体**：精选文章可「转为我的知识」，沉淀为个人资产
2. **复习队列**：收藏/稍后再读自动进入复习 Tab，「记住了/稍后再看」
3. **周计划 + 打卡**：本周读 N 篇可视化进度，连续天数激励
4. **今日任务**：阅读/复习/记录三项目标，引导完整日课闭环
5. **专题阅读路径**：4 条主题路线（科技/生活/文化/信息素养），进度可追踪
6. **阅读日历**：按月查看打卡日，可视化习惯养成
7. **成长可视化**：时间轴、分类统计、成就墙均来自真实本机操作

## 目标用户

希望「每天学一点并留下来」的读者，而非一次性刷资讯。
