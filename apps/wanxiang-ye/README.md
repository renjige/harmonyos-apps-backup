## 核心功能（v1.2.0）

| Tab | 能力 |
|-----|------|
| 首页 | 工作台：周计划、**今日任务**、四维统计、**专题阅读路径**、快捷操作、今日精选 |
| 知识库 | 平台精选 + 我的知识 + 灵感；筛选；FAB 新建 |
| 复习 | 复习队列、记住了/稍后再看、连续/待复习/已完成统计 |
| 我的 | **阅读日历**、数据统计、时间轴、成就墙、专题路径、收藏/笔记/历史 |

- v1.2.0 修复：HarmonyOS 6.x 本机统计读写兼容（已读/收藏/自建/打卡等不再恒为 0）

- 无登录、无支付、无广告
- 全部用户数据本机 Preferences 存储
- **0 个新增系统权限**

## 数据

- 内置 30 篇精选资讯（只读种子）
- 用户知识 / 灵感 / 计划 / 打卡 / 成就 / 时间轴（本机读写）
