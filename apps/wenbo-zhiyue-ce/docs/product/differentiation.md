# 差异化 — 智阅册

对照 avoidSlugs：`wenbo-zhishang-fang`（纸上方）· `wenbo-dushu-zhayu`（读书札语）· `wenbo-shuye-manyou`（书页漫游）

1. 主实体是「文稿」而非「书摘卡片」：必须先有可阅读正文与进度。
2. 四 Tab 为 阅读 / 摘录 / 知识册 / 我的，不是书房/添加/回顾 三 Tab。
3. 首页是书桌 Hero + 导入/粘贴双 CTA + 继续阅读条，不是书摘列表为主屏。
4. 沉浸阅读器带字号、进度档位、写入摘录，不是只填表单。
5. 知识册按主题收纳摘录，封面三张独立摄影，禁止与纸上方金点纸页标同构。
6. 智慧能力是归类标签 + 每日卡片 + 节律问卷模板，界面无「AI」字样。
7. 品牌色深海蓝 #2D3E50 + 香槟金 #C9A96E，Logo 为打开的书+书签，非 30° 单页。
8. 工作台 `catalog-tool`，主任务 3 秒内继续阅读或导入文稿。
