## 关于《审核指南》3.5（实用价值 / 非纯信息展示）

智阅册不是单一图书、不是网页套壳、不是内容聚合或链接罗列。它是本机知识管理工具，具备可执行闭环与可写操作。

**核心闭环（请按此路径验收）：**

1. **阅读**：导入 TXT / Markdown / PDF 或粘贴正文 → 沉浸阅读 → 记录 25%/50%/读完进度 → 写入摘录。  
2. **摘录**：保存原文 + 感想 + 标签 → 详情可收藏进每日卡片、编辑、复制、删除（删除需二次确认）。  
3. **知识册**：按职场 / 学习 / 生活 / 方法建册 → 封面与简介可编辑 → 把摘录收入该册。  
4. **阅读节律自检**：8 道选择题生成节律报告后，点「收入知识册并开始整理」会**真正写入**：一篇可继续阅读的节律计划文稿 + 一条可编辑摘录（并进入今日智慧卡片）。不是只展示报告。  
5. **回顾**：首页今日智慧卡片、摘录页随机回顾。游客即可完整使用，无广告、无内购、无外链跳转。

与系统备忘录的差异：文稿进度、摘录与知识册分栏、节律问卷产出可落库内容、每日一条复习。

## 问题 1（功能异常 · 已修复）

**测试步骤 1：阅读 → 导入文稿，导入后标题为乱码**

已修复。系统文件选择器返回的 URI 会对中文文件名做百分号编码；此前直接截取路径最后一段作为标题。现已改为：

1. 使用 `fileUri.FileUri.name` / 文件对象 `name` 取得解码后的显示名；
2. 对残留编码再做 `decodeURIComponent`；
3. 若仍无法得到可读标题，则使用「导入文稿 + 日期」，避免乱码上屏。

请用含中文文件名的 TXT 再测一次导入。

**测试步骤 2：阅读 → 导入文稿，PDF 导入后正文无内容**

已修复。此前仅对 TXT/Markdown 读文本，PDF 未复制、未预览，阅读页只显示空正文。现已改为：

1. 将 PDF 复制到应用沙箱，阅读页以原页预览（可缩放、翻页）；
2. 同时尽量抽取可复制文本；无文字层的扫描件仍可翻页阅读；
3. 需要沉淀的句子通过「写入摘录」粘贴保存。

请用一份带文字层的 PDF 导入后进入阅读页，应能看到原页内容。

   已改为收藏后立即切换按钮文案，首页「今日智慧卡片」与摘录列表同步更新。

3. **设置与隐私 → 深色模式，需杀进程才生效**  
   已改为切换后立刻重绘当前界面，无需杀进程。
