# Logo Concept — 智阅册

- 公司 / App / 行业：魏文波 · 智阅册 · wisdom-folio
- 品牌关键词：Folio / Open / Bookmark / Quiet / Accumulate
- brandAnchor：智（首字；以打开的书页 + 翘起书签表达「智慧沉淀成册」，不写汉字）
- 核心元素（仅 2 个）：打开的双页书本轮廓 + 一枚微微翘起的书签（抽象「册」）
- glyphStrategy：semantic-fusion
- 禁止项自检：无大脑、无机器人、无灯泡、无渐变球、无发光、无毛玻璃、无 3D、无 premium house 模板、非纸上方上扬单页、非荐书书架标
- 色板：深海蓝底 `#2D3E50` + 暖杏书页 `#E8D5B7` / 米白 `#F7F5F0`；书签香槟金 `#C9A96E` 仅作书签条
- 对比策略：App Icon 用「深海蓝底 + 浅书页标」，灰度后书脊与书签仍清晰；禁止蓝叠蓝
- 行业模板对比：
  1. 非纸上方 30° 单页+金点
  2. 非读书札语五 Tab 书架标
  3. 非轻知阁几何知识库标
