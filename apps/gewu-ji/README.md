## 产品概要

格物集是「发现 → 记录 → 计划 → 回顾 → 成长」的个人探索工具：

- **今日工作台**：功课进度、四项统计、快捷操作、最近观察、进行中功课、今日一物与小测
- **图鉴**：植物 / 动物 / 昆虫 / 矿物 / 日常物品；最近看过；收藏夹；搜索
- **功课**：物候打卡、周期功课（进度随观察增加）、自建专题册
- **记录**：五种笔记模板、标签、探索任务、搜索筛选
- **足迹**：阅读与观察统计、成就印记、年谱、本周柱状与周月回顾、设置与隐私

纯本地、零权限，无账号、无广告、无内购。首次隐私声明走华为托管，应用内不再重复弹窗。

## 审核对照（3.5 / 3.1）

1. 今日工作台 → 物候打卡 / 写观察 → 功课进度与足迹数字同步  
2. 图鉴详情 →「对照另一物」写笔记 → 格物记录可见；「最近看过」可回看  
3. 功课 → 新建周期目标 → 期内观察计入完成度  
4. 足迹 → 成就印记 / 年谱 / 七日物候点日期跳到当天观察  
5. **足迹 → 设置与隐私 → 查看《用户协议》/《隐私政策》全文：全屏、可滑到文末「全文完」**  
6. 格物三问保存后杀进程仍在  

## 自测清单

1. 冷启动 → 仅系统托管隐私弹窗 → 进入「每日一格」
2. 设置：打开协议须盖住底栏，能滚到最后一行；关闭后仍回设置页，底栏在关闭设置后恢复
3. 「写下今日观察」→ 保存 → 格物记录列表出现
4. 图鉴筛选 / 收藏夹 / 对照笔记 / 小测
5. 主题：浅色 / 深色 / 跟随系统
