# 格物集 · 丰富度升级方案（1.1.0）

## 1. 产品重新定位

**格物集**不是百科合集，也不是通用打卡工具。

定位：**本机「格物功课」——围绕真实物件做阅读、测验、观察、对照、计划与回顾。**

一句话：每日一物起手，用功课把探索变成可完成的目标，用年谱把足迹变成自己的成长史。

保留：零权限、零账号、预置图鉴 + 用户自写观察。不引入社交、支付、生成式对话、相机/定位。

## 2. 当前问题

| 维度 | 现状 | 问题 |
|------|------|------|
| 首页 | 今日知识物大卡 + 小测 | 像文章封面，不像工作台；缺少「我的数据」 |
| 导航 | 4 Tab：每日/图鉴/记录/足迹 | 计划、打卡、专题挤在记录/足迹里，层级不够 |
| 内容 | 预置图鉴 + 观察记录 | 用户不能建「专题册」；缺少最近浏览 |
| 计划 | 仅当日 5 个探索任务 | 不能自建周期目标（如本周 5 则植物观察） |
| 打卡 | 无 | 缺少轻量每日物候打卡 |
| 成长 | 环图 + 数字卡 | 无成就墙、无周柱状趋势、无活动年谱 |
| 视觉 | 卡片堆叠 | 首页信息层次弱，空用户与老用户几乎同一屏 |

## 3. 新增功能（均有真实数据与闭环）

1. **今日工作台**：进度环、四数、快捷入口、最近观察、进行中功课  
2. **物候打卡**：一日一条附记，写入年谱与连续天数  
3. **格物功课**：自建周期目标（图鉴范围 + 目标则数），进度随观察增加  
4. **专题册**：用户自建主题，收录图鉴条目，可进详情  
5. **最近浏览**：打开详情即记，图鉴可筛「最近看过」  
6. **格物年谱**：读/记/藏/测/打卡/功课 串成时间线  
7. **成就印记**：按真实数据解锁（首次观察、连续 7 天、10 则记录等）  
8. **本周趋势**：近 7 日观察条数柱状（真实计数）  
9. **本周/本月回顾**：由记录、打卡、小测汇总，非假数据  
10. **搜索增强**：记录页已有关键词/图鉴/标签/日期；图鉴增加最近浏览分栏  

不新增：假入口、空 Tab、相机定位、联网。

## 4. 页面结构

```
今日工作台
 ├─ 今日知识物详情（已有）→ 三问/札记/对照/写观察
 ├─ 格物小测（已有）
 ├─ 快捷：观察 / 打卡 / 功课 / 图鉴
 └─ 最近观察 → 记录详情

图鉴集册（已有 + 最近看过）
 └─ 详情 → 收藏夹 / 观察 / 对照

功课（新）
 ├─ 物候打卡（当日）
 ├─ 功课列表 → 功课详情（进度、关联观察）
 ├─ 新建/编辑功课
 └─ 专题册 → 条目列表 → 图鉴详情

记录（已有）
 └─ 列表 → 详情 → 编辑/追加/时间轴

足迹
 ├─ 统计 / 七日物候 / 图鉴进度（已有）
 ├─ 本周柱状 + 回顾
 ├─ 成就印记
 ├─ 年谱
 └─ 设置与隐私（协议全文，已有）
```

## 5. 底部导航

**今日｜图鉴｜功课｜记录｜足迹**

对应：工作台 / 内容中心 / 计划+打卡+专题 / 观察库 / 成长与设置。

## 6. 数据模型（本机 Preferences）

- `GewuPlan`：title, atlasKind, targetCount, startKey, endKey, note  
- `GewuCheckin`：dateKey, note, objectId  
- `GewuTopic`：title, objectIds[]  
- `GewuEvent`：dateKey, kind, title, refId  
- `GewuBadge`：catalog + unlockedIds  
- `browseIds`：最近打开的图鉴 id  

观察记录、收藏、三问、小测沿用现有模型。功课进度 = 周期内匹配图鉴的观察条数 / 目标。

## 7. 首页布局

1. 品牌 + 日期 + 今日功课完成环  
2. 四数：观察 / 收藏 / 连续 / 打卡  
3. 快捷：写观察、物候打卡、新建功课、打开图鉴  
4. 今日一物（压缩 Hero，保留已读/收藏/详情）  
5. 进行中功课进度  
6. 最近观察  
7. 探索方向 + 小测  

## 8. UI 方向

保持深蓝 + 雅金 + 米白；工作台用进度环做第一视觉，避免彩虹色块。快捷操作为文字胶囊，不用 Emoji 图标。

## 9. 用户闭环

浏览图鉴 → 小测/已读 → 打卡或写观察 → 计入功课进度 → 年谱与成就更新 → 周回顾激励下周功课。

## 10. 华为 3.5

实质功能：计划执行、打卡、自建专题、成就与回顾，均依赖用户自己的数据。不是信息罗列。0 新增权限。
