# 差异化说明 — 格物集 vs 仓库同类 App

对照 avoidSlugs：`wenbo-zhishi-tanbao`、`zhixun-zhishi-xunbao`、`ximan-guan`、`mingxu-ge`

1. **主任务**：每日单卡深度阅读，非闯关/积分/地图解锁
2. **Tab 结构**：3 Tab（每日一格 / 集册 / 足迹），非六件套 Home+AI+看板
3. **数据**：纯本地 JSON 池 + Preferences，无 SaaS `/biz/*`
4. **账号**：无登录注册，非 open_optional + LoginPage 模式
5. **权限**：零 requestPermissions，非 INTERNET / 提醒权限
6. **视觉**：新中式米白 + 深邃蓝 #1A3A5C + 雅金，窗棂 Logo，非工程橙仪表盘
7. **实体**：KnowledgeObject（时间轴+要点），非笔记/待办/习惯
8. **社交**：无排行、无分享、无 UGC
9. **生成式**：无 AI Tab、无 LLM、文案用「智慧足迹」
10. **影像**：书斋/器物摄影 Hero，非 Symbol 色块或纯渐变 Banner
