## 产品定位（重要）

格物集 **不是** 通用备忘录 / 日记 / 习惯打卡 App，而是 **「图鉴 + 每日一物 + 格物路径」** 的本机格物学习工具。

**1.2.0 信息架构调整（针对 3.7）**：

- **取消独立「观察札」Tab**（该形态易被误判为记事本列表 + 加号）
- 底栏改为 **四 Tab**：**今日 | 图鉴 | 功课 | 足迹**
- 观察札 **并入「功课」**，且 **只能从图鉴选物写入**，无空白自由新建
- 首页保留 **今日格物路径**（读→问→测→记→候）与 **格物三问 / 小测**
- 首次打开有 **产品引导**，说明非通用记事本

## 建议审核路径（3 分钟）

1. 首次启动 → 阅读引导 →「开始格物」
2. **今日** → 格物路径 + 三问 + 小测
3. **图鉴** → 五类知识物 → 进详情 → 两物对照 / 写观察
4. **功课** → 物候打卡 + 功课计划 + **图鉴观察札**（非独立记事 Tab）
5. **足迹** → 成就 / 年谱

## Connect 上架资料

- **分类**：教育 / 学习工具（勿选「生活 · 记录」）
- **一句话**：每日一物格物致知——图鉴学习、格物三问与小测，**不是通用备忘录**
- **截图**：引导 → 今日路径 → 图鉴 → 详情对照 → 功课页观察札区 → 足迹（**勿用空白列表主图**）
