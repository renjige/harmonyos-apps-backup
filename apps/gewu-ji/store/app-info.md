# 应用信息 — 格物集

- **版本**：1.2.0
- **分类**：教育 / 学习工具

## 一句话简介

每日一物格物致知——图鉴学习、格物三问与小测闭环，**不是通用备忘录**。

## 应用介绍

格物集是图鉴驱动的格物学习工具，**无独立记事 Tab**：

1. **今日**：格物路径（读→问→测→记→候）+ 每日一物 + 三问小测
2. **图鉴**：植物 / 动物 / 昆虫 / 矿物 / 日常物品
3. **功课**：物候打卡、周期计划、专题册、**图鉴观察札**（须从图鉴选物）
4. **足迹**：成就印记、年谱与成长统计

纯本地，无账号、无广告、无内购。

## 截图顺序（1.2.0）

1. 产品引导（非记事本说明）
2. 今日 · 格物路径 + 三问
3. 图鉴 · 五类
4. 详情 · 两物对照
5. 功课 · 观察札区（非独立列表 Tab）
6. 足迹 · 成就/年谱
