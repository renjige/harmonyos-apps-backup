# 功能清单 — 问知

| 能力 | 状态 | 说明 |
|------|------|------|
| 首页工作台 | ✅ | 今日进度、四维数据、快捷入口、最近动态、推荐继续学 |
| 适用场景 | ✅ | 6 类场景卡片：备考/职场/科普/错题/整理/习惯，首屏可见 |
| 今日学习任务 | ✅ | 路径 + 闪卡 + 新知 三项可勾选进度 |
| 学习功能中心 | ✅ | 工作台 8 宫格：路径/闪卡/挑战/错题/计划/日历/检索/笔记 |
| 闪卡复习 | ✅ | 卡片+错题翻转复习，记住了/还需复习闭环 |
| 学习日历 | ✅ | 14 日热力图 + 今日学习概览 |
| 结构化学习路径 | ✅ | 4 路径 × 多节章节，阅读+标记完成+进度持久化 |
| PathDetailPane | ✅ | 路径详情 Hero + 章节列表 + 阅读/标记 CTA |
| 深色模式 Toggle | ✅ | 我的页 Switch 即时切换界面与开关状态 |
| 学习动态（时间轴） | ✅ | 提问/收藏/阅读/答题/打卡/笔记/任务统一串联 |
| 学习回顾 | ✅ | 今日/本周/本月摘要 |
| 成就墙 | ✅ | 10 项里程碑，真实数据解锁 |
| 我的笔记 | ✅ | 用户自建笔记（非仅收藏备注） |
| 本周待学清单 | ✅ | 计划页添加任务、勾选完成 |
| 显式学习打卡 | ✅ | 首页/计划页打卡，连续天数联动 |
| 成长统计图表 | ✅ | 环形完成率 + 7 日柱图 + 收藏分类分布 |
| 知识检索 | ✅ | 关键词搜索 + 分类筛选 + 专题库（历史/科学/生活技巧/文化） |
| 解答详情 | ✅ | Hero + 摘要 + 正文 + 收藏 / 笔记 / 知识卡片 / 分享复制 |
| 平台知识百科 | ✅ | 知识库 Tab 展示 18+ 条分类百科与精选条目（新用户非空） |
| 我的知识库 | ✅ | 六类收藏夹、已学习/待了解/重点收藏标签、搜索、备注、删除 |
| 每日新知 | ✅ | 当日精选 + 今日一题答题 + 已阅 + 收藏 + 连续天数 |
| 知识挑战 | ✅ | 随机抽题、作答、成绩、错题入本 |
| 错题本 | ✅ | 查看正确答案、再看解答、移出 |
| 知识笔记 | ✅ | 收藏条目可写个人理解与学习心得 |
| 学习计划 | ✅ | 每日目标 3/5/8、今日进度、连续天数 |
| 成长统计 | ✅ | 提问、阅读、答题、收藏、连续天数 |
| 知识卡片 / 分享 | ✅ | 生成卡片保存；复制分享文案到剪贴板 |
| 我的 | ✅ | 昵称、学习入口、深色模式即时切换、设置与隐私、关于 |
| 求知偏好问卷 | ✅ | 6 题规则模板报告；无生成式对话 |
| 消息中心 | ✅ | GET `/messages` |
| 登录/注册 | ✅ | 协议勾选、账号密码、SessionStore；登录页不展示演示账号 |
| 隐私撤回 | ✅ | 设置与隐私 → async revoke + flush + logout + 顶层 Toast |
| 栏目数据 | ✅ | 平台 `/biz/wisdom-ask/*`；客户端无 localSeed |
| 无支付 / 无 AI 字样 | ✅ | `LLM_ENABLED=false` |
