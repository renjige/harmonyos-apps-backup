# 差异化 — 问知

对照 avoidSlugs：`wenbo-qingzhige`（轻知阁）、`zhixun-zhishi-xunbao`（知识寻宝）、知识探宝类闯关 App。

1. **产品定位**：个人知识**学习管理工作台**（路径 + 计划 + 知识库），不是轻阅读或闯关寻宝。
2. **底栏五 Tab**：工作台 / **学习** / 知识库 / 新知 / 我的 — 「学习」Tab 集中路径、清单、挑战、专题与百科。
3. **结构化学习路径**：4 条专题路径、多节进度、标记完成 — 非关卡地图或积分等级。
4. 工作台首屏是「8 宫格功能中心 + 今日数据 + 推荐路径」，提问检索默认折叠，不是「问答框 + 收藏」单场景。
5. 核心实体是「解答」与「路径章节」，支持要点 / 背景 / 延伸与路径进度。
6. 知识库按六类 + 三标签管理，支持笔记、卡片、导出式复制；不是背包或藏宝点。
7. 每日新知 = 精选 + 一题 + 打卡；挑战分 5/10 题，错题本可再练。
8. 品牌色 `#007DFF` + `#FF8C00`；C 端关闭生成式对话，界面无「AI」字样。
