## 应用介绍（上架用）

问知是面向学生与职场学习者的**个人知识学习管理 App**，不是简单的问答收藏工具。

**核心能力：**

1. **结构化学习路径**：历史文化、科学素养、生活实用、文化通识四条路径，每路径多节章节，可阅读解答、标记完成并追踪进度。
2. **工作台 + 学习 Tab**：**6 类适用场景**（备考/职场/科普/错题/整理/习惯）+ **今日 3 项学习任务** + 8 宫格功能中心。
3. **提问与解答**：关键词检索 + 分类筛选，结构化输出要点、背景与延伸阅读。
4. **个人知识库**：**平台百科 18+ 条**（6 分类可浏览）+ 个人收藏、标签、笔记与搜索。
5. **每日新知**：精选阅读 + 今日一题 + 连续学习天数。
6. **成长体系**：学习动态时间轴、本周/本月回顾、成就墙、成长统计图表。
7. **我的笔记**：用户自建知识笔记，独立于收藏备注。

不提供社交、支付、会员与生成式 AI 对话。

## 关键词

知识管理, 学习路径, 问答, 计划打卡, 错题本, 笔记, 鸿蒙

## 审核演示建议路径

1. 打开 **工作台** → 8 宫格 → **闪卡复习** / **学习日历**  
2. **学习** Tab → 点任一路径 → 阅读章节 → 标记完成  
3. **工作台** → 展开提问 → 收藏到知识库 → 写笔记  
4. **学习** → 快速挑战 5 题 → 错题本再练  
5. **新知** Tab → 每日阅读 + 答题  
6. **我的** → 成长中心（动态/回顾/成就）
