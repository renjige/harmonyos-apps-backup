# Logo Concept — 问知

- 公司 / App / 行业：魏文波 · 问知 · wisdom-ask
- 品牌关键词：Question / Clarity / Insight / Trust / Light
- 核心元素（仅 2 个）：几何问号曲线 + 底部暖橙光点（提问带来启迪）
- brandAnchor：问
- 行业模板对比：
  1. 不是轻知阁的「书页 + 阁檐」
  2. 不是知识探宝的罗盘 / 宝藏
  3. 不是 premium_logo 默认 house+cloud、不是五角星、不是灯泡
- 禁止项自检：无五角星、无灯泡、无机器人、无大脑、无渐变球、无 3D、无滤镜
- 色板：深空蓝 `#0B1F3A` + 白 `#FFFFFF`（暖橙 `#FF8C00` 仅作光点）
- 对比策略：App Icon 用近黑蓝底 + 白问号，缩小 24px 仍可辨弧线与圆点
