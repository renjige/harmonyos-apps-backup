# 差异化说明

本应用「筑科材料验收」与同公司其他产品职责不同，禁止视为换皮。

## 对照「筑科建筑」（企业展示）

1. 本应用不做企业介绍、案例展示或品牌官网式浏览。
2. 主任务是材料进场当场登记，而不是对外宣传。
3. 首页主 CTA 是「开始材料验收」，不是「了解我们」。
4. 数据以本机验收记录为源，不是内容栏目运营。
5. 不提供资讯流或活动报名。
6. 视觉为现场工业记录工具，而不是企业画册。

## 对照「筑科质量巡查」（现场质量巡查）

1. 巡查产品跟踪质量问题、整改闭环；本应用只记录材料进场验收。
2. 本应用检查项固定为外观、包装、数量、资料四项，不做巡查清单模板引擎。
3. 状态为通过 / 待处理 / 不通过，不是隐患等级或整改期限。
4. 游客即可完成本机记录；巡查类多为登录墙现场协同。
5. 不包含整改指派、复查签字或隐患台账。
6. 品牌符号为 ZK + 验收勾，主色建筑蓝 `#1E5A8A`，与巡查蓝系队列产品可区分。

## 本产品边界

只做：材料到场 → 填写 → 检查 → 拍照 → 保存 → 查询。  
不做：ERP、采购、财务、支付、商城、会员、社交、直播、自由对话生成。
