# Logo Concept — 筑科材料验收

- 公司 / App / 行业：筑科建筑工程有限公司 · 筑科材料验收 · 材料进场验收工具
- 品牌关键词：Structure / Trust / Record / Confirm / Order
- 核心元素（仅 2）：几何字母 ZK（筑/科）+ 验收勾
- brandAnchor：筑（字母 Z 为视觉锚点，K 为科，勾为验收确认）
- 禁止项自检：无安全帽、无塔吊、无楼宇剪影、无扳手、无渐变球、无 3D
- 色板：2 色 — 深石墨 `#1A1F26` + 白 `#FFFFFF`；点缀低饱和绿仅用于勾（打印时勾仍可辨）
- 对比策略：App Icon 深石墨底 + 白标；灰度后 Z 与勾轮廓仍清晰
- 行业模板 vs 本稿：
  1. 非「筑科建筑」企业展示的楼宇/案例封面
  2. 非「筑科质量巡查」的巡查队列/问题闭环图标
  3. 非传统工程软件安全帽/塔吊剪影
