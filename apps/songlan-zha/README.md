# 松岚札

智慧生活记录与轻量笔记工具 — 帮助用户优雅记录灵感、管理待办、沉淀思考。

## 功能概览（完整闭环）

| 模块 | 列表 | 详情 | 三级动作 |
|------|------|------|---------|
| **今日札记** | 首页语录+心情 | 日历月视图 | 按日查看/编辑/删除札记 |
| **智慧笔记** | 搜索+卡片列表 | Hero详情+标签 | 编辑/转待办/删除 |
| **待办清单** | 全部/进行中/已完成 | 编辑页 | 完成/改优先级/截止日期/删除/清空已完成 |
| **设置** | 数据统计 | 关于/协议 | 深色模式/清数据(确认)/撤回隐私(确认) |

## 自测路径（建议逐条点一遍）

1. 首次打开 → 同意隐私 → 进首页  
2. 写今日札记 → 打开日历回顾 → 点某天编辑  
3. 新建笔记 → 详情 → 转待办 → 待办 Tab 可见  
4. 待办添加(含截止日期) → 点行编辑 → 标记完成 → 清空已完成  
5. 设置 → 清数据确认 → 统计归零
