# 松岚札 — 差异化说明

与仓库内 `qingning-richang`、`jilei-riji` 等日记类 App 的差异：

1. **品牌气质**：深翠绿 + 香槟金 + 松雾摄影，禅意留白（非青柠绿打卡风）
2. **核心闭环**：笔记 + 待办 + 每日札记三合一（非单一打卡或相册日记）
3. **工作台**：`catalog-tool` — 今日语录 + 札记首屏（非大数字 KPI 仪表盘）
4. **详情链**：笔记/札记均有 DetailShell + Hero + CTA（编辑/转待办/删除）
5. **日历回顾**：独立 `JournalCalendarPage` 月视图，可点日期进详情
6. **智慧识别**：笔记正文自动提取日期/时间/地点标签并展示
7. **本地优先**：无 INTERNET 权限，Preferences 存储，无平台强依赖
8. **Tab 结构**：札记 · 笔记 · 待办 · 设置（四 Tab，无「我的」登录墙）

结构指纹自检：未使用「三 KPI + 宫格 + AI 横幅」工厂六件套。
