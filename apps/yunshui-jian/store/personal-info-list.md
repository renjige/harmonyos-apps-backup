# 个人信息收集清单 — 云水间

> 本应用为纯本地工具，以下信息均保存在设备本机，不上传云端。

| 信息类型 | 是否采集 | 采集场景 | 使用目的 | 存储位置 |
|---------|---------|---------|---------|---------|
| 札记标题与正文 | 是 | 用户创建/编辑札记 | 生活记录与回顾 | 本机 Preferences |
| 札记标签与分类 | 是 | 写札记时添加 | 筛选、统计与主题册 | 本机 |
| 札记本地照片路径 | 可选 | 用户添加照片 | 主题册与详情展示 | 本机沙箱 |
| 每日心情 | 可选 | 首页选择心情 | 心绪记录与统计 | 本机 |
| 灵感/经验卡片 | 是 | 经验库新建编辑 | 沉淀生活方法 | 本机 |
| 目标与挑战进度 | 可选 | 经验库目标/挑战类 | 进度追踪与成就统计 | 本机 |
| 收藏标记 | 可选 | 灵感卡片收藏 | 快速找回重要内容 | 本机 |
| 计划与清单事项 | 是 | 计划页新建编辑 | 日常安排与完成追踪 | 本机 |
| 习惯名称与打卡记录 | 是 | 习惯打卡操作 | 连续天数与累计统计 | 本机 |
| 纪念日名称与日期 | 可选 | 我的页添加 | 回顾页倒计时展示 | 本机 |
| 深色模式偏好 | 是 | 我的页切换 | 界面主题 | 本机 |
| 隐私同意标记 | 是 | 首次或设置操作 | 合规记录 | 本机 |

**不采集**：账号、密码、手机号、设备标识符用于追踪、地理位置、通讯录、生物特征。

**不上传**：以上信息不会通过网络传输至运营者或第三方服务器。
