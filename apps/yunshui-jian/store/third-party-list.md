# 第三方共享清单 — 云水间

更新日期：2026年9月1日

## 结论

**本应用不接入任何第三方 SDK，不向第三方共享用户个人信息。**

| 类别 | 是否使用 | 说明 |
|-----|---------|------|
| 广告 SDK | 否 | 无广告 |
| 统计/分析 SDK | 否 | 无埋点上报 |
| 社交分享 SDK | 否 | 无分享组件 |
| 支付 SDK | 否 | 无付费功能 |
| 地图/定位 SDK | 否 | 不申请定位权限 |
| 推送 SDK | 否 | 无推送 |
| 生成式 AI / 大模型 | 否 | 不提供 AI 对话，不向外部模型传输用户内容 |
| 云存储/账号 SDK | 否 | 无登录、无云端同步 |

## 网络说明

本应用不申请 `INTERNET` 权限，运行时不对接外部 API。
