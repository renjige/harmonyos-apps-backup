# 云水间 — 与仓库其他 App 差异

对照 avoidSlugs：`shenghuo-zha`, `songlan-zha`, `ximan-guan`

1. **品牌色**：青黛 #3D5A5C + 墨绿 #2C4A3E + 米白 #F7F5F0（非生活札暖橙、非松岚札深绿、非溪漫观蓝绿）
2. **工作台**：`cloud-atelier` 首页工作台首屏 + 快捷创建 + 数据摘要（非生活札时间线首屏、非松岚札札记首屏）
3. **Tab 结构**：首页 / 札记 / 计划 / 回顾 / 我的（五 Tab；札记含灵感/经验分段，回顾含主题册/月度/时光）
4. **影像**：云雾山水 Hero + 茶席 Banner（非暖橙手账摄影）
5. **实体**：跨模块主题册聚合 + 经验库 + 成就统计（生活札相册独立 Tab，溪漫观仅情绪三栏）
6. **Logo**：云水双曲线留白符号，青黛线条（非书页折角、非山形几何）
7. **权限**：0 系统权限，纯本机（生活札有系统提醒权限）
8. **架构**：YunLocalStore 统一数据联动引擎（统计/时光轴/成就同源计算）
