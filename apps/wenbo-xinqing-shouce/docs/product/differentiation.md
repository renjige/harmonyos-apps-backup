# 心情手册 · 差异化说明

与 `wenbo-shenghuo-zhaji`（生活札记）差异：

1. **产品定位**：情绪美学数字手账，以「心情状态」为核心而非通用生活札记
2. **Tab 结构**：首页 | 记录 | **日历** | **足迹** | 我的（无独立相册 Tab）
3. **首页首屏**：今日心情 Hero + 心情状态标签 + 一句话记录（非「写今日札记」）
4. **记录表单**：五步心情选择器 + 可选封面图（非仅标题正文）
5. **日历页**：月度心情点阵 + 图例（生活札记无此 Tab）
6. **成长足迹**：坚持天数 + 记录数 + 常用标签（非年度相册统计为主）
7. **视觉色板**：奶油白 + 雾霾紫 + 柔和粉 + 薄荷绿（非莫兰迪橙主色）
8. **Logo**：心形 + 手册 + 光点（brandAnchor=心）
