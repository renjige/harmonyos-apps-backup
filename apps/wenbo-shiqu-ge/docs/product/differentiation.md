# 识趣阁差异化

对照 avoidSlugs：`wenbo-qingzhige`（轻知阁）· `wenbo-shuye-manyou`（书页漫游）· `wenbo-sijian-tang`（思见堂）

1. 核心实体是编辑精选「趣知文章 + 每日一趣」，不是用户自建知识、不是书单笔记、不是思录社交。
2. 四类固定：文史趣谈 / 科学冷知 / 生活智慧 / 职场识趣，首页胶囊筛选而非复习队列。
3. 工作台 catalog-tool：Hero 摄影 + 内容流，主 CTA「阅读这篇」，无三 KPI 宫格。
4. 收藏与阅读记录默认本机且新用户为空，不是云端复习连续天数。
5. 品牌色暖灰褐 `#8B7A6B` + 香槟金 `#C4A882`，Logo 为飞檐+书卷，非书页曲线、非灯笼。
6. 无生成式对话；「识趣偏好」是问卷模板匹配，从「我的」进入，不是底栏 AI Tab。
7. 每日一趣是独立底栏，带日期大字号语录，不是「今日节选+书名作者」。
