# 研语 v1.3.0+ 审核修复说明

## v1.3.2（HarmonyOS 6.1 / API 24 专项）

### 问题 1 · 知识统计仍全为 0

**根因（二次排查）**：
1. Tab 切换用 `if/else` 销毁页面，保存数据后 `@Watch` 无法触达已卸载的「成长」页
2. `@Builder statRow(label, value)` 在部分机型上参数不随 `@State` 刷新，界面卡在初始 0
3. Preferences 在 SessionStore 初始化失败分支中可能未 `await` 完成，导致静默写失败

**修复**：
- `MainTabPage` 五 Tab **保活**（`Visibility.None` 隐藏而非销毁）
- `GrowthPage` / `StatsPage` 改用 `StatLineItem` + `ForEach(statRows)` 强制刷新
- 新增 `AppStoreContext` + 各 Store `ensureReady()` 二次恢复 Preferences
- `GrowthPage` 增加 `tabActive` + `researchRefresh` 监听；「刷新统计」按钮
- 打开「知识统计」Overlay 时主动 bump `researchRefresh`
- 笔记保存前校验 `ResearchStore.ensureReady()`

### 问题 2 · 润色 / 场景（延续 v1.3.1）

v1.3.1 已含 8 类场景 + 9 类成稿 + 一键演示 + 改写幅度展示；v1.3.2 无功能删减。

## v1.3.0 初版修复


**根因**：首页 / 成长 / 研究统计页刷新令牌分散，保存笔记、灵感、阅读记录后未统一触发 UI 重载。

**修复**：
- 新增 `AppRefresh.ets` 统一 `bumpHub / bumpResearch / bumpFav / bumpRecord`
- `ResearchStore` / `HubStore` / `FavoriteStore` / `LocalRecordStore` 写操作后统一 bump
- `GrowthPage`、`StatsPage`、`HubPage`、`ResearchPage`、`MinePage` 监听多路 refresh + `onVisibleAreaChange` 回到页面即 reload
- `GrowthPage` / `StatsPage` 补全笔记、专题、灵感、观点卡片、阅读记录、研究计划、近 7 天新笔记、连续思考等字段

### 问题 2 · 润色 / 场景偏少（3.5）— v1.4.0 加强

**修复**：
- 创作场景 **8 → 18 类**（职场 12 / 学术 3 / 研究 2 / 生活 1），按分类筛选 + **场景库**全屏浏览
- 场景成稿 **9 → 20 类**填空模板（含交接、改期、绩效、文献、论文、研究摘要、阅读札记、婉拒、合作、通知等）
- 新增 **8 条创作工作流**（口语→邮件、口水→纪要、长段→要点、催办、研究→汇报、致谢、学术、请假）一键演示 + 四风格对照
- 润色场景 **4 → 9 种**（邮件/纪要/汇报/请假/感谢/催办/学术/札记/通用）
- 口语样例 **5 → 9 条**

**审核员建议体验路径**：
1. **表达** Tab → 点「口语 → 正式邮件」工作流 → 自动四风格对照
2. **表达** → 场景条「全部」→ **场景库** → 任选「文献笔记 / 研究摘要」
3. **场景成稿** → 选「论文提纲」填空 → 生成 → **送到润色台**
4. 润色台选场景「学术」+ 风格「详尽」→ 查看改写幅度

### 问题 2 · 润色效果不明显 / 场景有限（3.5）— v1.3.1 加强

**修复**：
- **8 类创作场景**横滑入口（邮件/纪要/汇报/请假/感谢/催办/方案/邀请）→ 载入口语样例并自动润色 + 四风格对照
- **场景成稿**扩展至 9 类模板（新增请假、感谢、催办、方案、邀请）
- 润色结果展示 **原文字数 / 润色后字数 / 改写幅度（高/中/低）** + 改动清单
- **一键演示润色效果**：口语样例 → 正式邮件成稿 → 四风格对照
- 引擎增强口语替换与多段书面结构

**审核员建议体验路径**：
1. 表达 Tab → 点「工作邮件」场景卡片 → 自动弹出四风格对照
2. 或点「一键演示润色效果」→ 查看原文 vs 润色后 vs 四风格差异
3. 场景成稿 → 选「请假申请」填空 → 生成草稿 → 送到润色台

## AppGallery Connect 审核说明（可粘贴）

**知识统计设计说明**：研语为本地研究工具，统计数字来自用户在本机创建的研究笔记、专题、灵感、观点卡片、阅读记录、研究计划与每日思考。新安装或未创建内容时显示 0 属正常。请按：研究 → 写研究笔记 → 保存 → 成长 Tab 查看「知识统计」，或 研究 → 研究工具 → 知识统计 验证。

**润色能力说明**：表达 Tab 提供 8 类职场/学术场景入口、9 类成稿模板、四风格对照与一键演示；润色为规则引擎书面化改写（非联网大模型），结果展示原文字数、润色后字数与改写幅度。

## 复测步骤（提交审核前）

1. 研究 → 写一条研究笔记（填标题）→ 保存 → **成长** Tab → 知识统计「研究笔记」≥ 1
2. 研究 → 研究工具 → **知识统计** → 各指标与上一步一致；可点「刷新统计」
3. 研究 → 灵感快记 → 保存一句 → 成长页「灵感」+1
4. 表达 → 点「工作邮件」场景或「一键演示润色效果」→ 查看四风格对照与改写幅度
5. 表达 → 场景成稿 → 选模板填空 → 送到润色台
