# 研语 · App 丰富度升级方案（v1.2 规划）

> **状态（2026-08-31）**  
> - **v1.2.0** 丰富度升级（P1～P7）→ **已完成**（见 `feature-list.md`）  
> - **v1.3.0** 华为审核修复（统计刷新 / 润色增强 / 收藏联动）→ **已完成**（见 `audit-fix-v1.3.0.md`）  
> - **v1.4.0** 可选增量见文末「附录 C · v1.4 待办」

> 目标：从「润色小工具 + 功能堆叠」升级为「个人表达与思考工作台」商业级鸿蒙 App。  
> 原则：**渐进式增强**，保留现有可用能力；**0 新增系统权限**；所有数据来自用户真实操作。

---

## 1. 产品重新定位

| 维度 | 现状 | 升级后 |
|------|------|--------|
| 一句话 | 润色表达，也把学习与思考沉淀成研究资料 | **个人表达与思考工作台** — 写得更清楚，想得更深入，资料留得住 |
| 核心用户 | 学生、职场写作者 | 同上 + 有阅读/学习笔记、项目复盘、写作练笔需求的人 |
| 核心价值 | 规则润色 + 摘要 + 研究模块（较分散） | **表达产出 → 资料沉淀 → 计划推进 → 回顾成长** 一条闭环 |
| 与竞品差异 | 非 AI 对话、非纯备忘录 | **表达工具 + 知识整理 + 成长反馈** 三位一体（本机优先） |

**审核叙事（3.5）**：研语不是「改几个词的小工具」，而是帮助用户完成「写稿 → 整理 → 计划 → 回顾」完整写作与研究流程的原生 App。

## 2. 当前问题分析

### 2.1 产品 / 审核视角（对应问题 2）

| 问题 | 说明 |
|------|------|
| 润色「效果不明显」 | 审核员输入短句后期望「肉眼可见改写」；当前引擎已有结构性重写，但**缺少改写说明、前后对照强化、场景成稿引导**，体感仍像「替换几个词」 |
| 使用场景有限 | 润色/摘要/研究/灵感 **四块能力分属 4 个 Tab**，用户第一眼只见「输入框 + 按钮」，看不到「学习 / 项目 / 写作」完整场景 |
| 工具感 > 产品感 | 首屏（润色 Tab）是单页编辑器，**不是工作台**；缺少今日进度、目标、最近动态 |
| 研究模块「有功能无产品感」 | 12 个子能力以宫格入口呈现，**像功能清单**而非「我的研究空间」 |
| 数据孤岛 | `LocalRecordStore` / `ResearchStore` / `FavoriteStore` 三套存储，**首页无法统一展示「我的全部积累」** |
| 缺少成长反馈 | 无成就、无周/月回顾、无「本周我写了什么」总结 → **缺少持续使用动力** |
| 联动弱 | 润色结果 → 笔记、笔记 → 观点卡 有单点跳转，但**无统一「最近活动」与跨模块统计** |

### 2.2 架构 / 代码现状

| 项 | 现状 |
|----|------|
| 底部 Tab | 润色 · 摘要 · 研究 · 灵感 · 我的（5 Tab，已达 `tabMax`） |
| 页面 | 30+ 业务页；研究子页完整（笔记/专题/标签/灵感/时间线/计划/统计等） |
| 脚手架残留 | `DashboardPage` / `CoreBizPage` / `AIAssistantPage` 等非主 Tab 页仍存在，需清理或收编 |
| 视觉 | soft-editorial + 深蓝 #1A3A5C；部分页仍偏「表单 + 宫格」Demo 感 |
| 权限 | 仅 INTERNET + PhotoViewPicker（无 READ_IMAGEVIDEO）；**升级须保持 0 新增权限** |

### 2.3 已有能力（须保留，不推倒）

- 智慧润色（四风格 + 四场景 + 四风格对照 + 问题扫描）
- 智能摘要（精简/详细/待办/结论）
- 场景成稿（邮件/纪要/致歉/汇报）
- 表达诊断（问卷 + 模板报告）
- 灵感范例（平台 API + 详情 + 套用润色台 + 收藏）
- 研究全套（笔记/专题/标签/灵感库/观点卡/阅读/计划/收藏/每日思考/搜索/统计/时间线）
- 润色摘要历史、隐私合规、深浅色

## 3. 新增 / 强化功能列表（10 项 · 均有场景与闭环）

> 在已有 12 项研究能力基础上，**补产品层与联动层**，而非再堆 12 个空入口。

| # | 模块 | 类型 | 用户场景 | 数据来源 | 与现有关系 |
|---|------|------|----------|----------|------------|
| 1 | **首页工作台** | 新增 Tab | 打开 App 即见今日进度、快捷写笔记/润色/打卡 | 聚合三套 Store | 新 `HubPage` |
| 2 | **表达中心** | 重构 Tab | 润色+摘要+成稿+诊断同一入口，Segment 切换 | 现有四页合并 UI | 保留全部逻辑 |
| 3 | **稿本库** | 新增 | 润色/摘要结果「存为稿本」，可再编辑、送笔记、再润色 | `ManuscriptStore` | 延伸 LocalRecordStore |
| 4 | **润色增强** | 强化 | 改写摘要卡（改了什么/适合什么场景）+ 一键应用范例 | LanguageEngineService | 不改 LLM |
| 5 | **统一收藏中心** | 整合 | 灵感收藏 + 笔记星标 + 观点卡 一处浏览 | Favorite + Research | 新 `LibraryPage` |
| 6 | **成长 Tab** | 新增 Tab | 统计图表 + 成就墙 + 周回顾 | HubStore 计算 | 收编 Stats/Timeline |
| 7 | **成就系统** | 新增 | 首次笔记、连续 7 天思考、润色 10 次等 | `AchievementStore` | 规则触发 |
| 8 | **回顾系统** | 新增 | 本周/本月：写了多少、读了什么、计划完成度 | 从 Research + Record 聚合 | 新 `ReviewPage` |
| 9 | **写作目标** | 新增 | 周目标：润色 N 次 / 笔记 N 条 / 思考 7 天 | `GoalStore` | 首页进度条 |
| 10 | **最近活动流** | 新增 | 时间序：润色、笔记、灵感、打卡、收藏 | `ActivityStore` | 增强 Timeline |

**不做的（避免假丰富）**：假社交、假推荐流、假 AI 对话、新增权限（相机/定位等）、独立第六 Tab。

## 4. 页面结构（三级信息架构）

```text
首页 HubPage（一级 · 工作台）
├── 今日进度 / 周目标
├── 四宫格数据（笔记·稿本·收藏·连续）
├── 快捷：润色 / 写笔记 / 记灵感 / 今日思考
├── 最近活动（ActivityFeed）
└── 入口：成长 / 收藏中心 / 表达中心

表达 ExpressPage（一级 · Segment）
├── [润色] HomePage 能力（二级：四风格对照 Overlay）
├── [摘要] SummaryPage
├── [成稿] DraftPage Overlay
└── [诊断] Diagnose Overlay

研究 ResearchPage（一级 · 已有）
├── 笔记列表 → 详情 → 编辑（三级）
├── 专题 → 详情 → 笔记
├── 标签 / 灵感 / 阅读 / 计划 / 搜索 …（二级 Overlay）
└── 观点卡 / 收藏分类

成长 GrowthPage（一级 · 新）
├── 知识统计（图表 + 数字）
├── 成就墙
├── 本周回顾 / 本月回顾
└── 时间线（现有 Timeline 收编）

我的 MinePage（一级 · 强化）
├── 稿本库 / 润色摘要历史 / 收藏中心（入口）
├── 设置与隐私
└── 全局搜索（可选二级）
```

**层级验收**：每个主 Tab ≥1 个二级列表/分区 + ≥1 个三级详情/编辑；禁止「点进去只有一段文字」。

## 5. 底部导航方案

**现状**：润色 | 摘要 | 研究 | 灵感 | 我的（5 Tab，功能按「工具类型」切分 → 审核像多个小工具拼盘）

**升级方案（仍 5 Tab，符合 `tabMax: 5`）**：

| Index | 标签 | 图标 | 承载 |
|-------|------|------|------|
| 0 | **首页** | house | HubPage 工作台 |
| 1 | **表达** | edit | ExpressPage（润色/摘要/成稿/诊断） |
| 2 | **研究** | bookmark | ResearchPage + Overlays（保持） |
| 3 | **成长** | chart | GrowthPage（统计+成就+回顾+时间线） |
| 4 | **我的** | user | MinePage（强化入口） |

**灵感 Tab 去向**（不丢失能力）：
- 平台范例 → 首页「推荐表达」区块 + 表达页「范例库」入口 + 统一收藏中心
- 用户灵感 → 研究模块「灵感收集」（已有）

**摘要 Tab 去向**：并入「表达」Segment，减少 Tab 碎片化。

## 6. 数据模型升级

### 6.1 新增模型（`models/HubModels.ets`）

```text
Manuscript          # 稿本（润色/摘要产出）
├── id, title, body, kind(polish|summary)
├── styleKey, sceneKey, sourceText
├── linkedNoteId?, createdAt, updatedAt

ActivityEvent       # 统一活动流
├── id, kind, title, summary, entityId, at

WritingGoal         # 周目标
├── weekKey, polishTarget, noteTarget, dailyTarget
├── polishDone, noteDone, dailyDone

Achievement         # 成就
├── key, title, hint, unlockedAt

WeekReview          # 周回顾（可算不可手写）
├── weekKey, noteCount, polishCount, sparkCount
├── planProgress, streak, highlightText
```

### 6.2 新增 / 扩展 Store

| Store | 职责 |
|-------|------|
| `ManuscriptStore` | 稿本 CRUD；从润色/摘要保存 |
| `ActivityStore` | 各写操作 append 活动；供首页/时间线 |
| `GoalStore` | 周目标读写；首页进度 |
| `AchievementStore` | 解锁判定；成长页展示 |
| `HubStore` | **只读聚合**：dashboard 数字、周回顾计算 |
| `ResearchStore` | 保持；写操作后 notify Activity + Achievement |
| `LocalRecordStore` | 保持；保存时同步 Activity |
| `FavoriteStore` | 保持；收藏中心统一读 |

### 6.3 关联规则（联动）

```text
润色成功 → Activity(polish) + Goal.polishDone++ + Achievement 检查
存稿本 → Manuscript + Activity(manuscript)
写笔记 → ResearchStore + Activity(note) + Goal.noteDone++
每日思考 → Daily + Activity + streak + Achievement
收藏灵感 → Favorite + Activity(favorite)
完成计划阶段 → Activity(plan) + 周回顾 planProgress 重算
```

## 9. 用户使用闭环

```text
【新用户首日】
首页空态 → 点「试润色范例」→ 表达页看到明显改写 + 说明
→ 存稿本 → 写研究笔记引用稿本 → 打标签 / 入专题
→ 每日思考打卡 → 成长页见 1 天连续

【日常】
首页看周目标 → 润色邮件/纪要 → 存稿本
→ 摘要长文 → 笔记归档 → 观点卡
→ 研究计划勾选 → 首页进度更新

【周末】
成长 · 本周回顾 → 时间线浏览
→ 成就解锁（如「本周 5 次润色」）
→ 收藏中心整理范例与笔记

【表达 × 研究 × 成长 交叉】
灵感详情 · 套用到润色台 → 润色 → 存稿本 → 笔记详情 · 送到润色台（已有，强化入口）
```

## 10. 华为 3.5 合规检查

| 指南要求 | 升级后对应 |
|----------|------------|
| 实质功能，非纯展示 | 表达产出 + 研究整理 + 计划 + 回顾 + 成就，均可操作、可验证 |
| 非简单记录工具 | 润色/摘要/成稿/诊断 + 稿本库 + 专题体系，不止「记一条」 |
| 非模板套壳 | 本机规则引擎 + 用户数据驱动统计/回顾，非静态 HTML |
| 创意与差异化 | 「表达→沉淀→成长」工作台定位，区别于纯备忘录/纯输入法 |
| 功能完整闭环 | 列表→详情→编辑/删除；润色→存稿→笔记；计划→进度→回顾 |
| 新用户无假数据 | 栏目范例走 API；用户数据初始为空 |
| 无新增敏感权限 | 仅 INTERNET + PhotoViewPicker；不新增相机/定位等 |
| 润色「效果不明显」 | 引擎加改写摘要 + 对照高亮强化 + 场景成稿引导（仍无 LLM） |

**审核备注建议（AppGallery Connect）**：

> 研语是面向学生与职场写作者的「表达与思考工作台」。首页展示个人周目标与积累；表达中心提供润色、摘要、场景成稿与表达诊断；研究模块支持笔记/专题/计划/阅读/观点卡；成长模块提供统计、成就与周回顾。数据均来自用户本机操作，新用户为空态。
