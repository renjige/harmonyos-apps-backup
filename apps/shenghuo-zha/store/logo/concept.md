# Logo Concept — 生活札

- 公司 / App：生活札 / 生活札
- 行业：life-memo（生活记录）
- brandAnchor：**生**（生活、生长、日常温度）
- glyphStrategy：semantic-fusion（书页折角 + 暖日星芒）

## 品牌关键词
Warm · Record · Daily · Simple · Memory

## 核心元素（2 个）
1. 抽象书页/笔记本折角（负空间）
2. 小圆日 + 短射线（生活、温暖）

## 对比策略
- App Icon 背景：`#C4784A`（暖橙深）
- 前景 Symbol：`#FFF8F0`（米白）
- 灰度打印仍可辨折角与日轮

## 与行业模板差异
- 非 house / 非 cloud 模板
- 非松岚札山形几何
- 暖橙而非深绿禅意

## 禁止项自检
- 无渐变球、无 AI 脑、无机器人
- ≤2 主色；1~2 核心元素
