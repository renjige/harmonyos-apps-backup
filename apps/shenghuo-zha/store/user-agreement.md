# 生活札 — 用户协议

**运营者：** 魏文波  
**应用名称：** 生活札  
**更新日期：** 2026年8月29日

## 一、服务说明

生活札提供个人生活记录与日常管理，包括：

- 生活模板札记（今日心情、美食、旅行、家庭、灵感、成长）
- 图文生活记录与按日时间轴
- 每日心情、习惯打卡
- 购物 / 家务 / 出行 / 学习清单，清单模板，以及到点系统提醒
- 生活锦囊：经验卡、问题记录、生活目标、方案收藏、轻量挑战、灵感
- 时光相册、月度回忆册、纪念日、去年今天回顾
- 标签与分类、生活档案统计、深浅色主题

启动后即可使用全部本地功能。全部功能**免费**，无内购、无订阅、无广告。

## 二、数据存储

您的札记、照片副本、打卡、清单、生活锦囊与纪念日默认**仅保存在本机**。卸载应用或清除全部数据后，相关内容将无法恢复，请自行备份重要信息。

## 三、用户行为规范

不得利用本应用存储、传播违法违规内容。您对在本机创建的内容负责。

## 四、免责声明

提醒功能依赖系统通知、发布提醒权限与设备后台策略。请在保存提醒时允许通知；若关闭通知或限制后台，到期可能无法弹出。纪念日倒计时仅供个人参考。

## 五、协议变更

我们可能更新本协议，更新后继续使用即视为接受。可在应用内「我的 → 设置与隐私」查看最新版本。
