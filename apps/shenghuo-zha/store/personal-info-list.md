# 生活札 — 个人信息收集清单

| 字段/数据 | 是否采集 | 用途 | 存储 | 可否删除 |
|-----------|---------|------|------|---------|
| 札记标题与正文 | 是 | 记录展示 | 本机 | 可单条删除或清除全部 |
| 图片（沙箱副本） | 是 | 札记与相册 | 本机沙箱 | 随札记删除 |
| 分类 / 心情 / 模板 / 标签 | 是 | 分类检索与心情统计 | 本机 | 可编辑或删除 |
| 习惯打卡 | 是 | 连续天数 | 本机 | 清除全部数据时删除 |
| 生活清单与提醒时间 | 是 | 清单与系统通知 | 本机 | 可删除 |
| 纪念日 | 是 | 倒计时 | 本机 | 可删除 |
| 生活锦囊 | 是 | 经验/问题/目标/方案 | 本机 | 可单条删除或清除全部 |
| 统计（条数/连续天/打卡/心情/锦囊/档案天数） | 是 | 我的页展示 | 本机计算 | 随数据清除 |

**不采集**：账号、手机号、定位、设备标识上传、网络传输的个人内容。

首次隐私声明由华为「隐私声明托管」展示，应用内不采集额外授权弹窗数据。
