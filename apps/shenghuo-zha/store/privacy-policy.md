# 生活札 — 隐私政策

**运营者：** 魏文波  
**应用名称：** 生活札  
**更新日期：** 2026年8月29日

## 一、我们如何收集和使用信息

生活札为**纯本地**生活记录与成长管理工具，不向开发者服务器上传札记、照片、打卡或清单内容。

| 信息类型 | 是否采集 | 用途 | 存储位置 |
|---------|---------|------|---------|
| 生活札记（标题、正文、图片路径、分类、心情、模板、标签） | 是 | 时间线、相册、回忆册 | 本机 Preferences 与应用沙箱 |
| 每日心情 | 是 | 心情记录与统计 | 本机 Preferences |
| 习惯打卡 | 是 | 连续天数与累计次数 | 本机 Preferences |
| 生活清单与提醒时间 | 是 | 清单管理、系统到点通知 | 本机 Preferences |
| 纪念日 | 是 | 倒计时卡片 | 本机 Preferences |
| 生活锦囊（经验/问题/目标/方案/挑战/灵感） | 是 | 经验沉淀与目标进度 | 本机 Preferences |
| 主题偏好（浅/深色） | 是 | 界面展示 | 本机 Preferences |

首次打开时的隐私声明由华为应用市场「隐私声明托管服务」统一展示，**本应用不再另行弹出授权窗**。

## 二、权限说明

| 权限 | 用途 | 可否关闭 |
|------|------|---------|
| 代理提醒（PUBLISH_AGENT_REMINDER） | 清单/待办到点系统通知 | 可拒绝；清单仍保存在本机，但不会弹出到期通知 |

本应用通过系统相册选择器添加图片（**不申请**相机权限），**不申请**网络、定位、麦克风权限。

## 三、第三方共享

本应用**不接入**广告/统计/支付 SDK，**不向**第三方共享个人信息，**不提供**生成式大模型对话服务。界面中的「智能」功能均为本机规则推荐（今日备忘、标签建议），不上传云端。

## 四、您的权利

您可在「我的 → 设置与隐私」中：再次查看《用户协议》与《隐私政策》、清除缓存、清除全部本机数据。系统级隐私托管声明请在华为系统设置中管理。本应用**不会**在启动时再次弹出自行构建的授权窗。

## 五、联系我们

如有疑问，请通过华为应用市场预留的开发者联系方式与我们沟通。
