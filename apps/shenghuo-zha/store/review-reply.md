# 生活札 — 审核说明（可贴到 AGC「版本信息-应用审核信息」）

针对华为应用市场审核反馈的三项说明如下。

## 问题 1（指南 3.5 · 使用场景）

生活札定位为**个人生活管理与经验沉淀工具**，而非单一记事本。当前版本覆盖：

1. **生活模板**：今日心情、美食记录、旅行见闻、家庭时光、灵感记录、成长感悟，一键进入对应分类与标签。
2. **图文札记**：标题 + 正文 + 本机照片，详情可编辑/删除。
3. **生活时间轴**：按日期回顾全部记录。
4. **去年今天**：根据已有札记在应用内回顾（不新增系统通知权限）。
5. **每日心情**：在时间线选择当天心情，我的页统计心情天数。
6. **每日打卡**：早起 / 阅读 / 运动 / 整理等习惯，连续天数与累计次数。
7. **生活清单**：购物、家务、出行、学习；搬家/周末/节日/学习清单模板。
8. **生活锦囊**：经验卡、问题与解决办法、生活目标进度、方案收藏、轻量挑战、灵感；家庭/学习/工作/兴趣/成长看板与收藏夹。
9. **分类与标签**：家庭/美食/旅行/学习/工作/兴趣 + 自定义标签检索。
10. **重要日期**：纪念日倒计时。
11. **生活回忆册**：时光相册 + 本月回忆摘要。
12. **生活档案**：札记条数、完成事项、创建天数、锦囊与目标进度。

以上均在应用内可完成，无需跳转外部应用。锦囊与档案不申请额外系统权限。

## 问题 2（双重隐私弹窗）

本应用已接入华为「隐私声明托管服务」。**已删除应用内自行构建的首次隐私授权弹窗**（原 `PrivacyConsentOverlay` / 启动遮罩）。

- 启动路径：系统托管声明（如有）→ 直接进入时间线主界面。
- 「我的 → 设置与隐私」仅提供协议**全文查阅**，用户主动打开，不再于启动时弹出。

## 问题 3（指南 3.1 · 功能异常）— 已修复，非特殊设计

| 测试步骤 | 原因 | 修复 |
|---------|------|------|
| 时间线添加札记无标题/摘要/正文/照片，无法删除 | 详情页崩溃或未强制填写；标题曾可空 | 标题必填，正文或照片至少一项；保存失败有 Toast；详情含「编辑札记」「删除札记」二次确认 |
| 智能提醒到点未提醒 | 未申请通知/发布提醒权限；日期可选导致未向系统注册 | 必须选择日期+时间；保存时申请通知与 PUBLISH_AGENT_REMINDER；7 天内用 Timer，更长用日历提醒；失败则停留并提示 |
| 时光相册照片不显示 | HarmonyOS 6.x Image 需 `file://`；Grid 无高度被折叠 | 照片复制到沙箱并以 file:// 显示；相册改为 Flex 网格并固定宽高比 |

**请审核员 Rebuild 安装本版本后按下列路径复测：**

1. 时间线 → 选「美食记录」模板 → 填标题与正文或添加照片 → 保存 → 卡片可见标题/摘要 → 进入详情可删除。
2. 日常（原「智能提醒」）→ 新建清单 → 允许通知与发布提醒 → 将时间设为 **2～3 分钟后** → 等待系统通知。
3. 时间线写札记并添加照片 → 切到「回忆」Tab → 可见缩略图。
4. 冷启动：仅系统托管隐私声明（如有），**不应再出现应用内第二层隐私弹窗**。
5. 底栏「锦囊」→ 点「清洁技巧」快捷开始 → 进入详情完善/收藏 → 目标类点「进度 +10%」。
6. 日常 → 点「搬家准备清单」→ 列表出现条目（无系统提醒）。
7. 我的 → 可见锦囊条数与档案天数。
