# 生活札

轻量级**个人生活管理与经验沉淀**工具：记下生活片段，沉淀经验与方案，用目标、习惯和清单把日常过成可回顾的档案。

## DevEco 工程

打开目录：`apps/shenghuo-zha/app/`

## 上架图标

- 合成预览（优先上传）：`apps/shenghuo-zha/store/logo/preview-1024.png`
- 工程副本：`apps/shenghuo-zha/app/AppScope/resources/base/media/app_icon.png`

## 核心功能

| Tab | 能力 |
|-----|------|
| 时间线 | 生活模板、图文札记、每日心情、按日时间轴、去年今天回顾、搜索 |
| 日常 | 早起/阅读/运动/整理等习惯打卡、购物/家务/出行/学习清单、清单模板、到点提醒 |
| 锦囊 | 经验卡、问题记录、生活目标、方案收藏、轻量挑战、灵感、分类看板、收藏夹 |
| 回忆 | 时光相册、本月回忆册、纪念日倒计时 |
| 我的 | 生活档案统计、标签、纪念日、深浅色、设置与隐私 |

## 数据与隐私

- 默认**纯本机**存储（Preferences + 沙箱图片）
- 无网络权限、无账号登录、无广告与内购
- 首次隐私声明由**华为隐私托管**展示，应用内不再弹出自行构建的授权窗
