# 生活札 — 功能验收清单

## 生活记录
- [x] 生活模板：今日心情 / 美食 / 旅行 / 家庭 / 灵感 / 成长
- [x] 图文札记：标题必填，正文或照片至少一项；最多 9 张照片
- [x] 分类：家庭 / 美食 / 旅行 / 学习 / 工作 / 兴趣
- [x] 自定义标签与推荐标签
- [x] 时间轴按日期倒序；详情 Hero + 编辑/删除

## 心情与打卡
- [x] 时间线每日选择心情
- [x] 日常 Tab：阅读/运动/早睡/早起/整理预设打卡（需用户点击添加，无静默种子）
- [x] 连续天数与累计次数

## 生活清单与提醒
- [x] 购物 / 家务 / 出行 / 学习 / 提醒 分类
- [x] 清单模板：搬家 / 周末 / 节日 / 学习（生成条目，不自动设系统提醒）

- [x] 周期：不重复 / 每日 / 每周 / 每月
- [x] 标记完成/删除

## 生活锦囊（经验沉淀）
