## 功能概览

- **快速记录**：纯文本 + 5 种心情标签 + 可选位置 + 自动保存
- **智慧整理**：关键词/标签检索、标签云、相似主题聚合
- **森野日历**：月历打点、点击日期查看/补记
- **个人中心**：统计、标签管理、数据导出、深色模式
