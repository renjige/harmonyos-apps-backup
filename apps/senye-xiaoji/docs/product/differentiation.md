# 森野小记 — 差异化说明

与仓库内相近 App 的差异：

1. **森野美学**：主色 #3A7D5A 森林绿 + 暖木强调色，非梦隅紫/灵感备忘橙
2. **Tab 结构**：记录流 + 森野日历 + 智慧整理 + 我的（四 Tab，无相册/画板）
3. **心情体系**：5 种自然意象心情（宁静/期待/轻松/专注/沉思）
4. **本地优先**：记录存 Preferences，无需登录即可写记录
5. **智慧整理**：规则引擎推荐标签 + 标签云 + 相似主题聚合（非 LLM）
6. **连续记录徽章**：首页展示连续记录天数激励
7. **首次隐私弹窗**：符合 2026 审核文档要求（同意前不采集）
8. **无 AI 字样**：全应用使用「智慧」「智能」表述
