# 读书札语 · 产品规划

## 产品定位

**读书札语** — 一款记录阅读过程、管理个人书籍、收藏读书感悟的智慧阅读应用。

**核心理念**：记录阅读，沉淀思想。

**目标用户**：18–50 岁爱书之人，通勤与睡前阅读场景。

**准入模式**：`open_optional` — 游客可浏览精选荐书与示例书目；添加书籍、写笔记、收藏札语、制定计划需登录。

---

## 功能模块

| 模块 | 能力 |
|------|------|
| 阅读空间 | 当前在读、阅读进度、今日阅读、最近札语 |
| 我的书架 | 添加书籍、封面、分类、阅读状态（在读/已读/想读） |
| 读书笔记 | 创建笔记、文字、图片、标签、关联书籍 |
| 札语收藏 | 经典语句与个人感悟、来源标注 |
| 阅读计划 | 目标设定、完成进度 |
| 智慧整理 | 分类、标签、智能搜索 |
| 阅读报告 | 阅读量、时长、收藏统计 |
| 我的 | 阅读档案、设置与隐私 |

**明确不含**：AI 对话、支付、商城、会员。

---

## 页面结构

```
Index (open_optional)
├── MainTabPage
│   ├── Tab0 阅读空间 (HomePage)
│   ├── Tab1 书架 (ShelfPage)
│   ├── Tab2 笔记 (NotesPage)
│   ├── Tab3 计划 (PlansPage)
│   └── Tab4 我的 (MinePage)
├── Overlay 详情
│   ├── FeaturedDetailPane · BookDetailPane
│   ├── NoteDetailPane · QuoteDetailPane · PlanDetailPane
├── 二级页
│   ├── QuotesPage（札语收藏）
│   ├── OrganizePage（智慧整理）
│   └── ReportPage（阅读报告）
└── LoginPage（协议勾选 · 注册登录）
```

**核心闭环**：添加书籍 → 记录笔记/札语 → 制定计划 → 阅读报告回顾

## 页面视觉效果（简述）

1. **阅读空间**：顶部问候 + 日期；Hero 书桌阅读图；「当前在读」进度卡；今日阅读时长；精选荐书横滑；最近札语列表  
2. **书架**：分类 Tab（全部/在读/已读/想读）；书脊卡片网格；示例书目 + 用户书架  
3. **笔记**：笔记列表卡片（封面+标题+标签）；全屏创建表单  
4. **计划**：计划卡片 + 环形/条形进度；入口跳转阅读报告  
5. **我的**：阅读档案统计；入口：札语收藏、智慧整理、阅读报告、设置与隐私
