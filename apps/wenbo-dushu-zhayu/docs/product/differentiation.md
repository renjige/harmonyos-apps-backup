# 差异化说明（审核指南 3.7）

应用：**读书札语**  
版本：**1.2.0**

## 定位（一句话）

**强制思考型书房**，不是「阅读记录 / 摘抄 / 打卡」App。

## 1.2.0 信息架构（审核首屏可见）

```
底栏 3 Tab（无书架/笔记主 Tab）
├── 书房玩法   ← 默认首屏：三种独有交互 + 差异对比表
├── 札语链     ← 仅灯下共读 / 对读札 / 问书三札 产出
└── 我的       ← 书架、计划、札记等 = 「辅助工具（非主路径）」
```

首次安装：展示「读书札语 ≠ 阅读记录」说明页（非隐私弹窗）。

---

## 三种独有交互（必须完成思考动作）

### ① 灯下共读
计时结束 → **必须写「今日一句」** → 才记入打卡/金句/札语链

### ② 对读札
从金句库选 **两句** → 写对照思考 → 非再摘第三句

### ③ 问书三札
选书 → **三个固定追问全部必填** → 结构化反思

---

## 与同类差异

| 同类 App | 读书札语 |
|---|---|
| 计时即打卡 | 灯下共读须写今日一句 |
| 金句列表 | 对读札：两句对照短文 |
| 自由笔记 | 问书三札：三问模板 |
| 书架+笔记主 Tab | 主 Tab 为玩法+札语链 |

---

## 审核演示路径（约 5 分钟）

1. 冷启动 → 差异化说明 → 进入书房玩法  
2. 灯下共读 → 写今日一句 → **札语链 Tab** 可见  
3. 对读札 → 选两句 → 写对照  
4. 问书三札 → 三问必填  
5. 确认底栏无书架 Tab；书架在「我的 → 辅助工具」
