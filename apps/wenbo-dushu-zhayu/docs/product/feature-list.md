# 功能清单

应用：**读书札语**  
版本：1.0.4

## 核心闭环

- [x] 书籍管理：添加书籍，五分类（文学作品 / 历史文化 / 科普知识 / 学习提升 / 兴趣阅读），在读 / 已读 / 想读
- [x] 阅读进度：记录总页数与当前页，查看完成度
- [x] 读书笔记：创建笔记、文字感悟、插入阅读现场图（书桌 / 窗边 / 灯下）
- [x] 每日打卡：每日阅读计划打卡、连续天数、打卡详情
- [x] 金句摘录：保存书中句子、添加个人点评、语录收藏库
- [x] 阅读计划：创建目标、设置完成时间、每日分钟、查看进度（模板：一个月读 3 本 / 每天 30 分钟）
- [x] 书评记录：发布个人书评、评分、保存阅读体验
- [x] 灵感收藏：保存阅读想法并关联书籍
- [x] 专题书单：成长 / 旅行 / 亲子 / 经典，可收藏到我的书单
- [x] 标签管理：预设标签 + 自定义标签，按标签整理笔记 / 金句 / 书评 / 灵感
- [x] 阅读统计：次数、时长、打卡、书评、灵感
- [x] 灯下共读：氛围计时，结束必须写下今日一句，才记入打卡时长与札语
- [x] 对读札：选两句金句对照，写下它们为何对话
- [x] 深色模式：书房暖色深色主题，列表/输入框正文对比度达标

## 账号与合规

- [x] 游客浏览精选荐书与专题书单
- [x] 登录 / 注册 / 退出；协议勾选在登录页
- [x] 设置与隐私：协议全文、撤回同意、注销账号、清除缓存（无「删除业务数据」）
- [x] 栏目数据走平台 `/biz/reading-journal/*`，新用户活动数据为空
- [x] 消息中心对接 `GET /messages`

## 详情页

- [x] 书籍 / 笔记 / 金句 / 计划 / 打卡 / 书评 / 书单 / 灵感 / 精选 均有 Hero + 正文 + CTA
