## 本版能力

1. **灯下共读**：氛围计时，结束必须写下今日一句，才记入打卡与札语
2. **对读札**：选两句金句对照，写下它们为何对话
3. **书籍管理**：在读 / 已读 / 想读；五分类
4. **阅读进度**：总页数、当前页、完成度互相换算
5. **读书笔记**：心得 / 感悟 + 书桌 / 窗边 / 灯下现场图
6. **每日打卡**：连续天数；同日可累计时长；删除后即时刷新本周分钟
7. **金句摘录**：句子 + 个人点评（保存即时回列表）
8. **阅读计划**：截止日期、每日分钟、模板
9. **书评 / 灵感 / 专题书单 / 标签 / 月度回顾 / 阅读统计**

## 自测路径

1. 系统深色模式：书架、金句、书单副标题与输入框文字清晰。
2. 首页「开始共读」→ 选时长 → 结束并写今日一句 → 本周分钟增加。
3. 金句至少两句 → 「对读」→ 选两句写对照 → 灵感收藏可见。
4. 打卡后再打一次 → 时长累计；删除打卡 → 列表与本周分钟即时变化。
5. 书籍详情更新进度 → 返回书架页数与百分比已更新。
