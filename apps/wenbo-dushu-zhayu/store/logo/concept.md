# Logo Concept — 读书札语

- 公司 / App / 行业：承德锐泓科技信息有限公司 · 读书札语 · 阅读札记（非学历教育）
- 品牌关键词：Reading / Page / Note / Quiet / Continuity
- **brandAnchor**：读（落在「摊开的书页」，不写汉字以免 24px 糊死）
- **glyphStrategy**：semantic-fusion
- 核心元素（仅 2）：
  1. 宣纸白对开书页（读）
  2. 暖金札签（札语摘录从书脊抽出）
- 禁止项自检：无羽毛笔、无星星光芒、无写实精装书、无眼镜、无 3D、无渐变球、无 AI 大脑
- 色板（2 色 + 底）：墨绿底 `#2D5A4A` · 宣纸白 `#F7F3EB` · 暖金 `#C9A962`（金仅用于札签）
- 对比策略：App Icon **深底浅标**（墨绿底 + 近白书页），灰度后对开页与札签轮廓仍清晰；禁止墨绿叠墨绿
- 行业模板 vs 本稿：
  1. 非库存「合上的精装书」正视图
  2. 非羽毛笔 + 墨水瓶写作套模板
  3. 书页几何对开 + 札签，绑定 App 名「读 / 札」，与书架摄影封面区分
