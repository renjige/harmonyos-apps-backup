# 华为审核备注（3.7 差异化 · 请粘贴到提审说明）

应用名称：**读书札语**  
版本：**1.0.6**

## 本产品不是「简单阅读记录 / 摘抄本」

同类 App 常见形态：记一句话、打一个卡、堆列表。  
**读书札语**提供三种市场上少见的**强制思考交互**，并有独立「书房玩法」专页说明差异。

## 请审核员按以下顺序体验（约 5 分钟）

### 路径 A · 独有玩法总览（推荐先看）

1. 打开 App → 首页顶部卡片 **「进入书房玩法」**
2. 阅读「不是又一个摘抄本」说明
3. 查看三种玩法卡片与步骤说明
4. 底部 **「我的札语链」** 仅展示三种玩法产出（非普通摘录）

### 路径 B · 灯下共读

1. 书房玩法 → **开始共读**（或首页主视觉）
2. 选 15 分钟 → 提前结束
3. **必须填写「今日一句」** 才能完成（不写则无法记入）
4. 返回首页：本周阅读分钟增加；金句库新增带「灯下共读」标签条目

### 路径 C · 对读札

1. 金句摘录页 → **对读**（或书房玩法 → 开始对读）
2. 从已有金句 **选两句**
3. 写对照思考（非再摘第三句）
4. 灵感收藏可见「对读札」结构化内容

### 路径 D · 问书三札（1.0.6 新增）

1. 书房玩法 → **开始问书**
2. 选一本在读书
3. **依次回答三个固定追问**（全部必填）
4. 保存后灵感收藏可见「问书三札」标签与结构化正文

## 与同类差异一句话

| 同类 | 读书札语 |
|---|---|
| 计时即打卡 | 灯下共读：计时结束须写「今日一句」 |
| 金句列表 | 对读札：两句并置 + 对照短文 |
| 自由笔记 | 问书三札：三问模板，缺一不可 |
