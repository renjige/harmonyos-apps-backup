# 个人信息收集清单

**应用名称**：读书札语  
**运营者**：承德锐泓科技信息有限公司  
**更新日期**：2026年8月31日

| 信息类型 | 收集字段 | 使用目的 | 是否必需 |
|---------|---------|---------|---------|
| 账号信息 | 账号、密码、姓名、手机号 | 注册登录、身份识别 | 登录/注册时必需 |
| 书架数据 | 书名、作者、分类、页数、进度、标签 | 书籍管理与阅读追踪 | 添加书籍时 |
| 笔记数据 | 标题、正文、类型、场景图键、标签、日期 | 读书笔记记录 | 创建笔记时 |
| 金句数据 | 内容、来源、点评、标签 | 金句摘录、灯下共读今日一句 | 收藏札语 / 完成共读时 |
| 对读札 | 两句对照正文、标签 | 金句对照思考 | 保存对读札时 |
| 计划数据 | 计划名称、目标、截止日期、每日分钟、进度 | 阅读计划管理 | 创建计划时 |
| 打卡数据 | 日期、阅读分钟、备注 | 每日阅读打卡 | 打卡时 |
| 书评数据 | 标题、正文、评分、关联书籍 | 书评记录 | 发布书评时 |
| 灵感数据 | 标题、内容、关联书籍 | 灵感收藏 | 保存灵感时 |
| 标签数据 | 自定义标签名称 | 按标签整理 | 创建标签时 |
| 阅读记录 | 阅读时长、日期、关联书籍 | 阅读报告统计 | 记录阅读时 |
| 本地缓存 | 登录凭证、隐私同意状态 | 自动登录、合规 | 登录/同意协议时 |
| 设备信息 | 设备型号、系统版本、网络类型 | 服务稳定性 | 使用 App 时 |

**游客模式**：不收集账号信息与个人业务数据，仅浏览公开精选荐书、示例书目与专题书单。

**撤回与删除**：我的 → 设置与隐私 → 撤回隐私同意 / 注销账号。
