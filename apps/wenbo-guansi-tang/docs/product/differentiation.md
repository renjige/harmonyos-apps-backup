# 观思堂 vs 思见堂 — 差异化（≥6 条）

1. **Tab 结构**：观思堂为「洞察笔记 / 思辨空间 / 智慧洞察 / 我的」；思见堂为「今日堂 / 思录 / 思友圈 / 我的」。
2. **首屏主任务**：观思堂笔记优先 + 浮动新建；思见堂慧语 Hero 优先。
3. **无社交圈**：观思堂移除思友圈 Tab，改为统计看板与热力图。
4. **智慧洞察**：独有笔记统计、84 格热力图、周报/月报纯统计摘要。
5. **Logo**：观思堂「眼/窗格 + 金瞳」；思见堂「堂檐 + 慧光」。
6. **思辨空间**：每日一问 + 思维导图预览（只读层级），非荐读流首页。
7. **色彩**：观思堂 #F8F6F3 暖纸 + #C9A96E 香槟金；思见堂偏青玉辅色。
