# Logo Concept — 文波错题析

- 公司 / App / 行业：魏文波 · 文波错题析 · K12 错题整理
- 品牌关键词：Clarity / Correction / Structure / Trust / Progress
- 核心元素（2）：展开的笔记本折角 + 右下精确对勾缺口
- brandAnchor：析（语义融进「看清并订正」，不把汉字画进图标）
- 禁止项自检：无放大镜+书本+图表三件套、无机器人老师、无渐变球、无 AI 脑、无奖杯
- 色板：2 色 — 深海军 `#0B1F4A` + 近白 `#F8FAFC`；活力橙 `#FF6B35` 仅作对勾一点，不算铺满第三色
- 对比策略：App Icon 深底浅标；灰度后折页与对勾轮廓仍清晰；24px 可辨
- 行业模板 vs 本稿：
  1. 非打开书本剪影套模板
  2. 非童趣算坊「数字 7 + 算珠」
  3. 非亲子益智闯关徽章
