# 文波错题析 · 差异化说明

对比仓库内学习向应用（童趣算坊 / 亲子谜题 / 成语挑战 / 诗词寻宝），本 App 不是换皮：

1. **主对象是「本人错过的题」**，不是题库闯关、成语卡片或诗词地图。
2. **录入闭环**：拍照或手录 + 学科/知识点/错因五类，保存后可编辑、删除、标记掌握。
3. **智慧分析是规则统计**：学科柱状图、薄弱知识点排序、近七日新增，不是对战分数。
4. **纠错方法卡按错因拆开**（概念/粗心/审题/方法），与算术练习或谜题选项不同。
5. **学情诊断是 8 题问卷 + 模板复习计划**，CTA 回到录入或分析，不预约顾问、不开启大模型对话。
6. **导出是剪贴板文本错题本**，便于家长打印，不做社区分享、不做排行榜。
7. **视觉**：书桌红笔笔记本摄影 + 智慧蓝/活力橙，禁止卡通闯关 Banner 与水墨诗词换皮。
8. **行业 Pack `wrong-notebook`** 与 Admin 模块 `wqSubjects/wqMethods/wqTips/wqArticles/wqEntries` 为新实体，不复用课程报名表。
