# AGC 审核说明（版本 1.5.0 · 针对 3.5 内容丰富度）

## 产品定位（非「简单记录运动」）

「运动图册」是 **动作图鉴 + 场景精选课 + 跟练执行 + 计划挑战 + 成长复盘** 的个人训练资料库。  
记录日志只是闭环的一环，核心能力包括：

| 模块 | 能力 | 入口 |
|------|------|------|
| **32 动作图鉴** | 八类分类、搜索、收藏、详情知识卡 | 底栏「图鉴」 |
| **12 套精选课** | 居家/办公室/户外/跑后/HIIT/新手场景化模板 | 首页「场景训练」· 快捷「精选课」 |
| **跟练模式** | 逐步执行动作、组间休息倒计时、完成写日志 | 精选课详情 →「开始跟练」 |
| **体能自测** | 4 题问卷 → 规则模板推荐课表（非 AI 对话） | 首页/成长「体能自测」 |
| **训练周报** | 本周次数/连续天/构成分析/下一步建议，可复制 | 首页/成长「训练周报」 |
| **动作对比** | 两动作并排对照部位、难度、时长 | 成长「动作对比」 |
| **方案编排** | 自定义组合、周期 7–30 日计划、训练清单 | 底栏「计划」 |
| **挑战馆** | 模板/自定义连续挑战 + 成就墙 | 首页快捷入口 |
| **训练百科** | 16 篇热身/恢复/跟练/周报指南 | 首页「训练百科」 |
| **主题册/收藏夹/笔记/回顾** | 资料整理与长期复盘 | 首页/成长/我的 |

游客模式可完整体验上述功能，数据存本机。

## 建议审核体验路径（约 5 分钟）

1. 首页 → **体能自测** → 完成 4 题 → 查看推荐精选课  
2. 精选课 → 任选「晨间唤醒」→ **开始跟练** → 逐步完成 → 保存日志  
3. 成长 → **训练周报** → 复制周报文本  
4. 图鉴 → 收藏动作 → 成长 → **动作对比**  
5. 计划 → 编排方案 / 开启 14 日周期计划
