# 运动图册

当前 App 名称：**运动图册**

蜕变影像 · HarmonyOS NEXT

收藏动作，编排训练方案，打卡复盘，留下每一次进步。

## 上架图标（华为应用市场请用这个）

- `store/logo/preview-1024.png` ← **上架主图标 1024×1024**

## DevEco 路径

打开 **`apps/yundong-tuce/app/`** → Sync → Build → 运行

## 核心功能

| 首页 | 今日训练建议、坚持/次数/收藏/方案、挑战馆、**训练百科**、本周打卡 |
| 图鉴 | 32 个分类动作，收藏/搜索，详情可编排、知识卡 |
| 计划 | 编排方案、周期计划、训练清单 |
| 成长 | 日历热力、本周频次、日志、笔记、知识卡 |
| 我的 | 个人档案、成就墙、回顾、登录（可选）、设置与隐私 |

游客可使用全部训练功能，数据保存在本机。登录仅用于账号标识。
