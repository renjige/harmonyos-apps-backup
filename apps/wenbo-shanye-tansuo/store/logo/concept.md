# Logo Concept — 山野探索

- 公司 / App / 行业：魏文波 · 山野探索 · 户外路线与自然百科
- 品牌关键词：Explore / Direction / Ridge / Discover / Calm
- brandAnchor：山
- 核心元素（2）：指南针指针 + 山脊剪影（负空间融合）
- 禁止项自检：无写实山峰插画、无帐篷脚印、无渐变球、无指南针刻度堆砌
- 色板：墨黑底 `#1A1D1F` + 松石 `#2D8F6F` + 琥珀针 `#D4A84B`（App Icon 用深底浅标）
- 对比策略：背景 `#1A1D1F` / 山脊 `#2D8F6F` / 指针与枢纽近白+琥珀，灰度后轮廓仍清晰
- 行业模板对比：不是房子、不是清凉光环、不是夏日「夏」字、不是装备秤

## 几何

左峰+右峰构成「山」的两笔；琥珀菱形指针从两峰鞍部指向右上，同时是指南针与前进方向。
